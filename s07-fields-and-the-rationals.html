Fields, and why Q is more interesting than it looks

A ring lets you add, subtract and multiply. What it does not let you do is divide, and that is the one thing linear algebra, calculus and geometry all need. Add division and you have a field: the rationals, the reals, the complex numbers, and the finite fields behind error-correcting codes.

“Add division” needs care, though, because one element must be left out. This post is about how that exception is written down without weakening anything else, and about the rationals, where the equality also has to be chosen.

Division, minus one element

A field is a ring in which multiplication commutes and every element except 00 has a reciprocal:

ab=ba,a≠0⇒a−1a=1,1≠0.ab = ba, \qquad a \neq 0 \;\Rightarrow\; a^{-1}a = 1, \qquad 1 \neq 0.

The last condition rules out the one-element structure in which 0=10 = 1 and everything collapses; without it, the theorems below would be true but useless.

  Class Field (F : Type) {eq : EqRel F} {zero : Zero F} {add : HasAdd F}
              {neg : HasNeg F} {one : One F} {mult : HasMult F}
              {inv : HasInv F} := {
    ring                :: Ring F;
    inv_proper          :: Proper (equ ==> equ) inv;
    is_mul_commutative  :: Commutative F F mult;
    is_mul_left_inverse :: LeftInverseOn F (nonzero F) mult inv 1;

    nontrivial : (1 : F) =/= 0;
  }.

The interesting field is the third law. The group post’s inverse law was unconditional — every element has one. Here the law holds only where a stated condition does, so the catalogue has a guarded version:

  Class LeftInverseOn :=
    left_inverse_on : forall a, defined_on a -> inverse a ⋆ a == unit.

and the condition is supplied as an ordinary predicate:

Definition nonzero (T : Type) {eqT : EqRel T} {zeroT : Zero T} : Pred T :=
  fun a => ~ (a == 0).

LeftInverseOn F (nonzero F) mult inv 1 then reads exactly as the mathematics does: for aa satisfying nonzero, a−1a=1a^{-1}a = 1. The alternative — making inv a partial function — would infect every expression containing a reciprocal with a proof obligation. Keeping inv total and guarding the law means only the steps that actually divide carry the hypothesis.

Note that only the left inverse is required. The right one is a theorem, since multiplication commutes:

aa−1=a−1a=1a\,a^{-1} = a^{-1}a = 1

  Theorem field_right_inverse : forall a : F, a =/= 0 -> a * inv a == 1.
  Proof.
    intros a Ha.
    calc (a * inv a)
      == (inv a * a) { (commutative a (inv a)) }
      == (1 : F)     { ((left_inverse_on (defined_on := nonzero _)) a Ha) }.
  Qed.

The justification in the second step is wordier than usual because it says which guard is meant — defined_on := nonzero _ — and then supplies Ha, the proof that aa is not zero. That is the visible cost of the guarded law, and it appears only in steps that use it.

Cancelling a factor

In a ring you may not cancel: 0⋅3=0⋅50 \cdot 3 = 0 \cdot 5 says nothing about 33 and 55. In a field you may, provided the factor is not zero, and the proof is the same idea as the group post’s cancellation with a−1a^{-1} in place of −a-a:

b=1b=(a−1a)b=a−1(ab)=a−1(ac)=(a−1a)c=1c=cb = 1b = (a^{-1}a)b = a^{-1}(ab) = a^{-1}(ac) = (a^{-1}a)c = 1c = c

  Theorem mul_cancel_l : forall a b c : F,
    a =/= 0 -> a * b == a * c -> b == c.
  Proof.
    intros a b c Ha Heq.
    calc b
      == (1 * b)             { left_identity }
      == ((inv a * a) * b)   { ((left_inverse_on (defined_on := nonzero _)) a Ha) }
      == (inv a * (a * b))   { (associative (inv a) a b) }
      == (inv a * (a * c))   { Heq }
      == ((inv a * a) * c)   { (associative (inv a) a c) }
      == (1 * c)             { ((left_inverse_on (defined_on := nonzero _)) a Ha) }
      == c                   { left_identity }.
  Qed.

Seven steps, symmetric about the middle, and the middle step is the hypothesis. Everything else is the same three laws used forwards and then backwards.

A close relative says a field has no zero divisors — if neither factor is zero, the product is not zero either (field_mul_neq_0). Its proof runs the same way and ends by contradicting the assumption that bb was non-zero. That property is what makes polynomial and matrix arguments over a field behave.

The rationals, where equality is a choice

The obvious model is Q, Coq’s rationals, and it is more interesting than it looks. A rational is stored as a numerator and a denominator, so 1/21/2 and 2/42/4 are different values — different pairs of integers. They must nevertheless count as the same number, and that is settled by the carrier’s chosen equality:

Instance Q_EqRel : EqRel Q := Qeq.

Qeq is cross-multiplication: p/qp/q and r/sr/s are equal when ps=rqps = rq. Every theorem in this series holds for Q up to that relation, which is exactly what one wants, and is why the library carries a chosen equality per carrier rather than using Coq’s built-in one. This is the case that makes the whole apparatus in the Coq underneath pay for itself.

With the vocabulary and the laws named from the standard library, the structures cost a line each — the two that need help get it inline:

Instance Q_Field : Field Q :=
  { Field.inv_proper := Qinv_comp; Field.nontrivial := Q_apart_0_1 }.

Qinv_comp is the proof that taking a reciprocal respects Qeq — without it, no proof could rewrite under a reciprocal — and Q_apart_0_1 is 1≠01 \neq 0 for the rationals. Everything else search finds.

Letting Coq’s ring and field tactics in

There is one more thing worth having. Coq ships tactics called ring and field that prove polynomial identities outright, and they are happy to work up to a chosen equality — but they need the structure handed to them in their own format. Theory/Ring.v builds that record once, from the class:

  Definition ring_theory_of_Ring (Hcomm : forall a b : R, a * b == b * a) :
    ring_theory (0 : R) (1 : R) add mult (fun x y => x + - y) neg equ.

and each concrete carrier registers it:

Add Field Q_field : Q_field_theory.

After that line, a goal in Q that is a true polynomial identity closes with one word. It is worth knowing precisely what this does and does not buy: it decides identities that follow from the ring laws, so it will never invent the cancellation argument above, which needs a hypothesis.
