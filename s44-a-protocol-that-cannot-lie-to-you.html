A protocol that cannot lie to you

A faulty wire can be described without probabilities: fix a relation between the list of packets a sender emitted and the list a receiver saw, and let the relation contain exactly the manglings the wire is allowed to perform. Call the relation that permits dropping packets and duplicating them, in any pattern, lossy_dup. This post proves that the alternating-bit protocol — the oldest arrangement for talking reliably over an unreliable wire — never hands the application anything it was not sent, for every behaviour in that relation and every number of retransmissions, with no assumption whatever about how much gets through.

The protocol, in one paragraph

You want to send messages m1,m2,m3,…m_1, m_2, m_3, \dots over a wire that can drop packets and duplicate them. Tag each message with a single bit that alternates: m1m_1 goes out tagged 0, m2m_2 tagged 1, m3m_3 tagged 0 again, and so on — retransmitting the current message (same tag) until you’re satisfied it arrived. The receiver expects a bit, starting at 0; when a packet with the expected bit shows up, it’s delivered and the expectation flips; anything with the wrong bit is silently discarded. That’s the whole protocol. The bit’s only job: let the receiver recognize a stale duplicate of the message it already has, and throw it away.

The theorem

Theorem abp_safety : forall (k : nat) (b0 : bit) (ms : list M) (wire : list Packet),
  lossy_dup (sender_stream b0 ms k) wire -> subseq (deliver b0 wire) ms.

Read it in English: whatever the wire delivers — for any channel behavior in the lossy_dup class, any retransmission budget k, any message list ms — the sequence of messages the receiver actually accepts is a subsequence of what was sent. No duplicates get through that were never sent. No reordering. No message the application never wrote gets fabricated. This is the entire safety contract of a reliable-delivery protocol, and it is a theorem, not a hope.

Notice what’s absent: no assumption that packets eventually get through. If the channel drops everything, deliver returns the empty list — still, trivially, a subsequence of ms. That’s honest: safety (nothing bad happens) and liveness (something good eventually happens) are different properties, and this theorem only claims the first. Liveness needs a fairness hypothesis — “the channel doesn’t drop forever” — which is deliberately not assumed here, precisely so today’s theorem stays this strong and this simple.

Why the proof needed a detour through channels themselves

The interesting lemma isn’t about ABP at all — it’s about lossy_dup alone:

Lemma lossy_dup_app_split : forall (s r : list M),
  lossy_dup s r -> forall l1 l2 : list M, s = l1 ++ l2 ->
  exists r1 r2, r = r1 ++ r2 /\ lossy_dup l1 r1 /\ lossy_dup l2 r2.

If the channel acted on a sent list s that happens to be a concatenation l1 ++ l2, then the received list splits to match — a lossy_dup-behavior on the first part, followed by one on the second. Note the shape of the statement: the channel’s behaviour comes first and the split point s = l1 ++ l2 only afterwards, so the split stays free while the proof works on the behaviour. This sounds obvious and is not: the stutter constructor (duplication) can re-emit the front of what’s already been received without consuming anything more from the sent side, so a run of duplicates near the boundary could, in principle, straddle it in an awkward way. The proof goes by induction on the lossy_dup derivation itself — not on the lists — precisely to track that possibility honestly.

Once that lemma exists, ABP’s own proof is short: split the sent wire trace at each message’s retransmission burst, note that a whole burst (all copies carrying the same bit) contributes at most one delivered message no matter how the channel maims it — duplicates all carry the identical bit and get rejected after the first — and induct over the message list.

This is the recurring shape: a hard, general fact about the substrate (lossy_dup_app_split, purely about relations on lists) makes the domain-specific theorem (abp_safety) almost fall out. Go-Back-N, which replaces the alternating bit by an unbounded sequence number, reuses this exact lemma unchanged — it never mentions a packet type at all, so a new retransmission scheme only ever owes its own burst-delivery argument, not a new proof that channels behave sanely.
