An adjacent swap flips the sign of a permutation

Exchange two rows of a square matrix and its determinant changes sign. Read off the permutation sum

det⁡A=∑σsign⁡(σ)∏jAσ(j),j,\det A \;=\; \sum_{\sigma} \operatorname{sign}(\sigma) \prod_j A_{\sigma(j),\,j},

the claim splits cleanly in two. Swapping rows ii and jj replaces each factor Aσ(j),jA_{\sigma(j),j} by Aτ(σ(j)),jA_{\tau(\sigma(j)),j}, where τ\tau is the transposition of ii and jj — so every term of the sum becomes the term belonging to τ∘σ\tau \circ \sigma, except for its sign. That is the easy half: it is a rewrite inside a product, with no case analysis. The other half is that the sign really does differ, that

sign⁡(τ∘σ)=−sign⁡(σ),\operatorname{sign}(\tau \circ \sigma) \;=\; -\operatorname{sign}(\sigma),

and it is a fact about permutations alone — no matrix appears in it. This post proves it when τ\tau exchanges two neighbouring positions, which is where the induction closes, and reads off adjacent-row antisymmetry of the determinant as a consequence.

Why the sign half is the harder one

The sign of a permutation has to be computed from something. Here permutations are values of an inductive type (Impl/DetLeibniz.v): Perm_S c p records that σ\sigma sends the first position to c and defers the rest to a smaller permutation p. The sign is the product, down that spine, of sign_at at each level’s chosen value:

  Fixpoint perm_sign {n : nat} (sigma : Perm n) {struct sigma} : F :=
    match sigma with
    | Perm_O => 1
    | Perm_S c p => sign_at c * perm_sign p
    end.

with sign_at c alternating 1,−1,1,…1, -1, 1, \dots with the position. So perm_sign is (−1)(-1) raised to the sum of the chosen indices — the inversion count, computed structurally.

Now the difficulty is visible. To ask what postcomposition does to the sign you must have the postcomposed permutation as a value of Perm, because that is the only thing perm_sign can be applied to. Knowing where τ∘σ\tau \circ \sigma sends each point is not enough; the recursion needs the spine.

Postcomposition as a permutation value

The construction goes through a more basic one: perm_of (Impl/DetSign.v), which extracts the Perm code of any injective function. The code’s head is the function’s value at the first position; its tail is extracted from the function’s restriction past that position:

Fixpoint perm_of {n : nat} : (Fin.t n -> Fin.t n) -> Perm n :=
  match n as n0 return (Fin.t n0 -> Fin.t n0) -> Perm n0 with
  | O => fun _ => Perm_O
  | S m => fun f => Perm_S (f Fin.F1) (perm_of (fin_restrict f))
  end.

The restriction is one small operation on Impl/Fin.v’s index arithmetic: delete input position one and output value f Fin.F1, and renumber the survivors through unskip, the partial inverse of the skip injection:

Definition fin_restrict {m : nat} (f : Fin.t (S m) -> Fin.t (S m))
    (y : Fin.t m) : Fin.t m :=
  match unskip (f Fin.F1) (f (Fin.FS y)) with
  | Some t => t
  | None => y
  end.

The None branch is unreachable when f is injective — f (Fin.FS y) can never collide with f Fin.F1 — and injectivity is the standing hypothesis of every law about perm_of. Postcomposition is then just extraction of the composite, with τ\tau entering as a plain function:

Definition perm_postcompose {n : nat} (sigma : Perm n)
    (tau : Fin.t n -> Fin.t n) : Perm n :=
  perm_of (fun x => tau (perm_apply sigma x)).

Two facts make this the right value. Extraction is a retraction of application — perm_of_perm_apply says perm_of (perm_apply sigma) is sigma again, on the nose — and the extracted code applies to what the function said, which for the composite reads:

Theorem perm_apply_postcompose : forall (n : nat) (sigma : Perm n)
    (tau : Fin.t n -> Fin.t n),
  (forall x y : Fin.t n, tau x = tau y -> x = y) ->
  forall x : Fin.t n,
  perm_apply (perm_postcompose sigma tau) x = tau (perm_apply sigma x).

Applying the extracted permutation is applying τ\tau after σ\sigma, pointwise, for any injective τ\tau.

The sign flips, at every adjacent pair

An adjacent pair of positions is written fin_weaken k and Fin.FS k for a shared k : Fin.t n. Both embed k into Fin.t (S n) — the first keeping its value, the second shifting it by one — so they denote positions kk and k+1k+1, and as k ranges over Fin.t n the pair ranges over every neighbouring pair there is.

  Theorem perm_sign_postcompose_adj : forall (n : nat) (k : Fin.t n)
      (sigma : Perm (S n)),
    (perm_sign (perm_postcompose sigma (swap_fin (fin_weaken k) (Fin.FS k))) : F)
      == - perm_sign sigma.

How it goes. The theorem is proved one level down, about perm_of at an arbitrary injective function g (perm_sign_swap_adjacent), because that is the statement an induction can consume: restricting a function produces a function, not the application of some smaller Perm value. Induct on the size and peel one level of the extraction: the code of τ∘g\tau \circ g starts with τ(g(1))\tau(g(1)) and continues with the code of fin_restrict applied to τ∘g\tau \circ g. The case analysis is on where the head value g(1)g(1) sits relative to the swapped pair, and the two ways of being one of them are symmetric.

  • g(1)g(1) is one of the two swapped positions. Then τ(g(1))\tau(g(1)) is the other one, and the two contribute opposite sign_at values — that is sign_at_fweaken_FS, the statement that sign_at (Fin.FS k) and sign_at (fin_weaken k) are exact opposites, since they differ by exactly one position and sign_at alternates. What survives to the next level is fin_restrict g itself, unswapped: the two positions are neighbours, so once one of them is deleted there is nothing left between them to move (fin_restrict_swap_adjacent_at_lower and fin_restrict_swap_adjacent_at_upper). The flip comes entirely from the sign at the peeled level.
  • g(1)g(1) is neither. Then τ(g(1))=g(1)\tau(g(1)) = g(1), that level contributes the same sign as before, and the restriction carries the transposition down to an adjacent pair one size smaller (fin_restrict_swap_adjacent_missed). The induction hypothesis, at fin_restrict g, supplies the flip.

Each case ends by rewriting with perm_of_ext — pointwise equal functions extract to the same code, a plain equality of values — and the statement about σ\sigma follows by taking gg to be perm_apply sigma and folding with perm_of_perm_apply.

From the sign to the matrix

With the sign flip in hand, the two halves compose. Reindexing the sum over all permutations by σ↦τ∘σ\sigma \mapsto \tau \circ \sigma needs a psum-level version of “a sum does not care about a bijective relabelling of its index” (psum_reindex). That is not a new induction: Perm n is itself a finite index type — perm_enum lists all n!n! of them, duplicate-free, and FinIndex_Perm records the instance — so psum is the generic enumeration sum (psum_bigopI) and the relabelling is the generic bigopI_reindex, with perm_postcompose_inverse supplying the two inverse laws. perm_prod_row_swap rewrites the product half; perm_sign_postcompose_adj supplies the sign. That gives antisymmetry for the permutation-sum determinant, and the theorem that the two determinant formulas agree carries it back to the cofactor recursion:

  Theorem detM_swap_adjacent : forall (n : nat) (k : Fin.t n) (A : Matrix (S n) (S n) F),
    detM (row_swap A (fin_weaken k) (Fin.FS k)) == - detM A.
  Proof.
    intros n k A.
    calc (detM (row_swap A (fin_weaken k) (Fin.FS k)))
      == (detM_leibniz (row_swap A (fin_weaken k) (Fin.FS k)))
           { (detM_leibniz_eq_detM (S n) (row_swap A (fin_weaken k) (Fin.FS k))) }
      == (- detM_leibniz A) { (detM_leibniz_swap_adjacent n k A) }
      == (- detM A) { (detM_leibniz_eq_detM (S n) A) }.
  Qed.

That is a chained calculation: calc states a starting expression and then a sequence of == target { justification } steps, each justification being a proof that the previous expression equals the next one, and the whole chain proving that the first equals the last. Three steps here. Replace detM by the permutation sum, apply antisymmetry there, and replace the sum back by detM underneath the negation — the last step rewrites inside -, which is allowed because negation respects equality.

On numbers

The pair being arbitrary is worth checking on an instance that is not the top two rows. Take the nonsingular 3×33\times 3 matrix 1234567810\begin{smallmatrix}1&2&3\\4&5&6\\7&8&10\end{smallmatrix}, whose determinant computes to −3-3, and exchange its middle two rows:

Example detM_swap_adjacent_mid_Q_compute :
  detM (row_swap mat3_ns (fin_weaken (Fin.FS Fin.F1)) (Fin.FS (Fin.FS Fin.F1)))
    == (3#1)%Q.
Proof.
  reflexivity.
Qed.

Both sides evaluate independently, with no appeal to the theorem: the swapped matrix really has determinant +3+3. Applying detM_swap_adjacent to the same instance then closes 3=−(−3)3 = -(-3) as a resolution check.

Where adjacency was used

Exactly once: in the case where the peeled position is one of the two being swapped. Neighbouring positions have nothing strictly between them, so consuming one of them leaves the identity. For a pair that is not adjacent, peeling at one of them leaves a genuine three-cycle on the remaining positions — an object of a different shape, which the induction above cannot consume.

The classical repair is to build an arbitrary transposition out of adjacent ones. What that argument needs from here is the theorem above, unchanged, at every adjacent pair — which is why proving it for one fixed pair, say the top two, would not have been enough.
