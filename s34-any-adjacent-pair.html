Any adjacent pair

Exchange two rows of a square matrix and its determinant changes sign. Read off the permutation sum

det⁡A=∑σsign⁡(σ)∏jAσ(j),j,\det A \;=\; \sum_{\sigma} \operatorname{sign}(\sigma) \prod_j A_{\sigma(j),\,j},

the claim splits cleanly in two. Swapping rows ii and jj replaces each factor Aσ(j),jA_{\sigma(j),j} by Aτ(σ(j)),jA_{\tau(\sigma(j)),j}, where τ\tau is the transposition of ii and jj — so every term of the sum becomes the term belonging to τ∘σ\tau \circ \sigma, except for its sign. That is the easy half: it is a rewrite inside a product, with no case analysis. The other half is that the sign really does differ, that

sign⁡(τ∘σ)=−sign⁡(σ),\operatorname{sign}(\tau \circ \sigma) \;=\; -\operatorname{sign}(\sigma),

and it is a fact about permutations alone — no matrix appears in it. This post proves it when τ\tau exchanges two neighbouring positions, which is where the induction closes, and reads off adjacent-row antisymmetry of the determinant as a consequence.

Why the sign half is the harder one

The sign of a permutation has to be computed from something. Here permutations are values of an inductive type (Impl/DetLeibniz.v): Perm_S c p records that σ\sigma sends the first position to c and defers the rest to a smaller permutation p. The sign is the product, down that spine, of sign_at at each level’s chosen value:

  Fixpoint perm_sign {n : nat} (sigma : Perm n) {struct sigma} : F :=
    match sigma with
    | Perm_O => 1
    | Perm_S c p => sign_at c * perm_sign p
    end.

with sign_at c alternating 1,−1,1,…1, -1, 1, \dots with the position. So perm_sign is (−1)(-1) raised to the sum of the chosen indices — the inversion count, computed structurally.

Now the difficulty is visible. To ask what postcomposition does to the sign you must have the postcomposed permutation as a value of Perm, because that is the only thing perm_sign can be applied to. Knowing where τ∘σ\tau \circ \sigma sends each point is not enough; the recursion needs the spine.

Postcomposition as a permutation value

That construction is perm_postcompose (Impl/DetSign.v). It takes σ\sigma, a function τ\tau and an inverse τ′\tau' for it — supplied as a pair rather than as an existence claim, so the result computes — and rebuilds the spine:

  Fixpoint perm_postcompose {n : nat} (sigma : Perm n) {struct sigma}
      : (Fin.t n -> Fin.t n) -> (Fin.t n -> Fin.t n) -> Perm n :=
    match sigma in Perm n0
      return (Fin.t n0 -> Fin.t n0) -> (Fin.t n0 -> Fin.t n0) -> Perm n0
    with
    | Perm_O => fun _ _ => Perm_O
    | @Perm_S m c p => fun tau tau' =>
        Perm_S (tau c) (perm_postcompose p (bijection_skip_step c tau tau') (bijection_skip_step_inv c tau tau'))
    end.

The chosen value c becomes tau c. At the next level down, one position has been consumed, so tau must be restricted to the remaining ones — that is bijection_skip_step, the “restrict a bijection through the injection that misses a point” primitive from Theory/Fin.v. The construction is correct in the only sense that matters:

  Theorem perm_apply_postcompose : forall (n : nat) (sigma : Perm n)
      (tau tau' : Fin.t n -> Fin.t n),
    (forall x, tau' (tau x) = x) -> (forall y, tau (tau' y) = y) ->
    forall x : Fin.t n, perm_apply (perm_postcompose sigma tau tau') x = tau (perm_apply sigma x).

Applying the rebuilt permutation is applying τ\tau after σ\sigma, pointwise, for any two-sided inverse pair.

The sign flips, at every adjacent pair

An adjacent pair of positions is written fin_weaken k and Fin.FS k for a shared k : Fin.t n. Both embed k into Fin.t (S n) — the first keeping its value, the second shifting it by one — so they denote positions kk and k+1k+1, and as k ranges over Fin.t n the pair ranges over every neighbouring pair there is.

  Theorem perm_sign_postcompose_adj : forall (n : nat) (k : Fin.t n) (sigma : Perm (S n)),
    (perm_sign (perm_postcompose sigma (swap_fin (fin_weaken k) (Fin.FS k)) (swap_fin (fin_weaken k) (Fin.FS k))) : F)
      == - perm_sign sigma.

A transposition is its own inverse, which is why the same swap_fin appears twice.

How it goes. Induct on the size. Write σ\sigma as Perm_S c p and peel one level: the postcomposed spine starts with τ(c)\tau(c) instead of cc, and continues with p postcomposed by τ\tau restricted past cc. The case analysis is on where c sits relative to the swapped pair, and the two ways of being one of them are symmetric.

  • c is one of the two swapped positions. Then τ(c)\tau(c) is the other one, and the two contribute opposite sign_at values — that is sign_at_fweaken_FS, the statement that sign_at (Fin.FS k) and sign_at (fin_weaken k) are exact opposites, since they differ by exactly one position and sign_at alternates. What survives to the next level is the identity: the two swapped positions are neighbours, so once one of them is consumed there is nothing left between them to move. perm_sign_postcompose_id says postcomposing by a pointwise identity changes nothing, and the flip comes entirely from the sign at the peeled level.
  • c is neither. Then τ(c)=c\tau(c) = c, that level contributes the same sign as before, and the restricted transposition is again a transposition of an adjacent pair — one size smaller. The induction hypothesis supplies the flip.

One bookkeeping lemma runs through all of it: functions built by bijection_skip_step are only ever equal to a canonical description pointwise, never as terms, so perm_sign_postcompose_ext — pointwise equal τ\taus give equal signs after postcomposing — is what lets the case analysis rewrite at all.

From the sign to the matrix

With the sign flip in hand, the two halves compose. Reindexing the sum over all permutations by σ↦τ∘σ\sigma \mapsto \tau \circ \sigma needs a psum-level version of “a sum does not care about a bijective relabelling of its index” (psum_reindex, built from perm_postcompose and its correctness theorem); perm_prod_row_swap rewrites the product half; perm_sign_postcompose_adj supplies the sign. That gives antisymmetry for the permutation-sum determinant, and the theorem that the two determinant formulas agree carries it back to the cofactor recursion:

  Theorem detM_swap_adjacent : forall (n : nat) (k : Fin.t n) (A : Matrix (S n) (S n) F),
    detM (row_swap A (fin_weaken k) (Fin.FS k)) == - detM A.
  Proof.
    intros n k A.
    calc (detM (row_swap A (fin_weaken k) (Fin.FS k)))
      == (detM_leibniz (row_swap A (fin_weaken k) (Fin.FS k)))
           { (detM_leibniz_eq_detM (S n) (row_swap A (fin_weaken k) (Fin.FS k))) }
      == (- detM_leibniz A) { (detM_leibniz_swap_adjacent n k A) }
      == (- detM A) { (detM_leibniz_eq_detM (S n) A) }.
  Qed.

That is a chained calculation: calc states a starting expression and then a sequence of == target { justification } steps, each justification being a proof that the previous expression equals the next one, and the whole chain proving that the first equals the last. Three steps here. Replace detM by the permutation sum, apply antisymmetry there, and replace the sum back by detM underneath the negation — the last step rewrites inside -, which is allowed because negation respects equality.

On numbers

The pair being arbitrary is worth checking on an instance that is not the top two rows. Take the nonsingular 3×33\times 3 matrix 1234567810\begin{smallmatrix}1&2&3\\4&5&6\\7&8&10\end{smallmatrix}, whose determinant computes to −3-3, and exchange its middle two rows:

Example detM_swap_adjacent_mid_Q_compute :
  detM (row_swap mat3_ns (fin_weaken (Fin.FS Fin.F1)) (Fin.FS (Fin.FS Fin.F1)))
    == (3#1)%Q.
Proof.
  reflexivity.
Qed.

Both sides evaluate independently, with no appeal to the theorem: the swapped matrix really has determinant +3+3. Applying detM_swap_adjacent to the same instance then closes 3=−(−3)3 = -(-3) as a resolution check.

Where adjacency was used

Exactly once: in the case where the peeled position is one of the two being swapped. Neighbouring positions have nothing strictly between them, so consuming one of them leaves the identity. For a pair that is not adjacent, peeling at one of them leaves a genuine three-cycle on the remaining positions — an object of a different shape, which the induction above cannot consume.

The classical repair is to build an arbitrary transposition out of adjacent ones. What that argument needs from here is the theorem above, unchanged, at every adjacent pair — which is why proving it for one fixed pair, say the top two, would not have been enough.
