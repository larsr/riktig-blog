Full generality

Swapping two neighbouring rows of a matrix negates its determinant. Swapping two arbitrary rows ought to do the same, and on a blackboard the step between the two claims is one sentence: any transposition is a product of an odd number of adjacent ones, so its sign is the sign of one of them. This post is that sentence, carried out.

The reason it is not free is that “product of adjacent transpositions” has to be built. The sign of a permutation is computed here by recursion over a concrete data structure, so an identity about signs only becomes usable once the permutations it mentions are values that recursion can eat. Two things are therefore needed: a place where composing transpositions costs nothing, and a factorization that shrinks in a way an induction can follow.

Composition costs nothing at the function level

perm_postcompose sigma tau is perm_of (fun x => tau (perm_apply sigma x)) — extraction of the code of “σ\sigma, then τ\tau”, where τ\tau is a plain function. Because the composite is formed before extraction, chaining two postcompositions is one appeal to “pointwise equal functions extract to the same code” (perm_of_ext):

Theorem perm_postcompose_compose : forall (n : nat) (sigma : Perm n)
    (tau1 tau2 : Fin.t n -> Fin.t n),
  (forall x y : Fin.t n, tau1 x = tau1 y -> x = y) ->
  perm_postcompose (perm_postcompose sigma tau1) tau2
    = perm_postcompose sigma (fun x => tau2 (tau1 x)).

This is an equality of permutation values, not merely of their signs, and its whole proof is perm_of_ext plus the correctness of extraction. The same holds for the argument below: it never chains postcompositions at the code level at all. It works with perm_sign (perm_of ...) at composite functions, where associativity of composition is definitional, and only converts back to a statement about σ\sigma at the very end.

Building an arbitrary transposition from adjacent ones

(ij)=(ik)(kj)(ik)(i\ j) \;=\; (i\ k)\,(k\ j)\,(i\ k)

for any third position kk distinct from both. This is the classical conjugation identity, and in Impl/Fin.v it is a statement about the concrete transposition function, proved pointwise:

Lemma swap_fin_conj : forall (n : nat) (i j k : Fin.t n),
  i <> j -> i <> k -> j <> k ->
  forall x : Fin.t n,
  swap_fin i j x = swap_fin i k (swap_fin k j (swap_fin i k x)).

Choose kk to be the position immediately after ii. Then (ik)(i\ k) is adjacent, its sign flip is already known, and the middle factor (kj)(k\ j) spans a gap one shorter than (ij)(i\ j) did. So there is no need to construct a list of adjacent transpositions and reason about products of lists at all: the identity is applied inside the induction, once per step, and the measure that decreases is the distance between the two positions.

  Theorem swap_sign_flip_gap : forall (gap N : nat) (i j : Fin.t N),
    fin_to_nat j = (fin_to_nat i + S gap)%nat ->
    forall g : Fin.t N -> Fin.t N,
    (forall x y : Fin.t N, g x = g y -> x = y) ->
    (perm_sign (perm_of (fun x => swap_fin i j (g x))) : F)
      == - perm_sign (perm_of g).

The induction is on gap, an ordinary natural number, and it is structural: each step shrinks the gap by exactly one, because kk was chosen adjacent to ii rather than merely closer to jj. No well-founded recursion, no measure machinery. fin_to_nat is the position of an index as a plain number — a structural mirror of the standard library’s conversion, so that it computes on open terms. The statement quantifies over an injective function g rather than a permutation value, and that is what makes the step work: after the conjugation identity rewrites (ij)∘g(i\ j) \circ g into (ik)∘(kj)∘(ik)∘g(i\ k) \circ (k\ j) \circ (i\ k) \circ g, the two outer legs peel off by the adjacent flip and the induction hypothesis eats the middle one — each time at a composite function, which is just another injective g. Three negations compose to one.

Dropping the assumption that ii comes before jj is then a trichotomy on positions plus the symmetry of swap_fin, and taking g to be perm_apply sigma lands the statement on permutation values (perm_of_perm_apply folds perm_of (perm_apply sigma) back to sigma):

  Theorem perm_sign_postcompose_swap : forall (N : nat) (i j : Fin.t N),
    i <> j -> forall sigma : Perm N,
    (perm_sign (perm_postcompose sigma (swap_fin i j)) : F) == - perm_sign sigma.

Any two distinct positions, in either order, in any size, over any field.

The statement, unrestricted

The rest is the same chain as for the adjacent case, with the general sign flip substituted for the adjacent one: reindex the sum over all permutations, rewrite the product half, apply the sign flip, and carry the result from the permutation sum back to the cofactor recursion.

  Theorem detM_swap_general : forall (N : nat) (i j : Fin.t N),
    i <> j -> forall A : Matrix N N F,
    detM (row_swap A i j) == - detM A.
  Proof.
    intros N i j Hij A.
    calc (detM (row_swap A i j))
      == (detM_leibniz (row_swap A i j)) { (detM_leibniz_eq_detM N (row_swap A i j)) }
      == (- detM_leibniz A) { (detM_leibniz_swap_general N i j Hij A) }
      == (- detM A) { (detM_leibniz_eq_detM N A) }.
  Qed.

Any two distinct rows i≠ji \ne j: not the top two, not a neighbouring pair, any pair, in a matrix of any size, over any field. On numbers, the check that the adjacent version could not even state — swap the top and bottom rows of a 3×33\times 3 matrix:

Example detM_swap_general_top_bottom_Q_compute :
  detM (row_swap mat3_ns Fin.F1 (Fin.FS (Fin.FS Fin.F1))) == (3#1)%Q.
Proof.
  reflexivity.
Qed.

The base matrix has determinant −3-3, the swapped one evaluates to +3+3, and both are computed rather than derived, so the test does not degenerate into 0=−00 = -0.

The first elementary matrix

Row operations are usually presented as left multiplication by elementary matrices: elem_swap i j is the identity with rows ii and jj exchanged, and multiplying by it on the left performs that exchange on any matrix. Antisymmetry, restated in that language, is the determinant law of the first of the three:

  Theorem det_elem_swap : forall (n : nat) (i j : Fin.t n),
    i <> j -> forall A : Matrix n n F,
    detM (mat_mul (elem_swap i j) A) == - detM A.

The proof is detM_swap_general transported across elem_swap_mul, the fact that left multiplication really does perform the swap.

What antisymmetry does not give

There is a classical one-line derivation of the alternating property from antisymmetry: if two rows of AA are equal, swapping them changes nothing, so det⁡A=−det⁡A\det A = -\det A, hence 2det⁡A=02\det A = 0, hence det⁡A=0\det A = 0. The last step is division by two. In a field of characteristic two — and the Field interface used here assumes nothing about characteristic, so such fields are legal instances — that step is simply false.

The problem is not the phrasing of that particular argument. Any proof that compares the whole permutation sum with a global reindexing of itself can only ever conclude det⁡A=−det⁡A\det A = -\det A, no matter which transposition it reindexes by or how often. Getting det⁡A=0\det A = 0 needs a cancellation between individual terms, not between the sum and itself.
