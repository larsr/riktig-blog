From Coq Require Import RelationClasses.
From Coq.Vectors Require Fin.
From Riktig Require Import Interface.LinearMap Theory.Basis.

A basis of V is a family of n vectors with a linear coordinate map, each inverse to the other: every vector is the linear combination of the family with its coordinates, and the coordinates of such a combination are its coefficients.
Module Basis.
  Class Basis (n : nat) (F V : Type)
      {Fe : EqRel F} {Fz : Zero F} {Fa : HasAdd F} {Fn : HasNeg F} {Fo : One F}
      {Fm : HasMult F} {Fi : HasInv F} {FF : Field F}
      {eV : EqRel V} {zV : Zero V} {aV : HasAdd V} {nV : HasNeg V} {sV : HasScale F V}
      {VV : VectorSpace F V} := {
    vec : Fin.t n → V;
    coords : LinearMap F V (Fin.t n → F);
    reconstruction : ∀ v : V,
      lincomb vec (coords v) == v;
    coords_linear_combination : ∀ c : Fin.t n → F,
      coords (lincomb vec c) == c
  }.
  Arguments vec {n F V Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV}.
  Arguments coords {n F V Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV}.
  Arguments reconstruction {n F V Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV}.
  Arguments coords_linear_combination {n F V Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV}.
End Basis.
