1 and e are independent when no combination of them vanishes without both coefficients vanishing.
Definition independent_from_one (F : Type) {A : Type}
    {Fe : EqRel F} {Fz : Zero F}
    {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {Ao : One A}
    {As : HasScale F A} (e : A) : Prop :=
  ∀ a b : F, a *: 1 + b *: e == 0 → a == 0 ∧ b == 0.

The complex numbers, as a structure rather than a construction: an F-algebra that IS the plane the unit spans with a square root e of - (1) — every element is a combination a *: 1 + b *: e, and the two coefficients of an element are unique.
Module ComplexPlane.
  Class ComplexPlane (F A : Type) `{Field F}
      {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {An : HasNeg A}
      {Ao : One A} {Am : HasMult A} {As : HasScale F A}
      {AR : Ring A} {SL : ScaleLaws F A}
      {ML : ∀ y : A, Linear F A A (fun x ⇒ x × y)}
      {MR : ∀ x : A, Linear F A A (fun y ⇒ x × y)} (e : A) := {
    plane_root : e × e == - (1);
    plane_spans : ∀ x : A, ∃ a b : F, x == a *: 1 + b *: e;
    plane_independent : independent_from_one F e;
  }.
  Hint Mode ComplexPlane - ! - - - - - - - - - - - - - - - - - - - ! : typeclass_instances.
End ComplexPlane.
