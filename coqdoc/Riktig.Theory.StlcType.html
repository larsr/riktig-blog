Library Riktig.Theory.StlcType

From Riktig.Structure Require Export StlcType.
From Riktig.Theory Require Export Signature.
From Riktig.Impl Require Import CategoryFun SignaturePoly.

Induction, from the one theorem for every signature: nothing type-specific remains to prove.
Section StlcTypeInduction.
  Context {B Ty : Type}
    {yb : HasBuild Type (StlcType.shape (fun T0 : Type ⇒ T0) B) Ty}
    {yf : HasCata Type (StlcType.shape (fun T0 : Type ⇒ T0) B) Ty}
    `{!StlcType Type (fun T0 : Type ⇒ T0) B Ty yb yf}.

  Theorem sty_induction : ∀ P : Ty → Prop,
    (∀ b : B, P (yb (inl b))) →
    (∀ a c : Ty, P a → P c → P (yb (inr (a, c)))) →
    ∀ t : Ty, P t.
  Proof.
    intros P Hbase Harrow.
    apply (datatype_induction (fun T0 : Type ⇒ T0) (styS (S := sig Type) B) (T := Ty)
      (tb := yb) (tf := yf) (IA := StlcType.initial)).
    intros s [s' Es]. destruct s' as [b | [[a pa] [c pc]]]; cbn in Es; subst; cbn.
    - exact (Hbase b).
    - exact (Harrow a c pa pc).
  Qed.
End StlcTypeInduction.
