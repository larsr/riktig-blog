From Riktig Require Import Structure.Naturals.

A function over the abstract natural numbers.
Definition square_plus_succ {N : Type} `{Naturals N} (n : N) : N :=
  n × n + succ n.

At Coq's nat, reached through its recursion equations and the implementation of the natural numbers by them, it computes.
From Riktig Require Import Impl.PeanoArithNat Impl.NaturalsPeanoArith.

Example at_nat : square_plus_succ 3 = 13.
Proof. reflexivity. Qed.

Eval compute in square_plus_succ 10.

At Coq's binary N it computes as well, by its own arithmetic.
From Coq Require Import NArith.
From Riktig Require Import Impl.NaturalsN.

Example at_N : square_plus_succ 3%N = 13%N.
Proof. reflexivity. Qed.
