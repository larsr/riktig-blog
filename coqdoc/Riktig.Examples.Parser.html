From Coq Require Import Ascii String List.
From Riktig Require Import Theory.Parser Impl.ParserList Impl.EquDecAscii.
Import ListNotations.
Local Open Scope char_scope.

Parsers of characters, written with the structure's operations and run on Coq lists; what the abstract theorems say about them transfers, since the list parsers implement the structure.
Definition a_or_b : parser (list ascii) ascii := sym "a" <|> sym "b".

Eval vm_compute in a_or_b (list_ascii_of_string "abc").
Eval vm_compute in (sym "a" ⊗ sym "b" : parser (list ascii) (ascii × ascii)) (list_ascii_of_string "abc").

Choice is commutative, by the abstract theorem.
Example a_or_b_comm : a_or_b == sym "b" <|> sym "a".
Proof. apply alt_comm. Qed.

A failing branch can be dropped, and the readings of a symbol are what the theory says.
Example drop_fail : (sym "a" <|> fail : parser (list ascii) ascii) == sym "a".
Proof. apply alt_fail_r. Qed.

Example sym_a_reads : parses (sym "a" : parser (list ascii) ascii) (list_ascii_of_string "ab") "a" (list_ascii_of_string "b").
Proof. apply parses_sym. split; reflexivity. Qed.

Example sym_a_rejects : ¬ parses (sym "a" : parser (list ascii) ascii) (list_ascii_of_string "ba") "a" (list_ascii_of_string "a").
Proof. intros H. apply parses_sym in H. destruct H as [_ H]. discriminate H. Qed.
