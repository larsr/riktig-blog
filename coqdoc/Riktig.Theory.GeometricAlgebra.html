Section ScalarSquares.
  Context {F A : Type} `{Field F}.
  Context {eA : EqRel A} {zA : Zero A} {aA : HasAdd A} {nA : HasNeg A}
    {oA : One A} {mA : HasMult A} {sA : HasScale F A}.
  Context {RA : Ring A} {SL : ScaleLaws F A}.

  Theorem scalar_squares_add : ∀ (x y : A) (p q : F),
    x × x == p *: 1 → y × y == q *: 1 →
    (p *: (1 : A) + q *: 1) + (x × y + y × x) == (x + y) × (x + y).
  Proof.
    intros x y p q Hx Hy.
    calc (((p *: (1 : A) + q *: 1) + (x × y + y × x)) : A)
      == (((x × x + q *: 1) + (x × y + y × x)) : A) { Hx }
      == (((x × x + y × y) + (x × y + y × x)) : A) { Hy }
      == (((x + y) × (x + y)) : A) { square_expand }.
  Qed.

  Theorem scalar_squares_polarization : ∀ (x y : A) (p q s : F),
    x × x == p *: 1 → y × y == q *: 1 → (x + y) × (x + y) == s *: 1 →
    x × y + y × x == ((s + - p) + - q) *: 1.
  Proof.
    intros x y p q s Hx Hy Hs.
    apply (cancel_l (p *: (1 : A) + q *: 1)).
    calc (((p *: (1 : A) + q *: 1) + (x × y + y × x)) : A)
      == (((x + y) × (x + y)) : A)
        { scalar_squares_add }
      == ((s *: (1 : A)) : A)
        { Hs }
      == ((((p + q) + ((s + - p) + - q)) *: (1 : A)) : A)
        { add_sub_pair_cancel }
      == (((p + q) *: (1 : A) + ((s + - p) + - q) *: (1 : A)) : A)
        { right_distributive }
      == (((p *: (1 : A) + q *: (1 : A)) + ((s + - p) + - q) *: (1 : A)) : A)
        { right_distributive }.
  Qed.

End ScalarSquares.


Section Sandwich.
  Context {A : Type} {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A}
          {An : HasNeg A} {Ao : One A} {Am : HasMult A} {AR : Ring A}.

Two factors cancelling in the middle: with c × a == 1 a sandwich of a square is the square sandwiched.
  Lemma sandwich_square : ∀ a b c : A,
    c × a == 1 → (a × b × c) × (a × b × c) == a × (b × b) × c.
  Proof.
    intros a b c Hca.
    rewrite !associative.
    rewrite <- (associative c a (b × c)), Hca, (left_identity (b × c)).
    reflexivity.
  Qed.

  Context (rev : A → A)
          (rev_anti : ∀ x y : A, rev (x × y) == rev y × rev x).

Conjugating by S and then by R is conjugating by R × S: the sandwich is functorial, and reversal reversing products is the whole reason.
  Theorem sandwich_compose_anti : ∀ R S x : A,
    R × (S × x × rev S) × rev R == (R × S) × x × rev (R × S).
  Proof.
    intros R S x.
    rewrite (rev_anti R S).
    rewrite !associative.
    reflexivity.
  Qed.

End Sandwich.

The scalar line is faithful in A when it separates scalars. Without this an algebra equation between two scalars — which is all contraction can produce — does not say the two scalars are equal.
Definition one_faithful (F A : Type) {Fe : EqRel F} {Ae : EqRel A}
    {Ao : One A} {As : HasScale F A} : Prop :=
  ∀ a b : F, a *: (1 : A) == b *: 1 → a == b.

Section GATheory.
  Context {F V A : Type} `{GeometricAlgebra F V A}.

  Theorem vec_zero : ga_vec 0 == (0 : A).
  Proof.
    exact (additive_zero ga_vec).
  Qed.

  Lemma contraction_add : ∀ u v : V,
    (ga_vec u + ga_vec v) × (ga_vec u + ga_vec v) == Q (u + v) *: (1 : A).
  Proof.
    intros u v.
    calc (((ga_vec u + ga_vec v) × (ga_vec u + ga_vec v)) : A)
      == ((ga_vec (u + v) × ga_vec (u + v)) : A)
        { additive[ga_vec] }
      == ((Q (u + v) *: (1 : A)) : A)
        { contraction }.
  Qed.

  Lemma contract_add : ∀ u v : V,
    (Q u *: (1 : A) + Q v *: 1)
      + (ga_vec u × ga_vec v + ga_vec v × ga_vec u)
    == Q (u + v) *: 1.
  Proof.
    intros u v.
    calc (((Q u *: (1 : A) + Q v *: 1)
            + (ga_vec u × ga_vec v + ga_vec v × ga_vec u)) : A)
      == (((ga_vec u + ga_vec v) × (ga_vec u + ga_vec v)) : A)
        { (scalar_squares_add (ga_vec u) (ga_vec v) (Q u) (Q v)
             (contraction u) (contraction v)) }
      == ((Q (u + v) *: (1 : A)) : A)
        { contraction_add }.
  Qed.

  Lemma polar_recovers : ∀ u v : V, (Q u + Q v) + polar Q u v == Q (u + v).
  Proof.
    intros u v.
    exact (add_sub_pair_cancel (Q u) (Q v) (Q (u + v))).
  Qed.

  Theorem polarization : ∀ u v : V,
    ga_vec u × ga_vec v + ga_vec v × ga_vec u == polar Q u v *: (1 : A).
  Proof.
    intros u v.
    exact (scalar_squares_polarization (ga_vec u) (ga_vec v)
             (Q u) (Q v) (Q (u + v))
             (contraction u) (contraction v) (contraction_add u v)).
  Qed.

Orthogonal vectors anticommute. Polarization puts their symmetric part on the scalar line; when the polar form vanishes the remaining equation says one product is the negative of the other, and reading it that way is the group lemma `neg_unique_l`, not a fact about geometric algebra.
  Theorem orthogonal_anticommute : ∀ u v : V,
    polar Q u v == 0 →
    (ga_vec u × ga_vec v : A) == - (ga_vec v × ga_vec u).
  Proof.
    intros u v Hpolar.
    apply neg_unique_l.
    calc ((ga_vec u × ga_vec v + ga_vec v × ga_vec u) : A)
      == ((polar Q u v *: (1 : A)) : A) { polarization }
      == (((0 : F) *: (1 : A)) : A) { Hpolar }
      == ((0 : A)) { zero_scale }.
  Qed.


  Context (rev : A → A).

With R invertible by its reversal, sandwiching an element whose square sits on the scalar line leaves that scalar where it was.
  Theorem sandwich_scalar_square : ∀ (R x : A) (q : F),
    R × rev R == 1 → rev R × R == 1 → x × x == q *: 1 →
    (R × x × rev R) × (R × x × rev R) == q *: (1 : A).
  Proof.
    intros R x q Hright Hleft Hx.
    calc (((R × x × rev R) × (R × x × rev R)) : A)
      == ((R × (x × x) × rev R) : A)
         { (sandwich_square R x (rev R) Hleft) }
      == ((R × (q *: (1 : A)) × rev R) : A)
         { Hx }
      == (((q *: (R × (1 : A))) × rev R) : A)
         { scale_mul_r }
      == (((q *: R) × rev R) : A)
         { right_identity }
      == ((q *: (R × rev R)) : A)
         { scale_mul_l }
      == ((q *: (1 : A)) : A)
         { Hright }.
  Qed.

The rotation of a vector by a unit rotor has the same quadratic value, as an equation on the scalar line.
  Theorem sandwich_qform_scale : ∀ (R : A) (u w : V),
    R × rev R == 1 → rev R × R == 1 →
    ga_vec w == R × ga_vec u × rev R →
    Q w *: (1 : A) == Q u *: 1.
  Proof.
    intros R u w Hright Hleft Hw.
    calc ((Q w *: (1 : A)) : A)
      == ((ga_vec w × ga_vec w) : A)
         { contraction }
      == (((R × ga_vec u × rev R) × (R × ga_vec u × rev R)) : A)
         { Hw }
      == ((Q u *: (1 : A)) : A)
         { (sandwich_scalar_square R (ga_vec u) (Q u) Hright Hleft
              (contraction u)) }.
  Qed.

... and the same as an equation between the two scalars, once the scalar line is faithful.
  Theorem sandwich_preserves_qform : ∀ (R : A) (u w : V),
    one_faithful F A →
    R × rev R == 1 → rev R × R == 1 →
    ga_vec w == R × ga_vec u × rev R →
    Q w == Q u.
  Proof.
    intros R u w Hfaithful Hright Hleft Hw.
    exact (Hfaithful (Q w) (Q u)
             (sandwich_qform_scale R u w Hright Hleft Hw)).
  Qed.

End GATheory.
