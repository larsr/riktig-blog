Section RevSignValues.
  Context (rev_sign : nat → bool) {RS : RevSign rev_sign}.

  Lemma rev_sign_one : rev_sign 1%nat = false.
  Proof.
    rewrite (rev_sign_succ (rev_sign := rev_sign) 0%nat),
            (rev_sign_zero (rev_sign := rev_sign)).
    reflexivity.
  Qed.

  Lemma rev_sign_two : rev_sign 2%nat = true.
  Proof.
    rewrite (rev_sign_succ (rev_sign := rev_sign) 1%nat), rev_sign_one.
    reflexivity.
  Qed.

  Lemma rev_sign_three : rev_sign 3%nat = true.
  Proof.
    rewrite (rev_sign_succ (rev_sign := rev_sign) 2%nat), rev_sign_two.
    reflexivity.
  Qed.

  Lemma rev_sign_four : rev_sign 4%nat = false.
  Proof.
    rewrite (rev_sign_succ (rev_sign := rev_sign) 3%nat), rev_sign_three.
    reflexivity.
  Qed.
End RevSignValues.

Section GradedReversalTheory.
  Context {A : Type} {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A}
    {An : HasNeg A} {Ao : One A} {Am : HasMult A} {AR : Ring A}
    {Ag : HasGrade A}.
  Context (rev : A → A) {RV : Reversal A rev}.
  Context (rev_sign : nat → bool) {RS : RevSign rev_sign}
    {GR : GradedReversal A rev rev_sign}.

The law Structure/Magnitude.v's header says is missing: the reversal fixes vectors. It is the grade action at k = 1, where the sign is false.
  Theorem reversal_fixes_grade_1 : ∀ a : A, rev (⟨ a ⟩_ 1) == ⟨ a ⟩_ 1.
  Proof.
    intros a.
    transitivity (if rev_sign 1%nat then - ⟨ a ⟩_ 1 else ⟨ a ⟩_ 1).
    - exact (rev_grade 1%nat a).
    - rewrite (rev_sign_one rev_sign). reflexivity.
  Qed.

Scalars too, for the same reason.
  Theorem reversal_fixes_grade_0 : ∀ a : A, rev (⟨ a ⟩_ 0) == ⟨ a ⟩_ 0.
  Proof.
    intros a.
    transitivity (if rev_sign 0%nat then - ⟨ a ⟩_ 0 else ⟨ a ⟩_ 0).
    - exact (rev_grade 0%nat a).
    - rewrite (rev_sign_zero (rev_sign := rev_sign)). reflexivity.
  Qed.

And it flips bivectors, which is what makes a rotor's reverse its inverse rather than itself.
  Theorem reversal_flips_grade_2 : ∀ a : A, rev (⟨ a ⟩_ 2) == - ⟨ a ⟩_ 2.
  Proof.
    intros a.
    transitivity (if rev_sign 2%nat then - ⟨ a ⟩_ 2 else ⟨ a ⟩_ 2).
    - exact (rev_grade 2%nat a).
    - rewrite (rev_sign_two rev_sign). reflexivity.
  Qed.

End GradedReversalTheory.
