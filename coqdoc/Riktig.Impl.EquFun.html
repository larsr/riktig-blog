Functions compared pointwise: what a fold that answers a function is equal up to. Deliberately not registered as an instance -- a blanket setoid on every function type would capture resolutions that want a more particular one -- so a use passes it by name.
Definition EqFun (A B : Type) {eB : EqRel B} : EqRel (A → B) :=
  fun f g ⇒ ∀ a : A, f a == g a.

Definition EqFun_Equivalence (A B : Type) {eB : EqRel B}
  (EB : Equivalence (@equ B eB)) : Equivalence (@equ (A → B) (EqFun A B)).
Proof.
  split.
  - intros f a. reflexivity.
  - intros f g H a. symmetry. exact (H a).
  - intros f g h H1 H2 a. exact (transitivity (H1 a) (H2 a)).
Qed.
