Library Riktig.Interface.Alternative

From Coq Require Import Morphisms.
From Riktig Require Import Props.

Class HasFail (M : Type → Type) := fail : ∀ {A}, M A.
Class HasAlt (M : Type → Type) := alt : ∀ {A}, M A → M A → M A.

Hint Mode HasFail ! : typeclass_instances.
Hint Mode HasAlt ! : typeclass_instances.

Arguments fail {M _ A}.
Arguments alt {M _ A} p q.

Infix "<|>" := alt (at level 50, left associativity).

An alternative structure makes each M A a monoid: alt is associative and fail is its two-sided identity.
Module Alternative.
  Class Alternative (M : Type → Type) {Me : ∀ A, EqRel (M A)}
                    {Mf : HasFail M} {Ma : HasAlt M} := {
    equivalence :: ∀ A, Equivalence (@equ (M A) _);
    alt_proper :: ∀ A, Proper (equ ==> equ ==> equ) (@alt M _ A);

    is_associative :: ∀ A, Associative (M A) (M A) alt alt;
    fail_left_identity :: ∀ A, LeftIdentity (M A) (M A) alt fail;
    fail_right_identity :: ∀ A, RightIdentity (M A) (M A) alt fail
  }.
  Hint Mode Alternative ! - - - : typeclass_instances.
End Alternative.
