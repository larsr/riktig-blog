From Riktig.Theory Require Import Lambda Naturals.
From Riktig.Impl Require Import LambdaTerm NaturalsChurch CpsTerm.
Local Open Scope term_scope.

Terms are written as on paper, and the abstract theorems apply to them directly.
Example identity_beta : ∀ t : term, ⦅(λ #0) t⦆ == t.
Proof. exact beta_id. Qed.

Church's conditional picks its branch -- proven once, for every lambda calculus.
Example if_picks_true : ∀ g h : term, church_if church_true g h == g.
Proof. exact church_if_true. Qed.

Arithmetic up to conversion, computationally: normalize both sides and compare.
Local Notation TWO_term := (λ λ ⦅#1 ⦅#1 #0⦆⦆).
Local Notation THREE_term := (λ λ ⦅#1 ⦅#1 ⦅#1 #0⦆⦆⦆).
Local Notation FIVE_term := (λ λ ⦅#1 ⦅#1 ⦅#1 ⦅#1 ⦅#1 #0⦆⦆⦆⦆⦆).

Example add_two_three : ⦅PLUS TWO_term THREE_term⦆ == FIVE_term.
Proof. apply (joinable_of_normalize 5 0). vm_compute. reflexivity. Qed.

Distinct variables are distinct terms: the conversion setoid is not degenerate, by LambdaCalculus.confluence.
Example var_zero_not_one : #0 =/= #1.
Proof. apply var_discrete. discriminate. Qed.

Continuation-passing style: the translation of any term is trivial -- all its calls in head position -- and handing a translated value a continuation hands the continuation the value back, by the structure's laws.
Example cps_all_head_position : ∀ t : term, triv (cps t).
Proof. exact cps_trivial. Qed.

Example cps_of_value : ∀ b k : term, tail b → ⦅(cps (λ b)) k⦆ == ⦅k (psi (λ b))⦆.
Proof. intros b k Hb. exact (cps_value (λ b) k (triv_lam b Hb)). Qed.

And a terminating run is all it takes: the translation of a term that evaluates to a value hands any continuation that value, by the structure's law.
Example cps_of_run : ∀ k : term,
  ⦅(cps ⦅(λ #0) (λ #0)⦆) k⦆ == ⦅k (psi (λ #0))⦆.
Proof.
  intros k.
  apply (CPSLambda.cps_runs ⦅(λ #0) (λ #0)⦆ (λ #0) k).
  split; [ | reflexivity ].
  apply star_one. exact (cbv_beta #0 (λ #0) eq_refl).
Qed.

The translation itself, on the term above: every call sits in head position, and the continuation is the last argument.
Eval vm_compute in cps ⦅(λ #0) (λ #0)⦆.
