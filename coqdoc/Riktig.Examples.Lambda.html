A parser for lambda terms and definitions, written with the structure's operations on character lists. Syntax: \x y. body abstracts, juxtaposition applies, parentheses group, a number is a Church numeral, and a definition is name = term ;.
Definition is_space (c : ascii) : bool :=
  let n := nat_of_ascii c in Nat.eqb n 32 || Nat.eqb n 10 || Nat.eqb n 13 || Nat.eqb n 9.
Definition is_alpha (c : ascii) : bool :=
  let n := nat_of_ascii c in (Nat.leb 97 n && Nat.leb n 122) || (Nat.leb 65 n && Nat.leb n 90) || Nat.eqb n 95.
Definition is_digit (c : ascii) : bool :=
  let n := nat_of_ascii c in Nat.leb 48 n && Nat.leb n 57.

The grammar, over any stream of characters: next reads the stream and size bounds the greedy repetitions.
Section Grammar.
  Context {St : Type} {NX : HasNext ascii St} (size : St → nat).

  Definition spaces : parser St (list ascii) := p_many size (p_sat is_space).
  Definition token {A : Type} (p : parser St A) : parser St A := p <* spaces.
  Definition ident : parser St string := string_of_list_ascii <$> p_many1 size (p_sat is_alpha).
  Definition number : parser St nat :=
    (fun ds ⇒ fold_left (fun n d ⇒ (10 × n + (nat_of_ascii d - 48))%nat) ds O) <$> p_many1 size (p_sat is_digit).

  Fixpoint term_p (fuel : nat) : parser St named :=
    match fuel with
    | 0 ⇒ fail
    | S fuel ⇒
      ((token (sym "092"%char) *> p_many1 size (token ident)) >>= fun xs ⇒
         (token (sym "."%char) *> term_p fuel) >>= fun b ⇒ ret (fold_right NLam b xs))
      <|> (p_many1 size (atom_p fuel) >>= fun atoms ⇒
             match atoms with [] ⇒ fail | a :: rest ⇒ ret (fold_left NApp rest a) end)
    end
  with atom_p (fuel : nat) : parser St named :=
    match fuel with
    | 0 ⇒ fail
    | S fuel ⇒
      (NVar <$> token ident)
      <|> (NNum <$> token number)
      <|> (token (sym "("%char) *> term_p fuel <* token (sym ")"%char))
    end.

  Definition def_p (fuel : nat) : parser St (string × named) :=
    token ident >>= fun x ⇒ (token (sym "="%char) *> term_p fuel) >>= fun t ⇒
      token (sym ";"%char) *> ret (x, t).

  Definition defs_p (fuel : nat) : parser St (list (string × named)) := spaces *> p_many size (def_p fuel).

The readings of a whole input: definitions, and one term.
  Definition read_defs (s : St) : list (ctx × St) :=
    map (fun r ⇒ (map (fun d ⇒ (fst d, resolve [] (snd d))) (fst r), snd r)) (defs_p 64 s).
  Definition read_term (s : St) : list (term × St) :=
    map (fun r ⇒ (resolve [] (fst r), snd r)) ((spaces *> term_p 64) s).
End Grammar.

At lists of characters.
Definition parse_defs (s : string) : ctx :=
  match read_defs (@length ascii) (list_ascii_of_string s) with
  | (G, _) :: _ ⇒ G
  | [] ⇒ []
  end.

Definition parse_term (s : string) : option term :=
  match read_term (@length ascii) (list_ascii_of_string s) with
  | (t, []) :: _ ⇒ Some t
  | _ ⇒ None
  end.

The prelude: booleans, arithmetic on Church numerals, a fixed point combinator for call-by-value, and Euclid's algorithm.
Definition prelude : string := " true = \a b. a ; false = \a b. b ; succ = \n f x. f (n f x) ; add = \m n f x. m f (n f x) ; mul = \m n f. m (n f) ; pred = \n f x. n (\g h. h (g f)) (\u. x) (\u. u) ; sub = \m n. n pred m ; iszero = \n. n (\x. false) true ; leq = \m n. iszero (sub m n) ; fix = \f. (\x. f (\v. x x v)) (\x. f (\v. x x v)) ; mod = fix (\mod a b. (leq b a) (\u. mod (sub a b) b) (\u. a) 0) ; gcd = fix (\gcd a b. (iszero b) (\u. a) (\u. gcd b (mod a b)) 0) ; ".

Definition G : ctx := parse_defs prelude.

Eval vm_compute in map fst G.

Definition run (s : string) : option nat :=
  match parse_term s with
  | Some t ⇒ eval_numeral G 10000 t
  | None ⇒ None
  end.

Eval vm_compute in run "add 2 3".
Eval vm_compute in run "mul 6 7".
Eval vm_compute in run "sub 34 12".
Eval vm_compute in run "mod 34 12".
Eval vm_compute in run "gcd 12 34".

Example gcd_12_34 : run "gcd 12 34" = Some 2.
Proof. vm_compute. reflexivity. Qed.

The parsers are parsers in the structure's sense, so the abstract laws apply to them: for instance, offering the same reading twice changes nothing.
Example ident_idem : ident (@length ascii) <|> ident (@length ascii) == ident (St := list ascii) (@length ascii).
Proof. apply alt_idem. Qed.

The terms are a lambda calculus in the structure's sense, so what the theory proves by the equations alone holds of them up to conversion: Church's conditional picks its branch.
Example if_true_conv : ∀ g h : Lambda.term, church_if church_true g h == g.
Proof. intros g h. apply church_if_true. Qed.

And the evaluator agrees, reading the chosen branch back as a numeral.
Example if_true_runs : eval_numeral G 100 (church_if church_true (church 3) (church 4)) = Some 3.
Proof. vm_compute. reflexivity. Qed.
