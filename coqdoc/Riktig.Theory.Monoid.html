Section MonoidTheory.
  Context {M : Type} `{Monoid M}.

  Theorem id_unique : ∀ e f : M,
    (∀ a, e + a == a) → (∀ a, a + f == a) → e == f.
  Proof.
    intros e f He Hf.
    calc e
      == (e + f) { Hf }
      == f { He }.
  Qed.

  Theorem zero_unique_l : ∀ e : M, (∀ a, e + a == a) → e == 0.
  Proof.
    intros e He.
    calc e
      == (e + 0) { right_identity }
      == (0 : M) { He }.
  Qed.

  Theorem zero_unique_r : ∀ e : M, (∀ a, a + e == a) → e == 0.
  Proof.
    intros e He.
    calc e
      == (0 + e) { left_identity }
      == (0 : M) { He }.
  Qed.

  Lemma zero_add_swap : ∀ m : M, 0 + m == m + 0.
  Proof.
    intros m.
    calc (0 + m)
      == m { left_identity }
      == (m + 0) { right_identity }.
  Qed.

  Lemma add_zero_l {z y : M} : z == 0 → z + y == y.
  Proof.
    intros Hz.
    calc (z + y)
      == (0 + y) { Hz }
      == y { left_identity }.
  Qed.

  Lemma add_zero_r {y z : M} : z == 0 → y + z == y.
  Proof.
    intros Hz.
    calc (y + z)
      == (y + 0) { Hz }
      == y { right_identity }.
  Qed.

End MonoidTheory.

Section CommutativeMonoidTheory.
  Context {M : Type} `{MM : Monoid M} {MC : Commutative M M add}.

  Theorem add_swap_front : ∀ a b c : M, a + (b + c) == b + (a + c).
  Proof.
    intros a b c.
    calc (a + (b + c))
      == ((a + b) + c) { associative }
      == ((b + a) + c) { (commutative a) }
      == (b + (a + c)) { associative }.
  Qed.

End CommutativeMonoidTheory.

Section AlternatingMonoidTheory.
  Context {M : Type} `{MM : Monoid M} {MA : Alternates M add}.

Shifting twice by the same element returns it.
  Theorem add_shift : ∀ a b : M, a + (a + b) == b.
  Proof.
    intros a b.
    calc (a + (a + b))
      == ((a + a) + b) { (associative a a b) }
      == ((0 : M) + b) { (alternates (op := add) a) }
      == b { (left_identity b) }.
  Qed.

A sum vanishes exactly when its two summands agree: with every element its own inverse, the negation carries no information.
  Theorem add_zero_unique : ∀ a b : M, a + b == 0 → a == b.
  Proof.
    intros a b Hab.
    calc a
      == (a + (0 : M)) { (right_identity a) }
      == (a + (b + b)) { (alternates (op := add) b) }
      == ((a + b) + b) { (associative a b b) }
      == ((0 : M) + b) { Hab }
      == b { (left_identity b) }.
  Qed.

End AlternatingMonoidTheory.

Instance Monoid_LeftIdUnique M `{HM : Monoid M} :
  Unique M (fun e : M ⇒ ∀ a, e + a == a).
Proof.
  intros e f He Hf.
  calc e
    == (0 : M) { zero_unique_l }
    == f { zero_unique_l }.
Qed.



Section PowerTheory.
  Context {M : Type} {eM : EqRel M} {oM : One M} {mM : HasMult M}
    {MM : @Monoid M eM oM mM}.

The two equations pin the operation: any two powers agree at every exponent. Derivable here, and DerivLab.v's differential_unique is not, for one reason — nat is generated by O and S, so an induction reaches every exponent, whereas the derivative laws reach only the functions built from linear maps and constants and there is no basis of functions to reach the rest.
  Theorem pow_unique : ∀ (p q : M → nat → M),
    Power M p → Power M q → ∀ (x : M) (n : nat), p x n == q x n.
  Proof.
    intros p q Pp Pq x n.
    induction n as [| n IH].
    - calc (p x 0%nat)
        == (1 : M) { pow_zero }
        == (q x 0%nat) { pow_zero }.
    - calc (p x (S n))
        == (x × p x n) { pow_succ }
        == (x × q x n) { (op_proper x x (reflexivity x) _ _ IH) }
        == (q x (S n)) { pow_succ }.
  Qed.

  Context (pow : M → nat → M).

The exponent is a nat, not a carrier element, so moving along an arithmetic identity is a rewrite in an argument rather than a setoid step. No law is used: this holds of any function of an exponent.
  Lemma pow_exponent : ∀ (x : M) (m n : nat),
    m = n → pow x m == pow x n.
  Proof. intros x m n Hmn. rewrite Hmn. reflexivity. Qed.

  Context {P : Power M pow}.

Adding exponents multiplies powers: the induction whose every step is associativity.
  Lemma pow_add : ∀ (x : M) (m n : nat),
    pow x (m + n)%nat == pow x m × pow x n.
  Proof.
    intros x m; induction m as [| m IH]; intros n.
    - calc (pow x n)
        == (1 × pow x n) { left_identity }
        == (pow x 0%nat × pow x n) { pow_zero }.
    - calc (pow x (S m + n)%nat)
        == (x × pow x (m + n)%nat) { pow_succ }
        == (x × (pow x m × pow x n))
             { (op_proper x x (reflexivity x) _ _ (IH n)) }
        == ((x × pow x m) × pow x n) { associative }
        == (pow x (S m) × pow x n) { pow_succ }.
  Qed.

End PowerTheory.
