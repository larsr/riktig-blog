The rotors of an algebra form a group, and each of them acts on the algebra by the sandwich x |-> R x R¬. Every proof below reads the three equations off the Rotor instance; no coordinate formula for a rotor appears, and none is needed.

The unit is a rotor — the rotation that does nothing.
  #[export] Instance unit_is_rotor : Rotor rev even 1.
  Proof.
    split.
    - exact parity_even_one.
    - calc (((1 : A) × rev 1) : A)
        == ((rev 1) : A) { mul_left_identity }
        == ((1 : A)) { reverse_one }.
    - calc ((rev 1 × (1 : A)) : A)
        == ((rev 1) : A) { mul_right_identity }
        == ((1 : A)) { reverse_one }.
  Qed.

Two rotors compose to a rotor. Evenness is the Z/2 law of the grading and the unit equations are the reversal reversing the product, so a chain of rotors, however long, stays in the group.
  #[export] Instance mul_is_rotor (x y : A)
      {Rx : Rotor rev even x} {Ry : Rotor rev even y}
    : Rotor rev even (x × y).
  Proof.
    split.
    - exact (even_mul_even x y (rotor_even (rev := rev) x)
                               (rotor_even (rev := rev) y)).
    - calc (((x × y) × rev (x × y)) : A)
        == (((x × y) × (rev y × rev x)) : A) { reversal_anti }
        == ((x × (y × (rev y × rev x))) : A) { associative }
        == ((x × ((y × rev y) × rev x)) : A) { associative }
        == ((x × ((1 : A) × rev x)) : A) { (rotor_unit_r y) }
        == ((x × rev x) : A) { mul_left_identity }
        == ((1 : A)) { (rotor_unit_r x) }.
    - calc ((rev (x × y) × (x × y)) : A)
        == (((rev y × rev x) × (x × y)) : A) { reversal_anti }
        == ((rev y × (rev x × (x × y))) : A) { associative }
        == ((rev y × ((rev x × x) × y)) : A) { associative }
        == ((rev y × ((1 : A) × y)) : A) { (rotor_unit_l x) }
        == ((rev y × y) : A) { mul_left_identity }
        == ((1 : A)) { (rotor_unit_l y) }.
  Qed.

  Theorem rotor_reverse_inverts : ∀ R : A,
    Rotor rev even R → R × rev R == 1 ∧ rev R × R == 1.
  Proof.
    intros R HR. split; [ exact (rotor_unit_r R) | exact (rotor_unit_l R) ].
  Qed.

Conjugating by S and then by R is conjugating by R × S. Only the reversal's anti-automorphism law is used, so this holds of any two elements; the rotors are the ones for which it is a group action.
  Theorem rotor_sandwich_compose : ∀ R S x : A,
    R × (S × x × rev S) × rev R == (R × S) × x × rev (R × S).
  Proof.
    intros R S x.
    exact (sandwich_compose_anti rev (@reversal_anti A _ _ _ _ _ _ _ rev RV) R S x).
  Qed.

  Context {F V A : Type} `{GeometricAlgebra F V A}.

  Context (even odd : A → Prop) {PG : ParityGraded A even odd}.

Conjugating by a rotor leaves a square on the scalar line where it found it. Theory/GeometricAlgebra.v proves this from the two unit equations; here they come from the instance.
  Theorem rotor_sandwich_scalar_square : ∀ (x : A) (q : F),
    x × x == q *: 1 → (R × x × rev R) × (R × x × rev R) == q *: (1 : A).
  Proof.
    intros x q Hx.
    exact (sandwich_scalar_square rev R x q
             (rotor_unit_r R) (rotor_unit_l R) Hx).
  Qed.

A rotor's sandwich preserves the quadratic form, as an equation on the scalar line.
  Theorem rotor_qform_scale : ∀ u w : V,
    ga_vec w == R × ga_vec u × rev R → Q w *: (1 : A) == Q u *: 1.
  Proof.
    intros u w Hw.
    exact (sandwich_qform_scale rev R u w (rotor_unit_r R) (rotor_unit_l R) Hw).
  Qed.

... and as an equation between scalars, once the scalar line separates them.
  Theorem rotor_preserves_qform : ∀ u w : V,
    one_faithful F A → ga_vec w == R × ga_vec u × rev R → Q w == Q u.
  Proof.
    intros u w Hfaithful Hw.
    exact (sandwich_preserves_qform rev R u w Hfaithful
             (rotor_unit_r R) (rotor_unit_l R) Hw).
  Qed.

End RotorAction.
