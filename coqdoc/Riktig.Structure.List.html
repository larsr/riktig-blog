The lists over elements named by x: the datatype of the signature 1 + const x × self, one level being nothing or an element beside a hole. Nothing more is a law: the constructors are the two halves of build, the recursion is cata, and induction is its uniqueness.
Module List.
  Notation shape den x := (shape_of den (listS (S := sig _) x)).

  Class List (O : Type) `{Bicartesian O} {K : Type} (den : K → O) (x : K) (L : O)
      (build : HasBuild O (shape den x) L)
      (fold : HasCata O (shape den x) L) := {
    initial :: InitialAlgebra O (shape den x) L build fold;
  }.

The two constructors, the recursion and the shape's action, with the shape filled in.
  Notation nil := (build (F := shape _ _) ∘ inj1).
  Notation cons := (build (F := shape _ _) ∘ inj2).
  Notation fold := (cata (F := shape _ _)).
  Notation map := (fmap (F := shape _ _)).
End List.
