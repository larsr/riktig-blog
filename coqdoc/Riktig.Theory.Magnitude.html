  Context (rev : A → A) {RV : Reversal A rev}.

The equation reaches every element, so it leaves no freedom: two magnitudes on the same reversal agree. This is what makes the specification a definition, and what would make a second way of computing it provably the same one.
  Theorem magnitude_unique : ∀ m m' : A → A,
    Magnitude A rev m → Magnitude A rev m' → ∀ a : A, m a == m' a.
  Proof.
    intros m m' Hm Hm' a.
    calc (m a)
      == (⟨ rev a × a ⟩_ 0) { mag2_def }
      == (m' a) { mag2_def }.
  Qed.

End MagnitudeTheory.
