The Lie bracket of two elements.
Class HasBracket (V : Type) := bracket : BinOp V.
Notation "[ x , y ]" := (bracket x y).

Hint Mode HasBracket ! : typeclass_instances.

Typeclasses Transparent HasBracket.

A Lie algebra is a vector space with a bilinear bracket that vanishes on a repeated argument and satisfies the Jacobi identity, the cyclic sum of the doubled brackets below.
Module LieAlgebra.
  Class LieAlgebra (F V : Type) `{Field F}
      {Ve : EqRel V} {Vz : Zero V} {Va : HasAdd V} {Vn : HasNeg V}
      {Vs : HasScale F V} {VS : VectorSpace F V} {Vb : HasBracket V} := {
    is_bilinear :: Bilinear F V V V bracket;
    is_alternating :: Alternates V bracket;

    jacobi : ∀ x y z : V,
      [ x , [ y , z ] ] + [ y , [ z , x ] ] + [ z , [ x , y ] ] == 0;
  }.
  Hint Mode LieAlgebra - ! - - - - - - - - - - - - - - - : typeclass_instances.
End LieAlgebra.
