Decided propositions from the decided relations of a structure: equality, the strict order and the order.
Section DecidableOfStructures.
  Context {A : Type} {eqA : EqRel A}.

  #[export] Instance equ_decidable {EA : EquDec A} (a b : A) : Decidable (a == b) := equ_dec a b.

  Context {le : HasLe A}.
  #[export] Instance lt_decidable {LA : LtDec A} (a b : A) : Decidable (a < b) := lt_dec a b.

End DecidableOfStructures.
