Decided propositions: over Coq's own types, over the connectives, over pairs, options and lists -- and from the decided relations of a structure -- so a program has one place to ask from.
equ_decidable is the one that joins the two files: it hands a structure's decided equality to every list decision of above that asks for one, so membership a ∈ l, equality of lists and freedom from duplicates are decided up to == as soon as the elements are; and the predicates a list carries pointwise, Forall and Exists, are decided for any decided predicate, hence for any built from ==, < or ≤. Decided propositions over Coq's types: equalities and orders of the number types, characters and strings; the connectives; equality of pairs, options and lists of types with decided equality; and the predicates a list carries -- membership, the two quantifiers, equality and duplication -- both at Coq's equality and at a carrier's own. A program over any of these branches with if dec P then a else b.

Instance Q_eq_decidable (x y : Q) : Decidable (x == y)%Q := Qeq_dec x y.
Instance Q_lt_decidable (x y : Q) : Decidable (x < y)%Q :=
  match Qlt_le_dec x y with
  | left H ⇒ left H
  | right H ⇒ right (Qle_not_lt y x H)
  end.
Instance Q_le_decidable (x y : Q) : Decidable (x ≤ y)%Q :=
  match Qlt_le_dec y x with
  | left H ⇒ right (Qlt_not_le y x H)
  | right H ⇒ left H
  end.

Connectives

Instance True_decidable : Decidable True := left I.
Instance False_decidable : Decidable False := right (fun H ⇒ H).
Instance not_decidable (P : Prop) {DP : Decidable P} : Decidable (¬ P) :=
  match dec (P) with
  | left H ⇒ right (fun Hn ⇒ Hn H)
  | right H ⇒ left H
  end.
Instance and_decidable (P Q : Prop) {DP : Decidable P} {DQ : Decidable Q} : Decidable (P ∧ Q) :=
  match dec (P) with
  | left HP ⇒ match dec (Q) with
               | left HQ ⇒ left (conj HP HQ)
               | right HQ ⇒ right (fun H ⇒ HQ (proj2 H))
               end
  | right HP ⇒ right (fun H ⇒ HP (proj1 H))
  end.
Instance or_decidable (P Q : Prop) {DP : Decidable P} {DQ : Decidable Q} : Decidable (P ∨ Q) :=
  match dec (P) with
  | left HP ⇒ left (or_introl HP)
  | right HP ⇒ match dec (Q) with
                | left HQ ⇒ left (or_intror HQ)
                | right HQ ⇒ right (fun H ⇒ match H with or_introl H ⇒ HP H | or_intror H ⇒ HQ H end)
                end
  end.
Instance impl_decidable (P Q : Prop) {DP : Decidable P} {DQ : Decidable Q} : Decidable (P → Q) :=
  match dec (Q) with
  | left HQ ⇒ left (fun _ ⇒ HQ)
  | right HQ ⇒ match dec (P) with
                | left HP ⇒ right (fun H ⇒ HQ (H HP))
                | right HP ⇒ left (fun H ⇒ match HP H with end)
                end
  end.

Pairs, options and lists

Section Compound.
  Context {A B : Type} {DA : ∀ a a' : A, Decidable (a = a')} {DB : ∀ b b' : B, Decidable (b = b')}.

  #[export] Instance prod_eq_decidable (p q : A × B) : Decidable (p = q).
  Proof.
    destruct p as [a b], q as [a' b'].
    destruct (DA a a') as [Ha | Ha]; [ | right; intros H; apply Ha; exact (f_equal fst H) ].
    destruct (DB b b') as [Hb | Hb]; [ | right; intros H; apply Hb; exact (f_equal snd H) ].
    left. subst. reflexivity.
  Defined.

  #[export] Instance option_eq_decidable (o o' : option A) : Decidable (o = o').
  Proof.
    destruct o as [a |], o' as [a' |].
    - destruct (DA a a') as [Ha | Ha]; [ left; subst; reflexivity | right; intros H; apply Ha; injection H; trivial ].
    - right. discriminate.
    - right. discriminate.
    - left. reflexivity.
  Defined.

  #[export] Instance list_eq_decidable (l l' : list A) : Decidable (l = l').
  Proof.
    revert l'. induction l as [| a l IH]; intros [| a' l'].
    - left. reflexivity.
    - right. discriminate.
    - right. discriminate.
    - destruct (DA a a') as [Ha | Ha]; [ | right; intros H; apply Ha; injection H; trivial ].
      destruct (IH l') as [Hl | Hl]; [ left; subst; reflexivity | right; intros H; apply Hl; injection H; trivial ].
  Defined.

  #[export] Instance In_decidable (a : A) (l : list A) : Decidable (In a l).
  Proof.
    induction l as [| b l IH].
    - right. intros H. exact H.
    - destruct (DA b a) as [Hb | Hb]; [ left; left; exact Hb | ].
      destruct IH as [Hl | Hl]; [ left; right; exact Hl | right; intros [H | H]; [ exact (Hb H) | exact (Hl H) ] ].
  Defined.
End Compound.

Section Quantifiers.
  Context {A : Type} (P : A → Prop) {DP : ∀ a : A, Decidable (P a)}.

  #[export] Instance Forall_decidable (l : list A) : Decidable (Forall P l).
  Proof.
    induction l as [| a l IH].
    - left. constructor.
    - destruct (DP a) as [Ha | Ha]; [ | right; intros H; inversion H; exact (Ha H2) ].
      destruct IH as [Hl | Hl]; [ left; constructor; assumption | right; intros H; inversion H; exact (Hl H3) ].
  Defined.

  #[export] Instance Exists_decidable (l : list A) : Decidable (Exists P l).
  Proof.
    induction l as [| a l IH].
    - right. intros H. inversion H.
    - destruct (DP a) as [Ha | Ha]; [ left; constructor; exact Ha | ].
      destruct IH as [Hl | Hl]; [ left; apply Exists_cons_tl; exact Hl | right; intros H; inversion H; [ exact (Ha H1) | exact (Hl H1) ] ].
  Defined.
End Quantifiers.

Lists up to a carrier's own equality

The same decisions once the elements are compared by == rather than by Coq's equality: membership, equality, and duplication. The decider for the elements is a hypothesis rather than a structure's field, which keeps this file independent of the structures; the structure that supplies it does so in Impl.Decidable.
Notation "a ∈ l" := (InA equ a l) (at level 70, no associativity).

Section SetoidLists.
  Context {A : Type} {eqA : EqRel A} {DA : ∀ a b : A, Decidable (a == b)}.

  #[export] Instance elem_decidable (a : A) (l : list A) : Decidable (a ∈ l) := InA_dec DA a l.

  #[export] Instance eqlistA_decidable (l l' : list A) : Decidable (eqlistA equ l l').
  Proof.
    revert l'. induction l as [| a l IH]; intros [| a' l'].
    - left. constructor.
    - right. intros Hc. inversion Hc.
    - right. intros Hc. inversion Hc.
    - destruct (DA a a') as [Ha | Ha];
        [ | right; intros Hc; inversion Hc; contradiction ].
      destruct (IH l') as [Hl | Hl];
        [ left; constructor; assumption | right; intros Hc; inversion Hc; contradiction ].
  Defined.

  #[export] Instance NoDupA_decidable (l : list A) : Decidable (NoDupA equ l).
  Proof.
    induction l as [| a l IH].
    - left. constructor.
    - destruct (elem_decidable a l) as [Ha | Ha];
        [ right; intros Hc; inversion Hc; contradiction | ].
      destruct IH as [Hl | Hl];
        [ left; constructor; assumption | right; intros Hc; inversion Hc; contradiction ].
  Defined.
End SetoidLists.

A carrier compared by Coq's equality has == decided as soon as Coq's equality is. This is deliberately NOT an instance: with EqRel transparent, a == b at eqA := eq IS a = b, so search would go from EquDec A to ∀ a b, Decidable (a = b) and back through equ_decidable forever. A carrier that wants it names it, as Impl.EquDecNat and Impl.EquDecAscii do.
Definition equdec_of_eq (A : Type) (D : ∀ a b : A, Decidable (a = b))
  : EquDec A (eqA := eq) := D.
