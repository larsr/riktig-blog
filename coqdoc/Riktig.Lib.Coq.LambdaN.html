A lambda term over variables N, as plain Coq data.
Inductive lambda (N : Type) : Type :=
| Var (n : N)
| Abs (b : lambda N)
| App (f a : lambda N).
Arguments Var {N} n.
Arguments Abs {N} b.
Arguments App {N} f a.

One step of beta reduction on these terms, anywhere, with the contraction handed in -- so this file owes nothing to whoever defines substitution.
Inductive lstep {N : Type} (contract : lambda N → lambda N → lambda N)
  : lambda N → lambda N → Prop :=
| LStepBeta : ∀ b u, lstep contract (App (Abs b) u) (contract b u)
| LStepLam : ∀ b b', lstep contract b b' → lstep contract (Abs b) (Abs b')
| LStepAppL : ∀ f f' a, lstep contract f f' → lstep contract (App f a) (App f' a)
| LStepAppR : ∀ f a a', lstep contract a a' → lstep contract (App f a) (App f a').
