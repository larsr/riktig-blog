Church's booleans as terms of any lambda calculus, and what holds of them by the equations alone -- no induction over syntax.
Notation "'church_true'" := (lam (lam (var (succ 0)))).
Notation "'church_false'" := (lam (lam (var 0))).
Notation "'church_if' b g h" := (app (app b g) h) (at level 10, b at level 9, g at level 9, h at level 9).

Section LambdaTheory.
  Context {N T Sb : Type} `{LambdaCalculus N T Sb}.

  Theorem shift_cancel : ∀ (t u : T), (t.[sub_shift]).[u .: sub_id] == t.
  Proof.
    intros t u.
    calc ((t.[sub_shift]).[u .: sub_id]) == (t.[sub_id]) { (shift_cons t u sub_id) } == t { (subst_id t) }.
  Qed.

  Theorem beta_id : ∀ u : T, app (lam (var 0)) u == u.
  Proof.
    intros u.
    calc (app (lam (var 0)) u) == ((var 0 : T).[u .: sub_id]) { (beta (var 0) u) } == u { (var_zero_cons u sub_id) }.
  Qed.

Under one binder, a term shifted past it reads back the outer argument.
  Lemma var_one_up_cons : ∀ (g : T) (s : Sb), (var (succ 0) : T).[sub_up (g .: s)] == g.[sub_shift].
  Proof.
    intros g s.
    calc ((var (succ 0) : T).[sub_up (g .: s)])
      == (((var 0 : T).[g .: s]).[sub_shift]) { (var_succ_up 0 (g .: s)) }
      == (g.[sub_shift]) { (subst_proper _ _ sub_shift (var_zero_cons g s)) }.
  Qed.

  Theorem church_if_true : ∀ g h : T, church_if church_true g h == g.
  Proof.
    intros g h.
    calc (app (app (lam (lam (var (succ 0)))) g) h)
      == (app ((lam (var (succ 0))).[g .: sub_id]) h) { (beta (lam (var (succ 0))) g) }
      == (app (lam ((var (succ 0)).[sub_up (g .: sub_id)])) h) { (lam_subst (var (succ 0)) (g .: sub_id)) }
      == (app (lam (g.[sub_shift])) h) { (var_one_up_cons g sub_id) }
      == ((g.[sub_shift]).[h .: sub_id]) { (beta (g.[sub_shift]) h) }
      == g { (shift_cancel g h) }.
  Qed.

  Theorem church_if_false : ∀ g h : T, church_if church_false g h == h.
  Proof.
    intros g h.
    calc (app (app (lam (lam (var 0))) g) h)
      == (app ((lam (var 0)).[g .: sub_id]) h) { (beta (lam (var 0)) g) }
      == (app (lam ((var 0).[sub_up (g .: sub_id)])) h) { (lam_subst (var 0) (g .: sub_id)) }
      == (app (lam (var 0)) h) { (var_zero_up (g .: sub_id)) }
      == h { (beta_id h) }.
  Qed.
End LambdaTheory.
