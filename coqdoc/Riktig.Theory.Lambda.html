What holds in any lambda calculus, from the laws alone. Conversion is an equivalence -- transitivity is exactly one use of LambdaCalculus.confluence -- and the constructors respect it, so calculation with == is available; then Church's booleans behave as they should, with no induction over syntax anywhere.
Notation "'church_true'" := (lam (lam (var (succ 0)))).
Notation "'church_false'" := (lam (lam (var 0))).
Notation "'church_if' b g h" := (app (app b g) h) (at level 10, b at level 9, g at level 9, h at level 9).

Section LambdaTheory.
  Context {N T Sb : Type} `{LambdaCalculus N T Sb}.

Two terms are equal when they reduce to a common term; the witness is read off an equality and put back.
  Lemma equ_of_join : ∀ t u w : T, t -->* w → u -->* w → t == u.
  Proof. intros t u w Ht Hu. exact (proj2 (LambdaCalculus.equ_join t u) (ex_intro _ w (conj Ht Hu))). Qed.

  Lemma join_of_equ : ∀ t u : T, t == u → ∃ w : T, t -->* w ∧ u -->* w.
  Proof. intros t u Htu. exact (proj1 (LambdaCalculus.equ_join t u) Htu). Qed.

  Lemma reduces_equ : ∀ t u : T, t -->* u → t == u.
  Proof. intros t u Hr. exact (equ_of_join t u u Hr (LambdaCalculus.reduces_refl u)). Qed.

  #[export] Instance conversion_equivalence : Equivalence (@equ T eqT).
  Proof.
    split.
    - intros t. exact (reduces_equ t t (LambdaCalculus.reduces_refl t)).
    - intros t u Htu. destruct (join_of_equ t u Htu) as [w [Ht Hu]]. exact (equ_of_join u t w Hu Ht).
    - intros t u v Htu Huv.
      destruct (join_of_equ t u Htu) as [w1 [Ht1 Hu1]]. destruct (join_of_equ u v Huv) as [w2 [Hu2 Hv2]].
      destruct (LambdaCalculus.confluence u w1 w2 Hu1 Hu2) as [w [Hw1 Hw2]].
      exact (equ_of_join t v w (LambdaCalculus.reduces_trans t w1 w Ht1 Hw1) (LambdaCalculus.reduces_trans v w2 w Hv2 Hw2)).
  Qed.

  #[export] Instance lam_proper : Proper (equ ==> equ) (lam : T → T).
  Proof.
    intros b b' Hb. destruct (join_of_equ b b' Hb) as [w [H1 H2]].
    exact (equ_of_join (lam b) (lam b') (lam w) (LambdaCalculus.reduces_lam b w H1) (LambdaCalculus.reduces_lam b' w H2)).
  Qed.

  #[export] Instance app_proper : Proper (equ ==> equ ==> equ) (app : T → T → T).
  Proof.
    intros f f' Hf a a' Ha.
    destruct (join_of_equ f f' Hf) as [w1 [Hf1 Hf2]]. destruct (join_of_equ a a' Ha) as [w2 [Ha1 Ha2]].
    exact (equ_of_join (app f a) (app f' a') (app w1 w2)
             (LambdaCalculus.reduces_app f w1 a w2 Hf1 Ha1) (LambdaCalculus.reduces_app f' w1 a' w2 Hf2 Ha2)).
  Qed.

  Lemma subst_proper_l : ∀ (t t' : T) (s : Sb), t == t' → t.[s] == t'.[s].
  Proof.
    intros t t' s Ht. destruct (join_of_equ t t' Ht) as [w [H1 H2]].
    exact (equ_of_join (t.[s]) (t'.[s]) (w.[s]) (LambdaCalculus.reduces_subst t w s H1) (LambdaCalculus.reduces_subst t' w s H2)).
  Qed.

  Theorem beta_equ : ∀ b u : T, app (lam b) u == b.[u .: sub_id].
  Proof. intros b u. apply reduces_equ. exact (LambdaCalculus.beta b u). Qed.

  Theorem shift_cancel : ∀ t u : T, (t.[sub_shift]).[u .: sub_id] == t.
  Proof.
    intros t u.
    calc ((t.[sub_shift]).[u .: sub_id]) == (t.[sub_id]) { (LambdaCalculus.shift_cons t u sub_id) } == t { (LambdaCalculus.subst_id t) }.
  Qed.

  Theorem beta_id : ∀ u : T, app (lam (var 0)) u == u.
  Proof.
    intros u.
    calc (app (lam (var 0)) u) == ((var 0 : T).[u .: sub_id]) { (beta_equ (var 0) u) } == u { (LambdaCalculus.var_zero_cons u sub_id) }.
  Qed.

Under one binder, a term shifted past it reads back the outer argument.
  Lemma var_one_up_cons : ∀ (g : T) (s : Sb), (var (succ 0) : T).[sub_up (g .: s)] == g.[sub_shift].
  Proof.
    intros g s.
    calc ((var (succ 0) : T).[sub_up (g .: s)])
      == (((var 0 : T).[g .: s]).[sub_shift]) { (LambdaCalculus.var_succ_up 0 (g .: s)) }
      == (g.[sub_shift]) { (subst_proper_l _ _ sub_shift (LambdaCalculus.var_zero_cons g s)) }.
  Qed.

  Theorem church_if_true : ∀ g h : T, church_if church_true g h == g.
  Proof.
    intros g h.
    calc (app (app (lam (lam (var (succ 0)))) g) h)
      == (app ((lam (var (succ 0))).[g .: sub_id]) h) { (app_proper _ _ (beta_equ (lam (var (succ 0))) g) _ _ (reflexivity h)) }
      == (app (lam ((var (succ 0)).[sub_up (g .: sub_id)])) h) { (app_proper _ _ (LambdaCalculus.lam_subst (var (succ 0)) (g .: sub_id)) _ _ (reflexivity h)) }
      == (app (lam (g.[sub_shift])) h) { (app_proper _ _ (lam_proper _ _ (var_one_up_cons g sub_id)) _ _ (reflexivity h)) }
      == ((g.[sub_shift]).[h .: sub_id]) { (beta_equ (g.[sub_shift]) h) }
      == g { (shift_cancel g h) }.
  Qed.

  Theorem church_if_false : ∀ g h : T, church_if church_false g h == h.
  Proof.
    intros g h.
    calc (app (app (lam (lam (var 0))) g) h)
      == (app ((lam (var 0)).[g .: sub_id]) h) { (app_proper _ _ (beta_equ (lam (var 0)) g) _ _ (reflexivity h)) }
      == (app (lam ((var 0).[sub_up (g .: sub_id)])) h) { (app_proper _ _ (LambdaCalculus.lam_subst (var 0) (g .: sub_id)) _ _ (reflexivity h)) }
      == (app (lam (var 0)) h) { (app_proper _ _ (lam_proper _ _ (LambdaCalculus.var_zero_up (g .: sub_id))) _ _ (reflexivity h)) }
      == h { (beta_id h) }.
  Qed.

The setoid is not degenerate: distinct variables stay distinct.
  Theorem var_discrete : ∀ n m : N, n =/= m → var n =/= (var m : T).
  Proof. intros n m Hnm Hv. exact (Hnm (LambdaCalculus.var_injective n m Hv)). Qed.
