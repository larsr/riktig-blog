Parallel substitution over the lambda-term algebra: a substitution is a function from variables to terms, a fold answers a function of the substitution so it can be lifted under each binder, and lifting keeps the bound variable and shifts the rest.
Section Subst.
  Context {N T : Type} `{TermRec N T} `{NatRec N}.

Lifting a substitution past a binder.
  Definition up_subst (s : N → T) : N → T :=
    fun n ⇒ natrec T (#0) (fun m _ ⇒ shift (s m)) n.

  Definition subst (t : T) : (N → T) → T :=
    termrec ((N → T) → T)
      (fun n s ⇒ s n)
      (fun b s ⇒ λ (b (up_subst s)))
      (fun f a s ⇒ ⦅(f s) (a s)⦆)
      t.

The substitution that replaces the bound variable and lowers the rest: what a beta step applies.
  Definition beta_subst (u : T) : N → T :=
    fun n ⇒ natrec T u (fun m _ ⇒ #m) n.

  Definition subst0 (b u : T) : T := subst b (beta_subst u).
End Subst.
