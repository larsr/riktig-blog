Over any constructive reals: a square plus one, and the inverse of three, which exists because three is apart from zero.
Section OverAnyConstructiveReals.
  Context {R Q N : Type} `{ConstructiveReals R Q N}.

  Definition square_plus_one (x : R) : R := x × x + 1.

  Definition third : R := inv_apart (1 + 1 + 1) (inr three_pos).

The one comparison a real admits. true means a is below b, certainly; false means b is below a + eps, so a is not below b by more than the precision. Equal reals always answer false, since no precision separates them.
  Definition lt_decide (a b : R) (eps : Q) (Heps : 0 < eps) : bool :=
    match compare_at a b eps Heps with
    | inl _ ⇒ true
    | inr _ ⇒ false
    end.

The larger of two reals, up to the precision: when a is below b the answer is exactly b, otherwise a is at most eps below the larger one.
  Definition max_within (a b : R) (eps : Q) (Heps : 0 < eps) : R :=
    match compare_at a b eps Heps with
    | inl _ ⇒ b
    | inr _ ⇒ a
    end.
End OverAnyConstructiveReals.

At Coq's Cauchy reals both compute: the value of the function at 3/2 is approximated to within a millionth, and the inverse of three to within a thousandth, and the approximations are checked by evaluation.
Example square_plus_one_approx :
  abs (approx (square_plus_one (inject_Q 1.5%Q)) 0.000001%Q - 3.25%Q) ≤ 0.000001%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Example third_approx :
  abs (approx (third (R := CReal)) 0.001%Q - (1 # 3)%Q) ≤ 0.001%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Eval vm_compute in approx (square_plus_one (inject_Q 1.5%Q)) 0.000001%Q.

Comparisons evaluate too: the decision refines the precision of the sequences until the gap shows, or until it is seen to be below the requested precision.
Example three_below_square_plus_one :
  lt_decide (inject_Q 3%Q) (square_plus_one (inject_Q 1.5%Q)) 0.001%Q thousandth_pos = true.
Proof. vm_compute. reflexivity. Qed.

Example square_plus_one_not_below_three :
  lt_decide (square_plus_one (inject_Q 1.5%Q)) (inject_Q 3%Q) 0.001%Q thousandth_pos = false.
Proof. vm_compute. reflexivity. Qed.

Example three_thirds_within_one :
  lt_decide (third × (1 + 1 + 1)) 1 0.001%Q thousandth_pos = false.
Proof. vm_compute. reflexivity. Qed.

Example max_within_approx :
  approx (max_within (inject_Q 3%Q) (square_plus_one (inject_Q 1.5%Q)) 0.001%Q thousandth_pos)
    0.000001%Q == (13 # 4)%Q.
Proof. vm_compute. reflexivity. Qed.

Eval vm_compute in lt_decide (third × (1 + 1 + 1)) 1 0.001%Q thousandth_pos.
