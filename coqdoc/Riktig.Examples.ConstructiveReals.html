Over any constructive reals: a square plus one, and the inverse of three, which exists because three is apart from zero.
Section OverAnyConstructiveReals.
  Context {R Q N : Type} `{ConstructiveReals R Q N}.

  Definition square_plus_one (x : R) : R := x × x + 1.

  Lemma three_pos : (0 : R) ≺ 1 + 1 + 1.
  Proof.
    exact (lt_trans _ _ _ zero_lt_one
      (lt_trans _ _ _
        (lt_equ_l _ _ _ (right_identity (action := add) (1 : R)) (add_lt_mono_l 1 0 1 zero_lt_one))
        (lt_equ_l _ _ _ (right_identity (action := add) (1 + 1 : R)) (add_lt_mono_l (1 + 1) 0 1 zero_lt_one)))).
  Defined.

  Definition third : R := inv_apart (1 + 1 + 1) (inr three_pos).
End OverAnyConstructiveReals.

At Coq's Cauchy reals both compute: the value of the function at 3/2 is approximated to within a millionth, and the inverse of three to within a thousandth, and the approximations are checked by evaluation.
Example square_plus_one_approx :
  (Qabs (approx (square_plus_one (inject_Q (3 # 2))) (1 # 1000000) - (13 # 4)) ≤ (1 # 1000000))%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Example third_approx :
  (Qabs (approx (third (R := CReal)) (1 # 1000) - (1 # 3)) ≤ (1 # 1000))%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Eval vm_compute in approx (square_plus_one (inject_Q (3 # 2)%Q)) (1 # 1000000)%Q.
