Over any constructive reals: a square plus one, and the inverse of three, which exists because three is apart from zero.
Section OverAnyConstructiveReals.
  Context {R Q N : Type} `{ConstructiveReals R Q N}.

  Definition square_plus_one (x : R) : R := x × x + 1.

  Lemma three_pos : (0 : R) ≺ 1 + 1 + 1.
  Proof.
    exact (lt_trans _ _ _ zero_lt_one
      (lt_trans _ _ _
        (lt_equ_l _ _ _ (right_identity (action := add) (1 : R)) (add_lt_mono_l 1 0 1 zero_lt_one))
        (lt_equ_l _ _ _ (right_identity (action := add) (1 + 1 : R)) (add_lt_mono_l (1 + 1) 0 1 zero_lt_one)))).
  Defined.

  Definition third : R := inv_apart (1 + 1 + 1) (inr three_pos).

The one comparison a real admits: either a is below b, or b is below a plus the precision. Equal reals always take the second branch, since no precision separates them.
  Definition below_within (a b : R) (eps : Q) (Heps : 0 < eps) : bool :=
    match compare_at a b eps Heps with
    | inl _ ⇒ true
    | inr _ ⇒ false
    end.

The larger of two reals, up to the precision: when a is below b the answer is exactly b, otherwise a is at most eps below the larger one.
  Definition max_within (a b : R) (eps : Q) (Heps : 0 < eps) : R :=
    match compare_at a b eps Heps with
    | inl _ ⇒ b
    | inr _ ⇒ a
    end.
End OverAnyConstructiveReals.

At Coq's Cauchy reals both compute: the value of the function at 3/2 is approximated to within a millionth, and the inverse of three to within a thousandth, and the approximations are checked by evaluation.
Example square_plus_one_approx :
  (Qabs (approx (square_plus_one (inject_Q (3 # 2))) (1 # 1000000) - (13 # 4)) ≤ (1 # 1000000))%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Example third_approx :
  (Qabs (approx (third (R := CReal)) (1 # 1000) - (1 # 3)) ≤ (1 # 1000))%Q.
Proof. vm_compute. intro H. discriminate H. Qed.

Eval vm_compute in approx (square_plus_one (inject_Q (3 # 2)%Q)) (1 # 1000000)%Q.

Comparisons evaluate too: the decision refines the precision of the sequences until the gap shows, or until it is seen to be below the requested precision.
Lemma thousandth_pos : (0 : Q) < (1 # 1000)%Q.
Proof. split; [ discriminate | intro H; discriminate H ]. Qed.

Example three_below_square_plus_one :
  below_within (inject_Q 3%Q) (square_plus_one (inject_Q (3 # 2)%Q)) (1 # 1000)%Q thousandth_pos = true.
Proof. vm_compute. reflexivity. Qed.

Example square_plus_one_not_below_three :
  below_within (square_plus_one (inject_Q (3 # 2)%Q)) (inject_Q 3%Q) (1 # 1000)%Q thousandth_pos = false.
Proof. vm_compute. reflexivity. Qed.

Example three_thirds_within_one :
  below_within (third × (1 + 1 + 1)) 1 (1 # 1000)%Q thousandth_pos = false.
Proof. vm_compute. reflexivity. Qed.

Example max_within_approx :
  (approx (max_within (inject_Q 3) (square_plus_one (inject_Q (3 # 2))) (1 # 1000) thousandth_pos)
     (1 # 1000000) = 13 # 4)%Q.
Proof. vm_compute. reflexivity. Qed.

Eval vm_compute in below_within (third × (1 + 1 + 1)) 1 (1 # 1000)%Q thousandth_pos.
