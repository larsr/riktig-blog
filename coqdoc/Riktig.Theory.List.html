Library Riktig.Theory.List

From Riktig.Structure Require Export List.
From Riktig.Theory Require Export Signature.

Section ListTheory.
  Context {O : Type} `{Bicartesian O} {K : Type} {den : K → O} {x : K} {L : O}
    {build : HasBuild O (List.shape den x) L} {fold : HasCata O (List.shape den x) L}
    `{!List O den x L build fold}.

Taking a list apart is the inverse of building it.
  Theorem build_unbuild_list :
    build ∘ fold (List.shape den x L) (fmap (F := List.shape den x) build) == cat_id.
  Proof. exact build_unbuild. Qed.

  Theorem unbuild_build_list :
    fold (List.shape den x L) (fmap (F := List.shape den x) build) ∘ build == cat_id.
  Proof. exact unbuild_build. Qed.
End ListTheory.

Induction, from the one theorem for every signature: nothing list-specific remains to prove.
Section ListInduction.
  Context {X L : Type}
    {lb : HasBuild Type (List.shape (fun T0 : Type ⇒ T0) X) L}
    {lf : HasCata Type (List.shape (fun T0 : Type ⇒ T0) X) L}
    `{!List Type (fun T0 : Type ⇒ T0) X L lb lf}.

  Theorem list_induction : ∀ P : L → Prop,
    P (lb (inl tt)) →
    (∀ (x : X) (l : L), P l → P (lb (inr (x, l)))) →
    ∀ l : L, P l.
  Proof.
    intros P Hnil Hcons.
    apply (datatype_induction (fun T0 : Type ⇒ T0) (listS (S := sig Type) X) (T := L)
      (tb := lb) (tf := lf) (IA := List.initial)).
    intros s [s' Es]. destruct s' as [[] | [x [l pl]]]; cbn in Es; subst; cbn.
    - exact Hnil.
    - exact (Hcons x l pl).
  Qed.
End ListInduction.
