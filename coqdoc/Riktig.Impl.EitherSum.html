From Riktig.Theory Require Export Either.
From Riktig.Impl Require Export CategoryFun SignaturePoly.

Coq's sum is the datatype A + B over Coq's types: the shape at Type is sum itself, so build is the identity and case applies the algebra.
Section S.
  Context (A B : Type).

  #[export] Instance CoqSum_HasBuild : HasBuild Type (Either.shape (fun T0 : Type ⇒ T0) A B) (A + B)%type :=
    fun s ⇒ s.

  #[export] Instance CoqSum_HasCata : HasCata Type (Either.shape (fun T0 : Type ⇒ T0) A B) (A + B)%type :=
    fun X h ⇒ h.

  #[export] Instance CoqSum_Either :
    Either Type (fun T0 : Type ⇒ T0) A B (A + B)%type CoqSum_HasBuild CoqSum_HasCata.
  Proof.
    split. split.
    - exact (layer_functor (fun T0 : Type ⇒ T0) (eitherS (S := sig Type) A B)).
    - intros X h h' Hh s. exact (Hh s).
    - intros X h [x | y]; reflexivity.
    - intros X h u Hu [x | y]; [ exact (Hu (inl x)) | exact (Hu (inr y)) ].
  Qed.
End S.
