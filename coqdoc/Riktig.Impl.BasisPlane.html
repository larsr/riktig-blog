The plane's basis with its coordinate map: the coordinates of a vector of V2 are its two components, and every vector is the combination of the basis with them.
Instance Plane_HasCoords : HasCoords Q bool V2 := fun v i ⇒ if i then snd v else snd (fst v).

Instance Plane_Basis : Basis Q bool V2 nat plane_basis Plane_HasCoords.
Proof.
  split.
  - intros i i' Hi. rewrite Hi. reflexivity.
  - intros v v' Hv i i' Hi. rewrite Hi. destruct Hv as [[_ H1] H2].
    destruct i'; [ exact H2 | exact H1 ].
  - intros i. destruct i; intros u v; simpl; reflexivity.
  - intros i. destruct i; intros aq u; simpl; reflexivity.
  - intros v. destruct v as [[u0 xx] yy]. destruct u0. simpl.
    split; [ split; simpl | simpl ].
    + reflexivity.
    + calc ((0 + xx × 1) + yy × 0)
        == ((0 + xx × 1) + 0) { (Theory.Ring.mul_zero yy) }
        == (0 + xx × 1) { (right_identity (action := add) (0 + xx × 1)) }
        == ((0 : Q) + xx) { (right_identity (action := mult) xx) }
        == xx { (left_identity (action := add) xx) }.
    + calc ((0 + xx × 0) + yy × 1)
        == (((0 : Q) + 0) + yy × 1) { (Theory.Ring.mul_zero xx) }
        == ((0 : Q) + yy × 1) { (left_identity (action := add) (0 : Q)) }
        == ((0 : Q) + yy) { (right_identity (action := mult) yy) }
        == yy { (left_identity (action := add) yy) }.
  - intros i j. destruct i, j; vm_compute; reflexivity.
Qed.
