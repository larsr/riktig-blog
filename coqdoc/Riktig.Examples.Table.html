From Riktig Require Import Theory.Table Impl.TableFun Impl.FiniteBool Impl.FiniteUnit.

Appending two tables is reindexing along the sum of their indexes.
Definition append {I J A T T' T'' : Type} `{Table I A T} `{Table J A T'} `{Table (I + J) A T''}
    (s : T) (t : T') : T'' :=
  tabulate (fun k ⇒ match k with inl i ⇒ get s i | inr j ⇒ get t j end).

At function tables over bool and unit, the appended table is a function on bool + unit, and its entries compute.
Instance BoolUnit_EqRel : EqRel (bool + unit) := eq.

Definition s : bool → nat := fun b ⇒ if b then 1 else 2.
Definition t : unit → nat := fun _ ⇒ 3.

Example appended_left : get (append s t : bool + unit → nat) (inl true) = 1 := eq_refl.
Example appended_right : get (append s t : bool + unit → nat) (inr tt) = 3 := eq_refl.

And the two entry laws, from Theory/Table.v, at these tables.
Example by_the_law : get (append s t : bool + unit → nat) (inl false) == get s false.
Proof. exact (get_append_l s t false). Qed.

The same table over bool, as a list: tabulating lists the entries in the order of the index's numbering, false then true.
From Riktig Require Import Impl.TableList.
Instance Nat_HasDefault : HasDefault nat := 0.

Example as_list : (tabulate s : ListTable bool nat) = (2 :: 1 :: nil)%list := eq_refl.
Example read_back : get (tabulate s : ListTable bool nat) true = 1 := eq_refl.

And as a primitive array, which fits: two entries are well within an array's capacity. The instance takes that bound as an argument.
From Coq Require Import PArray ZArith.
From Riktig Require Import Impl.TableArray.
Local Close Scope Z_scope.
Lemma bool_fits : (Z.of_nat (card (I := bool)) ≤ max_nat)%Z.
Proof. vm_compute. intro H. discriminate H. Qed.

Instance Bool_ArrayTable :
  Table bool nat (ArrayTable bool nat) ArrayTable_HasGet ArrayTable_HasTabulate (eqI := eq) :=
  ArrayTable_Table bool_fits.

Example as_array : get (tabulate s : ArrayTable bool nat) true = 1 := eq_refl.
Example as_array_false : get (tabulate s : ArrayTable bool nat) false = 2 := eq_refl.
