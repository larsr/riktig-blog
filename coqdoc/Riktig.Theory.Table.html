Section TableTheory.
  Context {I A T : Type} `{Table I A T}.

Two tables with the same entries are the same table.
  Theorem table_ext : ∀ s t : T, (∀ i : I, get s i == get t i) → s == t.
  Proof.
    intros s t Hst.
    calc s
      == (tabulate (get s) : T) { tabulate_get }
      == (tabulate (get t) : T) { (tabulate_proper (get s) (get t) Hst) }
      == t { tabulate_get }.
  Qed.

End TableTheory.

Reindexing: a table over I read through a map J → I is a table over J, entry by entry. Appending two tables is reindexing along a sum of indexes, so its two entry laws are this one twice.
Section Reindexing.
  Context {I J A T T' : Type} `{Table I A T} `{Table J A T'}.

  Theorem get_reindex : ∀ (r : J → I) (t : T) (j : J),
    get (tabulate (fun j ⇒ get t (r j)) : T') j == get t (r j).
  Proof. intros r t j. exact (get_tabulate (fun j ⇒ get t (r j)) j). Qed.

End Reindexing.

Section Appending.
  Context {I J A T T' T'' : Type} `{Table I A T} `{Table J A T'} `{Table (I + J) A T''}.

  Theorem get_append_l : ∀ (s : T) (t : T') (i : I),
    get (tabulate (fun k ⇒ match k with inl i ⇒ get s i | inr j ⇒ get t j end) : T'') (inl i)
      == get s i.
  Proof. intros s t i. exact (get_tabulate _ (inl i)). Qed.

  Theorem get_append_r : ∀ (s : T) (t : T') (j : J),
    get (tabulate (fun k ⇒ match k with inl i ⇒ get s i | inr j ⇒ get t j end) : T'') (inr j)
      == get t j.
  Proof. intros s t j. exact (get_tabulate _ (inr j)). Qed.

End Appending.
