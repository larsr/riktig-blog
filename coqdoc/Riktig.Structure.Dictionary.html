Library Riktig.Structure.Dictionary

From Coq Require Export Morphisms.
From Riktig.Structure Require Export Decidable.

A dictionary from keys to values: the empty one holds nothing, inserting binds a key, and finding returns the latest binding of an equal key and nothing else. Keys need a decidable equality for an implementation to compare them. Finding answers with the stored value itself, so the bindings' equations need no equality on option.
Module Dictionary.
  Class Dictionary (K V D : Type) {eqK : EqRel K} {eqV : EqRel V} {eqD : EqRel D}
      {dK : EquDec K}
      (empty : HasEmpty D) (insert : HasInsert K V D) (find : HasFind K V D) := {
    entries :: Equivalence (@equ D eqD);

    insert_proper :: Proper (equ ==> equ ==> equ ==> equ) (insert : K → V → D → D);
    find_congruent : ∀ (d : D) (k k' : K), k == k' → find d k = find d k';

    find_empty : ∀ k : K, find (empty : D) k = None;
    find_insert_here : ∀ (k k' : K) (v : V) (d : D),
      k == k' → ∃ v' : V, find (insert k v d) k' = Some v' ∧ v' == v;
    find_insert_there : ∀ (k k' : K) (v : V) (d : D),
      k =/= k' → find (insert k v d) k' = find d k';
  }.
End Dictionary.
