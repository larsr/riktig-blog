What an involutive anti-automorphism fixes and what it carries. None of it is assumed: the class has four laws and everything here follows from them.

Section ReversalTheory.
  Context {A : Type} {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A}
          {An : HasNeg A} {Ao : One A} {Am : HasMult A} {AR : Ring A}.
  Context (rev : A → A) {RV : Reversal A rev}.

The unit is fixed. A reversal is not asked to fix it — that is a consequence of reversing products and undoing itself, so an instance never has to supply it.
  Theorem reverse_one : rev 1 == 1.
  Proof.
    symmetry.
    calc ((1 : A))
      == ((rev (rev 1)) : A) { (reversal_involutive (1 : A)) }
      == ((rev (rev 1 × 1)) : A) { mul_right_identity }
      == ((rev 1 × rev (rev 1))) { reversal_anti }
      == ((rev 1 × 1)) { reversal_involutive }
      == ((rev 1)) { mul_right_identity }.
  Qed.

  Theorem reverse_zero : rev 0 == 0.
  Proof. exact (additive_zero rev). Qed.

  Theorem reverse_neg : ∀ x : A, rev (- x) == - rev x.
  Proof. intros x. exact (additive_negation rev x). Qed.

  Theorem reverse_add : ∀ x y : A, rev (x + y) == rev x + rev y.
  Proof. intros x y. exact (additive (f := rev) x y). Qed.

Undoing itself makes it injective.
  #[export] Instance reverse_injective : Injective A A rev.
  Proof.
    intros a b Heq.
    calc (a : A)
      == ((rev (rev a)) : A) { reversal_involutive }
      == ((rev (rev b)) : A) { Heq }
      == (b : A) { reversal_involutive }.
  Qed.


End ReversalTheory.
