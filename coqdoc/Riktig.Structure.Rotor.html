A rotor of an algebra carrying a reversal: an element of the even part that its own reversal inverts on both sides. This is the definition — what a rotor means — and every coordinate formula for one is an element that satisfies it, never the other way round.
Module Rotor.
  Class Rotor {A : Type} {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A}
      {An : HasNeg A} {Ao : One A} {Am : HasMult A} {AR : Ring A}
      (rev : A → A) (even : A → Prop) (R : A) := {
    rotor_even : even R;
    rotor_unit_r : R × rev R == 1;
    rotor_unit_l : rev R × R == 1;
  }.
  Hint Mode Rotor ! - - - - - - - ! - ! : typeclass_instances.
End Rotor.
