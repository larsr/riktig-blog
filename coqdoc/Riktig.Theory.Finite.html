Section FiniteTheory.
  Context {I N : Type} `{Finite I N}.

  Theorem index_injective : ∀ i j : I, index i == index j → i == j.
  Proof.
    intros i j Hij.
    calc i
      == (elem (index i) : I) { elem_index }
      == (elem (index j) : I) { Hij }
      == j { elem_index }.
  Qed.

  Theorem elem_injective : ∀ k l : N,
    k < card → l < card → (elem k : I) == elem l → k == l.
  Proof.
    intros k l Hk Hl Hkl.
    calc k
      == (index (elem k : I)) { (index_elem k Hk) }
      == (index (elem l : I)) { Hkl }
      == l { (index_elem l Hl) }.
  Qed.

Equality on a finite index is decided, through the numbering.
  Theorem eq_or_ne_index : ∀ i j : I, i == j ∨ i =/= j.
  Proof.
    intros i j.
    destruct (eq_or_ne (index i) (index j)) as [Heq | Hne].
    - left. exact (index_injective i j Heq).
    - right. intros Hij. apply Hne. rewrite Hij. reflexivity.
  Qed.

End FiniteTheory.

Families over a finite index with decided equality: replacing one slot keeps a family proper, reads back at the replaced slot and as before elsewhere.
Section FamilyUpdate.
  Context {I N V : Type} `{Finite I N} {EI : EquDec I} {eV : EqRel V} {EqvV : Equivalence (A := V) equ}.
  Local Notation "'upd' vs j u" := (fun i : I ⇒ if equ_dec i j then u else vs i)
    (at level 10, vs at level 9, j at level 9, u at level 9).

  Lemma upd_proper : ∀ (vs : I → V) (j : I) (u : V), Proper (equ ==> equ) vs → Proper (equ ==> equ) (upd vs j u).
  Proof.
    intros vs j u Hvs i i' Hi.
    destruct (equ_dec i j) as [Hij | Hij]; destruct (equ_dec i' j) as [Hij' | Hij'].
    - reflexivity.
    - destruct Hij'. exact (transitivity (symmetry Hi) Hij).
    - destruct Hij. exact (transitivity Hi Hij').
    - apply Hvs. exact Hi.
  Qed.

  Lemma upd_ext : ∀ (vs : I → V) (j : I) (u u' : V), u == u' → ∀ i : I, upd vs j u i == upd vs j u' i.
  Proof. intros vs j u u' Hu i. simpl. destruct (equ_dec i j); [ exact Hu | reflexivity ]. Qed.

  Lemma upd_at : ∀ (vs : I → V) (j : I) (u : V), upd vs j u (elem (index j)) == u.
  Proof.
    intros vs j u. simpl.
    destruct (equ_dec (elem (index j)) j) as [_ | Hne]; [ reflexivity | destruct (Hne (elem_index j)) ].
  Qed.

  Lemma upd_off : ∀ (vs : I → V) (j : I) (u : V) (k : N), k < card → k =/= index j → upd vs j u (elem k) == vs (elem k).
  Proof.
    intros vs j u k Hk Hkj. simpl.
    destruct (equ_dec (elem k) j) as [Hej | _]; [ | reflexivity ].
    exfalso. apply Hkj.
    calc k == (index (I := I) (N := N) (elem (I := I) (N := N) k)) { (index_elem (I := I) (N := N) k Hk) }
      == (index j) { (index_proper (elem k) j Hej) }.
  Qed.
End FamilyUpdate.
