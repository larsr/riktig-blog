The plane algebra Cl(2) over the rationals, graded by Coq's naturals. Instance search cannot discover the inner vector space of a doubling by itself, so the tower is pinned in dependency order: the inner vector space of A2 is Extend 1 unit.
Instance A1_Graded : Graded nat Q (Double (1 : Q) Q) (Double_HasGrade (1 : Q)) (succ (0 : nat)) :=
  Double_Graded (N := nat) (V := unit) (1 : Q).
