From Riktig.Theory Require Import Naturals.
From Riktig.Impl Require Import NaturalsChurch.
Local Open Scope term_scope.

The Church numerals are naturals, and the numerals are built from the lambda constants alone: 0 is the term ZERO, succ applies the term SUCC, + applies PLUS. So TWO below is the term SUCC (SUCC ZERO), and no Coq numeral appears anywhere in what follows.
Impl.LambdaTerm stays out: its transparent EqRel term := joinable is the same relation the ChurchNat equality uses on the projections, so with both in scope a rewrite in one carrier matches in the other.
Definition TWO : ChurchNat := succ (succ 0).
Definition FIVE : ChurchNat := succ (succ (succ (succ (succ 0)))).
Definition SEVEN : ChurchNat := succ (succ (succ (succ (succ (succ (succ 0)))))).

These are lambda terms. Here is the one TWO stands for, and the one TWO + FIVE stands for -- PLUS applied to two towers of SUCC over ZERO.
Eval vm_compute in proj1_sig TWO.
Eval vm_compute in proj1_sig (TWO + FIVE).

And the sum is read off the structure: two of its theorems and nothing else. The script cites only Naturals, so it proves the same equation in any naturals whatever; what makes this one a statement about lambda terms is only which instance it lands on.
Example two_plus_five : TWO + FIVE == SEVEN.
Proof.
  unfold TWO, FIVE, SEVEN.
  repeat rewrite add_succ.
  rewrite add_zero.
  reflexivity.
Qed.

Being an equation between closed lambda terms, it is also witnessed by reduction: both sides reach one normal form.
Example two_plus_five_reduces :
  normalize 12 (proj1_sig (TWO + FIVE)) = normalize 12 (proj1_sig SEVEN).
Proof. vm_compute. reflexivity. Qed.

The rest of the theory transports verbatim -- nothing below is proved by hand, and each is a fact about lambda terms.
Example church_add_succ : ∀ c d : ChurchNat, c + succ d == succ (c + d).
Proof. exact add_succ. Qed.

Example church_mul_comm : ∀ c d : ChurchNat, c × d == d × c.
Proof. exact (commutative (op := mult)). Qed.

Example church_add_comm : ∀ c d : ChurchNat, c + d == d + c.
Proof. exact (commutative (op := add)). Qed.
