Section GradeDecomposition.
  Context {n : nat} {F A : Type}
    {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {As : HasScale F A}
    {AM : Monoid A} {Ag : HasGrade A}
    {bigop_list : ∀ J : Type, (J → A) → list J → A}
    {BL : BigOp A bigop_list}.
  Arguments bigop_list {J}.
  Notation bigop m f := (bigop_list f (seq 0 m)).
  Context {AG : Graded n F A (@bigop_list)}.

Every element is the sum of its grade parts.
  Theorem grade_decomposition : ∀ a : A,
    a == bigop (S n) (fun k ⇒ ⟨ a ⟩_ k).
  Proof.
    intros a. symmetry. exact (grade_complete a).
  Qed.

End GradeDecomposition.

Section DecompositionAtTwo.
  Context {F A : Type}
    {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {As : HasScale F A}
    {AM : Monoid A} {Ag : HasGrade A}
    {bigop_list : ∀ J : Type, (J → A) → list J → A}
    {BL : BigOp A bigop_list}.
  Arguments bigop_list {J}.
  Notation bigop m f := (bigop_list f (seq 0 m)).
  Context {AG : Graded 2 F A (@bigop_list)}.

The blackboard form of the decomposition in a top-grade-2 algebra: a scalar part, a vector part and a bivector part.
  Theorem grade_decomposition_two : ∀ a : A,
    a == ⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2.
  Proof.
    intros a.
    assert (Hsum : bigop 3 (fun k ⇒ ⟨ a ⟩_ k)
                     == ⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + 0))).
    { calc (bigop 3 (fun k ⇒ ⟨ a ⟩_ k))
        == (⟨ a ⟩_ 0 + bigop 2 (fun k ⇒ ⟨ a ⟩_ (S k)))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + bigop 1 (fun k ⇒ ⟨ a ⟩_ (S (S k)))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + bigop 0 (fun k ⇒ ⟨ a ⟩_ (S (S (S k)))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + 0)))
          { bigop_0 }. }
    calc a
      == (bigop 3 (fun k ⇒ ⟨ a ⟩_ k))
        { (grade_decomposition a) }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + 0)))
        { Hsum }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + ⟨ a ⟩_ 2))
        { right_identity }
      == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2)
        { (associative (⟨ a ⟩_ 0)) }.
  Qed.

An element without a vector part is its scalar plus its bivector.
  Theorem grade_decomposition_two_even : ∀ a : A,
    ⟨ a ⟩_ 1 == 0 → a == ⟨ a ⟩_ 0 + ⟨ a ⟩_ 2.
  Proof.
    intros a Ha.
    calc a
      == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2) { (grade_decomposition_two a) }
      == (⟨ a ⟩_ 0 + 0 + ⟨ a ⟩_ 2) { Ha }
      == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 2) { right_identity }.
  Qed.

End DecompositionAtTwo.

The blackboard form of the decomposition in a top-grade-3 algebra: the bounded sum, written out.
  Theorem grade_decomposition_three : ∀ a : A,
    a == ⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3.
  Proof.
    intros a.
    assert (Hsum : bigop 4 (fun k ⇒ ⟨ a ⟩_ k)
                     == ⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + 0)))).
    { calc (bigop 4 (fun k ⇒ ⟨ a ⟩_ k))
        == (⟨ a ⟩_ 0 + bigop 3 (fun k ⇒ ⟨ a ⟩_ (S k)))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + bigop 2 (fun k ⇒ ⟨ a ⟩_ (S (S k)))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + bigop 1 (fun k ⇒ ⟨ a ⟩_ (S (S (S k)))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + bigop 0 (fun k ⇒ ⟨ a ⟩_ (S (S (S (S k)))))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + 0))))
          { bigop_0 }. }
    calc a
      == (bigop 4 (fun k ⇒ ⟨ a ⟩_ k))
        { (grade_decomposition a) }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + 0))))
        { Hsum }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + ⟨ a ⟩_ 3)))
        { right_identity }
      == (⟨ a ⟩_ 0 + ((⟨ a ⟩_ 1 + ⟨ a ⟩_ 2) + ⟨ a ⟩_ 3))
        { (associative (⟨ a ⟩_ 1)) }
      == ((⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + ⟨ a ⟩_ 2)) + ⟨ a ⟩_ 3)
        { (associative (⟨ a ⟩_ 0)) }
      == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3)
        { (associative (⟨ a ⟩_ 0)) }.
  Qed.

End DecompositionAtThree.

The same in a top-grade-4 algebra: the spacetime split, a scalar, a vector, a bivector, a trivector and a pseudoscalar.
  Theorem grade_decomposition_four : ∀ a : A,
    a == ⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3 + ⟨ a ⟩_ 4.
  Proof.
    intros a.
    assert (Hsum : bigop 5 (fun k ⇒ ⟨ a ⟩_ k)
                     == ⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + (⟨ a ⟩_ 4 + 0))))).
    { calc (bigop 5 (fun k ⇒ ⟨ a ⟩_ k))
        == (⟨ a ⟩_ 0 + bigop 4 (fun k ⇒ ⟨ a ⟩_ (S k)))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + bigop 3 (fun k ⇒ ⟨ a ⟩_ (S (S k)))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + bigop 2 (fun k ⇒ ⟨ a ⟩_ (S (S (S k)))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + bigop 1 (fun k ⇒ ⟨ a ⟩_ (S (S (S (S k)))))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3
             + (⟨ a ⟩_ 4 + bigop 0 (fun k ⇒ ⟨ a ⟩_ (S (S (S (S (S k)))))))))))
          { bigop_S }
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + (⟨ a ⟩_ 4 + 0)))))
          { bigop_0 }. }
    
    assert (Hflat : ⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + ⟨ a ⟩_ 4)))
                    == ⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3 + ⟨ a ⟩_ 4).
    { calc (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + ⟨ a ⟩_ 4))))
        == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + ((⟨ a ⟩_ 2 + ⟨ a ⟩_ 3) + ⟨ a ⟩_ 4)))
          { (associative (⟨ a ⟩_ 2)) }
        == (⟨ a ⟩_ 0 + ((⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + ⟨ a ⟩_ 3)) + ⟨ a ⟩_ 4))
          { (associative (⟨ a ⟩_ 1)) }
        == (⟨ a ⟩_ 0 + (((⟨ a ⟩_ 1 + ⟨ a ⟩_ 2) + ⟨ a ⟩_ 3) + ⟨ a ⟩_ 4))
          { (associative (⟨ a ⟩_ 1)) }
        == ((⟨ a ⟩_ 0 + ((⟨ a ⟩_ 1 + ⟨ a ⟩_ 2) + ⟨ a ⟩_ 3)) + ⟨ a ⟩_ 4)
          { (associative (⟨ a ⟩_ 0)) }
        == (((⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + ⟨ a ⟩_ 2)) + ⟨ a ⟩_ 3) + ⟨ a ⟩_ 4)
          { (associative (⟨ a ⟩_ 0)) }
        == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3 + ⟨ a ⟩_ 4)
          { (associative (⟨ a ⟩_ 0)) }. }
    calc a
      == (bigop 5 (fun k ⇒ ⟨ a ⟩_ k))
        { (grade_decomposition a) }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + (⟨ a ⟩_ 4 + 0)))))
        { Hsum }
      == (⟨ a ⟩_ 0 + (⟨ a ⟩_ 1 + (⟨ a ⟩_ 2 + (⟨ a ⟩_ 3 + ⟨ a ⟩_ 4))))
        { right_identity }
      == (⟨ a ⟩_ 0 + ⟨ a ⟩_ 1 + ⟨ a ⟩_ 2 + ⟨ a ⟩_ 3 + ⟨ a ⟩_ 4)
        { Hflat }.
  Qed.

End DecompositionAtFour.

Section HomogeneousProducts.
  Context {n : nat} {F A : Type}.
  Context {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {An : HasNeg A}
          {Ao : One A} {Am : HasMult A} {As : HasScale F A}.
  Context {AR : Ring A}
          {Ag : HasGrade A}
          {bigop_list : ∀ J : Type, (J → A) → list J → A}
          {BL : BigOp A bigop_list} {AG : Graded n F A bigop_list}
          {Aw : HasGradedWedge A} {Ad : HasGradedDot A}
          {AP : GradedProducts n F A bigop_list}.
  Arguments bigop_list {J}.
  Notation bigop m f := (bigop_list f (seq 0 m)).

  Lemma grade_part_zero : ∀ k : nat, ⟨ (0 : A) ⟩_ k == 0.
  Proof.
    intros k. exact (additive_zero (grade_part k)).
  Qed.

An element equal to its own grade-r part has no other grade.
  Lemma homogeneous_grade_other : ∀ (r k : nat) (x : A),
    ⟨ x ⟩_ r == x → k ≠ r → ⟨ x ⟩_ k == 0.
  Proof.
    intros r k x Hx Hkr.
    calc (⟨ x ⟩_ k)
      == (⟨ ⟨ x ⟩_ r ⟩_ k) { Hx }
      == (0 : A) { (grade_orthogonal k r x Hkr) }.
  Qed.

  Lemma graded_double_sum_collapse :
    ∀ (g : nat → nat → nat) (r s : nat) (x y : A),
    (r ≤ n)%nat → (s ≤ n)%nat → ⟨ x ⟩_ r == x → ⟨ y ⟩_ s == y →
    bigop (S n) (fun r' ⇒ bigop (S n) (fun s' ⇒
      ⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ (g r' s')))
    == ⟨ x × y ⟩_ (g r s).
  Proof.
    intros g r s x y Hr Hs Hx Hy.
    assert (Hrow : ∀ r' : nat, r' ≠ r →
      bigop (S n) (fun s' ⇒ ⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ (g r' s')) == 0).
    { intros r' Hne.
      transitivity (bigop (S n) (fun _ : nat ⇒ (0 : A)));
        [| exact (bigop_zero (S n)) ].
      apply bigop_ext. intros s'.
      calc (⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ (g r' s'))
        == (⟨ (0 : A) × ⟨ y ⟩_ s' ⟩_ (g r' s'))
          { (homogeneous_grade_other r r' x Hx Hne) }
        == (⟨ (0 : A) ⟩_ (g r' s')) { mul_0_l }
        == (0 : A) { grade_part_zero }. }
    assert (Hcolumn : ∀ s' : nat, s' ≠ s →
      ⟨ ⟨ x ⟩_ r × ⟨ y ⟩_ s' ⟩_ (g r s') == 0).
    { intros s' Hne.
      calc (⟨ ⟨ x ⟩_ r × ⟨ y ⟩_ s' ⟩_ (g r s'))
        == (⟨ ⟨ x ⟩_ r × (0 : A) ⟩_ (g r s'))
          { (homogeneous_grade_other s s' y Hy Hne) }
        == (⟨ (0 : A) ⟩_ (g r s')) { mul_0_r }
        == (0 : A) { grade_part_zero }. }
    calc (bigop (S n) (fun r' ⇒ bigop (S n) (fun s' ⇒
            ⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ (g r' s'))))
      == (bigop (S n) (fun s' ⇒ ⟨ ⟨ x ⟩_ r × ⟨ y ⟩_ s' ⟩_ (g r s')))
        { (bigop_support_singleton (S n) r _ (le_n_S r n Hr) Hrow) }
      == (⟨ ⟨ x ⟩_ r × ⟨ y ⟩_ s ⟩_ (g r s))
        { (bigop_support_singleton (S n) s _ (le_n_S s n Hs) Hcolumn) }
      == (⟨ x × ⟨ y ⟩_ s ⟩_ (g r s)) { Hx }
      == (⟨ x × y ⟩_ (g r s)) { Hy }.
  Qed.

For homogeneous arguments the wedge is the top grade selection of the product...
  Theorem wedge_homogeneous : ∀ (r s : nat) (x y : A),
    (r ≤ n)%nat → (s ≤ n)%nat → ⟨ x ⟩_ r == x → ⟨ y ⟩_ s == y →
    x ∧ y == ⟨ x × y ⟩_ (r + s).
  Proof.
    intros r s x y Hr Hs Hx Hy.
    calc (x ∧ y)
      == (bigop (S n) (fun r' ⇒ bigop (S n) (fun s' ⇒
            ⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ (r' + s'))))
        { wedge_from_grade_parts }
      == (⟨ x × y ⟩_ (r + s))
        { (graded_double_sum_collapse (fun r' s' ⇒ (r' + s')%nat)
            r s x y Hr Hs Hx Hy) }.
  Qed.

... and the dot is the bottom one.
  Theorem dot_homogeneous : ∀ (r s : nat) (x y : A),
    (r ≤ n)%nat → (s ≤ n)%nat → ⟨ x ⟩_ r == x → ⟨ y ⟩_ s == y →
    x ⋅ y == ⟨ x × y ⟩_ ((r - s) + (s - r)).
  Proof.
    intros r s x y Hr Hs Hx Hy.
    calc (x ⋅ y)
      == (bigop (S n) (fun r' ⇒ bigop (S n) (fun s' ⇒
            ⟨ ⟨ x ⟩_ r' × ⟨ y ⟩_ s' ⟩_ ((r' - s') + (s' - r')))))
        { dot_from_grade_parts }
      == (⟨ x × y ⟩_ ((r - s) + (s - r)))
        { (graded_double_sum_collapse (fun r' s' ⇒ ((r' - s') + (s' - r'))%nat)
            r s x y Hr Hs Hx Hy) }.
  Qed.

End HomogeneousProducts.
