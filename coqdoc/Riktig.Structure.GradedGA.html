Library Riktig.Structure.GradedGA

From Riktig.Structure Require Export GradeInvolution Graded Reversal.

A geometric algebra with a grading and a reversal that agree with it: the unit has grade 0 and the grade-0 part of anything is a scalar multiple of the unit; a vector has grade 1; multiplying a grade-k part by a vector gives a part of grade one less and one more, and only grade 1 from grade 0; the grade involution and the reversal respect the grades, and the reversal respects scaling and leaves vectors alone.
Module GradedGA.
  Class GradedGA (N F V A : Type) `{GradeInvolution F V A} `{Naturals N} {natrecN : HasNatRec N} {NR : NatRec N natrecN}
      (grading : HasGrade N A) (top_grade : N) (scalar : HasScalarPart F A) (reversal : HasReverse A) := {
    graded :: Graded N F A grading top_grade;
    reversal :: Reversal A reversal;
    one_grade_zero : ⟨(1 : A)⟩_0 == 1;
    grade_zero_scalar : ∀ x : A, ⟨x⟩_0 == scalar_part x *: 1;
    vec_grade_one : ∀ u : V, ⟨vec u⟩_1 == vec u;
    vec_mul_grade_zero : ∀ (u : V) (x : A), vec u × ⟨x⟩_0 == ⟨vec u × ⟨x⟩_0⟩_1;
    vec_mul_grade_succ : ∀ (u : V) (x : A) (k : N),
      vec u × ⟨x⟩_(succ k) == ⟨vec u × ⟨x⟩_(succ k)⟩_k + ⟨vec u × ⟨x⟩_(succ k)⟩_(succ (succ k));
    involute_grade : ∀ (k : N) (x : A), involute ⟨x⟩_k == ⟨involute x⟩_k;
    reverse_grade : ∀ (k : N) (x : A), reverse ⟨x⟩_k == ⟨reverse x⟩_k;
    reverse_homogeneous :: Homogeneous F A A scale (fun a ⇒ a) reverse;
    reverse_vec : ∀ u : V, reverse (vec u) == vec u;
  }.

End GradedGA.
