Programs on lists, written as arrows in any bicartesian category: each is one fold, and none mentions an element.
Section Programs.
  Context {O : Type} `{Bicartesian O} {K : Type} {den : K → O} {x : K} {L : O}
    {lb : HasBuild O (List.shape den x) L} {lf : HasCata O (List.shape den x) L}
    `{!List O den x L lb lf}.

Taking a list apart: nothing, or its head beside its tail.
  Definition uncons : L ~> List.shape den x L :=
    List.fold (List.shape den x L) (List.map build).
End Programs.

Section FirstOr.
  Context {O : Type} `{Bicartesian O} {K : Type} {den : K → O} {x : K} {L : O}
    {lb : HasBuild O (List.shape den x) L} {lf : HasCata O (List.shape den x) L}
    `{!List O den x L lb lf} {B : O}.
  Local Open Scope object_scope.

Reading only the front of a list: the answer at its first element, or the default when there is none.
  Definition first_or (d : 1 ~> B) (f : den x ~> B) : L ~> B :=
    List.fold B (desc d (f ∘ pi1)).
End FirstOr.

    `{!NaturalNumbers O N nb nf}.

How long a list is, counted in the natural numbers of the same category.
  Definition length : L ~> N :=
    List.fold N (desc NaturalNumbers.zero (NaturalNumbers.succ ∘ pi2)).
End Counting.

Applying an arrow to every element.
  Definition map (f : den x ~> den y) : L ~> M :=
    List.fold M (desc List.nil (List.cons ∘ (f ×× cat_id))).
End Mapping.
