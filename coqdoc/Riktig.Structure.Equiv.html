An equivalence of setoids: a map and its inverse, each respecting equality, cancelling each way.
Module Equiv.
  Class Equiv (A B : Type) {eqA : EqRel A} {eqB : EqRel B} (to : A → B) (from : B → A) := {
    to_proper :: Proper (equ ==> equ) to;
    from_proper :: Proper (equ ==> equ) from;
    from_to : ∀ a : A, from (to a) == a;
    to_from : ∀ b : B, to (from b) == b;
  }.
End Equiv.
Export Equiv(Equiv).
#[export] Existing Instances Equiv.to_proper Equiv.from_proper.

A permutation of a carrier is an equivalence of it with itself.
Notation Permutation I p q := (Equiv I I p q).
