Parallel substitution over the typed-term algebra: a substitution is a function from variables to terms, a fold answers a function of the substitution so it can be lifted under each binder, and the annotation rides along untouched.
Section Subst.
  Context {N Ty T : Type} `{TypedTermRec N Ty T} `{NatRec N}.

Lifting a renaming past a binder: the bound variable stays, and every other is renamed one level out.
  Definition sup_ren (r : N → N) : N → N :=
    fun n ⇒ natrec N 0 (fun m _ ⇒ succ (r m)) n.

Renaming, as a fold that answers a function of the renaming.
  Definition srename (t : T) : (N → N) → T :=
    stermrec ((N → N) → T)
      (fun n r ⇒ var (r n))
      (fun A b r ⇒ tylam A (b (sup_ren r)))
      (fun f a r ⇒ app (f r) (a r))
      t.

Making room for one more variable.
  Definition sshift (t : T) : T := srename t (fun n : N ⇒ succ n).

Lifting a substitution past a binder.
  Definition sup_subst (s : N → T) : N → T :=
    fun n ⇒ natrec T (var 0) (fun m _ ⇒ sshift (s m)) n.

  Definition ssubst (t : T) : (N → T) → T :=
    stermrec ((N → T) → T)
      (fun n s ⇒ s n)
      (fun A b s ⇒ tylam A (b (sup_subst s)))
      (fun f a s ⇒ app (f s) (a s))
      t.

The substitution that replaces the bound variable and lowers the rest: what a beta step applies.
  Definition sbeta_subst (u : T) : N → T :=
    fun n ⇒ natrec T u (fun m _ ⇒ var m) n.

  Definition ssubst0 (b u : T) : T := ssubst b (sbeta_subst u).

One beta step anywhere in a term, and the reduction and conversion it generates.
  Inductive sstep : T → T → Prop :=
    | sstep_beta : ∀ (A : Ty) (b u : T), sstep (app (tylam A b) u) (ssubst0 b u)
    | sstep_lam : ∀ (A : Ty) (b b' : T), sstep b b' → sstep (tylam A b) (tylam A b')
    | sstep_app_l : ∀ f f' a : T, sstep f f' → sstep (app f a) (app f' a)
    | sstep_app_r : ∀ f a a' : T, sstep a a' → sstep (app f a) (app f a').

  Inductive ssteps : T → T → Prop :=
    | ssteps_refl : ∀ t : T, ssteps t t
    | ssteps_step : ∀ t u v : T, sstep t u → ssteps u v → ssteps t v.

  Definition sjoinable (t u : T) : Prop := ∃ w : T, ssteps t w ∧ ssteps u w.

Typing: a context is the types of the variables in scope, looked up by index and extended under a binder by the same recursion that lifts a substitution.
  Definition sextend (A : Ty) (g : N → Ty) : N → Ty :=
    fun n ⇒ natrec Ty A (fun m _ ⇒ g m) n.

  Context {arrowTy : HasArrow Ty}.

  Inductive styped : (N → Ty) → T → Ty → Prop :=
    | styped_var : ∀ (g : N → Ty) (n : N), styped g (var n) (g n)
    | styped_lam : ∀ (g : N → Ty) (A C : Ty) (b : T),
        styped (sextend A g) b C → styped g (tylam A b) (A --> C)
    | styped_app : ∀ (g : N → Ty) (A C : Ty) (f a : T),
        styped g f (A --> C) → styped g a A → styped g (app f a) C.
End Subst.
