Library Riktig.Examples.Category

From Riktig Require Import Theory.Exponentials Impl.CategoryFun.

Over any cartesian closed category: swapping the factors of a product, and applying an arrow twice, written without elements.
Section OverAnyCartesianClosed.
  Context {O : Type} `{CartesianClosed O}.

  Definition swap {a b : O} : a ⨯ b ~> b ⨯ a := lift pi2 pi1.

  Definition twice {a : O} : (a ⟹ a) ~> (a ⟹ a) := curry (eval ∘ lift pi1 eval).
End OverAnyCartesianClosed.

At Coq's types the arrows are functions, and they compute.
Example swap_at_types :
  (swap (O := Type) : nat × bool → bool × nat) (1, true)%nat = (true, 1)%nat.
Proof. reflexivity. Qed.

Example twice_at_types :
  (twice (O := Type) : (nat → nat) → nat → nat) (fun n ⇒ n + 1)%nat 5%nat = 7%nat.
Proof. reflexivity. Qed.

And the theorems apply as they stand: swapping twice is the identity.
Example swap_swap_at_types : ∀ p : nat × bool,
  (swap (O := Type) : bool × nat → nat × bool) ((swap (O := Type) : nat × bool → bool × nat) p) = p.
Proof. exact (swap_swap (O := Type) nat bool). Qed.
