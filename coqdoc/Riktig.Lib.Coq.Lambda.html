Lambda terms with de Bruijn variables and named constants, a context of named definitions, and a call-by-value evaluator with closures. A constant is looked up in the context -- the delta rule -- and one that is not defined is inert: applying it just collects the arguments. Evaluation takes fuel, since a term need not terminate.
Inductive term : Type :=
  | Var (n : nat)
  | Lam (body : term)
  | App (f a : term)
  | Const (x : string).

Inductive value : Type :=
  | Clo (env : list value) (body : term)
  | Neu (x : string) (args : list value).

Definition ctx : Type := list (string × term).

Fixpoint lookup (x : string) (G : ctx) : option term :=
  match G with
  | [] ⇒ None
  | (y, t) :: G' ⇒ if String.eqb x y then Some t else lookup x G'
  end.

Fixpoint eval (G : ctx) (fuel : nat) (env : list value) (t : term) : option value :=
  match fuel with
  | 0 ⇒ None
  | S fuel ⇒
    match t with
    | Var n ⇒ nth_error env n
    | Lam b ⇒ Some (Clo env b)
    | Const x ⇒ match lookup x G with
                 | Some t' ⇒ eval G fuel [] t'
                 | None ⇒ Some (Neu x [])
                 end
    | App f a ⇒
      match eval G fuel env f with
      | Some vf ⇒
        match eval G fuel env a with
        | Some va ⇒
          match vf with
          | Clo env' b ⇒ eval G fuel (va :: env') b
          | Neu x args ⇒ Some (Neu x (args ++ [va]))
          end
        | None ⇒ None
        end
      | None ⇒ None
      end
    end
  end.

Church numerals: n is fun f x ⇒ f (... (f x)).
Fixpoint church_body (n : nat) : term :=
  match n with 0 ⇒ Var 0 | S n ⇒ App (Var 1) (church_body n) end.
Definition church (n : nat) : term := Lam (Lam (church_body n)).

Reading a numeral back: apply it to the inert constants S and Z and count.
Fixpoint count_S (v : value) : option nat :=
  match v with
  | Neu x [] ⇒ if String.eqb x "Z" then Some 0 else None
  | Neu x [v'] ⇒ if String.eqb x "S" then option_map S (count_S v') else None
  | _ ⇒ None
  end.

Definition eval_numeral (G : ctx) (fuel : nat) (t : term) : option nat :=
  match eval G fuel [] (App (App t (Const "S")) (Const "Z")) with
  | Some v ⇒ count_S v
  | None ⇒ None
  end.

Terms with names, as written, and their resolution to de Bruijn indices: a name bound by an enclosing lambda becomes its index, any other name a constant, and a number its Church numeral.
Inductive named : Type :=
  | NVar (x : string)
  | NLam (x : string) (body : named)
  | NApp (f a : named)
  | NNum (n : nat).

Fixpoint index_of (x : string) (bound : list string) : option nat :=
  match bound with
  | [] ⇒ None
  | y :: bound' ⇒ if String.eqb x y then Some 0 else option_map S (index_of x bound')
  end.

Fixpoint resolve (bound : list string) (t : named) : term :=
  match t with
  | NVar x ⇒ match index_of x bound with Some n ⇒ Var n | None ⇒ Const x end
  | NLam x b ⇒ Lam (resolve (x :: bound) b)
  | NApp f a ⇒ App (resolve bound f) (resolve bound a)
  | NNum n ⇒ church n
  end.
