Decisions that transport between structures. A carrier whose elements embed in one with decided equality has its own decided: compare the images. This is the argument behind the decision on a finite index, which compares the numbers the elements are given. The proof is Defined, so a decision built this way still reduces on a concrete carrier.
Theorem equdec_of_injective (A B : Type) {eqA : EqRel A} {eqB : EqRel B} {EB : EquDec B}
    (f : A → B) {Pf : Proper (equ ==> equ) f} {If : Injective A B f} : EquDec A.
Proof.
  intros a b.
  destruct (EquDec.equ_dec (f a) (f b)) as [Hf | Hf];
    [ left; exact (injective a b Hf) | right; intros Hab; exact (Hf (Pf a b Hab)) ].
Defined.

Branching on a decision reads off the branch the facts select; the case analysis on the decision happens here, once.
Section Branch.
  Context {A : Type} {eqA : EqRel A} {EA : Equivalence eqA}.

  Theorem if_dec_l : ∀ (P : Prop) {D : Decidable P} (a b : A),
    P → (if dec P then a else b) == a.
  Proof. intros P D a b HP. destruct (dec P) as [_ | HnP]; [ reflexivity | destruct (HnP HP) ]. Qed.

  Theorem if_dec_r : ∀ (P : Prop) {D : Decidable P} (a b : A),
    ¬ P → (if dec P then a else b) == b.
  Proof. intros P D a b HnP. destruct (dec P) as [HP | _]; [ destruct (HnP HP) | reflexivity ]. Qed.

  Theorem if_dec_proper : ∀ (P P' : Prop) {D : Decidable P} {D' : Decidable P'} (a b : A),
    (P ↔ P') → (if dec P then a else b) == (if dec P' then a else b).
  Proof.
    intros P P' D D' a b HPP'. symmetry. destruct (dec P) as [HP | HnP];
      [ exact (if_dec_l P' a b (proj1 HPP' HP)) | exact (if_dec_r P' a b (fun HP' ⇒ HnP (proj2 HPP' HP'))) ].
  Qed.

  Theorem if_dec_congr : ∀ (P P' : Prop) {D : Decidable P} {D' : Decidable P'} (a a' b b' : A),
    (P ↔ P') → a == a' → b == b' → (if dec P then a else b) == (if dec P' then a' else b').
  Proof.
    intros P P' D D' a a' b b' HPP' Ha Hb. destruct (dec P) as [HP | HnP].
    - calc a == a' { Ha } == (if dec P' then a' else b') { (if_dec_l P' a' b' (proj1 HPP' HP)) }.
    - calc b == b' { Hb } == (if dec P' then a' else b') { (if_dec_r P' a' b' (fun HP' ⇒ HnP (proj2 HPP' HP'))) }.
  Qed.
End Branch.
