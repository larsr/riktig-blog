In a graded geometric algebra the grade-0 part of a product of two vectors is their inner product, and the grade-2 part is their wedge: the product of two vectors is u ⋅ v + u ∧ v, grade by grade.
Section GradedGATheory.
  Context {N F V A : Type} `{GradedGA N F V A}.

  Theorem scalar_grade_zero : ∀ a : F, ⟨a *: (1 : A)⟩_0 == a *: 1.
  Proof.
    intros a.
    calc (⟨a *: (1 : A)⟩_0) == (a *: ⟨(1 : A)⟩_0) { (grade_smul 0 a (1 : A)) } == (a *: (1 : A)) { GradedGA.one_grade_zero }.
  Qed.

  Theorem reverse_grade_zero : ∀ x : A, reverse ⟨x⟩_0 == ⟨x⟩_0.
  Proof.
    intros x.
    calc (reverse ⟨x⟩_0)
      == (reverse (scalar_part x *: (1 : A))) { (Reversal.reverse_proper _ _ (GradedGA.grade_zero_scalar x)) }
      == (scalar_part x *: reverse (1 : A)) { (homogeneous (f := reverse) (scalar_part x) (1 : A)) }
      == (scalar_part x *: (1 : A)) { (ScaleLaws.scale_proper _ _ (reflexivity _) _ _ reverse_one) }
      == (⟨x⟩_0) { (symmetry (GradedGA.grade_zero_scalar x)) }.
  Qed.

  Theorem grade_zero_reverse : ∀ x : A, ⟨reverse x⟩_0 == ⟨x⟩_0.
  Proof.
    intros x.
    calc (⟨reverse x⟩_0) == (reverse ⟨x⟩_0) { (symmetry (GradedGA.reverse_grade 0 x)) } == (⟨x⟩_0) { (reverse_grade_zero x) }.
  Qed.

  Theorem reverse_vec_mul : ∀ u v : V, reverse (vec u × vec v) == vec v × vec u.
  Proof.
    intros u v.
    calc (reverse (vec u × vec v))
      == (reverse (vec v) × reverse (vec u)) { (antiadditive[reverse] (vec u) (vec v)) }
      == (vec v × vec u) { (Magma.op_proper _ _ (GradedGA.reverse_vec v) _ _ (GradedGA.reverse_vec u)) }.
  Qed.

Pure-grade components: a scaled grade-k part stays pure.

  Lemma grade_pure_smul : ∀ (k : N) (c : F) (y : A), c *: ⟨y⟩_k == ⟨c *: ⟨y⟩_k⟩_k.
  Proof.
    intros k c y.
    calc (c *: ⟨y⟩_k)
      == (c *: ⟨⟨y⟩_k⟩_k) { (ScaleLaws.scale_proper _ _ (reflexivity c) _ _ (symmetry (Graded.grade_idempotent k y))) }
      == (⟨c *: ⟨y⟩_k⟩_k) { (symmetry (grade_smul k c ⟨y⟩_k)) }.
  Qed.

  Lemma grade_pure_orth : ∀ (k l : N) (c : F) (y : A), k =/= l → ⟨c *: ⟨y⟩_l⟩_k == 0.
  Proof.
    intros k l c y Hkl.
    calc (⟨c *: ⟨y⟩_l⟩_k)
      == (c *: ⟨⟨y⟩_l⟩_k) { (grade_smul k c ⟨y⟩_l) }
      == (c *: (0 : A)) { (ScaleLaws.scale_proper _ _ (reflexivity c) _ _ (Graded.grade_orthogonal k l y Hkl)) }
      == (0 : A) { (smul_zero c) }.
  Qed.

  Local Notation "'low' k b" := (natrec A 0 (fun (j : N) (_ : A) ⇒ ⟨b⟩_j) k) (at level 10, k at level 9, b at level 9).

A vector times a grade-k part splits into the part one below and the part one above -- uniformly in k, the one below read through low.
  Lemma vec_mul_grade_low : ∀ (u : V) (y : A) (k : N),
    vec u × ⟨y⟩_k == low k (vec u × ⟨y⟩_k) + ⟨vec u × ⟨y⟩_k⟩_(succ k).
  Proof.
    intros u y k. destruct (zero_or_succ k) as [Hk | [m Hk]].
    - assert (Hy : ⟨y⟩_k == ⟨y⟩_0) by exact (Graded.grade_index_proper k 0 y Hk).
      assert (HX : vec u × ⟨y⟩_k == vec u × ⟨y⟩_0) by exact (Magma.op_proper _ _ (reflexivity (vec u)) _ _ Hy).
      assert (Hlow : low k (vec u × ⟨y⟩_k) == 0).
      { apply (transitivity (low_index_proper k 0 _ Hk)). exact (low_zero _). }
      assert (Hup : ⟨vec u × ⟨y⟩_k⟩_(succ k) == ⟨vec u × ⟨y⟩_0⟩_(succ 0)).
      { apply (transitivity (Graded.grade_index_proper (succ k) (succ 0) _ (Peano.succ_proper _ _ Hk))).
        exact (grade_proper (succ 0) _ _ HX). }
      calc (vec u × ⟨y⟩_k)
        == (vec u × ⟨y⟩_0) { HX }
        == (⟨vec u × ⟨y⟩_0⟩_(succ 0)) { (GradedGA.vec_mul_grade_zero u y) }
        == (0 + ⟨vec u × ⟨y⟩_0⟩_(succ 0)) { (symmetry (left_identity (action := add) _)) }
        == (low k (vec u × ⟨y⟩_k) + ⟨vec u × ⟨y⟩_0⟩_(succ 0)) { (Magma.op_proper _ _ (symmetry Hlow) _ _ (reflexivity _)) }
        == (low k (vec u × ⟨y⟩_k) + ⟨vec u × ⟨y⟩_k⟩_(succ k)) { (Magma.op_proper _ _ (reflexivity _) _ _ (symmetry Hup)) }.
    - assert (Hy : ⟨y⟩_k == ⟨y⟩_(succ m)) by exact (Graded.grade_index_proper k (succ m) y Hk).
      assert (HX : vec u × ⟨y⟩_k == vec u × ⟨y⟩_(succ m)) by exact (Magma.op_proper _ _ (reflexivity (vec u)) _ _ Hy).
      assert (Hlow : low k (vec u × ⟨y⟩_k) == ⟨vec u × ⟨y⟩_(succ m)⟩_m).
      { apply (transitivity (low_index_proper k (succ m) _ Hk)).
        apply (transitivity (low_succ m _)). exact (grade_proper m _ _ HX). }
      assert (Hup : ⟨vec u × ⟨y⟩_k⟩_(succ k) == ⟨vec u × ⟨y⟩_(succ m)⟩_(succ (succ m))).
      { apply (transitivity (Graded.grade_index_proper (succ k) (succ (succ m)) _ (Peano.succ_proper _ _ Hk))).
        exact (grade_proper (succ (succ m)) _ _ HX). }
      calc (vec u × ⟨y⟩_k)
        == (vec u × ⟨y⟩_(succ m)) { HX }
        == (⟨vec u × ⟨y⟩_(succ m)⟩_m + ⟨vec u × ⟨y⟩_(succ m)⟩_(succ (succ m))) { (GradedGA.vec_mul_grade_succ u y m) }
        == (low k (vec u × ⟨y⟩_k) + ⟨vec u × ⟨y⟩_(succ m)⟩_(succ (succ m))) { (Magma.op_proper _ _ (symmetry Hlow) _ _ (reflexivity _)) }
        == (low k (vec u × ⟨y⟩_k) + ⟨vec u × ⟨y⟩_k⟩_(succ k)) { (Magma.op_proper _ _ (reflexivity _) _ _ (symmetry Hup)) }.
  Qed.

Nothing pure one grade above k survives low k.
  Lemma low_of_pure_above : ∀ (k : N) (c : F) (y : A), low k (c *: ⟨y⟩_(succ k)) == 0.
  Proof.
    intros k c y. destruct (zero_or_succ k) as [Hk | [m Hk]].
    - calc (low k (c *: ⟨y⟩_(succ k)))
        == (low 0 (c *: ⟨y⟩_(succ k))) { (low_index_proper k 0 _ Hk) }
        == (0 : A) { (low_zero _) }.
    - calc (low k (c *: ⟨y⟩_(succ k)))
        == (low (succ m) (c *: ⟨y⟩_(succ k))) { (low_index_proper k (succ m) _ Hk) }
        == (⟨c *: ⟨y⟩_(succ k)⟩_m) { (low_succ m _) }
        == (⟨c *: ⟨y⟩_(succ (succ m))⟩_m)
             { (grade_proper m _ _ (ScaleLaws.scale_proper _ _ (reflexivity c) _ _
                  (Graded.grade_index_proper (succ k) (succ (succ m)) y (Peano.succ_proper _ _ Hk)))) }
        == (0 : A) { (grade_pure_orth m (succ (succ m)) c y (ne_succ_succ m)) }.
  Qed.

What a doubled algebra asks of its halves: products with a

scaled unit and an involuted grade part, and low under the involution and the reversal.

  Lemma smul_one_mul_involute_grade : ∀ (c : F) (k : N) (a : A),
    (c *: (1 : A)) × involute ⟨a⟩_k == c *: ⟨involute a⟩_k.
  Proof.
    intros c k a.
    calc ((c *: (1 : A)) × involute ⟨a⟩_k)
      == (c *: involute ⟨a⟩_k) { (smul_one_mul c _) }
      == (c *: ⟨involute a⟩_k) { (ScaleLaws.scale_proper _ _ (reflexivity c) _ _ (GradedGA.involute_grade k a)) }.
  Qed.

  Lemma add_smul_involute_zero : ∀ (x : A) (s c : F),
    x + s *: ((c *: (1 : A)) × involute (0 : A)) == x.
  Proof.
    intros x s c.
    calc (x + s *: ((c *: (1 : A)) × involute (0 : A)))
      == (x + s *: ((c *: (1 : A)) × (0 : A)))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (ScaleLaws.scale_proper _ _ (reflexivity s) _ _ (Magma.op_proper _ _ (reflexivity _) _ _ involute_zero))) }
      == (x + s *: (0 : A))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (ScaleLaws.scale_proper _ _ (reflexivity s) _ _ (Theory.Ring.mul_zero (c *: (1 : A))))) }
      == (x + (0 : A))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (smul_zero s)) }
      == x
           { (right_identity (action := add) x) }.
  Qed.

  Lemma mul_zero_add_smul_involute : ∀ (y a : A) (c : F) (k : N),
    y × 0 + (c *: (1 : A)) × involute ⟨a⟩_k == c *: ⟨involute a⟩_k.
  Proof.
    intros y a c k.
    calc (y × 0 + (c *: (1 : A)) × involute ⟨a⟩_k)
      == ((0 : A) + (c *: (1 : A)) × involute ⟨a⟩_k) { (Magma.op_proper _ _ (Theory.Ring.mul_zero y) _ _ (reflexivity _)) }
      == ((c *: (1 : A)) × involute ⟨a⟩_k) { (left_identity (action := add) _) }
      == (c *: ⟨involute a⟩_k) { (smul_one_mul_involute_grade c k a) }.
  Qed.

  Lemma smul_smul_involute_grade : ∀ (s c : F) (k : N) (b : A),
    s *: ((c *: (1 : A)) × involute ⟨b⟩_k) == (s × c) *: ⟨involute b⟩_k.
  Proof.
    intros s c k b.
    calc (s *: ((c *: (1 : A)) × involute ⟨b⟩_k))
      == (s *: (c *: ⟨involute b⟩_k)) { (ScaleLaws.scale_proper _ _ (reflexivity s) _ _ (smul_one_mul_involute_grade c k b)) }
      == ((s × c) *: ⟨involute b⟩_k) { (symmetry (associative (op := mult) (action := scale) s c _)) }.
  Qed.

  Lemma smul_involute_grade_split : ∀ (s c : F) (k : N) (b : A),
    s *: ((c *: (1 : A)) × involute ⟨b⟩_k)
    == ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k
       + ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)).
  Proof.
    intros s c k b.
    assert (Hk : ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k == s *: ((c *: (1 : A)) × involute ⟨b⟩_k)).
    { calc (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k)
        == (⟨(s × c) *: ⟨involute b⟩_k⟩_k) { (grade_proper k _ _ (smul_smul_involute_grade s c k b)) }
        == ((s × c) *: ⟨involute b⟩_k) { (symmetry (grade_pure_smul k (s × c) (involute b))) }
        == (s *: ((c *: (1 : A)) × involute ⟨b⟩_k)) { (symmetry (smul_smul_involute_grade s c k b)) }. }
    assert (Hss : ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)) == 0).
    { calc (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)))
        == (⟨(s × c) *: ⟨involute b⟩_k⟩_(succ (succ k))) { (grade_proper (succ (succ k)) _ _ (smul_smul_involute_grade s c k b)) }
        == (0 : A) { (grade_pure_orth (succ (succ k)) k (s × c) (involute b) (ne_succ_succ' k)) }. }
    calc (s *: ((c *: (1 : A)) × involute ⟨b⟩_k))
      == (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k) { (symmetry Hk) }
      == (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k + 0) { (symmetry (right_identity (action := add) _)) }
      == (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k + ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (symmetry Hss)) }.
  Qed.

  Lemma vec_mul_grade_succ_split : ∀ (v : V) (a b : A) (s c : F) (k : N),
    vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k)
    == ⟨vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k
       + ⟨vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)).
  Proof.
    intros v a b s c k.
    calc (vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k))
      == ((⟨vec v × ⟨a⟩_(succ k)⟩_k + ⟨vec v × ⟨a⟩_(succ k)⟩_(succ (succ k))) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k))
           { (Magma.op_proper _ _ (GradedGA.vec_mul_grade_succ v a k) _ _ (reflexivity _)) }
      == ((⟨vec v × ⟨a⟩_(succ k)⟩_k + ⟨vec v × ⟨a⟩_(succ k)⟩_(succ (succ k)))
          + (⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k + ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k))))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (smul_involute_grade_split s c k b)) }
      == ((⟨vec v × ⟨a⟩_(succ k)⟩_k + ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k)
          + (⟨vec v × ⟨a⟩_(succ k)⟩_(succ (succ k)) + ⟨s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k))))
           { (add_add_add_comm _ _ _ _) }
      == (⟨vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_k
          + ⟨vec v × ⟨a⟩_(succ k) + s *: ((c *: (1 : A)) × involute ⟨b⟩_k)⟩_(succ (succ k)))
           { (Magma.op_proper _ _ (symmetry (grade_add k _ _)) _ _ (symmetry (grade_add (succ (succ k)) _ _))) }.
  Qed.

  Lemma vec_mul_low_split : ∀ (v : V) (a b : A) (c : F) (k : N),
    vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k)
    == low k (vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k))
       + ⟨vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k).
  Proof.
    intros v a b c k.
    assert (Hlow : low k ((c *: (1 : A)) × involute ⟨a⟩_(succ k)) == 0).
    { calc (low k ((c *: (1 : A)) × involute ⟨a⟩_(succ k)))
        == (low k (c *: ⟨involute a⟩_(succ k))) { (low_proper k _ _ (smul_one_mul_involute_grade c (succ k) a)) }
        == (0 : A) { (low_of_pure_above k c (involute a)) }. }
    assert (Hgr : ⟨(c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k) == (c *: (1 : A)) × involute ⟨a⟩_(succ k)).
    { calc (⟨(c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k))
        == (⟨c *: ⟨involute a⟩_(succ k)⟩_(succ k)) { (grade_proper (succ k) _ _ (smul_one_mul_involute_grade c (succ k) a)) }
        == (c *: ⟨involute a⟩_(succ k)) { (symmetry (grade_pure_smul (succ k) c (involute a))) }
        == ((c *: (1 : A)) × involute ⟨a⟩_(succ k)) { (symmetry (smul_one_mul_involute_grade c (succ k) a)) }. }
    calc (vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k))
      == ((low k (vec v × ⟨b⟩_k) + ⟨vec v × ⟨b⟩_k⟩_(succ k)) + (c *: (1 : A)) × involute ⟨a⟩_(succ k))
           { (Magma.op_proper _ _ (vec_mul_grade_low v b k) _ _ (reflexivity _)) }
      == ((low k (vec v × ⟨b⟩_k) + ⟨vec v × ⟨b⟩_k⟩_(succ k))
          + (low k ((c *: (1 : A)) × involute ⟨a⟩_(succ k)) + ⟨(c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k)))
           { (Magma.op_proper _ _ (reflexivity _) _ _ (symmetry (transitivity (Magma.op_proper _ _ Hlow _ _ Hgr) (left_identity (action := add) _)))) }
      == ((low k (vec v × ⟨b⟩_k) + low k ((c *: (1 : A)) × involute ⟨a⟩_(succ k)))
          + (⟨vec v × ⟨b⟩_k⟩_(succ k) + ⟨(c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k)))
           { (add_add_add_comm _ _ _ _) }
      == (low k (vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k))
          + ⟨vec v × ⟨b⟩_k + (c *: (1 : A)) × involute ⟨a⟩_(succ k)⟩_(succ k))
           { (Magma.op_proper _ _ (symmetry (low_add k _ _)) _ _ (symmetry (grade_add (succ k) _ _))) }.
  Qed.

  Lemma involute_low : ∀ (k : N) (b : A),
    involute (low k b) == low k (involute b).
  Proof.
    intros k b. destruct (zero_or_succ k) as [Hk | [m Hk]].
    - calc (involute (low k b))
        == (involute (low 0 b)) { (GradeInvolution.involute_proper _ _ (low_index_proper k 0 b Hk)) }
        == (involute (0 : A)) { (GradeInvolution.involute_proper _ _ (low_zero b)) }
        == (0 : A) { involute_zero }
        == (low 0 (involute b)) { (symmetry (low_zero (involute b))) }
        == (low k (involute b)) { (low_index_proper 0 k (involute b) (symmetry Hk)) }.
    - calc (involute (low k b))
        == (involute (low (succ m) b)) { (GradeInvolution.involute_proper _ _ (low_index_proper k (succ m) b Hk)) }
        == (involute ⟨b⟩_m) { (GradeInvolution.involute_proper _ _ (low_succ m b)) }
        == (⟨involute b⟩_m) { (GradedGA.involute_grade m b) }
        == (low (succ m) (involute b)) { (symmetry (low_succ m (involute b))) }
        == (low k (involute b)) { (low_index_proper (succ m) k (involute b) (symmetry Hk)) }.
  Qed.

  Lemma neg_involute_low : ∀ (k : N) (b : A),
    - involute (low k b) == low k (- involute b).
  Proof.
    intros k b.
    calc (- involute (low k b))
      == (- (low k (involute b))) { (Group.neg_proper _ _ (involute_low k b)) }
      == (low k (- involute b)) { (symmetry (low_neg k (involute b))) }.
  Qed.

  Lemma involute_reverse_low : ∀ (k : N) (b : A),
    involute (reverse (low k b)) == low k (involute (reverse b)).
  Proof.
    intros k b. destruct (zero_or_succ k) as [Hk | [m Hk]].
    - calc (involute (reverse (low k b)))
        == (involute (reverse (low 0 b))) { (GradeInvolution.involute_proper _ _ (Reversal.reverse_proper _ _ (low_index_proper k 0 b Hk))) }
        == (involute (reverse (0 : A))) { (GradeInvolution.involute_proper _ _ (Reversal.reverse_proper _ _ (low_zero b))) }
        == (involute (0 : A)) { (GradeInvolution.involute_proper _ _ reverse_zero) }
        == (0 : A) { involute_zero }
        == (low 0 (involute (reverse b))) { (symmetry (low_zero _)) }
        == (low k (involute (reverse b))) { (low_index_proper 0 k _ (symmetry Hk)) }.
    - calc (involute (reverse (low k b)))
        == (involute (reverse (low (succ m) b))) { (GradeInvolution.involute_proper _ _ (Reversal.reverse_proper _ _ (low_index_proper k (succ m) b Hk))) }
