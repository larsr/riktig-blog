Programs written by branching on decided propositions, in the plain style: if dec (a < b) then ... else .... The first is over any carrier with a decided strict order, and runs at Coq's naturals and rationals alike.
Definition max3 {A : Type} {eqA : EqRel A} {le : HasLe A} {LA : LtDec A} (a b c : A) : A :=
  if dec (a < b) then (if dec (b < c) then c else b) else (if dec (a < c) then c else a).

Eval vm_compute in max3 3 7 5.
Eval vm_compute in (max3 0.5 0.25 0.4)%Q.

The evidence of the decision is available in the branches.
Definition larger {A : Type} {eqA : EqRel A} {le : HasLe A} {LA : LtDec A} (a b : A) : {a < b} + {¬ a < b} :=
  if dec (a < b) as H then left H else right H.

Over Coq's types, with the compound instances: lists of pairs are compared entry by entry, and a list is searched.
Definition same_table (t u : list (nat × bool)) : bool := if dec (t = u) then true else false.

Eval vm_compute in same_table [(1, true); (2, false)]%nat [(1, true); (2, false)]%nat.
Eval vm_compute in same_table [(1, true)]%nat [(1, false)]%nat.
Eval vm_compute in (if dec (In 3 [1; 2; 3]%nat) then "found" else "missing")%string.
Eval vm_compute in (if dec (Forall (fun n ⇒ (n < 5)%nat) [1; 2; 3]%nat) then "all small" else "one is large")%string.
