Programs written by branching on decided propositions, in the plain style: if dec (a < b) then ... else ...
Definition max3 {A : Type} {eqA : EqRel A} {leA : HasLe A} {LA : LtDec A} (a b c : A) : A :=
  if dec (a < b) then (if dec (b < c) then c else b) else (if dec (a < c) then c else a).

Eval vm_compute in max3 3 7 5.
Eval vm_compute in max3 0.5%Q 0.25%Q 0.4%Q.

The evidence of the decision is available in the branches.
Definition larger {A : Type} {eqA : EqRel A} {leA : HasLe A} {LA : LtDec A} (a b : A) : {a < b} + {¬ a < b} :=
  if dec (a < b) as H then left H else right H.

Over Coq's types, with the compound instances: lists of pairs are compared entry by entry, a list is searched, and a predicate is checked entry by entry.
Eval vm_compute in (if dec ([(1%nat, true); (2%nat, false)]%list = [(1%nat, true); (2%nat, false)]%list) then true else false).
Eval vm_compute in (if dec ([(1%nat, true)]%list = [(1%nat, false)]%list) then true else false).
Eval vm_compute in if dec (3%nat ∈ [1%nat; 2%nat; 3%nat]%list) then "found"%string else "missing"%string.
Eval vm_compute in if dec (Forall (fun n ⇒ n < 5%nat) [1%nat; 2%nat; 3%nat]%list) then "all small"%string else "one is large"%string.

Up to a carrier's own equality, not Coq's: membership in a list, equality of lists, and freedom from repeats are all decided as soon as the elements are. Membership in the list of spaces tests a character for being a space.
Eval vm_compute in (if dec (" "%char ∈ [" "%char; "010"%char; "013"%char; "009"%char]%list) then true else false).
Eval vm_compute in (if dec ("a"%char ∈ [" "%char; "010"%char; "013"%char; "009"%char]%list) then true else false).
Eval vm_compute in if dec (eqlistA equ [1%nat; 2%nat; 3%nat]%list [1%nat; 2%nat; 3%nat]%list) then "same"%string else "different"%string.
Eval vm_compute in if dec (NoDupA equ [1%nat; 2%nat; 2%nat]%list) then "distinct"%string else "a repeat"%string.
