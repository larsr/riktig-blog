Gibbons' example (arXiv:2111.10413, section 5): the expression (3 - 4) - 5 over a language of literals and subtraction. Subtraction is deliberately not associative, so nothing in the development may lean on the source operator; what the compiler leans on is the associativity of concatenating code.
Definition sub_compiler := Code_Compiler (fun a b : Z ⇒ a - b).
#[local] Existing Instance sub_compiler | 0.

Definition e357 : expr Z := node (node (lit 3%Z) (lit 4%Z)) (lit 5%Z).

The source operator is not associative.
Example sub_not_associative : (3%Z - 4%Z) - 5%Z =/= 3%Z - (4%Z - 5%Z).
Proof. vm_compute. discriminate. Qed.

Read directly, the expression is -6.
Example evaluates : expr_eval (fun a b : Z ⇒ a - b) e357 == - 6%Z.
Proof. vm_compute. reflexivity. Qed.

Compiled, it is a bytecode: push, push, subtract, push, subtract the sequence the paper prints for compile4 expr.
Eval vm_compute in expr_compile e357.

Example compiles : expr_compile e357 = [PushI 3%Z; PushI 4%Z; OpI; PushI 5%Z; OpI]%list.
Proof. vm_compute. reflexivity. Qed.

Run on the empty stack, the bytecode leaves the value.
Example runs : code_exec (fun a b : Z ⇒ a - b) (expr_compile e357) []%list = [- 6%Z]%list.
Proof. vm_compute. reflexivity. Qed.

The rotation is an equation about code, not about subtraction: the bracketing that follows the tree and the bracketing that reads as a linear sequence are the same program. This is the step of the development that no handle-turning supplies, and here it is one rewrite by the associativity of the code monoid.
Example rotates :
  expr_compile (node (lit 3%Z) (lit 4%Z) : expr Z) = (expr_compile (lit 3%Z : expr Z) + expr_compile (lit 4%Z : expr Z)) + [OpI]%list.
Proof. exact (compile_rotate (lit 3%Z) (lit 4%Z)). Qed.

And the abstract theorem lands here: the code leaves the value on top of whatever stack it was run on, proved once for every compiler of this shape and never inspecting the operator.
Example correct : ∀ s : list Z,
  code_exec (fun a b : Z ⇒ a - b) (expr_compile e357) s = (- 6%Z :: s)%list.
Proof. intros s. rewrite (compile_correct e357 s). reflexivity. Qed.

The same code and the same theorem at another operator: the naturals under addition, where associativity happens to hold but is still never used.
Definition add_compiler := Code_Compiler (fun a b : nat ⇒ a + b).
#[local] Existing Instance add_compiler | 0.

Definition e23 : expr nat := node (lit 2%nat) (lit 3%nat).

Example nat_compiles : expr_compile e23 = [PushI 2%nat; PushI 3%nat; OpI]%list.
Proof. vm_compute. reflexivity. Qed.

Example nat_correct : ∀ s : list nat, code_exec (fun a b : nat ⇒ a + b) (expr_compile e23) s = (5%nat :: s)%list.
Proof. intros s. rewrite (compile_correct e23 s). reflexivity. Qed.
