Library Riktig.Structure.LambdaType

From Coq Require Export Morphisms.
From Riktig Require Export Props.

The simple types over base types B: a base type embeds, arrows are formed; both respect equality, are injective, and a base type is never an arrow -- what a type checker needs to compare types.
Module LambdaType.
  Class LambdaType (B Ty : Type) {eqB : EqRel B} {eqTy : EqRel Ty}
      (base_ : HasBase B Ty) (arrow_ : HasArrow Ty) := {
    bases :: Equivalence (@equ B eqB);
    types :: Equivalence (@equ Ty eqTy);
    base_proper :: Proper (equ ==> equ) (@ty_base B Ty base_);
    arrow_proper :: Proper (equ ==> equ ==> equ) (@ty_arrow Ty arrow_);
    base_injective : ∀ x y : B, ty_base x == (ty_base y : Ty) → x == y;
    arrow_injective : ∀ A A' C C' : Ty, (A --> C) == (A' --> C') → A == A' ∧ C == C';
    base_not_arrow : ∀ (x : B) (A C : Ty), ty_base x =/= (A --> C);
  }.
  Hint Mode LambdaType - ! - - - - : typeclass_instances.
End LambdaType.
Export LambdaType.
