su(3): the eight Gell-Mann generators, the nine numbers that fix their brackets, and the Jacobi identity checked rather than assumed. Theory/SU3Algebra.v does the algebra for any structure-constant table; this file is the table, and the two facts it owes — antisymmetry in the first two indices, and a vanishing Jacobi sum on the generators — are settled here by construction and by computation respectively.


The values the table takes, as constructors rather than as field elements: zero, plus or minus one, plus or minus a half, plus or minus half a square root of three. A symbolic table is what makes both facts cheap — a sign change becomes a constructor swap, and the Jacobi check runs in nat with no field in sight.
Inductive sv : Set :=
  | Szero | Spos1 | Sneg1 | Sposh | Snegh | Sposr | Snegr.

Definition svneg (u : sv) : sv :=
  match u with
  | Szero ⇒ Szero
  | Spos1 ⇒ Sneg1 | Sneg1 ⇒ Spos1
  | Sposh ⇒ Snegh | Snegh ⇒ Sposh
  | Sposr ⇒ Snegr | Snegr ⇒ Sposr
  end.

Lemma svneg_involutive : ∀ u : sv, svneg (svneg u) = u.
Proof. intros u. destruct u; reflexivity. Qed.

The half of the table with its first index below its second: the twenty-seven entries with a < b, as a match on the three generator numbers with everything unlisted sent to zero. This is the standard table, as Georgi's Lie Algebras in Particle Physics prints it, with each unordered triple's three cyclic readings spelled out.

The whole table: below the diagonal it is the enumeration above read backwards and negated, and on the diagonal it is zero.
Definition scv (a b c : nat) : sv :=
  if Nat.ltb a b then scLT a b c
  else if Nat.ltb b a then svneg (scLT b a c)
  else Szero.

Antisymmetry in the first two indices, out of the construction. Both readings of a swapped pair reach the same entry of scLT and exactly one of them negates it, so nothing has to be enumerated: the fact holds of any scLT whatsoever.
Theorem scv_antisym : ∀ a b c : nat, scv a b c = svneg (scv b a c).
Proof.
  intros a b c. unfold scv.
  destruct (Nat.ltb a b) eqn:Hab; destruct (Nat.ltb b a) eqn:Hba.
  - exfalso.
    apply Nat.ltb_lt in Hab. apply Nat.ltb_lt in Hba. lia.
  - symmetry. exact (svneg_involutive (scLT a b c)).
  - reflexivity.
  - reflexivity.
Qed.

A product of two table entries, and any sum of such products, is (p - q)/4 + (r - s)*sqrt(3)/4 for four naturals. Two counters per component instead of one integer: adding is Nat.add and vanishing is p = q, so nothing below has to reason about subtraction.
Record quad : Set := Quad { qa : nat; qb : nat; qc : nat; qd : nat }.

Definition qzero : quad := Quad 0 0 0 0.

Definition qadd (u v : quad) : quad :=
  Quad (qa u + qa v) (qb u + qb v) (qc u + qc v) (qd u + qd v).

Definition qneg (u : quad) : quad := Quad (qb u) (qa u) (qd u) (qc u).

Definition qnull (u : quad) : bool :=
  Nat.eqb (qa u) (qb u) && Nat.eqb (qc u) (qd u).

The magnitudes an entry can have. Splitting an entry into a sign and a magnitude turns a forty-nine entry product table into a sixteen entry one, and leaves exactly one product — a square root of three against itself — that needs anything but ring arithmetic.
Inductive mag : Set := Mzero | Mone | Mhalf | Mroot.

Definition svmag (u : sv) : mag :=
  match u with
  | Szero ⇒ Mzero
  | Spos1 | Sneg1 ⇒ Mone
  | Sposh | Snegh ⇒ Mhalf
  | Sposr | Snegr ⇒ Mroot
  end.

Definition svpos (u : sv) : bool :=
  match u with Sneg1 | Snegh | Snegr ⇒ false | _ ⇒ true end.

Definition magmul (m k : mag) : quad :=
  match m, k with
  | Mzero, _ | _, Mzero ⇒ qzero
  | Mone, Mone ⇒ Quad 4 0 0 0
  | Mone, Mhalf | Mhalf, Mone ⇒ Quad 2 0 0 0
  | Mone, Mroot | Mroot, Mone ⇒ Quad 0 0 2 0
  | Mhalf, Mhalf ⇒ Quad 1 0 0 0
  | Mhalf, Mroot | Mroot, Mhalf ⇒ Quad 0 0 1 0
  | Mroot, Mroot ⇒ Quad 3 0 0 0
  end.

Definition svmul (u v : sv) : quad :=
  if Bool.eqb (svpos u) (svpos v)
  then magmul (svmag u) (svmag v)
  else qneg (magmul (svmag u) (svmag v)).

Fixpoint qsum (n : nat) (g : Fin.t n → quad) : quad :=
  match n return (Fin.t n → quad) → quad with
  | O ⇒ fun _ ⇒ qzero
  | S m ⇒ fun h ⇒ qadd (h Fin.F1) (qsum m (fun i ⇒ h (Fin.FS i)))
  end g.

The Jacobi sum of three generators at one output coordinate, as a quad: three contractions of the table with itself.
Definition jacq (i j k d : Fin.t 8) : quad :=
  qadd (qadd (qsum 8 (fun b ⇒ svmul (scf j k b) (scf i b d)))
             (qsum 8 (fun b ⇒ svmul (scf k i b) (scf j b d))))
       (qsum 8 (fun b ⇒ svmul (scf i j b) (scf k b d))).

The whole check as one boolean over the 4096 index quadruples. This is the finite verification the file exists to do; it used to be 56 named lemmas, each an eight-way case split closed by rewriting in the field.
Definition jacobi_check : bool :=
  forallb (fun i ⇒ forallb (fun j ⇒ forallb (fun k ⇒
    forallb (fun d ⇒ qnull (jacq i j k d)) (fin_all 8)) (fin_all 8))
      (fin_all 8)) (fin_all 8).

Lemma jacobi_check_true : jacobi_check = true.
Proof. vm_compute. reflexivity. Qed.

Lemma jacq_null : ∀ i j k d : Fin.t 8, qnull (jacq i j k d) = true.
Proof.
  intros i j k d.
  pose proof jacobi_check_true as Hc. unfold jacobi_check in Hc.
  rewrite forallb_forall in Hc. specialize (Hc i (fin_all_complete 8 i)).
  rewrite forallb_forall in Hc. specialize (Hc j (fin_all_complete 8 j)).
  rewrite forallb_forall in Hc. specialize (Hc k (fin_all_complete 8 k)).
  rewrite forallb_forall in Hc. exact (Hc d (fin_all_complete 8 d)).
Qed.

  Lemma sden_neg : ∀ u : sv, sden (svneg u) == - sden u.
  Proof.
    intros u. destruct u; cbn [sden svneg].

    - reflexivity.
    - symmetry. exact (neg_involutive 1).
    - reflexivity.
    - symmetry. exact (neg_involutive (half 1)).
    - reflexivity.
    - symmetry. exact (neg_involutive (half sqrt3)).
  Qed.

  Lemma bracket_is_double_sum : ∀ (x y : Fin.t 8 → F) (c : Fin.t 8),
    [ x , y ] c == bigopI (fun a ⇒ bigopI (fun b ⇒ x a × y b × f a b c)).

                (bigopF (fun a ⇒ bigopF (fun b ⇒ x a × y b × f a b c)))) }

                bigopF_bigopI 8 (fun b ⇒ x a × y b × f a b c))) }

  Fixpoint nrep (k : nat) (a : F) : F :=
    match k with O ⇒ 0 | S m ⇒ a + nrep m a end.

  Definition quarter (a : F) : F := half (half a).

  Definition qden (u : quad) : F :=
    (nrep (qa u) (quarter 1) + - nrep (qb u) (quarter 1))
    + (nrep (qc u) (quarter sqrt3) + - nrep (qd u) (quarter sqrt3)).

  Lemma nrep_add : ∀ (m k : nat) (a : F),
    nrep (m + k) a == nrep m a + nrep k a.
  Proof.
    intros m. induction m as [| m IH]; intros k a.
    - cbn [Nat.add nrep]. symmetry. exact (left_identity (nrep k a)).
    - cbn [Nat.add nrep]. rewrite (IH k a).
      symmetry. exact (associative a (nrep m a) (nrep k a)).
  Qed.

  Lemma qden_zero : qden qzero == 0.
  Proof. unfold qden, qzero. cbn [qa qb qc qd nrep]. ring. Qed.

  Lemma qden_add : ∀ u v : quad, qden u + qden v == qden (qadd u v).
  Proof.
    intros u v. unfold qden, qadd. cbn [qa qb qc qd].
    rewrite (nrep_add (qa u) (qa v) (quarter 1)),
      (nrep_add (qb u) (qb v) (quarter 1)),
      (nrep_add (qc u) (qc v) (quarter sqrt3)),
      (nrep_add (qd u) (qd v) (quarter sqrt3)).
    ring.
  Qed.

  Lemma qden_neg : ∀ u : quad, qden (qneg u) == - qden u.
  Proof. intros u. unfold qden, qneg. cbn [qa qb qc qd]. ring. Qed.

A quad whose two counters agree in each component denotes zero — the only property of the denotation the check needs.
  Lemma qden_null : ∀ u : quad, qnull u = true → qden u == 0.
  Proof.
    intros u Hu. unfold qnull in Hu.
    apply andb_prop in Hu. destruct Hu as [Hab Hcd].
    apply Nat.eqb_eq in Hab. apply Nat.eqb_eq in Hcd.
    unfold qden. rewrite Hab, Hcd. ring.
  Qed.

  Proof. intros k. unfold qden. cbn [qa qb qc qd nrep]. ring. Qed.

  Lemma qden_roots : ∀ k : nat, qden (Quad 0 0 k 0) == nrep k (quarter sqrt3).
  Proof. intros k. unfold qden. cbn [qa qb qc qd nrep]. ring. Qed.

  Lemma quarter_sum : ∀ a : F, quarter a + quarter a == half a.
  Proof. intros a. exact (half_sum (half a)). Qed.

  Lemma nrep2_quarter : ∀ a : F, nrep 2 (quarter a) == half a.
  Proof.
    intros a. cbn [nrep].
    rewrite (add_right_identity (quarter a)).
    exact (quarter_sum a).
  Qed.

  Lemma nrep3_quarter : ∀ a : F,
    nrep 3 (quarter a) == quarter a + quarter a + quarter a.
  Proof.
    intros a. cbn [nrep].
    rewrite (add_right_identity (quarter a)).
    symmetry. exact (associative (quarter a) (quarter a) (quarter a)).
  Qed.

  Lemma nrep4_quarter : ∀ a : F, nrep 4 (quarter a) == a.
  Proof.
    intros a.
    transitivity (nrep 2 (quarter a) + nrep 2 (quarter a)).
    - exact (nrep_add 2 2 (quarter a)).
    - rewrite (nrep2_quarter a). exact (half_sum a).
  Qed.

  Lemma mden_one_one : (1 : F) × 1 == nrep 4 (quarter 1).
  Proof. rewrite (nrep4_quarter (1 : F)). ring. Qed.

  Lemma mden_one_half : (1 : F) × half 1 == nrep 2 (quarter 1).
  Proof. rewrite (nrep2_quarter (1 : F)). ring. Qed.

  Lemma mden_one_root : (1 : F) × half sqrt3 == nrep 2 (quarter sqrt3).
  Proof. rewrite (nrep2_quarter sqrt3). ring. Qed.

  Lemma mden_half_half : half (1 : F) × half 1 == nrep 1 (quarter 1).
  Proof. cbn [nrep]. unfold quarter, half. ring. Qed.

  Lemma mden_half_root : half (1 : F) × half sqrt3 == nrep 1 (quarter sqrt3).
  Proof. cbn [nrep]. unfold quarter, half. ring. Qed.

  Lemma mden_root_root : half sqrt3 × half sqrt3 == nrep 3 (quarter (1 : F)).
  Proof.
    rewrite (nrep3_quarter (1 : F)). unfold quarter, half.
    transitivity ((sqrt3 × sqrt3) × (inv two × inv two)).
    - ring.
    - rewrite sqrt3_sq. ring.

  Lemma magmul_den : ∀ m k : mag, mden m × mden k == qden (magmul m k).
  Proof.
    intros m k.
    destruct m, k; cbn [magmul mden];
      try (rewrite qden_zero; ring).
    - rewrite (qden_units 4). exact mden_one_one.
    - rewrite (qden_units 2). exact mden_one_half.
    - rewrite (qden_roots 2). exact mden_one_root.
    - rewrite (qden_units 2), (mul_commutative (half (1 : F)) 1).
      exact mden_one_half.
    - rewrite (qden_units 1). exact mden_half_half.
    - rewrite (qden_roots 1). exact mden_half_root.
    - rewrite (qden_roots 2), (mul_commutative (half sqrt3) 1).

    - rewrite (qden_roots 1), (mul_commutative (half sqrt3) (half (1 : F))).

The Jacobi identity on the generators, by evaluating the table rather than by rewriting in the field.
  Theorem jacobi_basis : ∀ i j k : Fin.t 8,
    jacobiator (e i) (e j) (e k) == 0.
  Proof.
    intros i j k d.
    calc (jacobiator (e i) (e j) (e k) d)
      == (bigopF (fun b ⇒ f j k b × f i b d)
            + bigopF (fun b ⇒ f k i b × f j b d)
            + bigopF (fun b ⇒ f i j b × f k b d))
      == (qden (jacq i j k d))
      == (0 : F).
    - exact (jacobi_basis_expand f i j k d).
    - rewrite (table_contract_den j k i d), (table_contract_den k i j d),
        (table_contract_den i j k d).
      rewrite (qden_add (qsum 8 (fun b ⇒ svmul (scf j k b) (scf i b d)))
                 (qsum 8 (fun b ⇒ svmul (scf k i b) (scf j b d)))).
      exact (qden_add
               (qadd (qsum 8 (fun b ⇒ svmul (scf j k b) (scf i b d)))
                  (qsum 8 (fun b ⇒ svmul (scf k i b) (scf j b d))))
               (qsum 8 (fun b ⇒ svmul (scf i j b) (scf k b d)))).
    - exact (qden_null (jacq i j k d) (jacq_null i j k d)).
  Qed.
