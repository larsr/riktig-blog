The ripple carry: adding the low digits with the carry in, then the high digits with the carry that produced, accounts for the whole sum at the product base, and a pair of digits has its value below the product base. What makes a pair of digit sets a digit set (Impl/DigitsPair).

  Context {D2 : Type} {eqD2 : EqRel D2} {radix2 : HasRadix D2 N} {val2 : HasVal D2 N}
    {add2 : HasAddDigit B D2} {carry2 : HasCarry B D2} {G2 : Digits D2 B N radix2 val2 valB add2 carry2}.
  Local Notation b1 := (@radix D1 N radix1).
  Local Notation b2 := (@radix D2 N radix2).

  Lemma ripple_value : ∀ (x1 y1 : D1) (x2 y2 : D2) (c : B),
    (val (add_digit x1 y1 c) + b1 × val (add_digit x2 y2 (carry x1 y1 c)))
      + (b1 × b2) × val (carry x2 y2 (carry x1 y1 c))
    == (val (add_digit x1 y1 c) + b1 × val (carry x1 y1 c)) + b1 × (val x2 + val y2).
  Proof.
    intros x1 y1 x2 y2 c.
    calc ((val (add_digit x1 y1 c) + b1 × val (add_digit x2 y2 (carry x1 y1 c)))
            + (b1 × b2) × val (carry x2 y2 (carry x1 y1 c)))
      == ((val (add_digit x1 y1 c) + b1 × val (add_digit x2 y2 (carry x1 y1 c)))
            + b1 × (b2 × val (carry x2 y2 (carry x1 y1 c))))
           { (associative (op := mult) (action := mult) b1 b2 (val (carry x2 y2 (carry x1 y1 c)))) }
      == (val (add_digit x1 y1 c)
            + (b1 × val (add_digit x2 y2 (carry x1 y1 c)) + b1 × (b2 × val (carry x2 y2 (carry x1 y1 c)))))
           { (associative (op := add) (action := add) (val (add_digit x1 y1 c)) _ _) }
      == (val (add_digit x1 y1 c)
            + b1 × (val (add_digit x2 y2 (carry x1 y1 c)) + b2 × val (carry x2 y2 (carry x1 y1 c))))
           { (left_distributive b1 _ _) }
      == (val (add_digit x1 y1 c) + b1 × (val x2 + val y2 + val (carry x1 y1 c)))
           { (Digits.add_digit_spec x2 y2 (carry x1 y1 c)) }
      == (val (add_digit x1 y1 c) + (b1 × (val x2 + val y2) + b1 × val (carry x1 y1 c)))
           { (left_distributive b1 (val x2 + val y2) (val (carry x1 y1 c))) }
      == ((val (add_digit x1 y1 c) + b1 × (val x2 + val y2)) + b1 × val (carry x1 y1 c))
           { (associative (op := add) (action := add) (val (add_digit x1 y1 c)) _ _) }
      == ((val (add_digit x1 y1 c) + b1 × val (carry x1 y1 c)) + b1 × (val x2 + val y2))
           { (add_right_comm (val (add_digit x1 y1 c)) (b1 × (val x2 + val y2)) (b1 × val (carry x1 y1 c))) }.
  Qed.

  Theorem ripple_spec : ∀ (x1 y1 : D1) (x2 y2 : D2) (c : B),
    (val (add_digit x1 y1 c) + b1 × val (add_digit x2 y2 (carry x1 y1 c)))
      + (b1 × b2) × val (carry x2 y2 (carry x1 y1 c))
    == (val x1 + b1 × val x2) + (val y1 + b1 × val y2) + val c.
  Proof.
    intros x1 y1 x2 y2 c.
    calc ((val (add_digit x1 y1 c) + b1 × val (add_digit x2 y2 (carry x1 y1 c)))
            + (b1 × b2) × val (carry x2 y2 (carry x1 y1 c)))
      == ((val (add_digit x1 y1 c) + b1 × val (carry x1 y1 c)) + b1 × (val x2 + val y2)) { (ripple_value x1 y1 x2 y2 c) }
      == ((val x1 + val y1 + val c) + b1 × (val x2 + val y2)) { (Digits.add_digit_spec x1 y1 c) }
      == ((val x1 + val y1 + val c) + (b1 × val x2 + b1 × val y2)) { (left_distributive b1 (val x2) (val y2)) }
      == ((val x1 + b1 × val x2) + (val y1 + b1 × val y2) + val c)
           { (add_add_add_add_comm (val x1) (val y1) (val c) (b1 × val x2) (b1 × val y2)) }.
  Qed.

  Lemma pair_val_proper : ∀ (d1 d1' : D1) (d2 d2' : D2), d1 == d1' → d2 == d2' →
    val d1 + b1 × val d2 == val d1' + b1 × val d2'.
  Proof.
    intros d1 d1' d2 d2' E1 E2.
    calc (val d1 + b1 × val d2) == (val d1' + b1 × val d2) { E1 } == (val d1' + b1 × val d2') { E2 }.
  Qed.

  Theorem ripple_lt : ∀ (d1 : D1) (d2 : D2), val d1 + b1 × val d2 < b1 × b2.
  Proof. intros d1 d2. exact (lt_of_digits _ _ _ _ (Digits.val_digit_lt d1) (Digits.val_digit_lt d2)). Qed.
End Ripple.
