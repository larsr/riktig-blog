From Riktig.Structure Require Export Monoid Linear.
From Riktig Require Import Theory.BigOp.

The grade projection: grade_part k a is the grade-k part of a, written ⟨ a ⟩_ k.
Class HasGrade (A : Type) := grade_part : nat → A → A.
Notation "⟨ a ⟩_ k" := (grade_part k a)
  (at level 0, k at level 0, format "⟨ a ⟩_ k").
Hint Mode HasGrade ! : typeclass_instances.
Typeclasses Transparent HasGrade.

A grading of A with top grade n: each grade projection is linear, projections are idempotent and mutually orthogonal, and the bounded sum of the grade parts of any element returns it.
Module Graded.
  Class Graded (n : nat) (F A : Type)
      {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {As : HasScale F A}
      {AM : Monoid A} {Ag : HasGrade A} := {
    grade_linear :: ∀ k : nat, Linear F A A (grade_part k);
    grade_idempotent : ∀ (k : nat) (a : A), ⟨ ⟨ a ⟩_ k ⟩_ k == ⟨ a ⟩_ k;
    grade_orthogonal : ∀ (k l : nat) (a : A),
                         k ≠ l → ⟨ ⟨ a ⟩_ l ⟩_ k == 0;
    grade_complete : ∀ a : A, bigop (S n) (fun k ⇒ ⟨ a ⟩_ k) == a;
  }.
  Hint Mode Graded - - ! - - - - - - : typeclass_instances.
End Graded.
