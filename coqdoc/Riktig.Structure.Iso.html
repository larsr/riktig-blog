From Coq Require Export Morphisms.
From Riktig Require Export Props.

An isomorphism: a map and its inverse, each respecting equality, cancelling each way.
Module Iso.
  Class Iso (A B : Type) {eqA : EqRel A} {eqB : EqRel B} (to : A → B) (from : B → A) := {
    to_proper :: Proper (equ ==> equ) to;
    from_proper :: Proper (equ ==> equ) from;
    from_to : ∀ a : A, from (to a) == a;
    to_from : ∀ b : B, to (from b) == b;
  }.
  Hint Mode Iso - - - - ! - : typeclass_instances.
  Hint Mode Iso - - - - - ! : typeclass_instances.
End Iso.
Export Iso.

A permutation of a carrier is an isomorphism of it with itself.
Notation Permutation I p q := (Iso I I p q).
