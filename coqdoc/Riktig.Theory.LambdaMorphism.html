Section MorphismLaws.
  Context {T Sb U Sc : Type} `{LambdaModel T Sb} `{LambdaModel U Sc}.
  Context {f : T → U} {g : Sb → Sc} {morphism : LambdaMorphism T Sb U Sc f g}.


A morphism respects conversion.
  Definition morphism_respects_conversion
    : ∀ t t' : T, t == t' → f t == f t' := morphism_proper.


  Lemma morphism_substitute_id : ∀ t : T, f (t.[sub_id]) == (f t).[sub_id].
  Proof.
    intros t.
    calc (f (t.[sub_id]))
      == ((f t).[g sub_id] : U) { (morphism_substitute t) }
      == ((f t).[sub_id] : U) { (morphism_sub_id (f := f) (g := g)) }.
  Qed.

  Lemma morphism_substitute_shift : ∀ t : T,
    f (t.[sub_shift]) == (f t).[sub_shift].
  Proof.
    intros t.
    calc (f (t.[sub_shift]))
      == ((f t).[g sub_shift] : U) { (morphism_substitute t) }
      == ((f t).[sub_shift] : U) { (morphism_sub_shift (f := f) (g := g)) }.
  Qed.

  Lemma morphism_substitute_cons : ∀ (t u : T) (s : Sb),
    f (t.[u .: s]) == (f t).[f u .: g s].
  Proof.
    intros t u s.
    calc (f (t.[u .: s]))
      == ((f t).[g (u .: s)] : U) { (morphism_substitute t) }
      == ((f t).[f u .: g s] : U) { (morphism_sub_cons u s) }.
  Qed.

  Lemma morphism_substitute_up : ∀ (t : T) (s : Sb),
    f (t.[sub_up s]) == (f t).[sub_up (g s)].
  Proof.
    intros t s.
    calc (f (t.[sub_up s]))
      == ((f t).[g (sub_up s)] : U) { (morphism_substitute t) }
      == ((f t).[sub_up (g s)] : U) { (morphism_sub_up (f := f) (g := g) s) }.
  Qed.

The substitution beta uses — one term for the outermost variable — crosses the morphism without mentioning g at all.
  Lemma morphism_substitute_one : ∀ t u : T,
    f (t.[u .: sub_id]) == (f t).[f u .: sub_id].
  Proof.
    intros t u.
    calc (f (t.[u .: sub_id]))
      == ((f t).[f u .: g sub_id] : U) { (morphism_substitute_cons t u sub_id) }
      == ((f t).[f u .: sub_id] : U) { (morphism_sub_id (f := f) (g := g)) }.
  Qed.


The image of a beta step is the target's beta step.
  Theorem morphism_beta : ∀ b u : T, val u →
    f (app (lam b) u) == (f b).[f u .: sub_id].
  Proof.
    intros b u Hu.
    calc (f (app (lam b) u))
      == (f (b.[u .: sub_id])) { (beta b u Hu) }
      == ((f b).[f u .: sub_id] : U) { morphism_substitute_one }.
  Qed.

What morphism_val is for. Here the abstraction is an arbitrary target term, the image of nothing, so the equation is out of reach of transporting any source equation: only the source argument's being a target value fires the step.
  Theorem morphism_value_beta : ∀ (b : U) (u : T), val u →
    app (lam b) (f u) == b.[f u .: sub_id].
  Proof.
    intros b u Hu.
    exact (beta b (f u) (morphism_val u Hu)).
  Qed.


  Lemma morphism_church_true : f church_true == church_true.
  Proof.
    unfold church_true.
    calc (f (lam (lam (var 1))))
      == (lam (f (lam (var 1))) : U) { (morphism_lam (lam (var 1))) }
      == (lam (lam (f (var 1))) : U) { (morphism_lam (var 1)) }
      == (lam (lam (var 1)) : U) { (morphism_var 1) }.
  Qed.

  Lemma morphism_church_false : f church_false == church_false.
  Proof.
    unfold church_false.
    calc (f (lam (lam (var 0))))
      == (lam (f (lam (var 0))) : U) { (morphism_lam (lam (var 0))) }
      == (lam (lam (f (var 0))) : U) { (morphism_lam (var 0)) }
      == (lam (lam (var 0)) : U) { (morphism_var 0) }.
  Qed.

  Lemma morphism_pair_body :
    f (app (app (var 0) (var 2)) (var 1))
    == app (app (var 0) (var 2)) (var 1).
  Proof.
    calc (f (app (app (var 0) (var 2)) (var 1)))
      == (app (f (app (var 0) (var 2))) (f (var 1)) : U)
           { (morphism_app (app (var 0) (var 2)) (var 1)) }
      == (app (app (f (var 0)) (f (var 2))) (f (var 1)) : U)
           { (morphism_app (var 0) (var 2)) }
      == (app (app (var 0) (f (var 2))) (f (var 1)) : U)
           { (morphism_var 0) }
      == (app (app (var 0) (var 2)) (f (var 1)) : U)
           { (morphism_var 2) }
      == (app (app (var 0) (var 2)) (var 1) : U)
           { (morphism_var 1) }.
  Qed.

  Lemma morphism_church_pair : f church_pair == church_pair.
  Proof.
    unfold church_pair.
    calc (f (lam (lam (lam (app (app (var 0) (var 2)) (var 1))))))
      == (lam (f (lam (lam (app (app (var 0) (var 2)) (var 1))))) : U)
           { (morphism_lam (lam (lam (app (app (var 0) (var 2)) (var 1))))) }
      == (lam (lam (f (lam (app (app (var 0) (var 2)) (var 1))))) : U)
           { (morphism_lam (lam (app (app (var 0) (var 2)) (var 1)))) }
      == (lam (lam (lam (f (app (app (var 0) (var 2)) (var 1))))) : U)
           { (morphism_lam (app (app (var 0) (var 2)) (var 1))) }
      == (lam (lam (lam (app (app (var 0) (var 2)) (var 1)))) : U)
           { morphism_pair_body }.
  Qed.

The conditional commutes with the morphism.
  Theorem morphism_church_if : ∀ b u v : T,
    f (church_if b u v) == church_if (f b) (f u) (f v).
  Proof.
    intros b u v. unfold church_if.
    calc (f (app (app b u) v))
      == (app (f (app b u)) (f v) : U) { (morphism_app (app b u) v) }
      == (app (app (f b) (f u)) (f v) : U) { (morphism_app b u) }.
  Qed.

Selection holds of the images, stated with the target's own booleans: this is what "the two implementations agree" says.
  Theorem morphism_church_if_true : ∀ u v : T, val u → val v →
    church_if church_true (f u) (f v) == f u.
  Proof.
    intros u v Hu Hv.
    calc (church_if (church_true : U) (f u) (f v))
      == (church_if (f church_true) (f u) (f v)) { morphism_church_true }
      == (f (church_if church_true u v)) { morphism_church_if }
      == (f u) { (church_if_true u v Hu Hv) }.
  Qed.

  Theorem morphism_church_if_false : ∀ u v : T, val u → val v →
    church_if church_false (f u) (f v) == f v.
  Proof.
    intros u v Hu Hv.
    calc (church_if (church_false : U) (f u) (f v))
      == (church_if (f church_false) (f u) (f v)) { morphism_church_false }
      == (f (church_if church_false u v)) { morphism_church_if }
      == (f v) { (church_if_false u v Hu Hv) }.
  Qed.

  Lemma morphism_app_three : ∀ a b c d : T,
    f (app (app (app a b) c) d) == app (app (app (f a) (f b)) (f c)) (f d).
  Proof.
    intros a b c d.
    calc (f (app (app (app a b) c) d))
      == (app (f (app (app a b) c)) (f d) : U)
           { (morphism_app (app (app a b) c) d) }
      == (app (app (f (app a b)) (f c)) (f d) : U)
           { (morphism_app (app a b) c) }
      == (app (app (app (f a) (f b)) (f c)) (f d) : U)
           { (morphism_app a b) }.
  Qed.

And the pair projections, again with the target's encodings.
  Theorem morphism_church_fst_pair : ∀ v w : T, val v → val w →
    app (app (app church_pair (f v)) (f w)) church_true == f v.
  Proof.
    intros v w Hv Hw.
    calc (app (app (app (church_pair : U) (f v)) (f w)) church_true)
      == (app (app (app (f church_pair) (f v)) (f w)) church_true)
           { morphism_church_pair }
      == (app (app (app (f church_pair) (f v)) (f w)) (f church_true))
           { morphism_church_true }
      == (f (app (app (app church_pair v) w) church_true))
           { morphism_app_three }
      == (f v)
           { (church_fst_pair v w Hv Hw) }.
  Qed.

  Theorem morphism_church_snd_pair : ∀ v w : T, val v → val w →
    app (app (app church_pair (f v)) (f w)) church_false == f w.
  Proof.
    intros v w Hv Hw.
    calc (app (app (app (church_pair : U) (f v)) (f w)) church_false)
      == (app (app (app (f church_pair) (f v)) (f w)) church_false)
           { morphism_church_pair }
      == (app (app (app (f church_pair) (f v)) (f w)) (f church_false))
           { morphism_church_false }
      == (f (app (app (app church_pair v) w) church_false))
           { morphism_app_three }
      == (f w)
           { (church_snd_pair v w Hv Hw) }.
  Qed.
End MorphismLaws.



Section Identity.
  Context {T Sb : Type} `{LambdaModel T Sb}.

  Definition identity_morphism
    : LambdaMorphism T Sb T Sb (fun t : T ⇒ t) (fun s : Sb ⇒ s) :=
    {| morphism_proper := fun (t t' : T) (Heq : t == t') ⇒ Heq;
       morphism_var := fun n : nat ⇒ reflexivity (var n);
       morphism_lam := fun b : T ⇒ reflexivity (lam b);
       morphism_app := fun a b : T ⇒ reflexivity (app a b);
       morphism_substitute := fun (t : T) (s : Sb) ⇒ reflexivity (t.[s]);
       morphism_sub_id := eq_refl;
       morphism_sub_shift := eq_refl;
       morphism_sub_cons := fun (u : T) (s : Sb) ⇒ eq_refl;
       morphism_sub_up := fun s : Sb ⇒ eq_refl;
       morphism_val := fun (t : T) (Ht : val t) ⇒ Ht |}.
End Identity.

Section Composition.
  Context {T Sb U Sc V Sd : Type}
    `{LambdaModel T Sb} `{LambdaModel U Sc} `{LambdaModel V Sd}.
  Context {f : T → U} {g : Sb → Sc} {mf : LambdaMorphism T Sb U Sc f g}.
  Context {h : U → V} {k : Sc → Sd} {mh : LambdaMorphism U Sc V Sd h k}.

  Definition compose_morphism
    : LambdaMorphism T Sb V Sd (fun t : T ⇒ h (f t)) (fun s : Sb ⇒ k (g s)).
  Proof.
    split.
    - intros t t' Heq. rewrite Heq. reflexivity.
    - intros n.
      calc (h (f (var n)))
        == (h (var n) : V) { (morphism_var (f := f) n) }
        == (var n : V) { (morphism_var (f := h) n) }.
    - intros b.
      calc (h (f (lam b)))
        == (h (lam (f b)) : V) { (morphism_lam (f := f) b) }
        == (lam (h (f b)) : V) { (morphism_lam (f := h) (f b)) }.
    - intros a b.
      calc (h (f (app a b)))
        == (h (app (f a) (f b)) : V) { (morphism_app (f := f) a b) }
        == (app (h (f a)) (h (f b)) : V) { (morphism_app (f := h) (f a) (f b)) }.
    - intros t s.
      calc (h (f (t.[s])))
        == (h ((f t).[g s]) : V) { (morphism_substitute (f := f) t s) }
        == ((h (f t)).[k (g s)] : V)
             { (morphism_substitute (f := h) (f t) (g s)) }.
    - rewrite (morphism_sub_id (f := f) (g := g)).
      exact (morphism_sub_id (f := h) (g := k)).
    - rewrite (morphism_sub_shift (f := f) (g := g)).
      exact (morphism_sub_shift (f := h) (g := k)).
    - intros u s.
      rewrite (morphism_sub_cons (f := f) (g := g) u s).
      exact (morphism_sub_cons (f := h) (g := k) (f u) (g s)).
    - intros s.
      rewrite (morphism_sub_up (f := f) (g := g) s).
      exact (morphism_sub_up (f := h) (g := k) (g s)).
    - intros t Ht.
      exact (morphism_val (f := h) (f t) (morphism_val (f := f) t Ht)).
  Qed.
End Composition.




Section Isomorphism.
  Context {T Sb U Sc : Type} `{LambdaModel T Sb} `{LambdaModel U Sc}.
  Context {to : T → U} {gto : Sb → Sc}
    {morphism_to : LambdaMorphism T Sb U Sc to gto}.
  Context {from : U → T} {gfrom : Sc → Sb}
    {morphism_from : LambdaMorphism U Sc T Sb from gfrom}.
  Context {iso : Inverse to from}.

An isomorphism reflects conversion: the target holds no equation between images that the source does not hold.
  Lemma iso_reflects_conversion : ∀ t t' : T, to t == to t' → t == t'.
  Proof.
    intros t t' Heq.
    calc t
      == (from (to t)) { (Inverse.from_to (f := to) (g := from) t) }
      == (from (to t')) { (morphism_respects_conversion (f := from) _ _ Heq) }
      == t' { (Inverse.from_to (f := to) (g := from) t') }.
  Qed.

So an equation holds in the source exactly when its image holds in the target. The two models have one equational theory, and anything proved of either transports to the other — which is what it means for two implementations of the lambda calculus to be the same calculus.
  Theorem iso_transports_equations : ∀ t t' : T, t == t' ↔ to t == to t'.
  Proof.
    intros t t'. split.
    - exact (morphism_respects_conversion (f := to) t t').
    - exact (iso_reflects_conversion t t').
  Qed.

End Isomorphism.
