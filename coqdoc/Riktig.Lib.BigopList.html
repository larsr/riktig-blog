Library Riktig.Lib.BigopList

From Coq Require Export List.
From Riktig Require Import Ops.

bigop_list f l is the sum of f over an explicit index list.
Definition bigop_list {M : Type} {Mz : Zero M} {Ma : HasAdd M}
    {J : Type} (f : J → M) (l : list J) : M :=
  fold_right (fun j acc ⇒ f j + acc) 0 l.
