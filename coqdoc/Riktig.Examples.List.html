The list programs are arrows over any bicartesian category. Naming the category of Coq's types, they are functions on Coq's lists, and compute.
Compute length (O := Type) (den := fun T0 : Type ⇒ T0) (x := nat) (N := nat) (7 :: 8 :: 9 :: nil)%list.

Compute map (O := Type) (den := fun T0 : Type ⇒ T0) (x := nat) (y := nat) (M := list nat) succ (7 :: 8 :: 9 :: nil)%list.

Compute uncons (O := Type) (den := fun T0 : Type ⇒ T0) (x := nat) (7 :: 8 :: 9 :: nil)%list.

And a list is a sequence, its head the first element read.
Check (eq_refl : step (7 :: 8 :: 9 :: nil)%list 7 (8 :: 9 :: nil)%list).

Rebuilding what was taken apart is the identity, by the abstract theorem.
Example rebuild (l : list nat) :
  CoqList_HasBuild nat (uncons (O := Type) (den := fun T0 : Type ⇒ T0) (x := nat) l) = l
  := build_unbuild_list l.
