What idempotent multiplication forces on the addition.
Section BooleanTheory.
  Context {K : Type} `{Boolean K}.

  Lemma square : ∀ a : K, a × a == a.
  Proof. intros a. exact (idempotent a). Qed.

Characteristic two. Expanding the square of a + a leaves four copies of a where two stand, and the group cancels the difference.
  Theorem add_self_zero : ∀ a : K, a + a == 0.
  Proof.
    intros a.
    apply (cancel_l (a + a)).
    calc ((a + a) + (a + a))
      == ((a × a + a × a) + (a × a + a × a)) { (square a) }
      == ((a + a) × a + (a + a) × a) { (right_distributive a a a) }
      == ((a + a) × (a + a)) { (left_distributive (a + a) a a) }
      == (a + a) { (square (a + a)) }
      == ((a + a) + (0 : K)) { (right_identity (a + a)) }.
  Qed.

Negation is the identity: with a + a == 0, every element is already its own inverse.
  Theorem neg_is_identity : ∀ a : K, - a == a.
  Proof.
    intros a. symmetry. apply neg_unique_l. exact (add_self_zero a).
  Qed.

  #[export] Instance boolean_alternates : Alternates K add := add_self_zero.

End BooleanTheory.
