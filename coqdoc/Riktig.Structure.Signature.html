The polynomial signatures over a set K of constant names: no constructors, a constructor with no fields, a recursive occurrence, a constant field named from K, a choice between two signatures and a field beside the rest. The signatures are the initial algebra of these six constructors, stated by the recursor: its equation at each constructor, and its uniqueness. The recursor answers into any type -- in particular into type formers, which no fold inside a fixed category of types can reach -- which is why the laws are equational rather than a categorical initial algebra. They are in Leibniz equality because the recursor's answers may be types themselves, where it is the only equality.
Module Signature.
  Class Signature (K S : Type) (zeroS : Zero S) (oneS : One S) (selfS : HasSelf S)
      (constS : HasConst K S) (plusS : HasAdd S) (timesS : HasMult S)
      (rec : HasPolyRec K S) := {
    rec_zero : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B),
      poly_rec B z o s c p t (0 : S) = z;
    rec_one : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B),
      poly_rec B z o s c p t (1 : S) = o;
    rec_self : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B),
      poly_rec B z o s c p t (self : S) = s;
    rec_const : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B) (k : K),
      poly_rec B z o s c p t (const k : S) = c k;
    rec_plus : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B) (a b : S),
      poly_rec B z o s c p t (a + b) =
      p (poly_rec B z o s c p t a) (poly_rec B z o s c p t b);
    rec_times : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B) (a b : S),
      poly_rec B z o s c p t (a × b) =
      t (poly_rec B z o s c p t a) (poly_rec B z o s c p t b);
    rec_unique : ∀ (B : Type) (z o s : B) (c : K → B) (p t : B → B → B)
        (u : S → B),
      u 0 = z → u 1 = o → u self = s → (∀ k : K, u (const k) = c k) →
      (∀ a b : S, u (a + b) = p (u a) (u b)) →
      (∀ a b : S, u (a × b) = t (u a) (u b)) →
      ∀ q : S, u q = poly_rec B z o s c p t q;
  }.
End Signature.

What a signature denotes, derived once by its recursor and shared by every implementation of signatures: one level of a datatype in any bicartesian category, an object former together with its action on arrows. The two are built together because the type of the action names the objects, so the pair travels in one record.
Section LayerRecord.
  Context {O : Type} {hom : HasHom O}.

  Record Layer := mk_layer {
    lobj : O → O;
    lmap : ∀ a b : O, (a ~> b) → (lobj a ~> lobj b);
  }.
End LayerRecord.

Section Denotation.
  Context {K S : Type} `{Signature K S}.
  Context {O : Type} `{Bicartesian O} (den : K → O).
  Local Open Scope object_scope.

  Definition layer (q : S) : Layer O :=
    poly_rec (Layer O)
      (mk_layer (fun _ ⇒ 0) (fun a b f ⇒ cat_id))
      (mk_layer (fun _ ⇒ 1) (fun a b f ⇒ cat_id))
      (mk_layer (fun a ⇒ a) (fun a b f ⇒ f))
      (fun k ⇒ mk_layer (fun _ ⇒ den k) (fun a b f ⇒ cat_id))
      (fun F G ⇒ mk_layer (fun a ⇒ lobj F a + lobj G a)
                    (fun a b f ⇒ lmap F f ⨿⨿ lmap G f))
      (fun F G ⇒ mk_layer (fun a ⇒ lobj F a × lobj G a)
                    (fun a b f ⇒ lmap F f ×× lmap G f))
      q.

  #[export] Instance layer_fmap (q : S) : HasFmap O O (lobj (layer q)) :=
    fun a b f ⇒ lmap (layer q) f.
End Denotation.

The Type a signature term denotes, one level, with the hole for the recursive occurrences: constants are types themselves.

The signatures of the first datatypes, written in the operations.
Section StandardSignatures.
  Context {K S : Type} `{Signature K S}.

  Definition natS : S := 1 + self.
  Definition listS (k : K) : S := 1 + const k × self.
  Definition treeS (k : K) : S := const k + self × self.
  Definition styS (k : K) : S := const k + self × self.
  Definition stlcS (n ty : K) : S := const n + const ty × self + self × self.
  Definition eitherS (a b : K) : S := const a + const b.
  Definition pairS (a b : K) : S := const a × const b.
End StandardSignatures.
