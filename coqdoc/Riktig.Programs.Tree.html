A program on trees, written as an arrow in any bicartesian category: one fold, and it mentions no element.
Section Programs.
  Context {O : Type} `{Bicartesian O} {K : Type} {den : K → O} {x : K} {T : O}
    {tb : HasBuild O (Tree.shape den x) T} {tf : HasCata O (Tree.shape den x) T}
    `{!Tree O den x T tb tf}.

The mirror image: a tip stays, a fork is rebuilt the other way around.
  Definition mirror : T ~> T :=
    Tree.fold T (desc Tree.tip (Tree.fork ∘ lift pi2 pi1)).
End Programs.

Section Counting.

    {tb : HasBuild O (Tree.shape den x) T} {tf : HasCata O (Tree.shape den x) T}
    `{!Tree O den x T tb tf}
    {nb : HasBuild O (NaturalNumbers.shape O) N} {nf : HasCata O (NaturalNumbers.shape O) N}
    `{!NaturalNumbers O N nb nf}.

How many tips a tree has, counted with any addition of the numbers; the plus argument stands in until an arithmetic structure on a natural-numbers object exists.
  Definition tips (plus : N ⨯ N ~> N) : T ~> N :=
    Tree.fold N (desc (NaturalNumbers.succ ∘ NaturalNumbers.zero ∘ to_term (den x)) plus).
End Counting.
