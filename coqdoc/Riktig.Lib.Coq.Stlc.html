The concrete syntax trees of the simply typed calculus: the simple types over base types B, and the terms over variables N and types Ty. Only the inductives live here; everything they satisfy is derived from initiality.

Inductive sty (B : Type) : Type :=
  | SBase (b : B)
  | SArrow (a c : sty B).
Arguments SBase {B} b.
Arguments SArrow {B} a c.

Inductive stlc (N Ty : Type) : Type :=
  | SVar (n : N)
  | SLam (A : Ty) (b : stlc N Ty)
  | SApp (f a : stlc N Ty).
Arguments SVar {N Ty} n.
Arguments SLam {N Ty} A b.
Arguments SApp {N Ty} f a.
