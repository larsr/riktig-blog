Library Riktig.Examples.BinaryNumber

From Riktig.Theory Require Import Naturals.

A program over any naturals, run at Coq's binary naturals seen as binary numbers: the arithmetic is the bit-by-bit one of Programs/BinaryNumber, and the laws come through the value.
Section Test.
  Context {N : Type} `{Naturals N}.
  Definition sum_of_squares (a b : N) : N := a × a + b × b.
End Test.

From Riktig.Impl Require Import BinaryNumberN BinaryArithBinRec NaturalsBinary.

Compute (sum_of_squares 3 4)%N.
Compute (succ 41 + 0)%N.
Check eq_refl : (sum_of_squares 3 4 == 25)%N.
Check eq_refl : (1000 × 1000 == 1000000)%N.
