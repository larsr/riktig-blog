From Coq Require Export Morphisms.
From Riktig Require Export Props.

Replacing one slot of a family: the new family reads as the new element at that slot and as the old family elsewhere, and respects equality whenever the old family does.
Module Upd.
  Class Upd (I V : Type) {eqI : EqRel I} {eqV : EqRel V} (update : HasUpd I V) := {
    upd_at : ∀ (vs : I → V) (i : I) (x : V) (j : I), j == i → upd vs i x j == x;
    upd_off : ∀ (vs : I → V) (i : I) (x : V) (j : I), j =/= i → upd vs i x j == vs j;
    upd_proper : ∀ (vs : I → V) (i : I) (x : V),
      Proper (equ ==> equ) vs → Proper (equ ==> equ) (upd vs i x);
  }.
  Hint Mode Upd ! ! - - - : typeclass_instances.
End Upd.
Export Upd.
