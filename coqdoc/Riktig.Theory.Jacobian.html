The matrix of a linear map between spaces of tables: its entry at i, j is the i-th coordinate of the image of the j-th unit table. The matrix of a composite is the product of the matrices: the chain rule for Jacobians.

  Lemma delta_fun_proper : ∀ j : J, Proper (equ ==> equ) (fun i : J ⇒ if EquDec.equ_dec i j then (1 : F) else 0).
  Proof.
    intros j i i' Hi. apply (Theory.Decidable.if_dec_proper (i == j) (i' == j)).
    rewrite Hi. reflexivity.
  Qed.

  Lemma delta_proper : Proper (equ ==> equ) (fun j : J ⇒ delta j).
  Proof.
    intros j j' Hj. apply Table.tabulate_proper. intros i.
    apply (Theory.Decidable.if_dec_proper (i == j) (i == j')). rewrite Hj. reflexivity.
  Qed.

The unit table's coordinates: one at its own index, zero elsewhere.
  Lemma get_delta : ∀ i j : J, get (delta j) i == if EquDec.equ_dec i j then (1 : F) else 0.
  Proof. intros i j. exact (Table.get_tabulate _ i). Qed.

  Lemma get_delta_same : ∀ i j : J, i == j → get (delta j) i == 1.
  Proof.
    intros i j Hij.
    calc (get (delta j) i)
      == (if EquDec.equ_dec i j then (1 : F) else 0) { (get_delta i j) }
      == (1 : F) { (Theory.Decidable.if_dec_l (i == j) 1 0 Hij) }.
  Qed.

  Lemma get_delta_other : ∀ i j : J, i =/= j → get (delta j) i == 0.
  Proof.
    intros i j Hij.
    calc (get (delta j) i)
      == (if EquDec.equ_dec i j then (1 : F) else 0) { (get_delta i j) }
      == (0 : F) { (Theory.Decidable.if_dec_r (i == j) 1 0 Hij) }.
  Qed.

  Lemma comb_step_proper : ∀ (c : J → F) (u : J → TJ),
    Proper (equ ==> equ) c → Proper (equ ==> equ) u →
    Proper (equ ==> equ ==> equ) (fun (k : N) (acc : TJ) ⇒ acc + c (elem k) *: u (elem k)).
  Proof.
    intros c u Hc Hu k k' Hk acc acc' Hacc. apply Magma.op_proper; [ exact Hacc | ].
    apply ScaleLaws.scale_proper; [ apply Hc | apply Hu ]; apply Finite.elem_proper; exact Hk.
  Qed.

Reading the coordinate i of a partial combination of units: zero up to the index of i, the coefficient from there on.
  Section Coordinate.
    Variables (t : TJ) (i : J).

    Lemma comb_delta_proper : ∀ n n' : N, n == n' →
      comb (get t) (fun j ⇒ delta j) n == comb (get t) (fun j ⇒ delta j) n'.
    Proof.
      exact (NatRec.natrec_proper TJ _ _ 0 _
               (comb_step_proper (get t) (fun j ⇒ delta j) (Table.get_proper t t (reflexivity t)) delta_proper)).
    Qed.

    Lemma get_comb_delta_succ : ∀ n : N,
      get (comb (get t) (fun j ⇒ delta j) (succ n)) i
        == get (comb (get t) (fun j ⇒ delta j) n) i + get t (elem n) × get (delta (elem n)) i.
    Proof.
      intros n.
      calc (get (comb (get t) (fun j ⇒ delta j) (succ n)) i)
        == (get (comb (get t) (fun j ⇒ delta j) n + get t (elem n) *: delta (elem n)) i)
             { (Table.get_proper _ _ (NatRec.natrec_succ TJ _ _ 0 _ n) i i (reflexivity i)) }
        == (get (comb (get t) (fun j ⇒ delta j) n) i + get (get t (elem n) *: delta (elem n)) i)
             { (TableSpace.get_add _ _ i) }
        == (get (comb (get t) (fun j ⇒ delta j) n) i + get t (elem n) × get (delta (elem n)) i)
             { (TableSpace.get_smul (get t (elem n)) (delta (elem n)) i) }.
    Qed.

    Lemma get_comb_delta_before : ∀ n : N, n ≤ index i → get (comb (get t) (fun j ⇒ delta j) n) i == 0.
    Proof.
      apply (Theory.NatOrder.nat_induction_le (index i) (fun n ⇒ get (comb (get t) (fun j ⇒ delta j) n) i == 0)).
      - intros n n' Hn. rewrite (comb_delta_proper n n' Hn). reflexivity.
      - calc (get (comb (get t) (fun j ⇒ delta j) 0) i)
          == (get (0 : TJ) i) { (Table.get_proper _ _ (NatRec.natrec_zero TJ _ _ 0 _) i i (reflexivity i)) }
          == (0 : F) { (TableSpace.get_zero i) }.
      - intros n Hn IH.
        calc (get (comb (get t) (fun j ⇒ delta j) (succ n)) i)
          == (get (comb (get t) (fun j ⇒ delta j) n) i + get t (elem n) × get (delta (elem n)) i)
               { (get_comb_delta_succ n) }
          == (0 + get t (elem n) × get (delta (elem n)) i) { IH }
          == (0 + get t (elem n) × 0)
               { (get_delta_other i (elem n) (fun Hie ⇒ proj2 Hn (Theory.Finite.index_eq_of_elem i n
                    (Theory.NatOrder.lt_trans n (index i) card Hn (Finite.index_lt i)) (symmetry Hie)))) }
          == ((0 : F) + 0) { (mul_zero (get t (elem n))) }
          == (0 : F) { (left_identity (action := add) (0 : F)) }.
    Qed.

    Lemma get_comb_delta_after : ∀ n : N, index i < n → n ≤ card →
      get (comb (get t) (fun j ⇒ delta j) n) i == get t i.
    Proof.
      apply (Theory.NatOrder.nat_induction_between (index i) card
               (fun n ⇒ get (comb (get t) (fun j ⇒ delta j) n) i == get t i)).
      - intros n n' Hn. rewrite (comb_delta_proper n n' Hn). reflexivity.
      - calc (get (comb (get t) (fun j ⇒ delta j) (succ (index i))) i)
          == (get (comb (get t) (fun j ⇒ delta j) (index i)) i + get t (elem (index i)) × get (delta (elem (index i))) i)
               { (get_comb_delta_succ (index i)) }
          == (0 + get t (elem (index i)) × get (delta (elem (index i))) i)
               { (get_comb_delta_before (index i) (Theory.NatOrder.le_refl (index i))) }
          == (0 + get t (elem (index i)) × 1)
               { (get_delta_same i (elem (index i)) (symmetry (Finite.elem_index i))) }
          == (get t (elem (index i)) × 1) { (left_identity (action := add) (get t (elem (index i)) × 1)) }
          == (get t (elem (index i))) { (right_identity (action := mult) (get t (elem (index i)))) }
          == (get t i) { (Table.get_proper t t (reflexivity t) _ _ (Finite.elem_index i)) }.
      - intros n Hlt Hn IH.
        calc (get (comb (get t) (fun j ⇒ delta j) (succ n)) i)
          == (get (comb (get t) (fun j ⇒ delta j) n) i + get t (elem n) × get (delta (elem n)) i)
               { (get_comb_delta_succ n) }
          == (get t i + get t (elem n) × get (delta (elem n)) i) { IH }
          == (get t i + get t (elem n) × 0)
               { (get_delta_other i (elem n) (fun Hie ⇒ proj2 Hlt
                    (symmetry (Theory.Finite.index_eq_of_elem i n Hn (symmetry Hie))))) }
          == (get t i + 0) { (mul_zero (get t (elem n))) }
          == (get t i) { (right_identity (action := add) (get t i)) }.
    Qed.
  End Coordinate.

Every table is the combination of the units by its coordinates.
  Theorem decompose : ∀ t : TJ, t == comb (get t) (fun j ⇒ delta j) card.
  Proof.
    intros t.
    apply (transitivity (symmetry (Table.tabulate_get t))).
    apply (transitivity (y := tabulate (get (comb (get t) (fun j ⇒ delta j) card)))); [ | exact (Table.tabulate_get _) ].
    apply Table.tabulate_proper. intros i. symmetry.
    exact (get_comb_delta_after t i card (Finite.index_lt i) (Theory.NatOrder.le_refl card)).
  Qed.

A linear map carries a combination to the combination of the images.
  Lemma linear_comb : ∀ (L : TJ → TI) (c : J → F) (u : J → TJ),
    Linear F TJ TI L → Proper (equ ==> equ) c → Proper (equ ==> equ) u →
    ∀ n : N, L (comb c u n) == natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: L (u (elem k))) n.
  Proof.
    intros L c u HL Hc Hu.
    assert (HLu : Proper (equ ==> equ) (fun j ⇒ L (u j)))
      by (intros j j' Hj; apply (Linear.proper (f := L)); apply Hu; exact Hj).
    assert (HsI : Proper (equ ==> equ ==> equ) (fun (k : N) (acc : TI) ⇒ acc + c (elem k) *: L (u (elem k))))
      by (intros k k' Hk acc acc' Hacc; apply Magma.op_proper; [ exact Hacc | apply ScaleLaws.scale_proper; [ apply Hc | apply HLu ]; apply Finite.elem_proper; exact Hk ]).
    apply (Peano.nat_induction (fun n ⇒ L (comb c u n) == natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: L (u (elem k))) n)).
    - intros n n' Hn.
      setoid_rewrite (NatRec.natrec_proper TJ _ _ 0 _ (comb_step_proper c u Hc Hu) n n' Hn).
      setoid_rewrite (NatRec.natrec_proper TI _ _ 0 _ HsI n n' Hn). reflexivity.
    - calc (L (comb c u 0))
        == (L (0 : TJ)) { (Linear.proper (f := L) _ _ (NatRec.natrec_zero TJ _ _ 0 _)) }
        == (0 : TI) { (additive_zero L) }
        == (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: L (u (elem k))) 0) { (NatRec.natrec_zero TI _ _ 0 _) }.
    - intros n IH.
      calc (L (comb c u (succ n)))
        == (L (comb c u n + c (elem n) *: u (elem n))) { (Linear.proper (f := L) _ _ (NatRec.natrec_succ TJ _ _ 0 _ n)) }
        == (L (comb c u n) + L (c (elem n) *: u (elem n))) { (additive (f := L) _ _) }
        == (L (comb c u n) + c (elem n) *: L (u (elem n))) { (homogeneous (f := L) (c (elem n)) (u (elem n))) }
        == (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: L (u (elem k))) n + c (elem n) *: L (u (elem n))) { IH }
        == (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: L (u (elem k))) (succ n)) { (NatRec.natrec_succ TI _ _ 0 _ n) }.
  Qed.

A coordinate of a combination of tables.
  Lemma get_comb : ∀ (c : J → F) (v : J → TI) (i : I),
    Proper (equ ==> equ) c → Proper (equ ==> equ) v →
    ∀ n : N, get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) n) i
                  == natrec F 0 (fun k acc ⇒ acc + c (elem k) × get (v (elem k)) i) n.
  Proof.
    intros c v i Hc Hv.
    assert (Hsv : Proper (equ ==> equ ==> equ) (fun (k : N) (acc : TI) ⇒ acc + c (elem k) *: v (elem k)))
      by (intros k k' Hk acc acc' Hacc; apply Magma.op_proper; [ exact Hacc | apply ScaleLaws.scale_proper; [ apply Hc | apply Hv ]; apply Finite.elem_proper; exact Hk ]).
    assert (Hsf : Proper (equ ==> equ ==> equ) (fun (k : N) (acc : F) ⇒ acc + c (elem k) × get (v (elem k)) i))
      by (intros k k' Hk acc acc' Hacc; apply Magma.op_proper; [ exact Hacc | ];
          apply Magma.op_proper; [ apply Hc; apply Finite.elem_proper; exact Hk | apply Table.get_proper; [ apply Hv; apply Finite.elem_proper; exact Hk | reflexivity ] ]).
    apply (Peano.nat_induction (fun n ⇒ get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) n) i
                  == natrec F 0 (fun k acc ⇒ acc + c (elem k) × get (v (elem k)) i) n)).
    - intros n n' Hn.
      setoid_rewrite (NatRec.natrec_proper TI _ _ 0 _ Hsv n n' Hn).
      setoid_rewrite (NatRec.natrec_proper F _ _ 0 _ Hsf n n' Hn). reflexivity.
    - calc (get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) 0) i)
        == (get (0 : TI) i) { (Table.get_proper _ _ (NatRec.natrec_zero TI _ _ 0 _) i i (reflexivity i)) }
        == (0 : F) { (TableSpace.get_zero i) }
        == (natrec F 0 (fun k acc ⇒ acc + c (elem k) × get (v (elem k)) i) 0) { (NatRec.natrec_zero F _ _ 0 _) }.
    - intros n IH.
      calc (get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) (succ n)) i)
        == (get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) n + c (elem n) *: v (elem n)) i)
             { (Table.get_proper _ _ (NatRec.natrec_succ TI _ _ 0 _ n) i i (reflexivity i)) }
        == (get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) n) i + get (c (elem n) *: v (elem n)) i)
             { (TableSpace.get_add _ _ i) }
        == (get (natrec TI 0 (fun k acc ⇒ acc + c (elem k) *: v (elem k)) n) i + c (elem n) × get (v (elem n)) i)
             { (TableSpace.get_smul (c (elem n)) (v (elem n)) i) }
        == (natrec F 0 (fun k acc ⇒ acc + c (elem k) × get (v (elem k)) i) n + c (elem n) × get (v (elem n)) i)
             { IH }
        == (natrec F 0 (fun k acc ⇒ acc + c (elem k) × get (v (elem k)) i) (succ n))
             { (NatRec.natrec_succ F _ _ 0 _ n) }.
  Qed.

  Lemma product_fun_proper : ∀ (L : TJ → TI) (M : TJ → TJ) (i : I) (k : J), Linear F TJ TI L →
    Proper (equ ==> equ) (fun l ⇒ get (M (delta k)) (elem l) × get (L (delta (elem l))) i).
  Proof.
    intros L M i k HL l l' Hl.
    exact (Magma.op_proper _ _ (Table.get_proper _ _ (reflexivity _) _ _ (Finite.elem_proper l l' Hl))
                           _ _ (Table.get_proper _ _ (linear_delta_proper L HL _ _ (Finite.elem_proper l l' Hl)) i i (reflexivity i))).
  Qed.

  Lemma product_fun_proper' : ∀ (L : TJ → TI) (M : TJ → TJ) (i : I) (k : J), Linear F TJ TI L →
    Proper (equ ==> equ) (fun l ⇒ jacobian L i (elem l) × jacobian M (elem l) k).
  Proof.

    exact (Magma.op_proper _ _ (Table.get_proper _ _ (linear_delta_proper L HL _ _ (Finite.elem_proper l l' Hl)) i i (reflexivity i))
                           _ _ (Table.get_proper _ _ (reflexivity _) _ _ (Finite.elem_proper l l' Hl))).
  Qed.

The chain rule for matrices: the matrix of a composite is the product of the matrices.
  Theorem jacobian_comp : ∀ (L : TJ → TI) (M : TJ → TJ) (i : I) (k : J),
    Linear F TJ TI L → Linear F TJ TJ M →
    jacobian (fun h ⇒ L (M h)) i k
      == natrec F 0 (fun l acc ⇒ acc + jacobian L i (elem l) × jacobian M (elem l) k) card.
  Proof.
    intros L M i k HL HM.
    pose proof (linear_delta_proper L HL) as HLd.
    calc (get (L (M (delta k))) i)
      == (get (L (comb (get (M (delta k))) (fun j ⇒ delta j) card)) i)
           { (Table.get_proper _ _ (Linear.proper (f := L) _ _ (decompose (M (delta k)))) i i (reflexivity i)) }
      == (get (natrec TI 0 (fun l acc ⇒ acc + get (M (delta k)) (elem l) *: L (delta (elem l))) card) i)
           { (Table.get_proper _ _ (linear_comb L (get (M (delta k))) (fun j ⇒ delta j) HL (Table.get_proper _ _ (reflexivity _)) delta_proper card) i i (reflexivity i)) }
      == (natrec F 0 (fun l acc ⇒ acc + get (M (delta k)) (elem l) × get (L (delta (elem l))) i) card)
           { (get_comb (get (M (delta k))) (fun j ⇒ L (delta j)) i (Table.get_proper _ _ (reflexivity _)) HLd card) }
      == (natrec F 0 (fun l acc ⇒ acc + jacobian L i (elem l) × jacobian M (elem l) k) card)
           { (natrec_ext F _ _ 0 _ _ (sum_step_proper _ (product_fun_proper L M i k HL)) (sum_step_proper _ (product_fun_proper' L M i k HL))
                (fun l acc ⇒ Magma.op_proper _ _ (reflexivity acc) _ _ (commutative (op := mult) _ _)) card) }.
  Qed.
End Jacobian.
