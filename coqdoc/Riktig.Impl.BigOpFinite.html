From Riktig Require Export Structure.BigOp Theory.FiniteSum.

A table over a finite index is summed by recursion on the count.
Section BigOpFinite.
  Context {I N A T : Type} `{Finite I N} {natrec : HasNatRec N} `{!NatRec N natrec}
          `{Monoid A} `{!Commutative A A add}
          {eqT : EqRel T} {get : HasGet T I A} {tabulate : HasTabulate T I A}
          `{!Table I A T get tabulate}.

  #[export] Instance Finite_HasBigOp : HasBigOp T A :=
    fun t ⇒ natrec A 0 (fun k acc ⇒ acc + get t (elem k)) card.

  #[export] Instance Finite_BigOp : BigOp I A T Finite_HasBigOp :=
    {| BigOp.bigop_proper := sum_card_proper;
       BigOp.bigop_zero := sum_card_zero;
       BigOp.bigop_add := sum_card_add;
       BigOp.bigop_single := sum_card_single |}.
End BigOpFinite.
