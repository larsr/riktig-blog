The abstract reader, run at ascii strings. The same grammar fills a dictionary with de Bruijn terms of whichever representation the context supplies: below, both the datatype-derived lambda nat and the hand-written term.

Definition prelude : string := " id = \x. x ; true = \a b. a ; false = \a b. b ; not = \p. p false true ; apply = \f x. f x ; twice = \f x. f (f x) ; ".

At the datatype-derived representation.
Definition G1 : assoc name (lambda nat) :=
  parse_first (defs_p (P := parser string) (E := list name) 64) nil prelude.

Compute find G1 (list_ascii_of_string "not").
Compute find G1 (list_ascii_of_string "twice").

At the hand-written de Bruijn terms, unchanged.
Definition G2 : assoc name term :=
  parse_first (defs_p (P := parser string) (E := list name) 64) nil prelude.

Compute find G2 (list_ascii_of_string "not").
