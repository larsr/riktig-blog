From Riktig Require Export Structure.Upd Structure.Decidable.

Slot replacement over an index with decided equality: the new family decides at each index whether it is the replaced slot.
Section UpdEquDec.
  Context {I V : Type} {eqI : EqRel I} {EqvI : Equivalence (A := I) equ} {EI : EquDec I}
    {eqV : EqRel V} {EqvV : Equivalence (A := V) equ}.

  #[export] Instance EquDec_HasUpd : HasUpd I V := fun vs i x j ⇒ if equ_dec j i then x else vs j.

  #[export] Instance EquDec_Upd : Upd I V EquDec_HasUpd.
  Proof.
    split; unfold upd, EquDec_HasUpd.
    - intros vs i x j Hji. destruct (equ_dec j i) as [_ | Hn]; [ reflexivity | destruct (Hn Hji) ].
    - intros vs i x j Hji. destruct (equ_dec j i) as [Hj | _]; [ destruct (Hji Hj) | reflexivity ].
    - intros vs i x Hvs j j' Hj.
      destruct (equ_dec j i) as [Hji | Hji]; destruct (equ_dec j' i) as [Hji' | Hji'].
      + reflexivity.
      + destruct Hji'. exact (transitivity (symmetry Hj) Hji).
      + destruct Hji. exact (transitivity Hj Hji').
      + apply Hvs. exact Hj.
  Qed.
End UpdEquDec.
