From Coq Require Import List.
Export ListNotations.

Expressions built from literals and one binary operator, and the stack code they compile to. This is the language McCarthy and Painter compiled ("Correctness of a compiler for arithmetic expressions", 1967), which Gibbons takes with a NON-associative operator -- subtraction -- so that no associativity of the source is available to the development (arXiv:2111.10413, section 5).
The code is a list of instructions run by a left fold over it, each instruction transforming the stack: PushI v pushes a literal, OpI replaces the top two cells by their combination. Compiling a node emits the code of the two subtrees and then the operation; concatenation of code is what the correctness proof turns on.
Inductive expr (V : Type) : Type :=
  | Lit (v : V)
  | Node (e f : expr V).
Arguments Lit {V} v.
Arguments Node {V} e f.

Inductive instr (V : Type) : Type :=
  | PushI (v : V)
  | OpI.
Arguments PushI {V} v.
Arguments OpI {V}.

Definition code (V : Type) : Type := list (instr V).

Section StackCode.
  Context {V : Type} (binop : V → V → V).

  Fixpoint expr_eval (e : expr V) : V :=
    match e with
    | Lit v ⇒ v
    | Node e1 e2 ⇒ binop (expr_eval e1) (expr_eval e2)
    end.

  Definition code_step (s : list V) (i : instr V) : list V :=
    match i with
    | PushI v ⇒ v :: s
    | OpI ⇒ match s with
             | b :: a :: s' ⇒ binop a b :: s'
             | _ ⇒ s
             end
    end.

  Definition code_exec (p : code V) (s : list V) : list V := fold_left code_step p s.

  Fixpoint expr_compile (e : expr V) : code V :=
    match e with
    | Lit v ⇒ [PushI v]
    | Node e1 e2 ⇒ expr_compile e1 ++ (expr_compile e2 ++ [OpI])
    end.

Running the empty program does nothing, and running a concatenation runs one program after the other: the left fold makes this fold_left_app.
  Lemma code_exec_nil : ∀ s : list V, code_exec [] s = s.
  Proof. reflexivity. Qed.

  Lemma code_exec_app : ∀ (p q : code V) (s : list V),
    code_exec (p ++ q) s = code_exec q (code_exec p s).
  Proof. intros p q s. unfold code_exec. apply fold_left_app. Qed.

  Lemma code_exec_push : ∀ (v : V) (s : list V), code_exec [PushI v] s = v :: s.
  Proof. reflexivity. Qed.

  Lemma code_exec_op : ∀ (a b : V) (s : list V),
    code_exec [OpI] (b :: a :: s) = binop a b :: s.
  Proof. reflexivity. Qed.
End StackCode.
