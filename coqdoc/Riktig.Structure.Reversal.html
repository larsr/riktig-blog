Library Riktig.Structure.Reversal

From Coq Require Import Morphisms.
From Riktig Require Export Structure.Ring.

An involutive anti-automorphism of a ring: an additive, order-reversing map that is its own inverse. Reversal in a Clifford algebra is one, transposition of matrices is one, and complex conjugation is one; a ring carrying such a map is what is usually called a ×-ring.
Module Reversal.
  Class Reversal (A : Type) {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A}
      {An : HasNeg A} {Ao : One A} {Am : HasMult A} {AR : Ring A}
      (rev : A → A) := {
    reversal_proper :: Proper (equ ==> equ) rev;
    reversal_additive :: Additive A A add add rev;
    reversal_anti : ∀ x y : A, rev (x × y) == rev y × rev x;
    reversal_involutive : ∀ x : A, rev (rev x) == x;
  }.
  Hint Mode Reversal ! - - - - - - - ! : typeclass_instances.
End Reversal.
Export Reversal.

Arguments reversal_anti {A Ae Az Aa An Ao Am AR rev _} x y.
Arguments reversal_involutive {A Ae Az Aa An Ao Am AR rev _} x.
