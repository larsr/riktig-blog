The determinant of two vectors in the plane: the area of the parallelogram they span, read as the pseudoscalar coefficient of their wedge.
Section OverAnyBasis.
  Context {F I V N : Type} `{Basis F I V N}.

The vector with the given two coordinates, and families read as columns -- everything through the structure's operations.
  Definition vec2 (x y : F) : V :=
    x *: basis (elem 0) + y *: basis (elem (succ 0)).
  Definition columns (u v : V) : I → V :=
    fun j ⇒ if EquDec.equ_dec j (elem 0) then u else v.
  Definition column2 (x y : F) : I → F :=
    fun i ⇒ if EquDec.equ_dec i (elem 0) then x else y.
  Definition matrix (a b c d : F) : I → (I → F) :=
    fun j ⇒ if EquDec.equ_dec j (elem 0) then column2 a c else column2 b d.
End OverAnyBasis.

Eval vm_compute in det (columns (vec2 (basis := plane_basis) 1%Q 2%Q) (vec2 (basis := plane_basis) 3%Q 4%Q) : two → V2).

det (1, 2) (3, 4) = 1 × 4 - 2 × 3 = - 2.
Example det_columns : det (columns (vec2 (basis := plane_basis) 1%Q 2%Q) (vec2 (basis := plane_basis) 3%Q 4%Q) : two → V2) == - 2%Q.
Proof. vm_compute. reflexivity. Qed.

Example det_plane_basis : det plane_basis == 1.
Proof. vm_compute. reflexivity. Qed.

A 2 x 2 matrix over the rationals, given by its columns: matrix a b c d is [a, b], [c, d] read by rows, so column i0 is (a, c) and column i1 is (b, d). Its determinant is the determinant of the columns read as vectors of the plane.
Eval vm_compute in det (matrix 1%Q 2%Q 3%Q 4%Q : two → (two → Q)).

Example det_1234 : det (matrix 1%Q 2%Q 3%Q 4%Q : two → (two → Q)) == - 2%Q.
Proof. vm_compute. reflexivity. Qed.

Two equal columns: zero by the theorem, and by evaluation.
Example det_equal_columns_law : det (matrix 1%Q 1%Q 3%Q 3%Q : two → (two → Q)) == 0%Q.
Proof. apply (det_equal_columns _ i0 i1); [ intros j j' Hj; rewrite Hj; reflexivity | discriminate | intros i; destruct i; reflexivity ]. Qed.

Example det_equal_columns_eval : det (matrix 1%Q 1%Q 3%Q 3%Q : two → (two → Q)) == 0%Q.
Proof. vm_compute. reflexivity. Qed.

Example det_identity : det (matrix 1 0 0 1 : two → (two → Q)) == 1.
Proof. vm_compute. reflexivity. Qed.

The basis carries a coordinate map: a vector's coordinates are read off, and the combination of the basis with them gives the vector back -- the structure's Basis.reconstruction law.
Eval vm_compute in (coords (vec2 (basis := plane_basis) 3%Q 4%Q : V2) i0, coords (vec2 (basis := plane_basis) 3%Q 4%Q : V2) i1).

Example coords_of_vec2 : coords (vec2 (basis := plane_basis) 3%Q 4%Q : V2) i0 == 3%Q ∧ coords (vec2 (basis := plane_basis) 3%Q 4%Q : V2) i1 == 4%Q.
Proof. vm_compute. split; reflexivity. Qed.

Example vec2_reconstructed :
  natrec V2 0 (fun k acc ⇒ acc + coords (vec2 (basis := plane_basis) 3%Q 4%Q : V2) (elem k) *: plane_basis (elem k)) card == (vec2 (basis := plane_basis) 3%Q 4%Q).
Proof. exact (Basis.reconstruction (vec2 (basis := plane_basis) 3%Q 4%Q : V2)). Qed.
