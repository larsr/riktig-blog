The determinant of a pair of vectors in the plane: the area of the parallelogram they span, read as the pseudoscalar coefficient of their wedge.
Definition vec2 (x y : Q) : V2 := ((tt, x), y).
Definition pair (u v : V2) : bool → V2 := fun j ⇒ if j then v else u.

Eval vm_compute in (det (pair (vec2 1 2) (vec2 3 4)))%Q.

det (1, 2) (3, 4) = 1 × 4 - 2 × 3 = - 2.
Example det_pair : (det (pair (vec2 1 2) (vec2 3 4)) == - 2)%Q.
Proof. vm_compute. reflexivity. Qed.

Example det_plane_basis : det plane_basis == 1.
Proof. vm_compute. reflexivity. Qed.

A 2 x 2 matrix over the rationals, given by its columns: matrix a b c d is [a, b], [c, d] read by rows, so column false is (a, c) and column true is (b, d). Its determinant is the determinant of the columns read as vectors of the plane.
Definition matrix (a b c d : Q) : bool → (bool → Q) :=
  fun j i ⇒ match j, i with
             | false, false ⇒ a | false, true ⇒ c
             | true, false ⇒ b | true, true ⇒ d
             end.

Eval vm_compute in (det (matrix 1 2 3 4))%Q.

Example det_1234 : (det (matrix 1 2 3 4) == - 2)%Q.
Proof. vm_compute. reflexivity. Qed.

Two equal columns: zero by the law, and by evaluation.
Example det_equal_columns_law : (det (matrix 1 1 3 3) == 0)%Q.
Proof.
  apply (alternating _ false true).
  - intros j j' Hj. rewrite Hj. reflexivity.
  - discriminate.
  - intros i. destruct i; reflexivity.
Qed.

Example det_equal_columns_eval : (det (matrix 1 1 3 3) == 0)%Q.
Proof. vm_compute. reflexivity. Qed.

Example det_identity : det (matrix 1 0 0 1) == 1.
Proof. vm_compute. reflexivity. Qed.

The basis carries a coordinate map: a vector's coordinates are read off, and the combination of the basis with them gives the vector back -- the structure's reconstruction law.
Eval vm_compute in (coords (vec2 3 4) false, coords (vec2 3 4) true)%Q.

Example coords_of_vec2 : (coords (vec2 3 4) false == 3 ∧ coords (vec2 3 4) true == 4)%Q.
Proof. vm_compute. split; reflexivity. Qed.

Example vec2_reconstructed :
  natrec V2 0 (fun k acc ⇒ acc + coords (vec2 3 4)%Q (elem k) *: plane_basis (elem k)) card == (vec2 3 4)%Q.
Proof. exact (reconstruction (vec2 3 4)%Q). Qed.
