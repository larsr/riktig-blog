A 2 x 2 matrix over the rationals as a function of two indices in bool, and its determinant as the pseudoscalar coefficient of the wedge of its columns.
Definition matrix (a b c d : Q) : bool → bool → Q :=
  fun i j ⇒ match i, j with
             | false, false ⇒ a | false, true ⇒ b
             | true, false ⇒ c | true, true ⇒ d
             end.

Eval vm_compute in det (matrix 1 (2 # 1) (3 # 1) (4 # 1))%Q.

det [[1, 2], [3, 4]] = 1 × 4 - 2 × 3 = - 2.
Example det_1234 : det (matrix 1 (2 # 1) (3 # 1) (4 # 1))%Q == (- (2 # 1))%Q.
Proof. vm_compute. reflexivity. Qed.

Two equal columns: zero by the law, and by evaluation.
Example det_equal_columns_law : det (matrix 1 1 (3 # 1) (3 # 1))%Q == 0.
Proof.
  apply (det_alternating _ false true).
  - intros i i' Hi j j' Hj. rewrite Hi, Hj. reflexivity.
  - discriminate.
  - intros i. destruct i; reflexivity.
Qed.

Example det_equal_columns_eval : det (matrix 1 1 (3 # 1) (3 # 1))%Q == 0.
Proof. vm_compute. reflexivity. Qed.

Example det_identity : det (matrix 1 0 0 1) == 1.
Proof. vm_compute. reflexivity. Qed.
