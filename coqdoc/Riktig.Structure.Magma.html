From Coq Require Export Morphisms.
From Riktig Require Export Props.

A magma is a setoid with a binary operation that respects the setoid equality.
Module Magma.
  Class Magma (M : Type) {eq : EqRel M} (op : BinOp M) := {
    equivalence :: Equivalence eq;
    op_proper :: Proper (equ ==> equ ==> equ) op;
  }.
  Hint Mode Magma ! - - : typeclass_instances.
End Magma.
Export Magma.
