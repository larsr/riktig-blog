From Riktig.Structure Require Export Adt.

The simply typed lambda terms with variables named by n and types by ty: the datatype of the signature const n + const ty × self + self × self, one level being a variable, an abstraction carrying the type it binds over a hole, or an application of one hole to another.
Module Stlc.
  Notation shape den n ty := (shape_of den (stlcS (S := sig _) n ty)).

  Class Stlc (O : Type) `{Bicartesian O} {K : Type}
      (den : K → O) (n ty : K) (T : O)
      (build : HasBuild O (shape den n ty) T)
      (fold : HasCata O (shape den n ty) T) := {
    initial :: InitialAlgebra O (shape den n ty) T build fold;
  }.
End Stlc.
