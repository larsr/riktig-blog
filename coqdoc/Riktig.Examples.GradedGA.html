The parts of a multivector of the plane algebra Cl(2) over the rationals, graded by Coq's naturals: the scalar, vector and bivector parts of 1 + e1 + 2 e1 e2, and nothing above grade 2. The graded tower of instances is pinned in Impl.CliffordPlaneQ.
Definition e1 : A2 := vec (plane_basis i0).
Definition e2 : A2 := vec (plane_basis i1).
Definition x : A2 := 1 + e1 + 2%Q *: (e1 × e2).

Eval vm_compute in x.
Eval vm_compute in ⟨x⟩_(0 : nat).
Eval vm_compute in ⟨x⟩_(1 : nat).
Eval vm_compute in ⟨x⟩_(2 : nat).
Eval vm_compute in ⟨x⟩_(3 : nat).

Example scalar_part_of_x : ⟨x⟩_(0 : nat) == 1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example vector_part_of_x : ⟨x⟩_(1 : nat) == e1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example bivector_part_of_x : ⟨x⟩_(2 : nat) == 2%Q *: (e1 × e2).
Proof. vm_compute. repeat split; reflexivity. Qed.

Example nothing_above : ⟨x⟩_(3 : nat) == 0.
Proof. vm_compute. repeat split; reflexivity. Qed.

The parts add up to the element, by the law.
Example parts_sum : natrec A2 0 (fun k acc ⇒ acc + ⟨x⟩_k) (succ (succ (succ (0 : nat)))) == x.
Proof. exact (Graded.grade_complete (N := nat) (F := Q) x). Qed.

Reversal swaps the order of the vectors in a product: the bivector changes sign, the vector does not.
Eval vm_compute in reverse (e1 × e2).

Example reverse_bivector : reverse (e1 × e2) == - (e1 × e2).
Proof. vm_compute. repeat split; reflexivity. Qed.

Example reverse_vector : reverse e1 == e1.
Proof. vm_compute. repeat split; reflexivity. Qed.

The scalar part reads the grade-0 coefficient.
Example scalar_of_x : scalar_part x == 1%Q.
Proof. vm_compute. reflexivity. Qed.

The unit bivector is a rotor: even, and inverted by its reversal; conjugating a vector with it rotates the plane by two right angles.
Example bivector_rotor : Rotor Q V2 A2 (e1 × e2).
Proof. split; vm_compute; repeat split; reflexivity. Qed.

Eval vm_compute in (e1 × e2) × e1 × reverse (e1 × e2).

Example rotor_sandwich : (e1 × e2) × e1 × reverse (e1 × e2) == - e1.
Proof. vm_compute. repeat split; reflexivity. Qed.
