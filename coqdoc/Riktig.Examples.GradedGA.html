The parts of a multivector of the plane algebra Cl(2) over the rationals, graded by Coq's naturals: the scalar, vector and bivector parts of 1 + e1 + 2 e1 e2, and nothing above grade 2.
Definition e1 : A2 := vec (plane_basis false).
Definition e2 : A2 := vec (plane_basis true).
Definition x : A2 := 1 + e1 + 2%Q *: (e1 × e2).

The grades are Coq's naturals here; the graded instances of the doublings are pinned, so instance search need not rebuild them.
Instance A1_Graded : Graded nat Q (Double (1 : Q) Q) (Double_HasGrade (1 : Q)) (succ (0 : nat)) :=
  Double_Graded (N := nat) (V := unit) (1 : Q).
Instance A2_Algebra : Algebra Q A2 (Double_Zero (1 : Q)) (Double_HasAdd (1 : Q)) (Double_HasNeg (1 : Q)) (Double_One (1 : Q)) (Double_HasMult (1 : Q)) (Double_HasScale (1 : Q)) :=
  Double_Algebra (V := Extend (1 : Q) unit) (1 : Q).
Instance A2_GradeInvolution : GradeInvolution Q V2 A2 (Double_Involute (1 : Q)) :=
  Double_GradeInvolution (V := Extend (1 : Q) unit) (1 : Q).
Instance A2_Graded : Graded nat Q A2 (Double_HasGrade (1 : Q)) (succ (succ (0 : nat))) :=
  Double_Graded (N := nat) (V := Extend (1 : Q) unit) (GA := A1_Graded) (1 : Q).

Local Notation "⟨ y ⟩_ k" := (grade_part (N := nat) k y) (at level 0, k at level 0, format "⟨ y ⟩_ k").

Eval vm_compute in x.
Eval vm_compute in ⟨x⟩_0.
Eval vm_compute in ⟨x⟩_1.
Eval vm_compute in ⟨x⟩_2.
Eval vm_compute in ⟨x⟩_3.

Example scalar_part_of_x : ⟨x⟩_0 == 1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example vector_part_of_x : ⟨x⟩_1 == e1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example bivector_part_of_x : ⟨x⟩_2 == 2%Q *: (e1 × e2).
Proof. vm_compute. repeat split; reflexivity. Qed.

Example nothing_above : ⟨x⟩_3 == 0.
Proof. vm_compute. repeat split; reflexivity. Qed.

The parts add up to the element, by the law.
Example parts_sum : natrec A2 0 (fun k acc ⇒ acc + ⟨x⟩_k) (succ (succ (succ (0 : nat)))) == x.
Proof. exact (grade_complete (N := nat) (F := Q) x). Qed.

Reversal swaps the order of the vectors in a product: the bivector changes sign, the vector does not.
Eval vm_compute in reverse (e1 × e2).

Example reverse_bivector : reverse (e1 × e2) == - (e1 × e2).
Proof. vm_compute. repeat split; reflexivity. Qed.

Example reverse_vector : reverse e1 == e1.
Proof. vm_compute. repeat split; reflexivity. Qed.

The scalar part reads the grade-0 coefficient.
Example scalar_of_x : scalar_part x == 1%Q.
Proof. vm_compute. reflexivity. Qed.

The unit bivector is a rotor: even, and inverted by its reversal; conjugating a vector with it rotates the plane by two right angles.
Example bivector_rotor : Rotor Q V2 A2 (e1 × e2).
Proof. split; vm_compute; repeat split; reflexivity. Qed.

Eval vm_compute in (e1 × e2) × e1 × reverse (e1 × e2).

Example rotor_sandwich : (e1 × e2) × e1 × reverse (e1 × e2) == - e1.
Proof. vm_compute. repeat split; reflexivity. Qed.
