A signature is an ordinary expression in the six operations, and its layer computes at the stock implementation.
Definition den_bool (b : bool) : Type := if b then nat else bool.

Compute lobj (layer den_bool (listS (S := poly bool) true)) unit.

The generic induction theorem, at the naturals of 1 + self.
Example nat_induction_derived : ∀ P : nat → Prop,
  P O → (∀ n, P n → P (S n)) → ∀ n, P n.
Proof.
  intros P h0 hS.
  apply (datatype_induction (fun e : Empty_set ⇒ match e with end)
    (natS (S := poly Empty_set)) (T := nat)).
  intros s [s' Es]. destruct s' as [[] | [n pn]]; cbn in Es; subst; cbn.
  - exact h0.
  - exact (hS n pn).
Qed.
