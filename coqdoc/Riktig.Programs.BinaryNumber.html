Library Riktig.Programs.BinaryNumber

From Riktig.Structure Require Import BinRec Naturals.

Arithmetic on any binary numbers with recursion, bit by bit: the successor carries a one bit to the left; addition recurses on the first summand and reads the bits of the second, adding one where two one bits meet; multiplication doubles and adds; and the value of a number in any naturals doubles as the bits go by. The zero-bit recursion equation holds for nonzero numbers only, so a number is read as zero, or a zero bit on a nonzero number, or a one bit.

Reading the top bit: one answer per shape.
  Definition bin_case {A : Type} (z : A) (f0 f1 : N → A) (n : N) : A :=
    binrec A z (fun m _ ⇒ f0 m) (fun m _ ⇒ f1 m) n.

  Definition bin_succ (n : N) : N :=
    binrec N (bit1 0) (fun m _ ⇒ bit1 m) (fun _ s ⇒ bit0 s) n.

  Definition bin_add (x : N) : N → N :=
    binrec (N → N) (fun y ⇒ y)
      (fun n rec y ⇒ bin_case (bit0 n) (fun m ⇒ bit0 (rec m)) (fun m ⇒ bit1 (rec m)) y)
      (fun n rec y ⇒ bin_case (bit1 n) (fun m ⇒ bit1 (rec m)) (fun m ⇒ bit0 (bin_succ (rec m))) y)
      x.

  Definition bin_mult (x y : N) : N :=
    binrec N 0 (fun _ p ⇒ bit0 p) (fun _ p ⇒ bin_add (bit0 p) y) x.

  Section Value.
    Context {N0 : Type} `{Naturals N0}.

    Definition bin_val (n : N) : N0 :=
      binrec N0 0 (fun _ v ⇒ v + v) (fun _ v ⇒ v + v + 1) n.
  End Value.
