Over any geometric algebra: the reflection of x in the hyperplane orthogonal to n, and the bivector of two vectors.
Section OverAnyGeometricAlgebra.
  Context {F V A : Type} `{GeometricAlgebra F V A}.

  Definition reflect (n x : V) : A := vec n × vec x × vec n.

  Definition bivector (u v : V) : A := vec u × vec v.
End OverAnyGeometricAlgebra.

Every Clifford algebra over the rationals is the scalars doubled once per generator, each doubling carrying the square of its generator: Cl(p,q,r) has p generators squaring to 1, q to - 1 and r to 0.

The plane, Cl(2,0,0)

Notation V2 := (Extend (1 : Q) (Extend (1 : Q) unit)).
Notation A2 := (Double (1 : Q) (Double (1 : Q) Q)).
Definition e1 : V2 := ((tt, 1), 0).
Definition e2 : V2 := ((tt, 0), 1).

Eval vm_compute in (bivector e1 e2 : A2).

The bivector squares to - 1, by evaluation and by the theorem.
Example e12_sq_eval : (bivector e1 e2 : A2) × bivector e1 e2 == - (1 : A2).
Proof. vm_compute. repeat split; reflexivity. Qed.

Example e12_sq_theorem : (bivector e1 e2 : A2) × bivector e1 e2 == - (⟪ e1 , e1 ⟫ × ⟪ e2 , e2 ⟫) *: 1.
Proof. apply orthogonal_mul_sq. vm_compute. reflexivity. Qed.

Reflecting e1 in the line orthogonal to e2 negates it.
Example reflect_e1 : (reflect e2 e1 : A2) == - vec e1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Dot and wedge of e1 + 2 e2 and 3 e1 + e2: the dot is 5, the wedge is - 5 e1 e2.
Definition u : V2 := ((tt, 1), (2 # 1)%Q).
Definition v : V2 := ((tt, (3 # 1)%Q), 1).

Eval vm_compute in ((u ⋅ v : A2), (u ∧ v : A2)).

Example dot_u_v : (u ⋅ v : A2) == ⟪ u , v ⟫ *: 1.
Proof. apply dot_eq_inner. discriminate. Qed.

The complex numbers, Cl(0,1,0): one generator squaring to - 1

Notation C := (Double (- (1 : Q)) Q).

(1 + 2 i) (3 + 4 i) = - 5 + 10 i.
Eval vm_compute in (((1, (2 # 1)%Q) : C) × (((3 # 1)%Q, (4 # 1)%Q) : C)).

Example i_sq : ((0, 1) : C) × (0, 1) == - (1 : C).
Proof. vm_compute. repeat split; reflexivity. Qed.

Plane projective geometric algebra, Cl(2,0,1): the last

generator squares to 0
Notation VP := (Extend (0 : Q) (Extend (1 : Q) (Extend (1 : Q) unit))).
Notation AP := (Double (0 : Q) (Double (1 : Q) (Double (1 : Q) Q))).
Definition e0 : VP := (((tt, 0), 0), 1).
Definition p1 : VP := (((tt, 1), 0), 0).

Example e0_sq : (vec e0 : AP) × vec e0 == 0.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example e0_p1_anticommute : (vec e0 : AP) × vec p1 == - (vec p1 × vec e0).
Proof. vm_compute. repeat split; reflexivity. Qed.

Spacetime algebra, Cl(1,3,0): γ0 squares to 1, the three

others to - 1
Notation VS := (Extend (- (1 : Q)) (Extend (- (1 : Q)) (Extend (- (1 : Q)) (Extend (1 : Q) unit)))).
Notation AS := (Double (- (1 : Q)) (Double (- (1 : Q)) (Double (- (1 : Q)) (Double (1 : Q) Q)))).
Definition g0 : VS := ((((tt, 1), 0), 0), 0).
Definition g1 : VS := ((((tt, 0), 1), 0), 0).

Example g0_sq : (vec g0 : AS) × vec g0 == 1.
Proof. vm_compute. repeat split; reflexivity. Qed.

Example g1_sq : (vec g1 : AS) × vec g1 == - (1 : AS).
Proof. vm_compute. repeat split; reflexivity. Qed.

The bivector γ0 γ1 squares to + 1: a boost, not a rotation.
Example g01_sq : (bivector g0 g1 : AS) × bivector g0 g1 == 1.
Proof. vm_compute. repeat split; reflexivity. Qed.
