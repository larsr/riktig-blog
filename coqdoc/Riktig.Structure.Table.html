Library Riktig.Structure.Table

From Coq Require Export Morphisms.
From Riktig Require Export Props.

A table over an index: reading an entry and tabulating a function cancel each way, and both respect equality.
Module Table.
  Class Table (I A T : Type) {eqI : EqRel I} {eqA : EqRel A} {eqT : EqRel T}
      (get : HasGet T I A) (tabulate : HasTabulate T I A) := {
    equivalence :: Equivalence eqT;
    get_proper :: Proper (equ ==> equ ==> equ) get;
    tabulate_proper :: Proper (pointwise_relation I equ ==> equ) tabulate;
    get_tabulate : ∀ (f : I → A) (i : I), get (tabulate f) i == f i;
    tabulate_get : ∀ t : T, tabulate (get t) == t;
  }.
  Hint Mode Table - - ! - - - - - : typeclass_instances.
End Table.
Export Table.
