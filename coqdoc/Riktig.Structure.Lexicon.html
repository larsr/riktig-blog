From Riktig.Structure Require Export Decidable.

What the lambda grammars read: characters with a decidable equality, decidable classes for the blank, the name-building and the digit ones, the value a digit carries, and the characters the grammars give meaning to -- abstraction, the dot, the parentheses, definition and its end, and the colon and arrow of the typed calculus.
Module Lexicon.
  Class Lexicon (C N : Type) {eqC : EqRel C} {eqN : EqRel N} {dC : EquDec C}
      (space alpha digit : Pred C) (digit_value : C → N)
      (backslash dot_c lparen rparen eqsign semi colon dash gt : C) := {
    characters :: Equivalence (@equ C eqC);
    space_proper :: Proper (equ ==> iff) space;
    alpha_proper :: Proper (equ ==> iff) alpha;
    digit_proper :: Proper (equ ==> iff) digit;
    digit_value_proper :: Proper (equ ==> equ) digit_value;
    space_dec : ∀ c : C, Decidable (space c);
    alpha_dec : ∀ c : C, Decidable (alpha c);
    digit_dec : ∀ c : C, Decidable (digit c);
  }.
End Lexicon.
Export Lexicon(Lexicon).
