From Riktig.Interface Require Export Field.

A formally real field, in the two-square form used here, is a field in which a × a + b × b == 0 forces a == 0; equivalently, - (1) is not a square.
Module FormallyReal.
  Class FormallyReal (F : Type) `{Field F} :=
    sum_of_squares : ∀ a b : F, a × a + b × b == 0 → a == 0.
  Hint Mode FormallyReal ! - - - - - - - - : typeclass_instances.
End FormallyReal.
Export FormallyReal.
