The plane algebra over the rationals as a frame over bool: the two generators as the basis, the coefficient of e1 e2 as the pseudoscalar coefficient.
Notation V2 := (Extend (1 : Q) (Extend (1 : Q) unit)).
Notation A2 := (Double (1 : Q) (Double (1 : Q) Q)).

Definition plane_basis (b : bool) : V2 := if b then ((tt, 0), 1) else ((tt, 1), 0).

Instance Plane_Top : HasTop Q A2 := fun x ⇒ snd (snd x).

Instance Plane_Frame : Frame Q V2 A2 bool nat plane_basis Plane_Top.
Proof.
  split.
  - intros H2. vm_compute in H2. discriminate H2.
  - intros b b' Hb. rewrite Hb. reflexivity.
  - intros x y [_ [_ Hd]]. exact Hd.
  - intros x y. reflexivity.
  - intros a x. reflexivity.
  - vm_compute. reflexivity.
Qed.
