Library Riktig.Lib.Coq.Two

From Coq Require Import Arith Lia.

The canonical two-element index: i0 is 0, i1 is 1.
Variant two : Set := i0 | i1.

Definition two_index (i : two) : nat := match i with i0 ⇒ 0 | i1 ⇒ 1 end.
Definition two_elem (k : nat) : two := match k with 0 ⇒ i0 | _ ⇒ i1 end.

Lemma two_index_lt : ∀ i : two, two_index i ≤ 2 ∧ two_index i ≠ 2.
Proof. intros [|]; simpl; lia. Qed.

Lemma two_elem_index : ∀ i : two, two_elem (two_index i) = i.
Proof. intros [|]; reflexivity. Qed.

Lemma two_index_elem : ∀ k : nat, k ≤ 2 ∧ k ≠ 2 → two_index (two_elem k) = k.
Proof. intros [| [| k]] [H1 H2]; [ reflexivity | reflexivity | lia ]. Qed.
