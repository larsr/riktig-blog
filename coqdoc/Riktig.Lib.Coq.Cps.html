Continuation-passing style. cps t is Fischer's call-by-value translation: every intermediate result is named and every call is the whole body -- the head position. triv are the trivial terms (no work to do), tail the terms whose every call is in head position; psi strips a value's translation back off.
Renaming that inserts one fresh variable at depth k.
Definition liftr (k : nat) : nat → nat := fun i ⇒ if Nat.ltb i k then i else S i.
Definition lift (k : nat) (t : term) : term := ren (liftr k) t.

Fixpoint cps (t : term) : term :=
  match t with
  | Var n ⇒ λ ⦅#0 (Var (S n))⦆
  | Const x ⇒ λ ⦅#0 (Const x)⦆
  | Lam b ⇒ λ ⦅#0 (λ (lift 1 (cps b)))⦆
  | App f a ⇒ λ ⦅(lift 0 (cps f)) (λ ⦅(lift 0 (lift 0 (cps a))) (λ ⦅#1 #0 #2⦆)⦆)⦆
  end.

Definition psi (v : term) : term :=
  match v with
  | Lam b ⇒ λ (cps b)
  | other ⇒ other
  end.

The head-position grammar

Inductive triv : term → Prop :=
  | triv_var : ∀ n : nat, triv (Var n)
  | triv_const : ∀ x : string, triv (Const x)
  | triv_lam : ∀ b : term, tail b → triv (Lam b)
with tail : term → Prop :=
  | tail_triv : ∀ v : term, triv v → tail v
  | tail_call : ∀ f v : term, triv f → triv v → tail ⦅f v⦆
  | tail_call2 : ∀ f v w : term, triv f → triv v → triv w → tail ⦅f v w⦆.

Scheme triv_tail_ind := Induction for triv Sort Prop
  with tail_triv_ind := Induction for tail Sort Prop.

The grammar is stable under renaming.
Lemma triv_ren : ∀ t : term, triv t → ∀ r : nat → nat, triv (ren r t).
Proof.
  apply (triv_tail_ind (fun t _ ⇒ ∀ r, triv (ren r t)) (fun t _ ⇒ ∀ r, tail (ren r t))).
  - intros n r. simpl. apply triv_var.
  - intros x r. simpl. apply triv_const.
  - intros b Hb IH r. simpl. apply triv_lam. apply IH.
  - intros v Hv IH r. apply tail_triv. apply IH.
  - intros f v Hf IHf Hv IHv r. simpl. apply tail_call; [ apply IHf | apply IHv ].
  - intros f v w Hf IHf Hv IHv Hw IHw r. simpl. apply tail_call2; [ apply IHf | apply IHv | apply IHw ].
Qed.

Lemma tail_ren : ∀ t : term, tail t → ∀ r : nat → nat, tail (ren r t).
Proof.
  apply (tail_triv_ind (fun t _ ⇒ ∀ r, triv (ren r t)) (fun t _ ⇒ ∀ r, tail (ren r t))).
  - intros n r. simpl. apply triv_var.
  - intros x r. simpl. apply triv_const.
  - intros b Hb IH r. simpl. apply triv_lam. apply IH.
  - intros v Hv IH r. apply tail_triv. apply IH.
  - intros f v Hf IHf Hv IHv r. simpl. apply tail_call; [ apply IHf | apply IHv ].
  - intros f v w Hf IHf Hv IHv Hw IHw r. simpl. apply tail_call2; [ apply IHf | apply IHv | apply IHw ].
Qed.

Every translated term is trivial, and its body is all tail calls: the recursive calls of a CPS program sit in head position.
Theorem cps_trivial : ∀ t : term, triv (cps t).
Proof.
  intros t. induction t as [n | b IH | f IHf a IHa | x]; simpl.
  - apply triv_lam. apply tail_call; [ apply triv_var | apply triv_var ].
  - apply triv_lam. apply tail_call; [ apply triv_var | ].
    apply triv_lam. unfold lift. apply tail_ren. apply tail_triv. exact IH.
  - apply triv_lam. apply tail_call.
    + unfold lift. apply triv_ren. exact IHf.
    + apply triv_lam. apply tail_call.
      × unfold lift. apply triv_ren. apply triv_ren. exact IHa.
      × apply triv_lam. apply tail_call2; [ apply triv_var | apply triv_var | apply triv_var ].
  - apply triv_lam. apply tail_call; [ apply triv_var | apply triv_const ].
Qed.

Applying a translated value to a continuation

One contraction hands the continuation the stripped value: the inserted lift is cancelled by the substitution.
Lemma psub_lift : ∀ (t k : term), psub (scons k Var) (lift 0 t) = t.
Proof.
  intros t k. unfold lift. rewrite psub_ren.
  rewrite (psub_ext t _ Var); [ apply psub_var | ].
  intros n. unfold liftr. simpl. reflexivity.
Qed.

Lemma psub_lift1 : ∀ (t k : term), psub (up (scons k Var)) (lift 1 t) = t.
Proof.
  intros t k. unfold lift. rewrite psub_ren.
  rewrite (psub_ext t _ Var); [ apply psub_var | ].
  intros [| n]; unfold liftr; simpl; reflexivity.
Qed.

Theorem cps_value : ∀ v k : term, triv v → joinable ⦅(cps v) k⦆ ⦅k (psi v)⦆.
Proof.
  intros v k Hv. destruct Hv as [n | x | b Hb]; simpl.
  - apply joinable_bsteps. apply star_one.
    exact (bstep_beta ⦅#0 (Var (S n))⦆ k).
  - apply joinable_bsteps. apply star_one.
    exact (bstep_beta ⦅#0 (Const x)⦆ k).
  - apply (joinable_trans _ (psub (scons k Var) ⦅#0 (λ (lift 1 (cps b)))⦆)).
    { apply joinable_bsteps. apply star_one. exact (bstep_beta _ k). }
    change (psub (scons k Var) ⦅#0 (λ (lift 1 (cps b)))⦆)
      with ⦅k (λ (psub (up (scons k Var)) (lift 1 (cps b))))⦆.
    rewrite psub_lift1. apply joinable_refl.
Qed.

Values, and how the translation renames

cps commutes with renaming on the nose, so does psi on values, and the translation of any value is one call away from handing its continuation the stripped value -- no grammar hypothesis needed.
Definition val (t : term) : bool := match t with App _ _ ⇒ false | _ ⇒ true end.

Lemma val_ren : ∀ (t : term) (r : nat → nat), val (ren r t) = val t.
Proof. intros [n | b | f a | x] r; reflexivity. Qed.

Lemma cps_ren : ∀ (t : term) (r : nat → nat), cps (ren r t) = ren r (cps t).
Proof.
  intros t. induction t as [n | b IH | f IHf a IHa | x]; intros r; simpl.
  - reflexivity.
  - rewrite IH. unfold lift. rewrite !ren_ren.
    apply f_equal. apply f_equal2; [ reflexivity | ].
    apply f_equal. apply ren_ext. intros [| j]; reflexivity.
  - rewrite IHf, IHa. unfold lift. rewrite !ren_ren.
    apply f_equal. apply f_equal2.
    + apply ren_ext. intros j. reflexivity.
    + apply f_equal. apply f_equal2.
      × apply ren_ext. intros j. reflexivity.
      × reflexivity.
  - reflexivity.
Qed.

Lemma psi_ren : ∀ (v : term) (r : nat → nat), val v = true → psi (ren r v) = ren r (psi v).
Proof.
  intros [n | b | f a | x] r H; simpl; try reflexivity; try discriminate.
  rewrite cps_ren. reflexivity.
Qed.

Lemma cps_val_eta : ∀ v : term, val v = true → cps v = λ ⦅#0 (ren S (psi v))⦆.
Proof.
  intros [n | b | f a | x] H; simpl; try reflexivity; try discriminate.
  unfold lift. apply f_equal. apply f_equal2; [ reflexivity | ].
  apply f_equal. apply ren_ext. intros [| j]; reflexivity.
Qed.

Lemma cps_val : ∀ v k : term, val v = true → joinable ⦅(cps v) k⦆ ⦅k (psi v)⦆.
Proof.
  intros v k Hv. rewrite (cps_val_eta v Hv).
  apply (joinable_trans _ (psub (scons k Var) ⦅#0 (ren S (psi v))⦆)).
  { apply joinable_bsteps. apply star_one. exact (bstep_beta _ k). }
  change (psub (scons k Var) ⦅#0 (ren S (psi v))⦆)
    with ⦅k (psub (scons k Var) (ren S (psi v)))⦆.
  rewrite psub_ren.
  rewrite (psub_ext (psi v) _ Var); [ rewrite psub_var; apply joinable_refl | intros n; reflexivity ].
Qed.

The translation commutes with substitution by values

The heart of the correctness argument: substituting values and then translating is translating and then substituting the stripped values.
Definition vals (s : sub) : Prop := ∀ n : nat, val (s n) = true.

Lemma vals_up : ∀ s : sub, vals s → vals (up s).
Proof. intros s Hs [| n]; simpl; [ reflexivity | rewrite val_ren; apply Hs ]. Qed.

Lemma psi_up : ∀ (s : sub) (n : nat), vals s → psi (up s n) = up (fun m ⇒ psi (s m)) n.
Proof. intros s [| n] Hs; simpl; [ reflexivity | rewrite psi_ren; [ reflexivity | apply Hs ] ]. Qed.

Theorem cps_psub : ∀ (t : term) (s : sub), vals s →
  cps (psub s t) = psub (fun n ⇒ psi (s n)) (cps t).
Proof.
  intros t. induction t as [n | b IH | f IHf a IHa | x]; intros s Hs; simpl.
  - rewrite (cps_val_eta (s n) (Hs n)). reflexivity.
  - rewrite (IH (up s) (vals_up s Hs)).
    rewrite (psub_ext (cps b) (fun n ⇒ psi (up s n)) (up (fun m ⇒ psi (s m)))).
    2: { intros n. apply psi_up. exact Hs. }
    assert (Hcomm : lift 1 (psub (up (fun m ⇒ psi (s m))) (cps b))
                    = psub (up (up (fun m ⇒ psi (s m)))) (lift 1 (cps b))).
    { unfold lift. rewrite ren_psub, psub_ren. apply psub_ext.
      intros [| j]; simpl; [ reflexivity | ].
      rewrite !ren_ren. apply ren_ext. intros m. reflexivity. }
    rewrite Hcomm. reflexivity.
  - rewrite (IHf s Hs), (IHa s Hs).
    assert (H1 : lift 0 (psub (fun n ⇒ psi (s n)) (cps f))
                 = psub (up (fun n ⇒ psi (s n))) (lift 0 (cps f))).
    { unfold lift. rewrite ren_psub, psub_ren. apply psub_ext.
      intros j. simpl. reflexivity. }
    assert (H2 : lift 0 (lift 0 (psub (fun n ⇒ psi (s n)) (cps a)))
                 = psub (up (up (fun n ⇒ psi (s n)))) (lift 0 (lift 0 (cps a)))).
    { unfold lift. rewrite !ren_psub, !psub_ren. apply psub_ext.
      intros j. simpl. rewrite !ren_ren. apply ren_ext. intros m. reflexivity. }
    rewrite H1, H2. reflexivity.
  - reflexivity.
Qed.

Substituting one value for index zero.
Lemma cps_psub_single : ∀ (b u : term), val u = true →
  cps (psub (scons u Var) b) = psub (scons (psi u) Var) (cps b).
Proof.
  intros b u Hu.
  rewrite (cps_psub b (scons u Var)).
  - apply psub_ext. intros [| n]; reflexivity.
  - intros [| n]; simpl; [ exact Hu | reflexivity ].
Qed.

Running a translated application

Contracting the head of cps (App f a) k hands cps f the continuation that will run a and then make the call; the inserted lifts cancel step by step.
Definition contf (a k : term) : term := λ ⦅(lift 0 (cps a)) (λ ⦅#1 #0 (ren S (ren S k))⦆)⦆.
Definition contv (w k : term) : term := λ ⦅(ren S w) #0 (ren S k)⦆.

Lemma psub_shift : ∀ t v : term, psub (scons v Var) (ren S t) = t.
Proof.
  intros t v. rewrite psub_ren.
  rewrite (psub_ext t _ Var); [ apply psub_var | intros n; reflexivity ].
Qed.

Lemma psub_up_lift00 : ∀ t k : term, psub (up (scons k Var)) (lift 0 (lift 0 t)) = lift 0 t.
Proof.
  intros t k. unfold lift. rewrite !psub_ren.
  rewrite (psub_ext t _ (fun j ⇒ Var (S j))); [ symmetry; apply ren_as_psub | ].
  intros j. reflexivity.
Qed.

Lemma psub_up_shift2 : ∀ t w : term, psub (up (scons w Var)) (ren S (ren S t)) = ren S t.
Proof.
  intros t w. rewrite !psub_ren.
  rewrite (psub_ext t _ (fun j ⇒ Var (S j))); [ symmetry; apply ren_as_psub | ].
  intros j. reflexivity.
Qed.

Lemma cps_app_unfold : ∀ f a k : term, joinable ⦅(cps (App f a)) k⦆ ⦅(cps f) (contf a k)⦆.
Proof.
  intros f a k.
  apply (joinable_trans _ (psub (scons k Var) ⦅(lift 0 (cps f)) (λ ⦅(lift 0 (lift 0 (cps a))) (λ ⦅#1 #0 #2⦆)⦆)⦆)).
  { apply joinable_bsteps. apply star_one. exact (bstep_beta _ k). }
  change (psub (scons k Var) ⦅(lift 0 (cps f)) (λ ⦅(lift 0 (lift 0 (cps a))) (λ ⦅#1 #0 #2⦆)⦆)⦆)
    with ⦅(psub (scons k Var) (lift 0 (cps f))) (λ ⦅(psub (up (scons k Var)) (lift 0 (lift 0 (cps a)))) (λ ⦅#1 #0 (ren S (ren S k))⦆)⦆)⦆.
  rewrite psub_lift, psub_up_lift00. apply joinable_refl.
Qed.

Lemma contf_apply : ∀ a k w : term, joinable ⦅(contf a k) w⦆ ⦅(cps a) (contv w k)⦆.
Proof.
  intros a k w. unfold contf.
  apply (joinable_trans _ (psub (scons w Var) ⦅(lift 0 (cps a)) (λ ⦅#1 #0 (ren S (ren S k))⦆)⦆)).
  { apply joinable_bsteps. apply star_one. exact (bstep_beta _ w). }
  change (psub (scons w Var) ⦅(lift 0 (cps a)) (λ ⦅#1 #0 (ren S (ren S k))⦆)⦆)
    with ⦅(psub (scons w Var) (lift 0 (cps a))) (λ ⦅(ren S w) #0 (psub (up (scons w Var)) (ren S (ren S k)))⦆)⦆.
  rewrite psub_lift, psub_up_shift2. apply joinable_refl.
Qed.

Lemma contv_apply : ∀ w k v : term, joinable ⦅(contv w k) v⦆ ⦅w v k⦆.
Proof.
  intros w k v. unfold contv.
  apply (joinable_trans _ (psub (scons v Var) ⦅(ren S w) #0 (ren S k)⦆)).
  { apply joinable_bsteps. apply star_one. exact (bstep_beta _ v). }
  change (psub (scons v Var) ⦅(ren S w) #0 (ren S k)⦆)
    with ⦅(psub (scons v Var) (ren S w)) v (psub (scons v Var) (ren S k))⦆.
  rewrite !psub_shift. apply joinable_refl.
Qed.

Lemma cps_app_val : ∀ f a k : term, val f = true →
  joinable ⦅(cps (App f a)) k⦆ ⦅(cps a) (contv (psi f) k)⦆.
Proof.
  intros f a k Hf.
  apply (joinable_trans _ ⦅(cps f) (contf a k)⦆); [ exact (cps_app_unfold f a k) | ].
  apply (joinable_trans _ ⦅(contf a k) (psi f)⦆); [ exact (cps_val f (contf a k) Hf) | ].
  exact (contf_apply a k (psi f)).
Qed.

Lemma cps_app_vals : ∀ f a k : term, val f = true → val a = true →
  joinable ⦅(cps (App f a)) k⦆ ⦅(psi f) (psi a) k⦆.
Proof.
  intros f a k Hf Ha.
  apply (joinable_trans _ ⦅(cps a) (contv (psi f) k)⦆); [ exact (cps_app_val f a k Hf) | ].
  apply (joinable_trans _ ⦅(contv (psi f) k) (psi a)⦆); [ exact (cps_val a _ Ha) | ].
  exact (contv_apply (psi f) k (psi a)).
Qed.

Contracting a redex with a value argument.
Lemma cps_beta : ∀ (b u k : term), val u = true →
  joinable ⦅(cps (App (Lam b) u)) k⦆ ⦅(cps (psub (scons u Var) b)) k⦆.
Proof.
  intros b u k Hu.
  apply (joinable_trans _ ⦅(psi (Lam b)) (psi u) k⦆); [ exact (cps_app_vals (Lam b) u k eq_refl Hu) | ].
  apply (joinable_trans _ ⦅(psub (scons (psi u) Var) (cps b)) k⦆).
  { apply joinable_bsteps. apply star_one. apply bstep_app_l. exact (bstep_beta (cps b) (psi u)). }
  rewrite <- (cps_psub_single b u Hu). apply joinable_refl.
Qed.

Call-by-value evaluation, and the correctness of the translation

Inductive cbv : term → term → Prop :=
  | cbv_beta : ∀ b u : term, val u = true → cbv (App (Lam b) u) (psub (scons u Var) b)
  | cbv_app_l : ∀ f f' a : term, cbv f f' → cbv (App f a) (App f' a)
  | cbv_app_r : ∀ f a a' : term, val f = true → cbv a a' → cbv (App f a) (App f a').

Definition cbvs : term → term → Prop := star cbv.

Lemma cbv_bstep : ∀ t t' : term, cbv t t' → bstep t t'.
Proof.
  intros t t' H. induction H as [b u Hu | f f' a H IH | f a a' Hf H IH].
  - exact (bstep_beta b u).
  - exact (bstep_app_l f f' a IH).
  - exact (bstep_app_r f a a' IH).
Qed.

Lemma cbvs_bsteps : ∀ t t' : term, cbvs t t' → bsteps t t'.
Proof.
  intros t t' H. induction H as [t | t x u Hx Hs IH].
  - apply star_refl.
  - exact (star_step bstep _ _ _ (cbv_bstep _ _ Hx) IH).
Qed.

One call-by-value step does not change what a translated term does with its continuation.
Theorem cps_cbv : ∀ t t' : term, cbv t t' →
  ∀ k : term, joinable ⦅(cps t) k⦆ ⦅(cps t') k⦆.
Proof.
  intros t t' H. induction H as [b u Hu | f f' a H IH | f a a' Hf H IH]; intros k.
  - exact (cps_beta b u k Hu).
  - apply (joinable_trans _ ⦅(cps f) (contf a k)⦆); [ exact (cps_app_unfold f a k) | ].
    apply (joinable_trans _ ⦅(cps f') (contf a k)⦆); [ exact (IH (contf a k)) | ].
    apply joinable_sym. exact (cps_app_unfold f' a k).
  - apply (joinable_trans _ ⦅(cps a) (contv (psi f) k)⦆); [ exact (cps_app_val f a k Hf) | ].
    apply (joinable_trans _ ⦅(cps a') (contv (psi f) k)⦆); [ exact (IH (contv (psi f) k)) | ].
    apply joinable_sym. exact (cps_app_val f a' k Hf).
Qed.

The theorem: a call-by-value run of l to a value v makes the translation hand any continuation the stripped value.
Theorem cps_correct : ∀ l v : term, cbvs l v → val v = true →
  ∀ k : term, joinable ⦅(cps l) k⦆ ⦅k (psi v)⦆.
Proof.
  intros l v H. induction H as [t | t x v Hx Hs IH]; intros Hv k.
  - exact (cps_val t k Hv).
  - apply (joinable_trans _ ⦅(cps x) k⦆); [ exact (cps_cbv t x Hx k) | ].
    exact (IH Hv k).
Qed.
