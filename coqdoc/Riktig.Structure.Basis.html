From Coq Require Import RelationClasses.
From Riktig Require Import Structure.LinearMap.
From Riktig Require Export Theory.Basis.

A basis of V is a family of vectors indexed by a finite carrier I, with a linear coordinate map, each inverse to the other: every vector is the linear combination of the family with its coordinates, and the coordinates of such a combination are its coefficients.
Module Basis.
  Class Basis (n : nat) (I F V : Type)
      {eI : EqRel I} {Ieq : EquDec I} {IFin : FinIndex n I}
      {Fe : EqRel F} {Fz : Zero F} {Fa : HasAdd F} {Fn : HasNeg F} {Fo : One F}
      {Fm : HasMult F} {Fi : HasInv F} {FF : Field F}
      {eV : EqRel V} {zV : Zero V} {aV : HasAdd V} {nV : HasNeg V} {sV : HasScale F V}
      {VV : VectorSpace F V} {Vl : HasLincomb I F V} := {
    vec : I → V;
    
    vec_proper :: Proper (equ ==> equ) vec;
    coords : LinearMap F V (I → F);
    
    coords_family_proper :: ∀ v : V,
      Proper (equ ==> equ) (coords v);
    reconstruction : ∀ v : V,
      lincomb vec (coords v) == v;
    
    coords_linear_combination : ∀ c : I → F,
      Proper (equ ==> equ) c →
      coords (lincomb vec c) == c
  }.
  Arguments vec {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
  Arguments vec_proper {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
  Arguments coords {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
  Arguments coords_family_proper {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
  Arguments reconstruction {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
  Arguments coords_linear_combination {n I F V eI Ieq IFin Fe Fz Fa Fn Fo Fm Fi FF eV zV aV nV sV VV Vl}.
End Basis.
Export Basis(Basis).
