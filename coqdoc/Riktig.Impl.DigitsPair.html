From Riktig.Structure Require Export Digits.
From Riktig.Theory Require Export Digits.

A pair of digit sets over the same carries is a digit set of the product base: the value is the low digit plus the base times the high digit, and adding ripples the carry from the low digits to the high. The laws are Theory.Digits' ripple facts.
Section DigitsPair.
  Context {N : Type} `{NatOrder N} {B : Type} {eqB : EqRel B} {valB : HasVal B N}.
  Context {D1 : Type} {eqD1 : EqRel D1} {radix1 : HasRadix D1 N} {val1 : HasVal D1 N}
    {add1 : HasAddDigit B D1} {carry1 : HasCarry B D1} {G1 : Digits D1 B N radix1 val1 valB add1 carry1}.
  Context {D2 : Type} {eqD2 : EqRel D2} {radix2 : HasRadix D2 N} {val2 : HasVal D2 N}
    {add2 : HasAddDigit B D2} {carry2 : HasCarry B D2} {G2 : Digits D2 B N radix2 val2 valB add2 carry2}.

  #[export] Instance Pair_EqRel : EqRel (D1 × D2) := fun p q ⇒ fst p == fst q ∧ snd p == snd q.
  #[export] Instance Pair_HasRadix : HasRadix (D1 × D2) N := {| radix := @radix D1 N radix1 × @radix D2 N radix2 |}.
  #[export] Instance Pair_HasVal : HasVal (D1 × D2) N := fun p ⇒ val (fst p) + @radix D1 N radix1 × val (snd p).
  #[export] Instance Pair_HasAddDigit : HasAddDigit B (D1 × D2) :=
    fun x y c ⇒ (add_digit (fst x) (fst y) c, add_digit (snd x) (snd y) (carry (fst x) (fst y) c)).
  #[export] Instance Pair_HasCarry : HasCarry B (D1 × D2) :=
    fun x y c ⇒ carry (snd x) (snd y) (carry (fst x) (fst y) c).

  #[export] Instance Pair_Digits : Digits (D1 × D2) B N Pair_HasRadix Pair_HasVal valB Pair_HasAddDigit Pair_HasCarry :=
    @Digits.Build_Digits (D1 × D2) B N _ _ _ _ _ _ _ _ _ Pair_EqRel eqB Pair_HasRadix Pair_HasVal valB Pair_HasAddDigit Pair_HasCarry
      {| Equivalence_Reflexive := fun p ⇒ conj (reflexivity _) (reflexivity _);
         Equivalence_Symmetric := fun p q E ⇒ conj (symmetry (proj1 E)) (symmetry (proj2 E));
         Equivalence_Transitive := fun p q r E F ⇒ conj (transitivity (proj1 E) (proj1 F)) (transitivity (proj2 E) (proj2 F)) |}
      (Digits.equivalence_carry (Digits := G1))
      (fun p q E ⇒ pair_val_proper (fst p) (fst q) (snd p) (snd q) (proj1 E) (proj2 E))
      (Digits.val_carry_proper (Digits := G1))
      (fun x x' Ex y y' Ey c c' Ec ⇒
         conj (Digits.add_digit_proper _ _ (proj1 Ex) _ _ (proj1 Ey) c c' Ec)
              (Digits.add_digit_proper _ _ (proj2 Ex) _ _ (proj2 Ey) _ _
                 (Digits.carry_proper _ _ (proj1 Ex) _ _ (proj1 Ey) c c' Ec)))
      (fun x x' Ex y y' Ey c c' Ec ⇒
         Digits.carry_proper _ _ (proj2 Ex) _ _ (proj2 Ey) _ _ (Digits.carry_proper _ _ (proj1 Ex) _ _ (proj1 Ey) c c' Ec))
      (fun p ⇒ ripple_lt (fst p) (snd p))
      (Digits.val_carry_lt (Digits := G1))
      (fun x y c ⇒ ripple_spec (fst x) (fst y) (snd x) (snd y) c).
End DigitsPair.
