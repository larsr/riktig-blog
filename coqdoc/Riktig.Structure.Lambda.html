From Coq Require Export Morphisms.
From Riktig.Structure Require Export Naturals.

The lambda calculus with variables indexed by the naturals N and explicit substitutions: terms T and substitutions Sb. Terms are compared up to conversion. A substitution acts on variables as the equations say -- the identity leaves a term alone, consing u answers u at index 0 and the rest of the substitution above, the shift raises every index, lifting under a binder keeps index 0 and shifts the others -- and it passes through application and abstraction, lifted under the binder. The two shift laws say how a shifted term meets a cons and a lift. Beta: applying an abstraction substitutes the argument for index 0.
Module LambdaCalculus.
  Class LambdaCalculus (N T Sb : Type) `{Naturals N} {eqT : EqRel T}
      (var_ : HasVar N T) (lam_ : HasLam T) (app_ : HasApp T) (subst_ : HasSubst T Sb)
      (id_ : HasSubId Sb) (shift_ : HasSubShift Sb) (cons_ : HasSubCons T Sb) (up_ : HasSubUp Sb) := {
    terms :: Equivalence (@equ T eqT);
    var_proper :: Proper (equ ==> equ) (@var N T var_);
    lam_proper :: Proper (equ ==> equ) (@lam T lam_);
    app_proper :: Proper (equ ==> equ ==> equ) (@app T app_);
    subst_proper : ∀ (t t' : T) (s : Sb), t == t' → t.[s] == t'.[s];
    subst_id : ∀ t : T, t.[sub_id] == t;
    var_zero_cons : ∀ (u : T) (s : Sb), (var 0 : T).[u .: s] == u;
    var_succ_cons : ∀ (n : N) (u : T) (s : Sb), (var (succ n) : T).[u .: s] == (var n : T).[s];
    var_shift : ∀ n : N, (var n : T).[sub_shift] == var (succ n);
    var_zero_up : ∀ s : Sb, (var 0 : T).[sub_up s] == var 0;
    var_succ_up : ∀ (n : N) (s : Sb), (var (succ n) : T).[sub_up s] == ((var n : T).[s]).[sub_shift];
    app_subst : ∀ (f a : T) (s : Sb), (app f a).[s] == app (f.[s]) (a.[s]);
    lam_subst : ∀ (b : T) (s : Sb), (lam b).[s] == lam (b.[sub_up s]);
    shift_cons : ∀ (t u : T) (s : Sb), (t.[sub_shift]).[u .: s] == t.[s];
    shift_up : ∀ (t : T) (s : Sb), (t.[sub_shift]).[sub_up s] == (t.[s]).[sub_shift];
    beta : ∀ (b u : T), app (lam b) u == b.[u .: sub_id];
  }.
  Hint Mode LambdaCalculus - ! - - - - - - - - - - - - - - - - - : typeclass_instances.
End LambdaCalculus.
