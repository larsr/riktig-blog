From Riktig.Structure Require Export VectorSpace Upd.

A form on families of vectors is multilinear when it respects equality of families and, in every slot of every family, is additive and homogeneous as a function of that slot. Families are functions that respect equality of the index.
Module Multilinear.
  Class Multilinear (F I V : Type) `{VectorSpace F V} {eqI : EqRel I} {update : HasUpd I V}
      (form : (I → V) → F) := {
    form_proper : ∀ vs vs' : I → V,
      Proper (equ ==> equ) vs → Proper (equ ==> equ) vs' →
      (∀ i : I, vs i == vs' i) → form vs == form vs';
    slot_additive : ∀ (vs : I → V) (j : I), Proper (equ ==> equ) vs →
      Additive V F add add (fun x ⇒ form (upd vs j x));
    slot_homogeneous : ∀ (vs : I → V) (j : I), Proper (equ ==> equ) vs →
      Homogeneous F V F mult (fun a ⇒ a) (fun x ⇒ form (upd vs j x));
  }.
  Hint Mode Multilinear - - - - - - - - - - - - - - - - - - - ! : typeclass_instances.
End Multilinear.
Export Multilinear.

A form on families is alternating when it vanishes on every family holding the same vector in two different slots.
Module Alternating.
  Class Alternating (F I V : Type) {eqF : EqRel F} {zF : Zero F} {eqI : EqRel I} {eqV : EqRel V}
      (form : (I → V) → F) :=
    alternating : ∀ (vs : I → V) (i j : I),
      Proper (equ ==> equ) vs → i =/= j → vs i == vs j → form vs == 0.
  Hint Mode Alternating - - - - - - - ! : typeclass_instances.
End Alternating.
Export Alternating.
