Library Riktig.Impl.SequenceList

From Coq Require Import List.
From Riktig Require Export Structure.Sequence.

Coq lists as sequences, compared by Coq's equality on both the elements and the lists.
Section SequenceList.
  Context {C : Type}.

  #[export] Instance List_EqRel : EqRel (list C) := eq.
  #[export] Instance List_HasEmpty : HasEmpty (list C) := Datatypes.nil.
  #[export] Instance List_HasCons : HasCons C (list C) := Datatypes.cons.

  #[export] Instance List_Sequence : Sequence C (list C) List_HasEmpty List_HasCons (eqC := eq).
  Proof.
    split.
    - exact eq_equivalence.
    - exact eq_equivalence.
    - intros c c' Hc s s' Hs. rewrite Hc, Hs. reflexivity.
    - intros c c' s s' H. injection H as Hc Hs. split; assumption.
    - intros c s H. discriminate H.
  Qed.
End SequenceList.
