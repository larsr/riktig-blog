A proposition is decidable when it or its negation holds.
Class Decidable (P : Prop) := dec : {P} + {¬ P}.
Arguments dec _ {_}.


Leibniz equality x = y on A is decidable — the syntactic equality of terms, not a setoid relation.
Class EqDec (A : Type) := eq_dec : ∀ (x y : A), Decidable (x = y).
Hint Mode EqDec ! : typeclass_instances.
Instance EqDec_Decidable {A} `{EqDec A} : ∀ x y : A, Decidable (x = y) := eq_dec.

The setoid equality a == b on A is decidable — the EqRel the algebra tower reasons up to, coarser than = on carriers such as Q.
Class EquDec (A : Type) {e : EqRel A} :=
  equ_dec : ∀ a b : A, Decidable (a == b).
Hint Mode EquDec ! - : typeclass_instances.
Instance EquDec_Decidable {A} {e : EqRel A} `{EquDec A} : ∀ a b : A, Decidable (a == b) := equ_dec.

On a carrier whose setoid equality is Leibniz eq, EqDec already decides ==.
Instance EqDec_EquDec {A} `{EqDec A} : EquDec A (e := eq) := eq_dec.
