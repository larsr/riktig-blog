From Riktig Require Export Ops.

A proposition is decided when it or its negation is given.
Class Decidable (P : Prop) := dec : {P} + {¬ P}.

Equality on a carrier is decided.
Module EquDec.
  Class EquDec (A : Type) {eqA : EqRel A} :=
    equ_dec : ∀ a b : A, Decidable (a == b).
  Hint Mode EquDec ! - : typeclass_instances.
End EquDec.
Export EquDec.

The strict order on a carrier is decided.
Module LtDec.
  Class LtDec (A : Type) {eqA : EqRel A} {le : HasLe A} :=
    lt_dec : ∀ a b : A, Decidable (a < b).
  Hint Mode LtDec ! - - : typeclass_instances.
End LtDec.
Export LtDec.
