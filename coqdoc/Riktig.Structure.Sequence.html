Library Riktig.Structure.Sequence

From Riktig.Structure Require Export Decidable.

A sequence of elements of C, read one element at a time: step s c s' says that s yields the element c and leaves s'. The reading respects equality and is determined by s.
Module Sequence.
  Class Sequence (C S : Type) {eqC : EqRel C} {eqS : EqRel S} (stepping : HasStep C S) := {
    elements :: Equivalence (@equ C eqC);
    equivalence :: Equivalence (@equ S eqS);
    step_proper :: Proper (equ ==> equ ==> equ ==> iff) (@step C S stepping);
    step_deterministic : ∀ (s : S) (c c' : C) (s' s'' : S),
      step s c s' → step s c' s'' → c == c' ∧ s' == s'';
  }.
  Hint Mode Sequence - ! - - - : typeclass_instances.
End Sequence.
Export Sequence.
