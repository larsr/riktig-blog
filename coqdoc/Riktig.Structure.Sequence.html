Library Riktig.Structure.Sequence

From Coq Require Export Morphisms.
From Riktig.Structure Require Export Decidable.

A sequence of elements of C: an empty sequence, and an element put in front of a sequence, which respects equality, is injective in both arguments, and never gives the empty sequence.
Module Sequence.
  Class Sequence (C S : Type) {eqC : EqRel C} {eqS : EqRel S} (empty_ : HasEmpty S) (cons_ : HasCons C S) := {
    elements :: Equivalence (@equ C eqC);
    equivalence :: Equivalence (@equ S eqS);
    cons_proper :: Proper (equ ==> equ ==> equ) (@cons C S cons_);
    cons_injective : ∀ (c c' : C) (s s' : S), cons c s == cons c' s' → c == c' ∧ s == s';
    cons_not_empty : ∀ (c : C) (s : S), cons c s =/= empty;
  }.
  Hint Mode Sequence - ! - - - - : typeclass_instances.
End Sequence.
Export Sequence.
