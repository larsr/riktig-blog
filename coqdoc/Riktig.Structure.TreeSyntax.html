Library Riktig.Structure.TreeSyntax

From Coq Require Export Morphisms.
From Riktig Require Export Props.

Binary trees over a carrier A: every tree is a tip carrying an element or a fork of two trees, a tip is never a fork, the constructors are injective, and a property that holds of every tip and passes from two trees to their fork holds of every tree. This is the shape the classical transformations traverse -- flattening a tree, and evaluating an expression built from literals and one binary operator (Gibbons, "Continuation-passing style, defunctionalization, accumulations, and associativity", 2022, arXiv:2111.10413, sections 4 and 5).
Module Tree.
  Class Tree (A Tr : Type) {eqA : EqRel A} {eqTr : EqRel Tr}
      (tipT : HasTip A Tr) (forkT : HasFork Tr) := {
    equivalence :: Equivalence (@equ Tr eqTr);
    tip_proper :: Proper (equ ==> equ) (tip : A → Tr);
    fork_proper :: Proper (equ ==> equ ==> equ) (fork : Tr → Tr → Tr);
    tip_injective :: Injective A Tr (tip : A → Tr);
    fork_injective : ∀ t u t' u' : Tr, fork t u == fork t' u' → t == t' ∧ u == u';
    tip_not_fork : ∀ (a : A) (t u : Tr), tip a =/= fork t u;
    tree_induction : ∀ P : Tr → Prop, Proper (equ ==> iff) P →
      (∀ a : A, P (tip a)) →
      (∀ t u : Tr, P t → P u → P (fork t u)) →
      ∀ t : Tr, P t;
  }.
End Tree.
