From Riktig.Structure Require Import Parser NatRec Decidable.

Combinators over any parser structure: reading one element that satisfies a decidable class, and repetition with the loop factored out -- natrec is the loop and the fuel is any naturals, a bound on how many times to read. Nothing here names an implementation: the parser, the stream and the naturals are all structures.
Section Combinators.
  Context {C S : Type} {P : Type → Type} `{Parser C S P}.
  Context {N : Type} `{NatRec N}.

  Definition p_sat (Q : C → Prop) (dQ : ∀ c : C, Decidable (Q c)) : P C :=
    item >>= (fun c ⇒ if dQ c then ret c else fail).

  Definition p_fold {A B : Type} (fuel : N) (p : P A) (b : B) (f : A → B → B) : P B :=
    natrec (P B) (ret b)
      (fun _ rec ⇒ ((p >>= fun a ⇒ rec >>= fun r ⇒ ret (f a r)) <|> ret b))
      fuel.

  Definition p_foldl {A B : Type} (fuel : N) (p : P A) (b : B) (f : B → A → B) : P B :=
    natrec (B → P B) (fun acc ⇒ ret acc)
      (fun _ rec acc ⇒ ((p >>= fun a ⇒ rec (f acc a)) <|> ret acc))
      fuel b.
End Combinators.
