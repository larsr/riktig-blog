From Coq Require Import List.
From Riktig Require Import Ops Lib.Coq.Parser.
Import ListNotations.

Repetition, with the loop factored out of the program: the step reads one element and hands the rest of the input to the function it is given for the recursive call; natrec is the loop, and the fuel is any naturals -- a bound on how much can be read.
Section Repeat.
  Context {St : Type} {N : Type} {natrecN : HasNatRec N}.

  Definition p_many {A : Type} (size : St → N) (p : parser St A) : parser St (list A) :=
    fun s ⇒ natrec (parser St (list A)) (p_ret nil) (fun _ rec ⇒ p_many_step p rec) (size s) s.

  Definition p_many1 {A : Type} (size : St → N) (p : parser St A) : parser St (list A) :=
    p_bind p (fun a ⇒ p_bind (p_many size p) (fun l ⇒ p_ret (a :: l))).
End Repeat.
