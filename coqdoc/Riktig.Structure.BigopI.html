bigopI f is the sum of f over a finite index carrier.
Module BigopI.
  Class BigopI (n : nat) (I M : Type) {eI : EqRel I} {Ieq : EquDec I}
      {IFin : FinIndex n I}
      {Me : EqRel M} {Mz : Zero M} {Ma : HasAdd M} {MM : Monoid M}
      (bigopI : (I → M) → M) :=
    bigopI_def : ∀ f : I → M, bigopI f == bigop_list f enum.
  Hint Mode BigopI - ! ! - - - - - - - - : typeclass_instances.
End BigopI.

A sum over a sum carrier splits. This is the index-level face of Theory/Biproduct.v's join_fork, and the recurrence a divide-and-conquer matrix product runs on.
Module BigopSum.
  Class BigopSum (J1 J2 M : Type) {Me : EqRel M} {Ma : HasAdd M}
      (bigop_l : (J1 → M) → M) (bigop_r : (J2 → M) → M)
      (bigop_sum : (J1 + J2 → M) → M) :=
    bigopI_sum : ∀ f : J1 + J2 → M,
      bigop_sum f == bigop_l (fun j ⇒ f (inl j)) + bigop_r (fun j ⇒ f (inr j)).
  Hint Mode BigopSum ! ! ! - - - - - : typeclass_instances.
End BigopSum.
Export BigopSum.
