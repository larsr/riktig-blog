The three constructors of any lambda-term algebra over Coq's types, as the operations the notation classes name.
Section Ops.
  Context {N T : Type}
    {tb : HasBuild Type (LambdaTerm.shape (fun T0 : Type ⇒ T0) N) T}
    {tf : HasCata Type (LambdaTerm.shape (fun T0 : Type ⇒ T0) N) T}
    `{!LambdaTerm Type (fun T0 : Type ⇒ T0) N T tb tf}.

  #[export] Instance LambdaTerm_HasVar : HasVar N T := fun n ⇒ tb (inl (inl n)).
  #[export] Instance LambdaTerm_HasLam : HasLam T := fun b ⇒ tb (inl (inr b)).
  #[export] Instance LambdaTerm_HasApp : HasApp T := fun f a ⇒ tb (inr (f, a)).
End Ops.
