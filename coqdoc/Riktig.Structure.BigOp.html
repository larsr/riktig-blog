Library Riktig.Structure.BigOp

From Riktig.Structure Require Export Table Monoid.

The sum of a table of monoid elements: it respects equality, the zero table sums to zero, the entrywise sum of two tables sums to the sum of their sums, and a table that is a at one index and zero elsewhere sums to a.
Module BigOp.
  Class BigOp (I A T : Type) `{Monoid A} {eqI : EqRel I} {eqT : EqRel T}
      {get : HasGet T I A} {tabulate : HasTabulate T I A} `{!Table I A T get tabulate}
      (bigop : HasBigOp T A) := {
    bigop_proper :: Proper (equ ==> equ) bigop;
    bigop_zero : bigop (tabulate (fun _ ⇒ 0)) == 0;
    bigop_add : ∀ s t : T, bigop (tabulate (fun i ⇒ get s i + get t i)) == bigop s + bigop t;
    bigop_single : ∀ (t : T) (i : I) (a : A),
      get t i == a → (∀ j : I, j =/= i → get t j == 0) → bigop t == a;
  }.
  Hint Mode BigOp - - ! - - - - - - - - - - : typeclass_instances.
End BigOp.
Export BigOp.
