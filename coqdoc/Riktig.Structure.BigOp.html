bigop_list f l is the sum of f over an explicit index list, and these are the two equations that say so.
Module BigOp.
  Class BigOp (M : Type) {Me : EqRel M} {Mz : Zero M} {Ma : HasAdd M}
      (bigop_list : ∀ J : Type, (J → M) → list J → M) := {
    bigop_list_nil : ∀ (J : Type) (f : J → M),
      bigop_list J f nil == 0;
    bigop_list_cons : ∀ (J : Type) (f : J → M) (j : J) (l : list J),
      bigop_list J f (j :: l) == f j + bigop_list J f l;
  }.
  Hint Mode BigOp ! - - - - : typeclass_instances.
  Arguments bigop_list_nil {M Me Mz Ma bigop_list BigOp J} f.
  Arguments bigop_list_cons {M Me Mz Ma bigop_list BigOp J} f j l.
End BigOp.
Export BigOp.

A sum over a sum carrier splits. This is the index-level face of Theory/Biproduct.v's join_fork, and the recurrence a divide-and-conquer matrix product runs on.
Module BigopSum.
  Class BigopSum (n1 n2 nS : nat) (J1 J2 M : Type)
      {e1 : EqRel J1} {d1 : EquDec J1} {FI1 : FinIndex n1 J1}
      {e2 : EqRel J2} {d2 : EquDec J2} {FI2 : FinIndex n2 J2}
      {eS : EqRel (J1 + J2)} {dS : EquDec (J1 + J2)}
      {FIS : FinIndex nS (J1 + J2)}
      {Me : EqRel M} {Mz : Zero M} {Ma : HasAdd M}
      (bigop_list : ∀ {J : Type}, (J → M) → list J → M)
      {BL : BigOp M (@bigop_list)} :=
    bigopI_sum : ∀ f : J1 + J2 → M,
      bigop_list f enum
        == bigop_list (fun j ⇒ f (inl j)) enum
         + bigop_list (fun j ⇒ f (inr j)) enum.
  Hint Mode BigopSum - - - ! ! ! - - - - - - - - - - - - - - :
    typeclass_instances.
End BigopSum.
Export BigopSum.
