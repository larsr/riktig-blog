Library Riktig.Structure.TypedLambda

From Riktig.Structure Require Export Lambda LambdaType.

Well-typed lambda terms: a typing relation between a context -- the types of the free variables, one per index -- a term, and a type, generated as the three rules say: a variable has the type the context gives it, an abstraction sends the type it binds to the type of its body, an application eats the arrow's source. Typing respects equality of everything involved.
Module TypedLambda.
  Class TypedLambda (B Ty N T Sb G : Type) `{LambdaCalculus N T Sb} `{LambdaType B Ty}
      (lookup_ : G → N → Ty) (extend_ : Ty → G → G)
      (typing : G → T → Ty → Prop) := {
    typing_proper : ∀ (g : G) (t : T) (A A' : Ty),
      A == A' → typing g t A → typing g t A';
    typed_var : ∀ (g : G) (n : N), typing g (var n) (lookup_ g n);
    typed_lam : ∀ (g : G) (A C : Ty) (b : T),
      typing (extend_ A g) b C → typing g (lam b) (A --> C);
    typed_app : ∀ (g : G) (A C : Ty) (f a : T),
      typing g f (A --> C) → typing g a A → typing g (app f a) C;
    lookup_extend_zero : ∀ (g : G) (A : Ty), lookup_ (extend_ A g) 0 == A;
    lookup_extend_succ : ∀ (g : G) (A : Ty) (n : N), lookup_ (extend_ A g) (succ n) == lookup_ g n;
    
    preservation : ∀ (g : G) (t t' : T) (A : Ty),
      typing g t A → t -->* t' → typing g t' A;
  }.
  Hint Mode TypedLambda - - - ! - - - - - - - - - - - - - - - - - - - - - - - - - - - ! : typeclass_instances.
End TypedLambda.
