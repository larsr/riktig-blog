The computational reals: a root of two to twenty digits, by reflexivity, and an exact root where there is one.
Example sqrt_two_20_digits :
  approx_sqrt (2 # 1)%Q (1 # 100000000000000000000)%Q
    == (141421356237309504880 # 100000000000000000000)%Q.
Proof. reflexivity. Qed.

Example sqrt_twenty_five : approx_sqrt (25 # 1)%Q (1 # 10000)%Q == (5 # 1)%Q.
Proof. reflexivity. Qed.

And the bracket the structure promises, at this carrier.
Example bracket : ∀ x eps : Q, 0 ≤ x → 0 < eps →
  approx_sqrt x eps × approx_sqrt x eps ≤ x ∧
  x ≤ (approx_sqrt x eps + eps) × (approx_sqrt x eps + eps).
Proof. intros x eps Hx Heps. split; [ exact (approx_sqrt_le x eps Hx Heps) | exact (approx_sqrt_close x eps Hx Heps) ]. Qed.
