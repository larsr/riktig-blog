From Coq Require Import QArith.
From Riktig Require Import Structure.ApproxSqrt Impl.ApproxSqrtQ.

The computational reals: roots to any precision asked, by reflexivity -- the literal is exactly the rational computed.
Example sqrt_23 : (approx_sqrt 23 0.0001 = 4.7958)%Q := eq_refl.

Example sqrt_2_20_digits :
  (approx_sqrt 2 0.00000000000000000001 = 1.41421356237309504880)%Q := eq_refl.

Example sqrt_25 : (approx_sqrt 25 0.0001 == 5)%Q := eq_refl.

And the bracket the structure promises, at this carrier.
Local Close Scope Q_scope.
Example bracket : ∀ x eps : Q, 0 ≤ x → 0 < eps →
  approx_sqrt x eps × approx_sqrt x eps ≤ x ∧
  x ≤ (approx_sqrt x eps + eps) × (approx_sqrt x eps + eps).
Proof. intros x eps Hx Heps. split; [ exact (approx_sqrt_le x eps Hx Heps) | exact (approx_sqrt_close x eps Hx Heps) ]. Qed.
