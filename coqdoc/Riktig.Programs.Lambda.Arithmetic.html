Definition arithmetic_fuel : nat := 4.


Seven, spelled out: the normal form is the numeral, application by application.
Example three_plus_four_normalises :
  normalize arithmetic_fuel ⦅PLUS (numeral 3) (numeral 4)⦆
    = λ λ ⦅#1 ⦅#1 ⦅#1 ⦅#1 ⦅#1 ⦅#1 ⦅#1 #0⦆⦆⦆⦆⦆⦆⦆.
Proof. vm_compute. reflexivity. Qed.

Theorem three_plus_four : beta_conv ⦅PLUS (numeral 3) (numeral 4)⦆ (numeral 7).
Proof. apply (beta_conv_by_normalize arithmetic_fuel 0). vm_compute. reflexivity. Qed.

Theorem three_times_four :
  beta_conv ⦅MULT (numeral 3) (numeral 4)⦆ (numeral 12).
Proof. apply (beta_conv_by_normalize arithmetic_fuel 0). vm_compute. reflexivity. Qed.

Two operators in one term: (2 + 3) × 4.
Theorem two_plus_three_times_four :
  beta_conv ⦅MULT ⦅PLUS (numeral 2) (numeral 3)⦆ (numeral 4)⦆ (numeral 20).
Proof. apply (beta_conv_by_normalize arithmetic_fuel 0). vm_compute. reflexivity. Qed.


Lemma numeral_is_value : ∀ n : nat, value (numeral n).
Proof. intros n. apply value_abs. Qed.

Example first_of_a_pair_of_numerals :
  FST ⦅PAIR (numeral 3) (numeral 4)⦆ == numeral 3.
Proof.
  exact (FST_PAIR (numeral 3) (numeral 4)
           (numeral_is_value 3) (numeral_is_value 4)).
Qed.
