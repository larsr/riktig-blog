Library Riktig.Structure.Compiler

From Riktig.Structure Require Export TreeSyntax StackMachine.

A compiler from expressions to stack code. The source is a tree of literals and one binary operator, read directly by evaluate; the target is the code of a stack machine. compile emits one push for a literal, and for a node the code of the two subtrees followed by the operation -- the shape McCarthy and Painter gave ("Correctness of a compiler for arithmetic expressions", 1967). Nothing here assumes the source operator associative: Gibbons takes the source operator to be subtraction on purpose, so that the only associativity in play is that of code concatenation (arXiv:2111.10413, section 5).
Module Compiler.
  Class Compiler (V E C S : Type)
      {eqV : EqRel V} {eqE : EqRel E} {eqC : EqRel C} {eqS : EqRel S}
      {zC : Zero C} {aC : HasAdd C}
      (binop : V → V → V) (push_instr : V → C) (op_instr : C)
      (exec : C → S → S) (push : V → S → S)
      (litE : HasTip V E) (nodeE : HasFork E)
      (evaluate : E → V) (compile : E → C) := {
    machine :: StackMachine V C S binop push_instr op_instr exec push;
    source :: Tree V E litE nodeE;
    evaluate_proper :: Proper (equ ==> equ) evaluate;
    compile_proper :: Proper (equ ==> equ) compile;
    
    evaluate_lit : ∀ v : V, evaluate (lit v) == v;
    evaluate_node : ∀ e f : E, evaluate (node e f) == binop (evaluate e) (evaluate f);
    
    compile_lit : ∀ v : V, compile (lit v) == push_instr v;
    compile_node : ∀ e f : E, compile (node e f) == compile e + (compile f + op_instr);
  }.
End Compiler.
