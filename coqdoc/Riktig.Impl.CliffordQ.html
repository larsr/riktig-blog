The Clifford algebras over the rationals, named by signature: Cl(p,q,r) is the scalars doubled once per generator, each doubling carrying the square of its generator, and the vector space extended alongside.
The plane, Cl(2,0,0).
Notation V2 := (Extend (1 : Q) (Extend (1 : Q) unit)).
Notation A2 := (Double (1 : Q) (Double (1 : Q) Q)).

The complex numbers, Cl(0,1,0).
Notation C := (Double (- (1 : Q)) Q).

Plane projective geometric algebra, Cl(2,0,1).
Notation VP := (Extend (0 : Q) (Extend (1 : Q) (Extend (1 : Q) unit))).
Notation AP := (Double (0 : Q) (Double (1 : Q) (Double (1 : Q) Q))).

Spacetime algebra, Cl(1,3,0).
Notation VS := (Extend (- (1 : Q)) (Extend (- (1 : Q)) (Extend (- (1 : Q)) (Extend (1 : Q) unit)))).
Notation AS := (Double (- (1 : Q)) (Double (- (1 : Q)) (Double (- (1 : Q)) (Double (1 : Q) Q)))).
