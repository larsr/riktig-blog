Library Riktig.Impl.TableList

From Coq Require Import List Arith.
From Riktig Require Export Structure.Table Structure.Finite Impl.NatOrderNat Lib.Coq.Nat Lib.Coq.List.

Lists are tables over a finite index numbered by nat: an entry is read at the index's number, past the end it is the default, and a function is tabulated by listing its values in number order. Two list tables are equal when they agree at every index.
Section TableList.
  Context {I A : Type} {eqA : EqRel A} {EA : Equivalence eqA} {dA : HasDefault A}
          {card : HasCard I nat} {index : HasIndex I nat} {elem : HasElem I nat}
          {HF : Finite I nat card index elem (eqI := eq)}.

  #[export] Instance ListTable_EqRel : EqRel (ListTable I A) :=
    fun l l' ⇒ ∀ i : I, nth (index i) l default == nth (index i) l' default.
  #[export] Instance ListTable_HasGet : HasGet (ListTable I A) I A :=
    fun l i ⇒ nth (index i) l default.
  #[export] Instance ListTable_HasTabulate : HasTabulate (ListTable I A) I A :=
    fun f ⇒ tabulate_list card (fun k ⇒ f (elem k)).

  #[export] Instance ListTable_Table :
    Table I A (ListTable I A) ListTable_HasGet ListTable_HasTabulate (eqI := eq).
  Proof.
    split.
    - split.
      + intros l i. reflexivity.
      + intros l l' Hll' i. symmetry. exact (Hll' i).
      + intros l l' l'' H1 H2 i. transitivity (nth (index i) l' default); [ exact (H1 i) | exact (H2 i) ].
    - intros l l' Hll' i j Hij. rewrite Hij. exact (Hll' j).
    - intros f g Hfg i. unfold get, ListTable_HasGet, tabulate, ListTable_HasTabulate.
      rewrite !nth_tabulate_list by exact (lt_of_le_neq _ _ (index_lt i)).
      exact (Hfg (elem (index i))).
    - intros f i. unfold get, ListTable_HasGet, tabulate, ListTable_HasTabulate.
      rewrite nth_tabulate_list by exact (lt_of_le_neq _ _ (index_lt i)).
      rewrite (elem_index i). reflexivity.
    - intros l i. unfold get, ListTable_HasGet, tabulate, ListTable_HasTabulate.
      rewrite nth_tabulate_list by exact (lt_of_le_neq _ _ (index_lt i)).
      rewrite (elem_index i). reflexivity.
  Qed.
End TableList.
