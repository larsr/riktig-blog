From Coq Require Export Morphisms.

The binary numbers: zero, and two ways to append a bit -- bit0 n is 2n and bit1 n is 2n + 1. Appending a zero bit to zero gives zero, so every number has one representation: the two appendings are injective and never meet, a one bit never gives zero, and a property that holds at zero and is kept by both appendings holds of every number.
Module BinaryNumber.
  Class BinaryNumber (N : Type) {eq : EqRel N} (zero : Zero N) (bit0 : HasBit0 N) (bit1 : HasBit1 N) := {
    equivalence :: Equivalence eq;
    bit0_proper :: Proper (equ ==> equ) bit0;
    bit1_proper :: Proper (equ ==> equ) bit1;
    bit0_injective :: Injective N N bit0;
    bit1_injective :: Injective N N bit1;
    bit0_zero : bit0 0 == 0;
    bit1_not_zero : ∀ n : N, bit1 n =/= 0;
    bit0_ne_bit1 : ∀ n m : N, bit0 n =/= bit1 m;
    bin_induction : ∀ P : N → Prop, Proper (equ ==> iff) P →
      P 0 → (∀ n : N, P n → P (bit0 n)) → (∀ n : N, P n → P (bit1 n)) → ∀ n : N, P n;
  }.
End BinaryNumber.
