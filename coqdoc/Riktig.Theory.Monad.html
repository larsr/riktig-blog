Derived combinators, as notation: mapping a function over a result, running two computations in sequence and keeping both, one, or the other result, and Kleisli composition.
Notation "f <$> p" := (p >>= fun a ⇒ ret (f a)) (at level 61, left associativity).
Notation "p ⊗ q" := (p >>= fun a ⇒ q >>= fun b ⇒ ret (a, b)) (at level 40, left associativity).
Notation "p *> q" := (p >>= fun _ ⇒ q) (at level 40, left associativity).
Notation "p <* q" := (p >>= fun a ⇒ q >>= fun _ ⇒ ret a) (at level 40, left associativity).
Notation "f >=> g" := (fun a ⇒ f a >>= g) (at level 60, right associativity).

What holds of every monad: the functions fed to bind respect equality, mapping respects identities and composition, and Kleisli composition is associative with return as its identity.
Section MonadTheory.
  Context {P : Type → Type} `{Monad P}.

  Lemma bind_proper_l : ∀ `{Setoid A} `{Setoid B} (p p' : P A) (f : A → P B),
    Proper (equ ==> equ) f → p == p' → p >>= f == p' >>= f.
  Proof. intros A eqA EqvA B eqB EqvB p p' f Hf Hp. exact (Monad.bind_proper p p' f f Hf Hf Hp (fun a ⇒ reflexivity (f a))). Qed.

  Lemma bind_proper_r : ∀ `{Setoid A} `{Setoid B} (p : P A) (f g : A → P B),
    Proper (equ ==> equ) f → Proper (equ ==> equ) g → (∀ a : A, f a == g a) → p >>= f == p >>= g.
  Proof. intros A eqA EqvA B eqB EqvB p f g Hf Hg Hfg. exact (Monad.bind_proper p p f g Hf Hg (reflexivity p) Hfg). Qed.

  Lemma bind_fun_proper : ∀ `{Setoid A} `{Setoid B} `{Setoid D} (f : A → P B) (g : B → P D),
    Proper (equ ==> equ) f → Proper (equ ==> equ) g → Proper (equ ==> equ) (f >=> g).
  Proof. intros A eqA EqvA B eqB EqvB D eqD EqvD f g Hf Hg a a' Ha. exact (bind_proper_l _ _ g Hg (Hf a a' Ha)). Qed.

  Lemma const_fun_proper : ∀ `{Setoid A} `{Setoid B} (q : P B), Proper (equ ==> equ) (fun _ : A ⇒ q).
  Proof. intros A eqA EqvA B eqB EqvB q x y _. reflexivity. Qed.

  Lemma fmap_fun_proper : ∀ `{Setoid A} `{Setoid B} (f : A → B),
    Proper (equ ==> equ) f → Proper (equ ==> equ) (fun a ⇒ (ret (f a) : P B)).
  Proof. intros A eqA EqvA B eqB EqvB f Hf a a' Ha. exact (Monad.ret_proper _ _ (Hf a a' Ha)). Qed.

  Lemma comp_proper : ∀ `{Setoid A} `{Setoid B} `{Setoid D} (f : A → B) (g : B → D),
    Proper (equ ==> equ) f → Proper (equ ==> equ) g → Proper (equ ==> equ) (fun a ⇒ g (f a)).
  Proof. intros A eqA EqvA B eqB EqvB D eqD EqvD f g Hf Hg a a' Ha. exact (Hg _ _ (Hf a a' Ha)). Qed.

Mapping is a functor

  Theorem fmap_id : ∀ `{Setoid A} (p : P A), (fun a ⇒ a) <$> p == p.
  Proof. intros A eqA EqvA p. exact (Monad.bind_ret_r p). Qed.

  Theorem fmap_comp : ∀ `{Setoid A} `{Setoid B} `{Setoid D} (f : A → B) (g : B → D) (p : P A),
    Proper (equ ==> equ) f → Proper (equ ==> equ) g →
    g <$> (f <$> p) == (fun a ⇒ g (f a)) <$> p.
  Proof.
    intros A eqA EqvA B eqB EqvB D eqD EqvD f g p Hf Hg.
    calc (g <$> (f <$> p))
      == (p >>= fun a ⇒ (ret (f a) : P B) >>= fun b ⇒ ret (g b))
           { (Monad.bind_assoc p _ _ (fmap_fun_proper f Hf) (fmap_fun_proper g Hg)) }
      == (p >>= fun a ⇒ ret (g (f a)))
           { (bind_proper_r p _ _ (bind_fun_proper _ _ (fmap_fun_proper f Hf) (fmap_fun_proper g Hg))
                (fmap_fun_proper _ (comp_proper f g Hf Hg))
                (fun a ⇒ Monad.bind_ret_l (f a) _ (fmap_fun_proper g Hg))) }.
  Qed.

Kleisli composition is a category

  Theorem kleisli_assoc : ∀ `{Setoid A} `{Setoid B} `{Setoid D} `{Setoid E}
      (f : A → P B) (g : B → P D) (h : D → P E),
    Proper (equ ==> equ) f → Proper (equ ==> equ) g → Proper (equ ==> equ) h →
    ∀ a : A, ((f >=> g) >=> h) a == (f >=> (g >=> h)) a.
  Proof. intros A eqA EqvA B eqB EqvB D eqD EqvD E eqE EqvE f g h Hf Hg Hh a. exact (Monad.bind_assoc (f a) g h Hg Hh). Qed.

  Theorem kleisli_ret_l : ∀ `{Setoid A} `{Setoid B} (f : A → P B),
    Proper (equ ==> equ) f → ∀ a : A, ((ret : A → P A) >=> f) a == f a.
  Proof. intros A eqA EqvA B eqB EqvB f Hf a. exact (Monad.bind_ret_l a f Hf). Qed.

  Theorem kleisli_ret_r : ∀ `{Setoid A} `{Setoid B} (f : A → P B),
    ∀ a : A, (f >=> (ret : B → P B)) a == f a.
  Proof. intros A eqA EqvA B eqB EqvB f a. exact (Monad.bind_ret_r (f a)). Qed.
