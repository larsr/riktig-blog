Library Riktig.Structure.Category

From Coq Require Export Morphisms.
From Riktig Require Export Props.

A category is a collection of objects with a type of arrows between any two, each carrying an equivalence; an identity arrow on every object and an associative compose of arrows, for which the identities are neutral.
Module Category.
  Class Category (O : Type) {hom : HasHom O} {hom_equ : ∀ x y : O, EqRel (x ~> y)}
      (ident : HasId O) (compose : HasComp O) := {
    hom_equivalence :: ∀ x y : O, Equivalence (@equ (x ~> y) (hom_equ x y));
    comp_proper :: ∀ x y z : O, Proper (equ ==> equ ==> equ) (@comp O hom compose x y z);
    is_left_identity :: ∀ x y : O, LeftIdentity (y ~> y) (x ~> y) (@comp O hom compose x y y) cat_id;
    is_right_identity :: ∀ x y : O, RightIdentity (x ~> x) (x ~> y) (@comp O hom compose x x y) cat_id;
    comp_assoc : ∀ (w x y z : O) (f : y ~> z) (g : x ~> y) (h : w ~> x),
      f ∘ (g ∘ h) == (f ∘ g) ∘ h;
  }.
  Hint Mode Category ! - - - - : typeclass_instances.
End Category.
Export Category.
