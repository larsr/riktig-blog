Library Riktig.Structure.Digits

From Riktig.Structure Require Export NatOrder.

Digits of a base, with a carry bit: every digit has a value below the base and every carry a value below two, and adding two digits with a carry in gives a sum digit and a carry out whose values account for the whole sum. Bits are the digits of base two, their own carries; a pair of digit sets is a digit set of the product base (Impl/DigitsPair), which is how wider adders are made of narrower ones.
Module Digits.
  Class Digits (D B N : Type) `{NatOrder N} {eqD : EqRel D} {eqB : EqRel B}
      (radixD : HasRadix D N) (valD : HasVal D N) (valB : HasVal B N)
      (add_digit : HasAddDigit B D) (carry : HasCarry B D) := {
    equivalence_digit :: Equivalence eqD;
    equivalence_carry :: Equivalence eqB;
    val_digit_proper :: Proper (equ ==> equ) (val : D → N);
    val_carry_proper :: Proper (equ ==> equ) (val : B → N);
    add_digit_proper :: Proper (equ ==> equ ==> equ ==> equ) add_digit;
    carry_proper :: Proper (equ ==> equ ==> equ ==> equ) carry;
    val_digit_lt : ∀ d : D, val d < @radix D N radixD;
    val_carry_lt : ∀ b : B, val b < 1 + 1;
    add_digit_spec : ∀ (x y : D) (c : B),
      val (add_digit x y c) + @radix D N radixD × val (carry x y c) == val x + val y + val c;
  }.
End Digits.
