Choosing by index over any finite carrier: the first element's answer or the other one's.
Section Pick.
  Context {I N A : Type} `{Finite I N} {EI : EquDec I}.

  Definition pick2 (x y : A) : I → A :=
    fun i ⇒ if EquDec.equ_dec i (elem 0) then x else y.
End Pick.

A table over the two-element index with values in nat, summed by recursion on the count.
Definition t : two → nat := pick2 4 3.

Example sum_t : bigop t == 7 := eq_refl.

Swapping the two entries is a permutation of the index; the sum is the same, by the theorem, and by computation.
Example sum_swapped_by_theorem :
  bigop (tabulate (fun i ⇒ get t (two_swap i)) : two → nat) == bigop t :=
  bigop_permutation t.

Example sum_swapped_by_computation :
  bigop (tabulate (fun i ⇒ get t (two_swap i)) : two → nat) == 7 := eq_refl.
