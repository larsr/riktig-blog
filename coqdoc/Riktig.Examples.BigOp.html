A table over bool with values in nat, summed by recursion on the count: false first, then true.
Definition t : bool → nat := fun b ⇒ if b then 3 else 4.

Example sum_t : bigop t = 7 := eq_refl.

Swapping the two entries is a permutation of the index; the sum is the same, by the theorem, and by computation.
Instance negb_Permutation : Permutation bool negb negb :=
  {| Iso.to_proper := f_equal negb; Iso.from_proper := f_equal negb;
     Iso.from_to := Bool.negb_involutive; Iso.to_from := Bool.negb_involutive |}.

Example sum_swapped_by_theorem :
  bigop (tabulate (fun b ⇒ get t (negb b)) : bool → nat) = bigop t :=
  bigop_permutation t.

Example sum_swapped_by_computation :
  bigop (tabulate (fun b ⇒ get t (negb b)) : bool → nat) = 7 := eq_refl.
