From Riktig.Theory Require Import Defunctionalization.
From Riktig.Impl Require Import DefunctionalizationLambda.
Local Open Scope term_scope.

What defunctionalizing the continuations buys: the continuation stops being a lambda term the translation built and becomes a piece of data the Compiler.machine can carry. Here it is, carried.
Definition idt : term := λ#0.
Definition tm : term := ⦅⦅idt idt⦆ idt⦆.

Two steps in, the Compiler.machine has entered both applications and its continuation is a stack two frames deep -- an ordinary value that prints, with the two pending arguments sitting in it. Nothing of the sort can be inspected in the higher-order translation, where this same continuation is a closure.
Eval vm_compute in drun 2 (Ev tm Halt).

Example stack_after_two_steps :
  drun 2 (Ev tm Halt) = Ev idt (KArg idt (KArg idt Halt)).
Proof. vm_compute. reflexivity. Qed.

Because the transition is a function on states, the Compiler.machine runs: eleven steps take the term to its value on the empty stack.
Example machine_finishes : drun 11 (Ev tm Halt) = Ap Halt idt.
Proof. vm_compute. reflexivity. Qed.

The computed trace is a proof of a run, since each step the function took is a step of the relation.
Example machine_runs : druns tm Halt idt.
Proof. unfold druns. rewrite <- machine_finishes. apply drun_dsteps. Qed.

That a frame stands for the continuation it replaced is the structure's law, not a coincidence of this term: pushing the argument onto the stack is what building the closure did.
Example pushing_a_frame :
  app (cps ⦅⦅idt idt⦆ idt⦆) (reify Halt) == app (cps ⦅idt idt⦆) (reify (KArg idt Halt)).
Proof. exact (Defunctionalization.reify_karg ⦅idt idt⦆ idt Halt). Qed.

And the abstract theorems land on the run: the Compiler.machine's answer is what the translated term hands the empty stack, and it agrees with the evaluator's.
Example evaluates_to_id : evaluates tm idt.
Proof.
  split; [ | reflexivity ].
  eapply star_step; [ apply cbv_app_l; exact (cbv_beta #0 idt eq_refl) | ].
  apply star_one. exact (cbv_beta #0 idt eq_refl).
Qed.

Example cps_answer : app (cps tm) (reify Halt) == psi idt.
Proof. exact (Defunctionalization.druns_sound tm idt Halt machine_runs). Qed.

Example machine_agrees_with_evaluator : psi idt == psi idt.
Proof. exact (druns_agree tm idt idt machine_runs evaluates_to_id). Qed.
