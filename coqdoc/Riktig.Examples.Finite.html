Summing a function over a finite index: recursion on the count, adding the value at each numbered element.
Definition bigsum {I N M : Type} `{Finite I N} {natrec : HasNatRec N} `{!NatRec N natrec}
    `{Monoid M} (f : I → M) : M :=
  natrec M 0 (fun k acc ⇒ acc + f (elem k)) card.

At bool numbered by nat, summing into nat, it computes.
From Riktig Require Import Impl.FiniteBool Impl.NatRecNat.

Example bigsum_bool : bigsum (fun b : bool ⇒ if b then 3 else 4) = 7.
Proof. reflexivity. Qed.
