The lambda terms with variables named by n: the datatype of the signature const n + self + self × self, one level being a variable, an abstraction of a hole, or an application of one hole to another.
Module LambdaTerm.
  Definition lamS {K S : Type} `{Signature K S} (n : K) : S :=
    const n + self + self × self.

  Notation shape den n := (shape_of den (lamS (S := sig _) n)).

  Class LambdaTerm (O : Type) `{Bicartesian O} {K : Type}
      (den : K → O) (n : K) (T : O)
      (build : HasBuild O (shape den n) T)
      (fold : HasCata O (shape den n) T) := {
    initial :: InitialAlgebra O (shape den n) T build fold;
  }.
End LambdaTerm.
Export LambdaTerm(LambdaTerm).

The lambda notation, on the operations rather than on any one representation: #n is a variable, λ b an abstraction, and ⦅f a b⦆ an application, left associated.
Notation "'λ' a" := (lam a) (at level 10) : lambda_term_scope.
Notation "# a" := (var a) (at level 0, a at level 0, format "'#' a") : lambda_term_scope.
Notation "⦅ a b .. c ⦆" := (app .. (app a b) .. c)
  (at level 0, a at level 0, b at level 0, c at level 0) : lambda_term_scope.
