Library Riktig.Examples.Ring

From Riktig Require Import Theory.Ring.

A function over any ring, and what it equals.
Definition sq_diff {R : Type} `{Ring R} (a b : R) : R := (a + - b) × (a + b).

Theorem sq_diff_eq {R : Type} `{Ring R} : ∀ a b : R,
  a × b == b × a → sq_diff a b == a × a + - (b × b).
Proof.
  intros a b Hab. unfold sq_diff.
  calc ((a + - b) × (a + b))
    == (a × (a + b) + - (b × (a + b))) { sub_mul }
    == ((a × a + a × b) + - (b × (a + b))) { left_distributive }
    == ((a × a + a × b) + - (b × a + b × b)) { (left_distributive (op := mult) b a b) }
    == ((a × a + a × b) + (- (b × a) + - (b × b))) { neg_add }
    == ((a × a + a × b) + (- (a × b) + - (b × b))) { Hab }
    == (a × a + (a × b + (- (a × b) + - (b × b)))) { associative }
    == (a × a + - (b × b)) { (add_neg_cancel_left (a × b) (- (b × b))) }.
Qed.

At Coq's Z it computes.
From Coq Require Import ZArith.
From Riktig Require Import Impl.IntegersZ.

Example sq_diff_Z : sq_diff 5%Z 3%Z = 16%Z.
Proof. reflexivity. Qed.

At Coq's Q it computes, up to Qeq.
From Coq Require Import QArith.
From Riktig Require Import Impl.RationalsQ.

Example sq_diff_Q : sq_diff (5#2)%Q (1#2)%Q == (6#1)%Q.
Proof. reflexivity. Qed.

At Coq's R nothing computes -- the operations are axioms -- but the theorem above is as true there as anywhere.
From Coq Require Import Reals.
From Riktig Require Import Impl.RealsR.

Example sq_diff_R : ∀ a b : R, sq_diff a b = (a × a + - (b × b))%R.
Proof. intros a b. exact (sq_diff_eq a b (Rmult_comm a b)). Qed.
