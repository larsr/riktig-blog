From Riktig.Theory Require Import Ring.

The difference of squares, over any ring.
Section OverAnyRing.
  Context {R : Type} `{Ring R}.
  Definition sq_diff (a b : R) : R := (a + - b) × (a + b).
End OverAnyRing.

From Riktig.Impl Require Import IntegersZ RationalsQ RealsR.
Local Close Scope R_scope.

At three carriers.
Example sq_diff_Z : sq_diff 5%Z 3%Z == 16%Z := eq_refl.

Example sq_diff_Q : sq_diff 2.5%Q 0.5%Q == 6%Q := eq_refl.

At Coq's R nothing computes -- the operations are axioms -- but the theorem applies, commutativity coming from the field.
Example sq_diff_R : ∀ a b : R, sq_diff a b == a × a + - (b × b).
Proof. intros a b. exact (sq_diff_eq a b (commutative (op := mult) a b)). Qed.
