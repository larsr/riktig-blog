Section IndependentCoordinates.
  Context {F A : Type} `{Field F}.
  Context {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {An : HasNeg A}
          {Ao : One A} {As : HasScale F A}
          {AG : AbGroup A} {SL : ScaleLaws F A}.

Independent coordinates are unique coordinates.
  Lemma independent_separates : ∀ e : A,
    independent_from_one F e →
    ∀ a b c d : F,
      a *: 1 + b *: e == c *: 1 + d *: e → a == c ∧ b == d.
  Proof.
    intros e Hindependent a b c d Heq.
    assert (Hzero : (a + - c) *: (1 : A) + (b + - d) *: e == 0).
    { calc (((a + - c) *: (1 : A) + (b + - d) *: e) : A)
        == (((a *: (1 : A) + - (c *: (1 : A))) + (b + - d) *: e) : A)
           { sub_scale }
        == (((a *: (1 : A) + - (c *: (1 : A)))
               + (b *: e + - (d *: e))) : A)
           { sub_scale }
        == (((a *: (1 : A) + b *: e)
               + - (c *: (1 : A) + d *: e)) : A)
           { sub_pair }
        == (((c *: (1 : A) + d *: e)
               + - (c *: (1 : A) + d *: e)) : A)
           { Heq }
        == ((0 : A))
           { add_right_inverse }. }
    destruct (Hindependent (a + - c) (b + - d) Hzero) as [Hac Hbd].
    split; [ exact (sub_eq_zero a c Hac) | exact (sub_eq_zero b d Hbd) ].
  Qed.

End IndependentCoordinates.


Section PlaneReversal.
  Context {F A : Type} `{Field F}.
  Context {Ae : EqRel A} {Az : Zero A} {Aa : HasAdd A} {An : HasNeg A}
          {Ao : One A} {Am : HasMult A} {As : HasScale F A}
          {AR : Ring A} {SL : ScaleLaws F A}.

  Theorem reversal_two_term : ∀ rev : A → A,
    Reversal A rev →
    (∀ (a : F) (x : A), rev (a *: x) == a *: rev x) →
    ∀ e : A, rev e == - e →
    ∀ a b : F, rev (a *: 1 + b *: e) == a *: 1 + (- b) *: e.
  Proof.
    intros rev RV rev_scale e rev_e a b.
    calc ((rev (a *: (1 : A) + b *: e)) : A)
      == ((rev (a *: (1 : A)) + rev (b *: e)) : A) { reverse_add }
      == ((a *: rev (1 : A) + rev (b *: e)) : A) { rev_scale }
      == ((a *: (1 : A) + rev (b *: e)) : A) { reverse_one }
      == ((a *: (1 : A) + b *: rev e) : A) { rev_scale }
      == ((a *: (1 : A) + b *: (- e)) : A) { rev_e }
      == ((a *: (1 : A) + - (b *: e)) : A) { scale_neg }
      == ((a *: (1 : A) + (- b) *: e) : A) { neg_scale }.
  Qed.

End PlaneReversal.


Section ComplexPlaneTheory.
  Context {F A : Type} (e : A) `{CP : ComplexPlane F A e}.
  Add Ring complex_plane_scalars : (ring_theory_of_Ring (R := F) commutative).

The multiplication table. The class adds no product law of its own and needs none: this is Theory/Algebra.v's two_term_product at the plane's root.
  Theorem plane_product : ∀ a b c d : F,
    (a *: 1 + b *: e) × (c *: 1 + d *: e)
    == (a × c + - (b × d)) *: 1 + (a × d + b × c) *: e.
  Proof. intros a b c d. exact (two_term_product a b c d e plane_root). Qed.

Coordinates are unique: that is what independence buys.
  Theorem plane_coordinates_unique : ∀ a b c d : F,
    a *: 1 + b *: e == c *: 1 + d *: e → a == c ∧ b == d.
  Proof. exact (independent_separates e plane_independent). Qed.

The plane is a commutative ring — which is why a reversal on it is also an automorphism, and why the order of a product carries no information here.
  Theorem plane_mul_commutative : ∀ x y : A, x × y == y × x.
  Proof.
    intros x y.
    destruct (plane_spans (e := e) x) as [a [b Hx]].
    destruct (plane_spans (e := e) y) as [c [d Hy]].
    assert (Hxy : x × y == (a × c + - (b × d)) *: 1 + (a × d + b × c) *: e).
    { rewrite Hx, Hy. exact (two_term_product a b c d e plane_root). }
    assert (Hyx : y × x == (c × a + - (d × b)) *: 1 + (c × b + d × a) *: e).
    { rewrite Hx, Hy. exact (two_term_product c d a b e plane_root). }
    assert (Hscalar : a × c + - (b × d) == c × a + - (d × b)) by ring.
    assert (Hroot : a × d + b × c == c × b + d × a) by ring.
    calc ((x × y) : A)
      == (((a × c + - (b × d)) *: (1 : A) + (a × d + b × c) *: e) : A)
         { Hxy }
      == (((c × a + - (d × b)) *: (1 : A) + (a × d + b × c) *: e) : A)
         { Hscalar }
      == (((c × a + - (d × b)) *: (1 : A) + (c × b + d × a) *: e) : A)
         { Hroot }
      == ((y × x) : A)
         { Hyx }.
  Qed.


  Context (conjugate : A → A) {RV : Reversal A conjugate}
          (conjugate_scale :
             ∀ (a : F) (x : A), conjugate (a *: x) == a *: conjugate x)
          (conjugate_root : conjugate e == - e).

Conjugation in coordinates: the unit is fixed, the root is negated.
  Theorem plane_conjugate : ∀ a b : F,
    conjugate (a *: 1 + b *: e) == a *: 1 + (- b) *: e.
  Proof. exact (reversal_two_term conjugate RV conjugate_scale e conjugate_root). Qed.

And there is no second one: any F-linear reversal negating the root is this map. Conjugation is determined by the plane, not chosen for it.
  Theorem plane_conjugate_unique : ∀ f : A → A,
    Reversal A f →
    (∀ (a : F) (x : A), f (a *: x) == a *: f x) →
    f e == - e →
    ∀ x : A, f x == conjugate x.
  Proof.
    intros f RVf f_scale f_root x.
    destruct (plane_spans (e := e) x) as [a [b Hx]].
    calc ((f x) : A)
      == ((f (a *: (1 : A) + b *: e)) : A)
         { Hx }
      == ((a *: (1 : A) + (- b) *: e) : A)
         { (reversal_two_term f RVf f_scale e f_root a b) }
      == ((conjugate (a *: (1 : A) + b *: e)) : A)
         { (plane_conjugate a b) }
      == ((conjugate x) : A)
         { Hx }.
  Qed.

On a commutative plane the anti-automorphism law is the automorphism law.
  Theorem plane_conjugate_mul : ∀ x y : A,
    conjugate (x × y) == conjugate x × conjugate y.
  Proof.
    intros x y.
    calc ((conjugate (x × y)) : A)
      == ((conjugate y × conjugate x) : A) { reversal_anti }
      == ((conjugate x × conjugate y) : A) { plane_mul_commutative }.
  Qed.

The norm in coordinates: the sum of two squares, on the scalar line.
  Theorem plane_conjugate_norm : ∀ a b : F,
    conjugate (a *: 1 + b *: e) × (a *: 1 + b *: e) == (a × a + b × b) *: 1.
  Proof.
    intros a b.
    assert (Hscalar : a × a + - ((- b) × b) == a × a + b × b) by ring.
    assert (Hroot : a × b + (- b) × a == (0 : F)) by ring.
    assert (Hdrop : (a × a + b × b) *: (1 : A) + (0 : F) *: e
                    == (a × a + b × b) *: (1 : A)).
    { calc (((a × a + b × b) *: (1 : A) + (0 : F) *: e) : A)
        == (((a × a + b × b) *: (1 : A) + (0 : A)) : A) { zero_scale }
        == (((a × a + b × b) *: (1 : A)) : A) { right_identity }. }
    calc ((conjugate (a *: 1 + b *: e) × (a *: 1 + b *: e)) : A)
      == (((a *: (1 : A) + (- b) *: e) × (a *: (1 : A) + b *: e)) : A)
         { (plane_conjugate a b) }
      == (((a × a + - ((- b) × b)) *: (1 : A)
             + (a × b + (- b) × a) *: e) : A)
         { (two_term_product a (- b) a b e plane_root) }
      == (((a × a + b × b) *: (1 : A) + (a × b + (- b) × a) *: e) : A)
         { Hscalar }
      == (((a × a + b × b) *: (1 : A) + (0 : F) *: e) : A)
         { Hroot }
      == (((a × a + b × b) *: (1 : A)) : A)
         { Hdrop }.
  Qed.

Coordinate-free: the norm of any element is on the scalar line.
  Corollary plane_norm_on_scalar_line : ∀ x : A,
    ∃ n : F, conjugate x × x == n *: 1.
  Proof.
    intros x.
    destruct (plane_spans (e := e) x) as [a [b Hx]].
    ∃ (a × a + b × b).
    calc ((conjugate x × x) : A)
      == ((conjugate (a *: (1 : A) + b *: e) × (a *: (1 : A) + b *: e)) : A)
         { Hx }
      == (((a × a + b × b) *: (1 : A)) : A)
         { (plane_conjugate_norm a b) }.
  Qed.

End ComplexPlaneTheory.
