From Coq Require Import Reals Lra.
From Riktig Require Import Theory.Reals Impl.RealsR.
Open Scope R_scope.

What the reals have that the rationals lack: every inhabited set with an upper bound has a least upper bound. For the numbers at most two it is two, by completeness and the uniqueness of the bound.
Example sup_of_le_two :
  ∃ s : R,
    (∀ x : R, x ≤ 2 → x ≤ s) ∧
    (∀ b : R, (∀ x : R, x ≤ 2 → x ≤ b) → s ≤ b) ∧
    s = 2.
Proof.
  destruct (complete (fun x : R ⇒ x ≤ 2)
              (ex_intro (fun x : R ⇒ x ≤ 2) 0 (ltac:(lra) : 0 ≤ 2))
              (ex_intro (fun b : R ⇒ ∀ x : R, x ≤ 2 → x ≤ b) 2 (fun x Hx ⇒ Hx)))
    as [s [Hub Hleast]].
  ∃ s. split; [ exact Hub | split; [ exact Hleast | ] ].
  exact (lub_unique (fun x : R ⇒ x ≤ 2) s 2 Hub Hleast
           (fun x Hx ⇒ Hx) (fun b Hb ⇒ Hb 2 (Rle_refl 2))).
Qed.
