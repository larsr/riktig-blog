What the reals have that the rationals lack: every inhabited set with an upper bound has a least upper bound. For the numbers at most two it is two, over any reals.
Section OverAnyReals.
  Context {R' : Type} `{Reals R'}.

  Example sup_of_le_two :
    ∃ s : R',
      (∀ x : R', x ≤ 1 + 1 → x ≤ s) ∧
      (∀ b : R', (∀ x : R', x ≤ 1 + 1 → x ≤ b) → s ≤ b) ∧
      s == 1 + 1.
  Proof. exact (lub_of_le_self (1 + 1)). Qed.
End OverAnyReals.

At Coq's R, by instantiation.
Example sup_of_le_two_at_R :
  ∃ s : R,
    (∀ x : R, x ≤ 1 + 1 → x ≤ s) ∧
    (∀ b : R, (∀ x : R, x ≤ 1 + 1 → x ≤ b) → s ≤ b) ∧
    s == 1 + 1.
Proof. exact sup_of_le_two. Qed.
