Library Riktig.Structure.Parser

From Riktig.Structure Require Export Sequence.
Generalizable All Variables.

Parsers over sequences of C, indexed by the type of what they read, with their meaning: parses p s a s' says that p can read a from the front of s and leave s'. What is read is compared in its own setoid, so every law quantifies over one. Two parsers are equal when they have the same meaning. Returning reads nothing; binding reads with the first parser and goes on with the second, which respects equality, on what is left; failing reads nothing; a choice reads as either parser; and item reads the first element.
Module Parser.
  Class Parser (C S : Type) (P : Type → Type)
      {eqC : EqRel C} {eqS : EqRel S} {stepping : HasStep C S} {Seq : Sequence C S stepping}
      {eqP : ∀ (A : Type) (eqA : EqRel A), EqRel (P A)}
      (return_ : HasReturn P) (bind_ : HasBind P) (fail_ : HasFail P) (alt_ : HasAlt P)
      (item_ : HasItem C P) (parses_ : HasParses S P) := {
    parser_equ : ∀ `{Setoid A} (p q : P A),
      p == q ↔ (∀ (s s' : S) (a : A), parses p s a s' ↔ parses q s a s');
    parses_proper :: ∀ `{Setoid A} (p : P A),
      Proper (equ ==> equ ==> equ ==> iff) (parses p);
    parses_ret : ∀ `{Setoid A} (a a' : A) (s s' : S),
      parses (ret a : P A) s a' s' ↔ a' == a ∧ s' == s;
    parses_bind : ∀ `{Setoid A} `{Setoid B}
        (p : P A) (f : A → P B) (s s'' : S) (b : B), Proper (equ ==> equ) f →
      (parses (p >>= f : P B) s b s'' ↔ ∃ (a : A) (s' : S), parses p s a s' ∧ parses (f a) s' b s'');
    parses_fail : ∀ `{Setoid A} (s s' : S) (a : A), ¬ parses (fail : P A) s a s';
    parses_alt : ∀ `{Setoid A} (p q : P A) (s s' : S) (a : A),
      parses (p <|> q) s a s' ↔ parses p s a s' ∨ parses q s a s';
    parses_item : ∀ (s s' : S) (c : C), parses (item : P C) s c s' ↔ step s c s';
  }.
  Hint Mode Parser - - ! - - - - - - - - - - - : typeclass_instances.
End Parser.
