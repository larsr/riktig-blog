Library Riktig.Structure.Parser

From Riktig.Structure Require Export Sequence.

Parsers over sequences of C, indexed by the type of what they read, with their meaning: parses p s a s' says that p can read a from the front of s and leave s'. Two parsers are equal when they have the same meaning. Returning reads nothing; binding reads with the first parser and goes on with the second on what is left; failing reads nothing; a choice reads as either parser; and item reads the first element. What is read is compared by Coq's equality, as it is data the parser builds.
Module Parser.
  Class Parser (C S : Type) (P : Type → Type)
      {eqC : EqRel C} {eqS : EqRel S} {empty_ : HasEmpty S} {cons_ : HasCons C S} {Seq : Sequence C S empty_ cons_}
      {eqP : ∀ A : Type, EqRel (P A)}
      (return_ : HasReturn P) (bind_ : HasBind P) (fail_ : HasFail P) (alt_ : HasAlt P)
      (item_ : HasItem C P) (parses_ : HasParses S P) := {
    parser_equ : ∀ (A : Type) (p q : P A),
      p == q ↔ (∀ (s : S) (a : A) (s' : S), parses p s a s' ↔ parses q s a s');
    parses_proper :: ∀ (A : Type) (p : P A), Proper (equ ==> eq ==> equ ==> iff) (parses p);
    parses_ret : ∀ (A : Type) (a : A) (s : S) (a' : A) (s' : S),
      parses (ret a : P A) s a' s' ↔ a' = a ∧ s' == s;
    parses_bind : ∀ (A B : Type) (p : P A) (f : A → P B) (s : S) (b : B) (s'' : S),
      parses (p >>= f : P B) s b s'' ↔ ∃ (a : A) (s' : S), parses p s a s' ∧ parses (f a) s' b s'';
    parses_fail : ∀ (A : Type) (s : S) (a : A) (s' : S), ¬ parses (fail : P A) s a s';
    parses_alt : ∀ (A : Type) (p q : P A) (s : S) (a : A) (s' : S),
      parses (p <|> q) s a s' ↔ parses p s a s' ∨ parses q s a s';
    parses_item : ∀ (s : S) (c : C) (s' : S), parses (item : P C) s c s' ↔ s == cons c s';
  }.
  Hint Mode Parser - - ! - - - - - - - - - - - - : typeclass_instances.
End Parser.
