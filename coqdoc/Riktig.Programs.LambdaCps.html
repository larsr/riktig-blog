From Riktig.Structure Require Export LambdaTerm TermRec NatRec.

The continuation-passing translation over any lambda terms: the recursion is the terms' own, and the translation is Fischer's call-by-value one -- every intermediate result is named and every call is the whole body.
Section Cps.
  Context {N T : Type} `{TermRec N T} `{NatRec N}.

Lifting a renaming past a binder: the bound variable stays, and every other is renamed one level out.
  Definition up (r : N → N) : N → N :=
    fun n ⇒ natrec N 0 (fun m _ ⇒ succ (r m)) n.

Renaming, as recursion that answers a function of the renaming, so that the renaming can be lifted under each binder.
  Definition rename (t : T) : (N → N) → T :=
    termrec ((N → N) → T)
      (fun n r ⇒ #(r n))
      (fun b r ⇒ λ (b (up r)))
      (fun f a r ⇒ ⦅(f r) (a r)⦆)
      t.

Making room for one more variable, at the top and under a binder.
  Definition shift (t : T) : T := rename t (fun n : N ⇒ succ n).
  Definition shift_under (t : T) : T := rename t (up (fun n : N ⇒ succ n)).

The translation.
  Definition cps (t : T) : T :=
    termrec T
      (fun n : N ⇒ λ ⦅#0 #(succ n)⦆)
      (fun b : T ⇒ λ ⦅#0 (λ (shift_under b))⦆)
      (fun f a : T ⇒
         λ ⦅(shift f)
            (λ ⦅(shift (shift a))
                (λ ⦅#(succ 0) #0 #(succ (succ 0))⦆)⦆)⦆)
      t.
End Cps.
