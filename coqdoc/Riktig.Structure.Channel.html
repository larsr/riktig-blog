From Riktig.Structure Require Export Category.

A channel carries one object's values across another: encode is a section of decode, so the round trip loses nothing.
Module Channel.
  Class Channel (O : Type) `{Category O} (A W : O)
      (encode : A ~> W) (decode : W ~> A) := {
    decode_encode : decode ∘ encode == cat_id;
  }.
End Channel.
Export Channel(Channel).
