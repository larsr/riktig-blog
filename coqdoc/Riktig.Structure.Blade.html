Library Riktig.Structure.Blade

From Riktig.Structure Require Export Boolean.

A blade algebra over an index I with bits in K: a carrier B whose elements answer, for each generator, whether they contain it. The empty blade, the full blade, symmetric difference and intersection are the carrier's 0, 1, + and ×, membership carries each of them to the bit of the same name, and membership is faithful — a blade is the generators it holds.
Module Blade.
  Class Blade (I K B : Type)
      {eK : EqRel K} {zK : Zero K} {aK : HasAdd K} {nK : HasNeg K}
      {oK : One K} {mK : HasMult K} {bits : Boolean K}
      {eB : EqRel B} {zB : Zero B} {aB : HasAdd B} {nB : HasNeg B}
      {oB : One B} {mB : HasMult B} := {
    setoid :: Equivalence (@equ B eB);
    member : B → I → K;
    member_proper :: Proper (equ ==> eq ==> equ) member;
    member_faithful : ∀ x y : B,
                        (∀ i : I, member x i == member y i) → x == y;
    member_empty : ∀ i : I, member 0 i == (0 : K);
    member_full : ∀ i : I, member 1 i == (1 : K);
    member_symmetric_difference : ∀ (x y : B) (i : I),
                        member (x + y) i == member x i + member y i;
    member_intersection : ∀ (x y : B) (i : I),
                        member (x × y) i == member x i × member y i;
    member_complement : ∀ (x : B) (i : I),
                        member (- x) i == - member x i;
  }.
  Hint Mode Blade - - ! - - - - - - - - - - - - - : typeclass_instances.
End Blade.
