The reversal fixes an embedded vector: it is grade 1, and the reversal fixes grade 1.
  Lemma reversal_fixes_vectors : ∀ u : V,
    rev (ga_vec u : A) == (ga_vec u : A).
  Proof.
    intros u.
    calc (rev (ga_vec u : A))
      == (rev (⟨ (ga_vec u : A) ⟩_ 1)) { (vec_is_grade_1 u) }
      == (⟨ (ga_vec u : A) ⟩_ 1)
           { (reversal_fixes_grade_1 rev rev_sign (ga_vec u)) }
      == (ga_vec u : A) { (vec_is_grade_1 u) }.
  Qed.

And therefore the squared magnitude of a vector is its quadratic form, scaled into the algebra.
  Theorem mag2_on_vectors : ∀ u : V,
    mag2 (ga_vec u : A) == Q u *: (1 : A).
  Proof.
    intros u.
    calc (mag2 (ga_vec u : A))
      == (⟨ rev (ga_vec u : A) × (ga_vec u : A) ⟩_ 0) { mag2_def }
      == (⟨ (ga_vec u : A) × (ga_vec u : A) ⟩_ 0)
           { (reversal_fixes_vectors u) }
      == (⟨ Q u *: (1 : A) ⟩_ 0) { (contraction u) }
      == (Q u *: ⟨ (1 : A) ⟩_ 0)
           { (homogeneous (f := grade_part 0%nat) (Q u) (1 : A)) }
      == (Q u *: (1 : A)) { one_is_grade_0 }.
  Qed.

End MagnitudeOnVectors.
