The determinant is multiplicative

det⁡(AB)=det⁡(A)det⁡(B).\det(AB) \;=\; \det(A)\,\det(B).

Everything one wants from a determinant follows from this. The determinant of a linear map on a space of finite dimension is computed by choosing a basis, writing the map as a matrix and taking the determinant of that matrix — and the number is only worth calling a property of the map if it comes out the same in every basis. Two matrices for the same map are related by A↦P−1APA \mapsto P^{-1}AP, so basis-independence is the calculation

det⁡(P−1AP)=det⁡(P−1)det⁡(A)det⁡(P)=det⁡(A),\det(P^{-1}AP) \;=\; \det(P^{-1})\det(A)\det(P) \;=\; \det(A),

which is multiplicativity and nothing else. Invertibility, the composition law, and the fact that a determinant detects singularity all rest on it in the same way.

Neither definition of the determinant makes it obvious. Cofactor expansion is a recursion on the size of the matrix, and the entries of ABAB are sums, so expanding det⁡(AB)\det(AB) produces a mass of terms with no visible relation to the two smaller expansions. The permutation sum does no better: ∏j(AB)σ(j),j\prod_j (AB)_{\sigma(j),j} is a product of sums, and multiplying it out ranges over all functions rather than all permutations.

There are two ways through, and this post takes both. They need different things from the field, which is the interesting part.

What the determinant is, as a function of its rows

Both routes use the same three facts, none of which mentions a product of matrices:

  • det\det is additive in each row: splitting one row as r1+r2r_1 + r_2 splits the determinant (det_rowI_add).
  • det\det is homogeneous in each row: scaling one row by cc scales the determinant by cc (det_rowI_scale).
  • det\det is alternating: two equal rows force 00 (detM_alternating).

They hold for detM, the cofactor-recursion determinant of Impl/Det.v, over any field, with no assumption on the characteristic.

Route one: elimination, and the price of a pivot

Gaussian elimination reduces a square matrix to the identity, or exposes a zero row, by a finite sequence of row operations, each of which multiplies the determinant by a known factor. If AA reduces to the identity by operations with accumulated factor ff, then fdet⁡A=1f\det A = 1; run the same operations on ABAB — they act on the left factor — and fdet⁡(AB)=det⁡Bf\det(AB) = \det B. Regroup and the product law drops out, with no division performed anywhere.

Turning that into a proof means making “reduces to” a value rather than a story. An ElemOp is a row operation carrying its own justification: a swap of two positions carrying their distinctness, a scaling carrying a certified inverse for the scale factor (c * d == 1 is part of the value), or an add-a-multiple carrying its distinctness. elem_op_apply acts by left multiplication with the corresponding elementary matrix, elem_op_factor names the factor the determinant picks up, and det_eop_apply proves the two agree. Lists of operations inherit all of it: factors multiply (det_eops_apply), the accumulated factor keeps a certified inverse (elem_ops_factor_cofactor), and applying a list commutes with multiplying on the right (elem_ops_apply_mul).

The reduction itself is then a theorem producing such a list:

  Theorem gauss_reduce : forall (dec : DecEq F) (n : nat) (A : Matrix n n F),
    exists l : list (ElemOp n),
      (elem_ops_apply l A == @mat_id F _ _ n)
      \/ (exists i : Fin.t n, forall j : Fin.t n, elem_ops_apply l A i j == 0).

Every square matrix goes, by finitely many certified row operations, either to the identity or to a matrix with an explicit zero row. The disjunction is the singular/nonsingular dichotomy, carried as data: no rank, no dimension theory, no case left implicit.

Note the first argument. Elimination has to choose a pivot, which means deciding whether a candidate entry is zero. A Field here is a setoid with an equality relation ==; for a general field there is no algorithm answering x == 0, so the decision procedure is taken as an explicit argument on exactly the results that need it.

  Theorem detM_mul_dec : forall (dec : DecEq F) (n : nat)
      (A B : Matrix n n F),
    detM (mat_mul A B) == detM A * detM B.

The nonsingular branch is the regrouping above. The singular branch is shorter: a matrix with a zero row has determinant zero (det_zero_row — which is row scaling at c:=0c := 0, so it too says nothing about characteristic), and a zero row of AA is still a zero row of ABAB (mat_mul_zero_row), so both sides are 00 once the accumulated factor is cancelled through its certified inverse.

For the rationals the hypothesis costs nothing:

Corollary detM_mul_Q : forall (n : nat) (A B : Matrix n n Q),
  detM (mat_mul A B) == detM A * detM B.

The same file proves the classical triangular fact on the way, which is worth having on its own:

  Theorem det_upper_triangular : forall (n : nat) (A : Matrix n n F),
    (forall i j : Fin.t n, (fin_to_nat j < fin_to_nat i)%nat -> A i j == 0) ->
    detM A == prodF (fun i => A i i).

The determinant of an upper-triangular matrix is the product of its diagonal, by induction: such a matrix has one possibly-nonzero entry in its first column, so the cofactor expansion collapses to a single term at each level.

Route two: a determinant is the only thing it could be

The decidability hypothesis is an artifact of elimination, not of the theorem. The classical way to avoid it is the uniqueness argument: a function of the rows that is multilinear, alternating, and takes the value 11 at the identity matrix is the determinant — so to prove det⁡(AB)=det⁡(A)det⁡(B)\det(AB) = \det(A)\det(B), fix BB and observe that A↦det⁡(AB)A \mapsto \det(AB) is multilinear and alternating in the rows of AA, hence equal to det⁡(A)\det(A) times its own value at A=IA = I.

Carried out in Impl/DetMulGeneral.v, that argument has three pieces.

Antisymmetry, abstractly. Row swaps negate any function that is row-additive and alternating — not just the determinant. The proof is the classical (ri+rj)(r_i + r_j) trick: set both rows ii and jj to ri+rjr_i + r_j, which is 00 by alternating, and expand that same value by additivity in row ii and then in row jj; two of the four cross terms vanish by alternating, and the remaining two are g(A)g(A) and g(A with i,j swapped)g(A \text{ with } i, j \text{ swapped}).

  Theorem g_swap_antisym : forall (n:nat) (g : Matrix n n F -> F),
    Proper (equ ==> equ) g ->
    (forall (i:Fin.t n)(A:Matrix n n F)(r1 r2:Fin.t n->F),
       g (upd_row A i (fun k=>r1 k+r2 k)) == g(upd_row A i r1)+g(upd_row A i r2)) ->
    (forall (A:Matrix n n F)(i j:Fin.t n), i<>j -> (forall c, A i c==A j c) -> g A == 0) ->
    forall (A:Matrix n n F)(i j:Fin.t n), i<>j -> g (row_swap A i j) == - g A.

No characteristic assumption, no homogeneity, no permutation combinatorics — pure algebra, proved once and instantiated twice below.

Expansion over all row assignments. Write each row of AA as a combination of standard basis rows and use multilinearity once per row. What comes out is a sum over all functions from row indices to column indices — fsum, not a sum over permutations, so there is no injectivity bookkeeping:

  Theorem row_expand : forall (n p : nat) (g : Matrix p n F -> F),
    Proper (equ ==> equ) g ->
    (forall (i:Fin.t p)(A:Matrix p n F)(r1 r2:Fin.t n->F),
       g (upd_rowP A i (fun k=>r1 k+r2 k)) == g(upd_rowP A i r1)+g(upd_rowP A i r2)) ->
    (forall (i:Fin.t p)(A:Matrix p n F)(c:F)(r0:Fin.t n->F),
       g (upd_rowP A i (fun k=>c*r0 k)) == c*g(upd_rowP A i r0)) ->
    forall A : Matrix p n F,
    g A == fsum n p (fun f : Fin.t p -> Fin.t n =>
      prodF (fun i : Fin.t p => A i (f i)) * g (basis_rowsP f)).

detM satisfies the same hypotheses, so the same expansion applies to it. Matching the two term by term reduces everything to one question: what is gg at a matrix whose rows are basis rows?

The termwise comparison. For every ff — injective or not — g (basis_rowsP f) == g mat_id * detM (basis_rowsP f), by strong induction on how many positions ff moves. If ff takes the same value twice, two rows of basis_rowsP f are literally equal and both sides are 00 outright. Otherwise pick a position pp that ff moves; precomposing ff with the transposition of pp and f(p)f(p) turns basis_rowsP f into its own row swap and strictly decreases the count of moved positions, so antisymmetry applied to both gg and detM, plus the induction hypothesis, closes the step.

The measure argument needs to decide equality of indices, which is always available — Fin.t n has decidable equality for every n — and never equality of field elements. That is the whole difference from route one.

Putting the three together gives the uniqueness statement — any row-multilinear alternating gg is detM scaled by gg’s own value at the identity:

  Theorem g_row_expand_eq : forall (N:nat) (g : Matrix N N F -> F),
    Proper (equ ==> equ) g ->
    (forall (i:Fin.t N)(A:Matrix N N F)(r1 r2:Fin.t N->F),
       g (upd_row A i (fun k=>r1 k+r2 k)) == g(upd_row A i r1)+g(upd_row A i r2)) ->
    (forall (i:Fin.t N)(A:Matrix N N F)(c:F)(r0:Fin.t N->F),
       g (upd_row A i (fun k=>c*r0 k)) == c*g(upd_row A i r0)) ->
    (forall (A:Matrix N N F)(i j:Fin.t N), i<>j -> (forall c, A i c==A j c) -> g A == 0) ->
    forall A : Matrix N N F, g A == g mat_id * detM A.

Applying it to g:=A↦det⁡(AB)g := A \mapsto \det(AB) gives the theorem.

  Theorem detM_mul : forall (N:nat)(A B:Matrix N N F), detM (mat_mul A B) == detM A * detM B.
  Proof.
    intros N A B.
    destruct N as [| p0].
    - rewrite (detM_0 (mat_mul A B)), (detM_0 A), (detM_0 B).
      ring.
    - assert (Hg := g_row_expand_eq (S p0) (g_mulB B) (g_mulB_proper (S p0) B)
                 (fun i A' r1 r2 => g_mulB_add (S p0) p0 eq_refl B i A' r1 r2)
                 (fun i A' c r0 => g_mulB_scale (S p0) p0 eq_refl B i A' c r0)
                 (g_mulB_alt (S p0) B) A).
      unfold g_mulB in Hg.
      calc (detM (mat_mul A B))
        == (detM (mat_mul mat_id B) * detM A)
        == (detM A * detM (mat_mul mat_id B))
        == (detM A * detM B).
      + exact Hg.
      + exact (mul_comm (detM (mat_mul mat_id B)) (detM A)).
      + apply Magma.op_proper; [reflexivity |].
        apply detM_proper. exact (mat_mul_left_identity (S p0) (S p0) B).
  Qed.

The empty matrix is handled separately because its determinant is 11 by definition: detM_0 rewrites all three determinants to 11, leaving 1=1⋅11 = 1 \cdot 1, and ring — Coq’s decision procedure for polynomial identities in a commutative ring — closes that without anyone having to name the unit law. Otherwise g_row_expand_eq is instantiated at g_mulB B, which is A↦det⁡(AB)A \mapsto \det(AB) packaged with its three proofs. The two linearity ones come from mat_mul_upd_row — row ii of ABAB reads only row ii of AA, linearly, through BB — composed with det_rowI_add and det_rowI_scale. The alternating one is detM_alternating again: equal rows of AA force equal rows of ABAB. The uniqueness statement then reads det⁡(AB)=det⁡(IB)det⁡(A)\det(AB) = \det(IB)\det(A), and the last two links are commutativity and dropping the identity factor.

No decidability, no characteristic assumption, any size, any field.

What it buys

The coordinate-free determinant of an endomorphism, det B f := detM (mat_of B B f), lives in Theory/Determinant.v. Two of its theorems — that it is multiplicative under composition, and that it does not depend on the basis — are stated there under a named local hypothesis rather than proved, because matrix multiplicativity is not in scope at that point in the development:

  Context (detM_mul : forall (m : nat) (A A' : Matrix m m F),
    detM (mat_mul A A') == detM A * detM A').

That is a parameter, not an axiom: every caller of det_comp or det_basis_independent must hand it over. detM_mul above hands it over for any field, so those two theorems hold unconditionally wherever it is in scope. Impl/DetMul.v also records the rational instances explicitly, discharged through the elimination route:

Corollary det_comp_Q : forall (U : Type)
    (eU : EqRel U) (zU : Zero U) (aU : HasAdd U) (nU : HasNeg U)
    (sU : HasScale Q U) (VU : VectorSpace Q U) (n : nat)
    (B : Basis n Q U) (f g : LinearMap Q U U),
  det B (linear_map_comp f g) == det B f * det B g.

Corollary det_basis_indep_Q : forall (U : Type)
    (eU : EqRel U) (zU : Zero U) (aU : HasAdd U) (nU : HasNeg U)
    (sU : HasScale Q U) (VU : VectorSpace Q U)
    (n : nat) (B B' : Basis n Q U) (f : LinearMap Q U U),
  det B' f == det B f.

On numbers

The product law is also run. With the matrix 1234567810\begin{smallmatrix}1&2&3\\4&5&6\\7&8&10\end{smallmatrix}, determinant −3-3, and a second matrix of determinant 55, both sides are evaluated independently by conversion before the theorem is applied to the same instance:

Example detM_mulGeneral_Q_compute_lhs :
  detM (mat_mul mat3_ns_g mat3_b_g) == ((-15)#1)%Q.
Proof. reflexivity. Qed.

Example detM_mulGeneral_Q_compute_rhs :
  detM mat3_ns_g * detM mat3_b_g == ((-15)#1)%Q.
Proof. reflexivity. Qed.

Two computations that know nothing about each other land on −15-15.
