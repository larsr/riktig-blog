Normed spaces, and what it takes to say “tends to”

A vector space has no notion of size, so it has no notion of close, and without that there is no analysis. One function supplies both: a length for each vector, from which “close” means “the difference is short”. This post gives that structure and then the first thing built on it — the limit of a sequence — with the two proofs that make the definition worth having.

Length, by four laws

A norm on a vector space VV over an ordered field FF assigns to each vector a scalar ∥u∥\|u\| such that

∥u∥≥0,∥u∥=0⇒u=0,\|u\| \geq 0, \qquad \|u\| = 0 \Rightarrow u = 0,

∥a*:u∥=|a|∥u∥,∥u+v∥≤∥u∥+∥v∥.\|a *: u\| = |a|\,\|u\|, \qquad \|u + v\| \leq \|u\| + \|v\|.

The last is the triangle inequality: a detour is never shorter than going direct.

  Class NormedSpace (F V : Type) `{OrderedField F}
      {Ve : EqRel V} {Vz : Zero V} {Va : HasAdd V} {Vn : HasNeg V}
      {Vs : HasScale F V} {VS : VectorSpace F V} {Vnorm : HasNorm F V} := {
    vnorm_proper :: Proper (equ ==> equ) Vnorm;

    nonneg   : forall u : V, 0 <= ‖ u ‖;
    definite : forall u : V, ‖ u ‖ == 0 -> u == 0;
    is_homogeneous :: Homogeneous F V F mult abs Vnorm;
    triangle : forall u v : V, ‖ u + v ‖ <= ‖ u ‖ + ‖ v ‖;
  }.

Two details reward a slow reading. The scalars are an ordered field, not merely a field: comparing lengths needs <=, which is structure in its own right, so this cannot be stated with the complex numbers as scalars without saying where the sizes live.

And the homogeneity law is not written fresh. It is the catalogue’s Homogeneous entry with the weight slot filled by abs — a scalar pulled out of a norm comes out as its absolute value, not itself. The same entry with the weight left as the identity is what makes a map linear. One law shape, two readings, as in the earlier posts.

Nothing here says the field is the real numbers, and nothing below needs it to be. Over the rationals every statement in this post still holds; what fails without completeness is the existence of limits, not their theory.

What “tends to” means

A sequence x0,x1,x2,…x_0, x_1, x_2, \dots of vectors converges to LL when its terms eventually stay within any tolerance you name:

∀ε>0,∃N,∀n≥N:∥xn−L∥<ε.\forall \varepsilon > 0,\ \exists N,\ \forall n \geq N: \quad \|x_n - L\| < \varepsilon.

  Definition seq_lim (x : nat -> V) (L : V) : Prop :=
    forall eps : F, 0 < eps ->
      exists N : nat, forall n : nat, (N <= n)%nat -> ‖ x n + - L ‖ < eps.

The transcription is the mathematics with x n + - L for the difference, since subtraction is addition of the negative. The order of the quantifiers carries the whole content: NN is chosen after ε\varepsilon and may depend on it, and that dependency is what makes the definition say anything at all.

A sequence cannot go to two places

The first theorem licenses the phrase “the limit”: if xn→L1x_n \to L_1 and xn→L2x_n \to L_2 then L1=L2L_1 = L_2.

On the blackboard: given ε\varepsilon, go far enough out that xnx_n is within ε/2\varepsilon/2 of both limits — possible because far enough for one and far enough for the other is just the larger of the two indices. Then

∥L1−L2∥≤∥L1−xn∥+∥xn−L2∥<ε2+ε2=ε.\|L_1 - L_2\| \leq \|L_1 - x_n\| + \|x_n - L_2\| < \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \varepsilon.

So ∥L1−L2∥\|L_1 - L_2\| is below every positive number. A non-negative quantity below every positive number is zero, and a vector of length zero is the zero vector, so L1−L2=0L_1 - L_2 = 0.

  Theorem lim_unique : forall (x : nat -> V) (L1 L2 : V),
    seq_lim x L1 -> seq_lim x L2 -> L1 == L2.
  Proof.
    intros x L1 L2 Hx1 Hx2.
    apply sub_eq_zero.
    apply definite.
    apply nonneg_below_all_pos_is_zero.

Those three lines are the last three sentences of the argument, in reverse: sub_eq_zero from the group post (a vanishing difference is an equality), then the norm axiom definite, then nonneg_below_all_pos_is_zero. What remains is the estimate, which uses Nat.max N1 N2 for “far enough for both” exactly as the blackboard does.

The halving is real work, incidentally. half eps exists because the scalars form an ordered field, where 22 is positive and therefore invertible — the same halving the geometric-algebra post had to pay for, and the reason so much of analysis quietly assumes you can divide by two.

Limits respect the operations

The remaining theorems say the limit of a sum is the sum of the limits, and likewise for scaling and negation:

  Theorem lim_add : forall (x y : nat -> V) (L M : V),
    seq_lim x L -> seq_lim y M -> seq_lim (fun n => x n + y n) (L + M).

The proof is the ε/2\varepsilon/2 argument again: to hold the sum within ε\varepsilon, hold each part within ε/2\varepsilon/2 and take the later of the two indices. The estimate that assembles it,

∥(xn+yn)−(L+M)∥≤∥xn−L∥+∥yn−M∥,\|(x_n + y_n) - (L + M)\| \leq \|x_n - L\| + \|y_n - M\|,

is norm_sub_pair, one of a small family of rearrangement lemmas in Theory/Norm.v that exist so analysis proofs can cite a named fact rather than re-derive it. lim_scale is the same shape with |c|ε|c|\,\varepsilon in place of ε/2\varepsilon/2, and lim_neg follows from lim_scale at −1-1 — as the vector-space post showed, scaling by −1-1 is negation.
