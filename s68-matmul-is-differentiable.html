Matmul is differentiable

Training a layer that multiplies data by weights means differentiating the multiplication — in both arguments at once, since the weights are what you are adjusting. That is more than the derivative of a linear map, which is itself and needs no work. The product A⋅BA \cdot B is linear in AA for fixed BB and linear in BB for fixed AA, but it is not linear in the pair: doubling both factors quadruples the product. A function like that is called bilinear, and its derivative is the product rule,

D(A0,B0)[dA,dB]=dA⋅B0+A0⋅dB,D(A_0, B_0)\,[\,dA, dB\,] \;=\; dA \cdot B_0 \;+\; A_0 \cdot dB,

with a leftover term dA⋅dBdA \cdot dB that has to be shown small. The leftover is the whole difficulty. It is a product of two small things rather than a sum of two small things, so it cannot be dismissed by algebra — proving it negligible needs an actual estimate, and the estimate needs a way to measure how big a matrix is.

What follows is that measurement and that estimate.

What “derivative” means here

The derivative of ff at a point aa is a bounded linear map LL that approximates ff near aa with an error small compared with the step. Written without division, so that no deleted neighborhood is needed:

∥f(a+h)−(f(a)+Lh)∥≤ε∥h∥whenever ∥h∥<δ.\|f(a + h) - (f(a) + L\,h)\| \;\le\; \varepsilon\,\|h\| \qquad\text{whenever } \|h\| < \delta.

That is the definition the development uses (Theory/Derivative.v):

Definition is_deriv (f : U -> V) (a : U) (L : LinearMap F U V) : Prop :=
  linear_map_bounded L /\
  forall eps : F, 0 < eps ->
    exists delta : F, 0 < delta /\
      forall h : U, ‖ h ‖ < delta ->
        ‖ f (a + h) + - (f a + L h) ‖ <= eps * ‖ h ‖.

Every symbol in that statement that measures size is ‖ ‖, the norm of a NormedSpace. So before matrix multiplication can be differentiated, matrices need a norm.

A norm on matrices, without a square root

The classical choice is the Frobenius norm ∥A∥F=∑i,jAij2\|A\|_F = \sqrt{\sum_{i,j} A_{ij}^2}, and it is unavailable: the scalars here are an arbitrary ordered field, and an ordered field has no square root. What every ordered field does have is absolute value. So the norm is the entrywise L1L^1 norm, a double sum of absolute values (Impl/MatrixNorm.v):

∥A∥:=∑i,j|Aij|\|A\| \;:=\; \sum_{i,j} |A_{ij}|

Definition mat_norm (A : Matrix m n F) : F :=
  bigopF (fun i : Fin.t m => bigopF (fun j : Fin.t n => abs (A i j))).

The five NormedSpace laws — mat_norm_proper, mat_norm_nonneg, mat_norm_definite, mat_norm_scale and mat_norm_triangle — are each the corresponding fact about abs, applied under the two sums, and they assemble into Matrix_NormedSpace. This is not merely the cheaper choice: under multiplication the L1L^1 norm behaves better than Frobenius does, as the next section shows.

Matmul is bilinear, and that is already proved

Being bilinear is four laws — additive and homogeneous in each slot — plus respect for the setoid equality. All five hold of mat_mul already, because each is one distributivity or commutativity step under a finite sum (Impl/Matrix.v):

Theorem mat_mul_add_l : forall (m n p : nat) (A A' : Matrix m n F)
    (B : Matrix n p F),
  mat_mul (A + A') B == mat_mul A B + mat_mul A' B.
Theorem mat_mul_scale_l : forall (m n p : nat) (a : F)
    (A : Matrix m n F) (B : Matrix n p F),
  mat_mul (a *: A) B == a *: mat_mul A B.

mat_mul_bilinear bundles those two, their right-hand twins mat_mul_add_r and mat_mul_scale_r, and mat_mul_proper into a BilinearMap — supplying its projections bilinear_left_additive, bilinear_left_scale, bilinear_right_additive, bilinear_right_scale and bilinear_map_proper respectively. There is nothing to prove; it is packaging.

What is not packaging is the estimate. A bilinear map is differentiable when it is bounded — when some constant CC makes ∥Buv∥≤C∥u∥∥v∥\|B\,u\,v\| \le C\,\|u\|\,\|v\| hold everywhere (Theory/BilinearDeriv.v):

Definition bm_bounded (B : BilinearMap F U V W) : Prop :=
  exists C : F, 0 <= C /\ forall (u : U) (v : V), ‖ B u v ‖ <= C * ‖ u ‖ * ‖ v ‖.

Any CC that works is enough for differentiability. For matmul under the L1L^1 norm, C=1C = 1 works — no dimension-dependent slack.

The sharp bound

Blackboard. Each entry of ABAB is a sum, so the triangle inequality and |xy|=|x||y||xy| = |x|\,|y| bound its absolute value; then rearrange:

∥AB∥=∑i,k|∑jAijBjk|definition of the norm≤∑i,k∑j|Aij||Bjk|triangle inequality, |xy|=|x||y|=∑i∑j∑k|Aij||Bjk|interchange the j,k sums=∑i∑j|Aij|⋅(∑k|Bjk|)factor |Aij| out≤∑i∑j|Aij|⋅∥B∥one row of |B|≤ all of it=∥A∥⋅∥B∥factor ∥B∥ out.\begin{aligned} \|AB\| \;&=\; \sum_{i,k}\Big|\sum_j A_{ij}B_{jk}\Big| &&\text{definition of the norm}\\ &\le\; \sum_{i,k}\sum_j |A_{ij}|\,|B_{jk}| &&\text{triangle inequality, } |xy| = |x||y|\\ &=\; \sum_i \sum_j \sum_k |A_{ij}|\,|B_{jk}| &&\text{interchange the } j,k \text{ sums}\\ &=\; \sum_i \sum_j |A_{ij}| \cdot \Big(\sum_k |B_{jk}|\Big) &&\text{factor } |A_{ij}| \text{ out}\\ &\le\; \sum_i \sum_j |A_{ij}| \cdot \|B\| &&\text{one row of } |B| \le \text{ all of it}\\ &=\; \|A\| \cdot \|B\| &&\text{factor } \|B\| \text{ out.} \end{aligned}

The one step worth pausing on is the fifth. A single row’s absolute sum ∑k|Bjk|\sum_k |B_{jk}| is bounded by the whole double sum ∥B∥\|B\| because the rows that were dropped contribute absolute values, which are non-negative — dropping them can only weaken the bound, never invalidate it. That is why no factor of nn appears anywhere.

Coq. Each line of the display above is a named lemma, and the theorem is the chain of them:

Theorem mat_mul_norm_submultiplicative : forall (A : Matrix m n F)
    (B : Matrix n p F), ‖ mat_mul A B ‖ <= ‖ A ‖ * ‖ B ‖.
Proof.
  intros A B.
  calc (‖ mat_mul A B ‖)
    == (bigopF (fun i => bigopF (fun k =>
          bigopF (fun j => abs (A i j) * abs (B j k)))))
       { (mat_mul_norm_bound_step1 A B) }
    == (bigopF (fun i => bigopF (fun j =>
          bigopF (fun k => abs (A i j) * abs (B j k)))))
       { (mat_mul_norm_bound_step2 A B) }
    == (bigopF (fun i => bigopF (fun j =>
          abs (A i j) * bigopF (fun k => abs (B j k)))))
       { (mat_mul_norm_bound_step3 A B) }
    == (bigopF (fun i => bigopF (fun j => abs (A i j) * ‖ B ‖)))
       { (mat_mul_norm_bound_step5 A B) }
    == (‖ A ‖ * ‖ B ‖)
       { (mat_mul_norm_bound_step6 A B) }.
Qed.

calc writes a proof as the sequence of objects it passes through, with the law justifying each step in braces. The relation is read off the goal, so this is a chain of <= even though the separator is spelled ==; each justification is applied in whichever direction closes its own step, which is how the three links that are equations sit in a chain of inequalities. The endpoints are unified against the goal, so the written chain is checked rather than trusted.

Line by line: mat_mul_norm_bound_step1 is the entrywise bound summed twice, mat_mul_norm_bound_step2 is the interchange (one use of bigopF_swap), mat_mul_norm_bound_step3 and mat_mul_norm_bound_step6 are bigopF_mul_l and bigopF_mul_r pulling a constant factor through a sum, and mat_mul_norm_bound_step5 applies the one-row bound under both sums. That one-row bound, mat_mul_norm_bound_step4, is the fussy ingredient the fifth blackboard line described:

Lemma mat_mul_norm_bound_step4 : forall (B : Matrix n p F) (j : Fin.t n),
  bigopF (fun k => abs (B j k)) <= ‖ B ‖.

Boundedness with C=1C = 1 then costs four lines, and rewrite left_identity is doing the only real work in them — turning 1 * ‖A‖ * ‖B‖ into ‖A‖ * ‖B‖:

Theorem mat_mul_bm_bounded : bm_bounded mat_mul_bilinear.
Proof.
  exists 1.
  split.
  - exact zero_le_one.
  - intros A B.
    rewrite left_identity.
    exact (mat_mul_norm_submultiplicative A B).
Qed.

The derivative

Blackboard. Expand the perturbed product by bilinearity in each slot. Four terms come out:

(A0+dA)(B0+dB)=A0B0⏟value+dAB0+A0dB⏟linear in the step+dAdB⏟remainder.(A_0 + dA)(B_0 + dB) \;=\; \underbrace{A_0 B_0}_{\text{value}} \;+\; \underbrace{dA\,B_0 + A_0\,dB}_{\text{linear in the step}} \;+\; \underbrace{dA\,dB}_{\text{remainder}}.

Exactly one term is left over, and the bound just proved makes it ∥dA∥∥dB∥\|dA\|\,\|dB\| at worst. With h=(dA,dB)h = (dA, dB) measured by ∥h∥=∥dA∥+∥dB∥\|h\| = \|dA\| + \|dB\|, both factors are at most ∥h∥\|h\|, so the remainder is at most ∥h∥2\|h\|^2 — and ∥h∥2≤ε∥h∥\|h\|^2 \le \varepsilon\|h\| as soon as ∥h∥≤ε\|h\| \le \varepsilon. That is the definition satisfied, with δ\delta read off from ε\varepsilon; the general version, for an arbitrary bound CC, takes δ=ε/(1+C)\delta = \varepsilon/(1 + C).

Coq. That argument is bilinear_is_deriv, proved once for every bilinear map, with bilinear_remainder_eq doing the four-term cancellation and bilinear_remainder_bound doing the estimate. What matmul contributes is the two ingredients: the BilinearMap witness and the boundedness proof. The derivative itself is named first,

Definition mat_mul_deriv_lm (A0 : Matrix m n F) (B0 : Matrix n p F) :
    LinearMap F (Matrix m n F * Matrix n p F) (Matrix m p F) :=
  bilinear_deriv_lm mat_mul_bilinear A0 B0.

— which unfolds to the product rule, since bilinear_deriv_lm is built from

Definition bilinear_deriv_fun (p : U * V) : W :=
  B (fst p) v0 + B u0 (snd p).

— and then the theorem is one application:

Theorem mat_mul_is_deriv : forall (A0 : Matrix m n F) (B0 : Matrix n p F),
  is_deriv (fun AB : Matrix m n F * Matrix n p F => mat_mul (fst AB) (snd AB))
    (A0, B0) (mat_mul_deriv_lm A0 B0).
Proof.
  intros A0 B0.
  exact (bilinear_is_deriv mat_mul_bilinear A0 B0 mat_mul_bm_bounded).
Qed.

Read the statement carefully: the function being differentiated takes a pair of matrices and multiplies them, and the point is the pair (A0,B0)(A_0, B_0). This is differentiability in the weights and in the activations simultaneously, at every point, with the derivative written out. A layer that multiplies its input by a weight matrix inherits it; there is no per-layer argument to make.

What this does not cover

Multiplication was the piece that needed a genuinely new mathematical ingredient — the norm, and the sharp bound. The other layers of a transformer are in different states. Theory/MLDerivatives.v proves the two one-sided facts about ReLU, is_deriv_relu_pos and is_deriv_relu_neg, and deliberately claims nothing at the kink, where ReLU has no two-sided derivative at all. The derivative of exp is not a consequence of its algebraic laws — those laws say nothing about limits — so it appears there as an explicit hypothesis, and is_deriv_exp_scale is conditional on it. Softmax and layernorm need two things that do not exist yet: a norm on the plain coordinate space Fin.t n -> F (only matrices have one), and a derivative rule for inv, which is not bilinear and needs an estimate of its own.
