A determinant you can compute, and a trace that doesn’t care about your basis

A linear map between finite-dimensional spaces turns into a grid of numbers as soon as you choose bases: column jj holds the coordinates of the image of the jj-th source basis vector. The grid depends on that choice. Pick a different basis and every entry can change. So a number computed from the grid is, until proved otherwise, a fact about the coordinates rather than about the map.

Two such numbers are taught anyway as though they were facts about the map: the determinant and the trace. They belong in one post because they are the same kind of claim at two different stages. The determinant comes first as a program — the cofactor recipe, running on actual rationals — together with the two properties that recipe hands over immediately. The trace comes second because for it the independence claim is small enough to prove here, start to finish.

The determinant, by the formula you learned

Every course teaches the determinant by expansion: pick a column, multiply each entry by its cofactor — the determinant of the matrix with that entry’s row and column struck out — alternate signs, and add. Written as a program along the first column, that is a recursion on the size of the matrix, and it is exactly what Impl/Det.v defines:

  Fixpoint detM {n : nat} (A : Matrix n n F) {struct n} : F :=
    match n as n0 return Matrix n0 n0 F -> F with
    | O => fun _ => 1
    | S m => fun B =>
        bigopF (fun i : Fin.t (S m) =>
          sign_at i * (B i Fin.F1 * detM (minor B i)))
    end A.

The empty matrix has determinant 11. Otherwise bigopF, the finite sum of a family indexed by Fin.t (S m), runs over the rows: each row i contributes a sign, times the first-column entry Bi,1B_{i,1}, times the determinant of the smaller matrix left after deleting row i and column one.

Two supporting definitions do the bookkeeping. sign_at produces 1,−1,1,…1, -1, 1, \dots by recursion on the index, staying inside the field — no integers and no parity function anywhere:

  Fixpoint sign_at {n : nat} (i : Fin.t n) : F :=
    match i with
    | Fin.F1 => 1
    | Fin.FS j => - sign_at j
    end.

And minor deletes one row and the first column, using skip i, the increasing injection Fin.t p -> Fin.t (S p) that misses i:

  Definition minor {p : nat} (A : Matrix (S p) (S p) F) (i : Fin.t (S p))
      : Matrix p p F :=
    fun r c => A (skip i r) (Fin.FS c).

Making skip behave — proving it is injective, that it never hits the deleted point, and that it composes the way the recursion needs — is real work, but it is bookkeeping about finite index types, not about fields or matrices. What it buys is a type that records the size correctly: a minor really is one row and one column smaller, so the recursion is structural and detM computes.

Over ℚ\mathbb{Q} it computes at the end of the file, on a matrix small enough to check by hand:

Example det2_Q :
  detM (mat2 (1#1)%Q (2#1)%Q (3#1)%Q (4#1)%Q) == ((-2)#1)%Q.
Proof.
  reflexivity.
Qed.

1⋅4−3⋅2=−21\cdot 4 - 3\cdot 2 = -2, and reflexivity closes it: both sides reduce to the same rational, with nothing left to prove.

Two properties the recipe hands over

The identity matrix has determinant one.

det⁡(I)=1⋅det⁡(In−1)+0+…+0=det⁡(In−1)=…=1.\det(I) \;=\; 1\cdot\det(I_{n-1}) \;+\; 0 \;+\;\dots\;+\;0 \;=\; \det(I_{n-1}) \;=\; \dots \;=\; 1.

Expanding II along its first column, only the top-left term survives — every other first-column entry is 00 — its minor is again an identity matrix one size smaller, and the recursion bottoms out at 11.

  Theorem det_id : forall n : nat, detM (@mat_id F _ _ n) == 1.

The determinant is additive in its first column. Overwrite column one of AA with a column vector cc, written upd_col1 A c. Then

det⁡(A[c+d])=det⁡(A[c])+det⁡(A[d]),\det\big(A[\,c+d\,]\big) \;=\; \det\big(A[\,c\,]\big) \;+\; \det\big(A[\,d\,]\big),

because that column enters every term of the expansion exactly once, as the plain factor cic_i, and the minors never read column one at all — they only ever read columns of the form Fin.FS c. Each term distributes on its own, and a sum of split terms is the split of the sum:

  Theorem det_col1_add : forall (p : nat) (A : Matrix (S p) (S p) F)
      (c d : Fin.t (S p) -> F),
    detM (upd_col1 A (fun i => c i + d i))
      == detM (upd_col1 A c) + detM (upd_col1 A d).
  Proof.
    intros p A c d.
    calc (detM (upd_col1 A (fun i => c i + d i)))
      == (bigopF (fun i : Fin.t (S p) =>
            sign_at i * (c i * detM (minor A i))
            + sign_at i * (d i * detM (minor A i))))
      == (detM (upd_col1 A c) + detM (upd_col1 A d)).
    - rewrite (det_col1_expand p A (fun i => c i + d i)).
      apply bigopF_ext. intros i. ring.
    - rewrite (bigopF_add (S p)
                 (fun i : Fin.t (S p) => sign_at i * (c i * detM (minor A i)))
                 (fun i : Fin.t (S p) => sign_at i * (d i * detM (minor A i)))),
        (det_col1_expand p A c), (det_col1_expand p A d).
      reflexivity.
  Qed.

The calc block names the one intermediate expression the proof passes through — the expansion with each term already split in two — and leaves two goals, one per link.

The first link is det_col1_expand, the observation that the minors do not see the update: the expansion of upd_col1 A c is the ordinary expansion with c i sitting in the linear slot and the old matrix inside every minor. Then bigopF_ext reduces “these two sums are equal” to “these two terms are equal, for an arbitrary index i”, and what remains is s((ci+di)m)=s(cim)+s(dim)s\,\big((c_i + d_i)\,m\big) = s\,(c_i m) + s\,(d_i m) — distributivity plus a reassociation of a triple product, in a fixed number of steps with no induction anywhere. ring proves it. That tactic works here because the section opens with

  Add Ring F_ring : (ring_theory_of_Ring (R := F) commutative).

which hands Coq’s ring solver a ring_theory record built from the field’s own laws, so ring normalizes both sides of any polynomial identity over the abstract F and compares them. Any goal that is a true equation between two polynomial expressions in the same variables closes in one word.

The second link is bookkeeping about sums: bigopF_add splits one sum of pairs into a pair of sums, and det_col1_expand, read backwards, folds each half back into a determinant.

Homogeneity, det_col1_scale, is the same two links with bigopF_mul_l in place of bigopF_add, and the same one-word ring for the per-term rearrangement s((aci)m)=a(s(cim))s\,\big((a c_i)\, m\big) = a\,\big(s\,(c_i m)\big). Additivity and homogeneity in one distinguished slot are the first two of the three laws a determinant is classically characterized by; the third, vanishing on repeated arguments, and the extension of the first two from column one to every row, need machinery this file does not have.

Trace: the sum you’d compute either way

The trace of a square matrix is the sum of its diagonal — simpler than the determinant by any measure. The classical fact about it is almost never proved in a first course, only asserted: the trace does not care which basis you wrote the matrix in. In Theory/Trace.v that assertion is a theorem, and its proof is short enough to follow whole.

  Definition matrix_trace {n : nat} (A : Matrix n n F) : F :=
    bigopF (fun i => A i i).

Step one, a fact about products. For any AA and BB whose two products are both defined,

tr(AB)=∑i∑jAijBji=∑j∑iBjiAij=tr(BA).\mathrm{tr}(AB) \;=\; \sum_i \sum_j A_{ij} B_{ji} \;=\; \sum_j \sum_i B_{ji} A_{ij} \;=\; \mathrm{tr}(BA).

Both traces are the same double sum: the middle equality reorders the two summations and commutes each product. That is the entire proof, and the Coq version says exactly that, one calc link per step:

  Theorem trace_mul_commutes_rect : forall (m n : nat) (A : Matrix m n F)
      (B : Matrix n m F),
    matrix_trace (mat_mul A B) == matrix_trace (mat_mul B A).
  Proof.
    intros m n A B.
    rewrite (matrix_trace_mul_expand m n A B), (matrix_trace_mul_expand n m B A).
    calc (bigopF (fun i : Fin.t m => bigopF (fun j : Fin.t n => A i j * B j i)))
      == (bigopF (fun j : Fin.t n => bigopF (fun i : Fin.t m => A i j * B j i)))
      == (bigopF (fun i : Fin.t n => bigopF (fun j : Fin.t m => B i j * A j i))).
    - exact (bigopF_swap m n (fun i j => A i j * B j i)).
    - apply bigopF_ext. intros j.
      apply bigopF_ext. intros i.
      exact (mul_commutative (A i j) (B j i)).
  Qed.

matrix_trace_mul_expand unfolds each side into its double sum — by reflexivity, since that is what the definitions already say. bigopF_swap is the interchange ∑i∑j=∑j∑i\sum_i\sum_j = \sum_j\sum_i for finite sums, proved once by induction in Theory/BigOp.v and used wherever a double sum needs reordering. The last two lines rewrite underneath both summations to swap the two factors of each term. Note the shape: AA and BB need not be square, only composable both ways, and the theorem still holds — trace_mul_commutes is the square special case.

Step two, change of basis is conjugation. Two bases B,B′B, B' of the same space give two matrices for the same endomorphism, and the transporter between them is the identity map written down in mixed bases:

  Definition change_of_basis (B B' : Basis n F U) : Matrix n n F :=
    mat_of B' B (linear_map_id (F:=F) (U:=U)).

Two facts about it, each one application of the representation theorem. change_of_basis_inv says the two directions cancel: their product is the matrix of the identity composed with itself, which is the identity matrix. And mat_of_conj says re-reading ff in the other basis conjugates its matrix, [[f]]B′=P−1[[f]]BP[\![f]\!]_{B'} = P^{-1}[\![f]\!]_B P with $P := $ change_of_basis B B'.

The theorem. Put the two together:

tr(P−1AP)=tr(APP−1)=tr(AI)=tr(A).\mathrm{tr}\big(P^{-1} A P\big) \;=\; \mathrm{tr}\big(A P P^{-1}\big) \;=\; \mathrm{tr}(A\, I) \;=\; \mathrm{tr}(A).

Rotate the product under the trace by step one, cancel the two transporters, drop the identity factor.

  Theorem tr_basis_independent : forall (B B' : Basis n F U)
      (f : LinearMap F U U),
    matrix_trace (mat_of B' B' f) == matrix_trace (mat_of B B f).
  Proof.
    intros B B' f.
    calc (matrix_trace (mat_of B' B' f))
      == (matrix_trace (mat_mul (change_of_basis B' B) (mat_mul (mat_of B B f) (change_of_basis B B'))))
      == (matrix_trace (mat_mul (mat_mul (mat_of B B f) (change_of_basis B B')) (change_of_basis B' B)))
      == (matrix_trace (mat_mul (mat_of B B f) (mat_mul (change_of_basis B B') (change_of_basis B' B))))
      == (matrix_trace (mat_mul (mat_of B B f) (@mat_id F _ _ n)))
      == (matrix_trace (mat_of B B f)).
    - exact (matrix_trace_proper n
               (mat_of B' B' f)
               (mat_mul (change_of_basis B' B) (mat_mul (mat_of B B f) (change_of_basis B B')))
               (mat_of_conj B B' f)).
    - exact (trace_mul_commutes n (change_of_basis B' B)
               (mat_mul (mat_of B B f) (change_of_basis B B'))).
    - exact (matrix_trace_proper n
               (mat_mul (mat_mul (mat_of B B f) (change_of_basis B B')) (change_of_basis B' B))
               (mat_mul (mat_of B B f) (mat_mul (change_of_basis B B') (change_of_basis B' B)))
               (mat_mul_assoc n n n n (mat_of B B f)
                  (change_of_basis B B') (change_of_basis B' B))).
    - exact (matrix_trace_proper n
               (mat_mul (mat_of B B f) (mat_mul (change_of_basis B B') (change_of_basis B' B)))
               (mat_mul (mat_of B B f) (@mat_id F _ _ n))
               (mat_mul_proper n n n
                  (mat_of B B f) (mat_of B B f)
                  (reflexivity (mat_of B B f))
                  (mat_mul (change_of_basis B B') (change_of_basis B' B)) (@mat_id F _ _ n)
                  (change_of_basis_inv B' B))).
    - exact (matrix_trace_proper n
               (mat_mul (mat_of B B f) (@mat_id F _ _ n))
               (mat_of B B f)
               (mat_mul_right_identity n n (mat_of B B f))).
  Qed.

The calc chain is the blackboard chain, line for line, and each link is discharged by a lemma that already exists: mat_of_conj for the conjugation, trace_mul_commutes for the rotation, mat_mul_assoc for the regrouping, change_of_basis_inv for the cancellation, mat_mul_right_identity for the last step. What surrounds them is only plumbing — matrix_trace_proper and mat_mul_proper carry a rewrite under the trace and under a product, since equality of matrices is pointwise and has to be transported explicitly. No new machinery.

Using it

With independence proved, the trace of an endomorphism can be defined through a basis without apology:

  Definition tr (B : Basis n F U) (f : LinearMap F U U) : F :=
    matrix_trace (mat_of B B f).

tr_indep, one line away from the theorem above, says the basis argument is immaterial: compute in whichever basis is convenient and the answer is the same. And the definition really does assemble — the file closes by asking Coq to build the trace on the coordinate space with its standard basis, with every structure argument left to instance search:

Example tr_check (F : Type) `{FF : Field F} (n : nat) : F :=
  tr (FinVec_Basis (F := F) n) linear_map_id.

The determinant deserves the same treatment, and the argument that gets it there is the same shape: conjugation plus a fact about products. For the trace that fact was tr(AB)=tr(BA)\mathrm{tr}(AB) = \mathrm{tr}(BA), one page. For the determinant it is det⁡(AB)=det⁡(A)det⁡(B)\det(AB) = \det(A)\det(B), and the cofactor recursion above gives no grip on it at all.
