Being isomorphic is an equivalence, because inverses cancel in the middle

In a category — objects, arrows between them, an associative composition ∘ with an identity arrow at each object, and arrow equality == given per pair of objects — you are not allowed to ask what an object contains, only how it connects. So when should two objects count as the same? Literal equality of objects is the wrong currency: nothing in the arrow language can even state it. The arrow-level answer is a pair of arrows that undo each other — a trip from x to y and back that loses nothing, in either order. That is an isomorphism, and this post develops its small algebra: what the data is, what the laws are, and the theorem that makes “isomorphic” behave like an equality — any object is isomorphic to itself, isomorphisms reverse, and they compose. The composition step is the one with content: it needs a cancellation argument, proved once and used twice.

The data and the laws, separated

From Theory/Category.v. The two round-trip laws are stated first, on their own, about any pair of arrows:

Module TwoSidedInverse.
  Class TwoSidedInverse {O : Type} `{Category O} {x y : O}
      (f : x ~> y) (g : y ~> x) := {
    from_to : g ∘ f == cat_id;
    to_from : f ∘ g == cat_id;
  }.
End TwoSidedInverse.

TwoSidedInverse f g says the two composites are the identities on their respective ends — going and coming back is a no-op, both ways around. An isomorphism then carries the two arrows as data, with one field holding the proof that they are mutually inverse:

  Class Iso (x y : O) := {
    iso_to : x ~> y;
    iso_from : y ~> x;
    iso_inverse :: TwoSidedInverse iso_to iso_from;
  }.

The file is deliberate about which of these instance search may supply on its own — the comment above Iso says which isomorphism one has is data, so search must never invent it, and the hint above TwoSidedInverse restricts search to checking a given pair of morphisms. The two laws are available under the names a caller expects, iso_fromto and iso_tofrom, projected out of iso_inverse; and iso_from_laws to from fromto tofrom assembles an Iso from the two arrows and the two laws, in that order.

Reflexive and symmetric, for free

Every object is isomorphic to itself: both arrows are the identity, and both round-trip laws are the same fact, cat_id ∘ cat_id == cat_id, an instance of the left identity law.

  Definition iso_refl (x : O) : Iso x x :=
    iso_from_laws cat_id cat_id
      (comp_left_identity x x cat_id)
      (comp_left_identity x x cat_id).

And an isomorphism reverses by swapping its two arrows, which swaps the two laws with them:

  Definition iso_sym {x y : O} (f : Iso x y) : Iso y x :=
    iso_from_laws (iso_from f) (iso_to f) (iso_tofrom f) (iso_fromto f).

Neither needed a proof script — both isomorphisms are constructed, each law filled by a law already in hand.

The cancellation in the middle

Transitivity is where something has to be computed. Compose the forward arrows, compose the backward arrows in the opposite order, and the round trip through the middle object must vanish: (a∘b)∘(b′∘a′)(a \circ b) \circ (b' \circ a') should be the identity whenever b∘b′b \circ b' and a∘a′a \circ a' are. On the blackboard, five steps, each justified by a named law or hypothesis:

(a∘b)∘(b′∘a′)=a∘(b∘(b′∘a′)){associativity} (a \circ b) \circ (b' \circ a') \;=\; a \circ (b \circ (b' \circ a')) \quad\{\text{associativity}\} =a∘((b∘b′)∘a′){associativity}=a∘(id∘a′){b∘b′=id} \;=\; a \circ ((b \circ b') \circ a') \quad\{\text{associativity}\} \;=\; a \circ (\mathrm{id} \circ a') \quad\{b \circ b' = \mathrm{id}\} =a∘a′{left identity}=id{a∘a′=id} \;=\; a \circ a' \quad\{\text{left identity}\} \;=\; \mathrm{id} \quad\{a \circ a' = \mathrm{id}\}

The Coq proof is that chain, written as a calc block whose braces name the justification of each step:

  Lemma comp_cancel :
    forall (x y z : O) (a : y ~> z) (b : x ~> y) (b' : y ~> x) (a' : z ~> y),
      b ∘ b' == cat_id -> a ∘ a' == cat_id -> (a ∘ b) ∘ (b' ∘ a') == cat_id.
  Proof.
    intros x y z a b b' a' Hb Ha.
    calc ((a ∘ b) ∘ (b' ∘ a'))
      == (a ∘ (b ∘ (b' ∘ a')))  { comp_associative }
      == (a ∘ ((b ∘ b') ∘ a'))  { comp_associative }
      == (a ∘ (cat_id ∘ a'))    { Hb }
      == (a ∘ a')               { comp_left_identity }
      == (cat_id : z ~> z)      { Ha }.
  Qed.

The two associativity steps regroup the four arrows so that the inner pair b ∘ b' sits together; the hypothesis Hb collapses it to the identity; the left identity law removes it; the hypothesis Ha finishes. Nothing here mentions isomorphisms — it is a fact about any four arrows with the two stated cancellations, and it is the group-theory cancellation shape played on typed arrows.

Transitivity is now assembly. The composite isomorphism runs f then g forward, g then f backward, and comp_cancel proves both round trips — once with the roles of the two isomorphisms one way, once the other:

  Definition iso_trans {x y z : O} (f : Iso x y) (g : Iso y z) : Iso x z :=
    iso_from_laws (iso_to g ∘ iso_to f) (iso_from f ∘ iso_from g)
      (comp_cancel _ _ _ _ _ _ _ (iso_fromto g) (iso_fromto f))
      (comp_cancel _ _ _ _ _ _ _ (iso_tofrom f) (iso_tofrom g)).

From data to a relation

Iso x y is data — it says which pair of arrows witnesses the isomorphism, and two different pairs are two different values. So Iso itself cannot be an equivalence relation; its transitivity above chooses a witness. The relation is its propositional truncation — “some isomorphism exists”, with the witness forgotten:

  Definition Isomorphic (x y : O) : Prop := inhabited (Iso x y).

  #[export] Instance Isomorphic_Equivalence : Equivalence Isomorphic.
  Proof.
    split.
    - intros x; exact (inhabits (iso_refl x)).
    - intros x y [f]; exact (inhabits (iso_sym f)).
    - intros x y z [f] [g]; exact (inhabits (iso_trans f g)).
  Qed.

The three constructions of this post are exactly the three fields of Equivalence: reflexivity is iso_refl, symmetry is iso_sym applied to the unpacked witness, transitivity is iso_trans applied to both. The registered instance is what lets reflexivity, symmetry and calc chains operate on goals of the form x ≅ y — the infix the file gives Isomorphic.

What the relation is for

≅ is category theory’s working notion of “the same object,” and the next theorems in this series conclude with it. Any two terminal objects are isomorphic, and dually for initial ones — proved in the universal-property post by handing iso_from_laws the only arrows the definitions permit — which is what entitles the phrase the terminal object. And because the whole development sits over an arbitrary Category instance, it lands on every instance at once: in the category of Coq types and functions, iso_trans composes bijections; in the category of typed lambda terms of the syntax-category post, it composes programs whose round trips are convertible to the identity — one proof, every world with arrows.
