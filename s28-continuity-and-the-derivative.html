Continuity, and why linear maps need a boundedness condition

The limit post was about sequences. The same ε\varepsilon apparatus applied to functions gives continuity — and one surprise. In finite dimensions every linear map is continuous, which is why the fact is rarely stated; here nothing says the space is finite-dimensional, so continuity has to be earned by a hypothesis, and seeing which one is instructive.

Limits of functions

A function ff tends to LL at the point aa when values of ff can be forced within any ε\varepsilon by taking the argument within some δ\delta of aa:

∀ε>0,∃δ>0,∀u:∥u−a∥<δ⇒∥f(u)−L∥<ε.\forall \varepsilon > 0,\ \exists \delta > 0,\ \forall u: \quad \|u - a\| < \delta \;\Rightarrow\; \|f(u) - L\| < \varepsilon.

  Definition limit_at (f : U -> V) (a : U) (L : V) : Prop :=
    forall eps : F, 0 < eps ->
      exists delta : F, 0 < delta /\
        forall u : U, ‖ u + - a ‖ < delta -> ‖ f u + - L ‖ < eps.

Continuity at a point is then not a new definition but a special case — the limit is the value:

  Definition continuous_at (f : U -> V) (a : U) : Prop :=
    limit_at f a (f a).

  Definition continuous (f : U -> V) : Prop :=
    forall a : U, continuous_at f a.

That is the whole idea of continuity: the function does not jump, because the value it approaches is the value it takes.

Uniqueness of these limits repeats the sequence argument almost word for word — go within ε/2\varepsilon/2 of both candidates, use the triangle inequality, conclude the distance is below every positive number:

  Theorem limit_at_unique : forall (f : U -> V) (a : U) (L1 L2 : V),
    limit_at f a L1 -> limit_at f a L2 -> L1 == L2.

and limit_at_add, limit_at_scale, limit_at_neg mirror their sequence counterparts. The pattern is deliberate: two notions of limit, the same three closure theorems, the same ε/2\varepsilon/2 device.

Linear does not imply continuous

Now the interesting part. A linear map preserves sums and scaling, but that alone does not stop it from being wild. What tames it is a single number bounding how much it can stretch:

∃C≥0,∀u:∥f(u)∥≤C∥u∥.\exists C \geq 0,\ \forall u: \quad \|f(u)\| \leq C\,\|u\|.

  Definition linear_map_bounded (f : LinearMap F U V) : Prop :=
    exists C : F, 0 <= C /\ forall u : U, ‖ f u ‖ <= C * ‖ u ‖.

A map with such a CC is called bounded, and for linear maps bounded and continuous turn out to be the same thing. The direction proved here is the useful one:

  Theorem bounded_continuous : forall f : LinearMap F U V,
    linear_map_bounded f -> continuous (lm_fun f).

The argument is short once linearity is used in the right place. To control ∥f(u)−f(a)∥\|f(u) - f(a)\|, note that linearity turns the difference of the values into the value at the difference,

f(u)−f(a)=f(u−a),f(u) - f(a) = f(u - a),

so the whole question is how big ff makes a small vector, and the bound answers exactly that: ∥f(u−a)∥≤C∥u−a∥\|f(u-a)\| \leq C\|u - a\|. Choosing δ=ε/(1+C)\delta = \varepsilon/(1 + C) finishes it.

The 1 + is not decoration. Dividing by CC would need C≠0C \neq 0, and C=0C = 0 is a legitimate bound — the zero map has it. Padding to 1+C1 + C keeps the denominator positive whatever CC is, so the proof never has to split into cases. The same padding shows up in limit_at_scale, where the scalar might be zero.

Two more, both worth their length

Continuity has an equivalent formulation in terms of sequences: ff is continuous at aa exactly when it carries every sequence converging to aa to one converging to f(a)f(a).

  Theorem continuous_at_seq_lim : forall (f : U -> V) (a : U) (x : nat -> U),

This is the bridge between the two limit notions, and it is what lets a proof about functions be discharged by an argument about sequences, or the other way round.

Finally, composition:

  Theorem continuous_comp : forall (f : U -> V) (g : V -> W) (a : U),

continuous at aa and continuous at f(a)f(a) gives continuous at aa for the composite. The proof is the classic one — pick the δ\delta for gg first, then feed it as the ε\varepsilon for ff — and it is worth noticing that the statement needs three spaces at once, UU, VV and WW, each with its own norm over the same ordered field. That constraint is why the section headers in Theory/Continuity.v are long: only one of the spaces may be introduced with a generalizing binder, or Coq would silently create a second field of scalars beside the first.
