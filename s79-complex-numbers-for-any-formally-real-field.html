Complex numbers over any field where −1 is not a square

A field is a set with addition and multiplication behaving the way they do in the rationals: both are associative and commutative, multiplication distributes over addition, there is a 0 and a 1, and — the property that makes it a field rather than merely a ring — every element except 0 has a multiplicative inverse. That last clause is what lets you divide: inv x is the thing you multiply x by to get 1, and it exists for every x that is not zero.

Now try to build the complex numbers on top of an arbitrary field F. Represent a complex number as a pair (a, b), meaning a+bia + b\,i. Adding and multiplying such pairs is straightforward algebra. The interesting operation is division, because the inverse of a+bia + b\,i is

a−bia2+b2.\frac{a - b\,i}{a^2 + b^2}.

That formula divides by a2+b2a^2 + b^2. For it to make sense whenever a+bia + b\,i is nonzero, we need a2+b2a^2 + b^2 to be nonzero whenever aa and bb are not both zero. Over the rationals that is obvious — a sum of two squares is a sum of two nonnegative numbers, zero only when both are. But over an arbitrary field it can fail: in a field where −1-1 is itself a square, say −1=j2-1 = j^2, the sum 12+j2=1+(−1)=01^2 + j^2 = 1 + (-1) = 0 vanishes with neither summand zero, and the formula divides by zero. So building complex numbers over F needs a hypothesis, and the hypothesis is exactly the one that rules this out.

Formal reality: the one-line hypothesis

The property is called formal reality. Here is its entire definition, from Structure/MinusOneNotASquare.v:

Module MinusOneNotASquare.
  Class MinusOneNotASquare (F : Type) `{Field F} :=
    two_squares_vanish : forall a b : F, a * a + b * b == 0 -> a == 0.
  Hint Mode MinusOneNotASquare ! - - - - - - - - : typeclass_instances.
End MinusOneNotASquare.
Export MinusOneNotASquare.

One axiom, MinusOneNotASquare.two_squares_vanish: if a*a + b*b == 0, then a == 0. By the symmetry of the statement b must vanish too — that companion fact is two_squares_vanish_r in Theory/Field.v, proved in three lines by commuting the two squares and appealing to MinusOneNotASquare.two_squares_vanish. Equivalently: −1-1 is not a square. The rationals Q and the reals R satisfy this, because their order makes every square nonnegative and a sum of nonnegatives zero only when each is zero. The complex numbers do not (12+i2=01^2 + i^2 = 0) — which is the whole reason i cannot already live in such an F.

This is precisely the missing fact from the division formula, and nothing more. We are not asking F to be ordered, or complete, or the rationals specifically — only that a sum of two squares cannot vanish unless both squares do.

The construction

Complex numbers over F are pairs with named projections, from Impl/Complex.v:

Record C (F : Type) := mkC { re : F; im : F }.

Two of them are equal when their real and imaginary parts are equal componentwise — this is why every proof below splits a goal about C F into a real-part obligation and an imaginary-part obligation:

#[export] Instance C_EqRel : EqRel (C F) :=
  fun z w => re z == re w /\ im z == im w.

Multiplication is the ordinary rule (a+bi)(c+di)=(ac−bd)+(ad+bc)i(a + b\,i)(c + d\,i) = (ac - bd) + (ad + bc)\,i, written componentwise:

#[export] Instance C_Mult : HasMult (C F) :=
  fun z w => mkC (re z * re w + - (im z * im w))
                 (re z * im w + im z * re w).

The quantity a2+b2a^2 + b^2 gets a name of its own, norm2, and the inverse is the division formula from the top, spelled out in components — real part a⋅(a2+b2)−1a \cdot (a^2+b^2)^{-1}, imaginary part −b⋅(a2+b2)−1-b \cdot (a^2+b^2)^{-1}:

Definition norm2 (z : C F) : F := re z * re z + im z * im z.

(* inv 0 is inv 0 in F, i.e. garbage; the field law speaks only for
   z =/= 0, where norm2 z is invertible by formal reality. *)
#[export] Instance C_Inv : HasInv (C F) :=
  fun z => mkC (re z * inv (norm2 z)) (- im z * inv (norm2 z)).

For z = 0 this divides by inv (norm2 0) = inv 0, which is garbage — but the field law only ever speaks about inv z for z nonzero, and there norm2 z is invertible. Making that precise is where formal reality does its work.

Where the hypothesis enters

The bridge is a single lemma: away from the origin, norm2 z is nonzero. On the blackboard, writing z=a+biz = a + b\,i: suppose z≠0z \neq 0 and, for contradiction, a2+b2=0a^2 + b^2 = 0. Then

a2+b2=0⇒a=0 and b=0⇒z=0,a^2 + b^2 = 0 \;\Longrightarrow\; a = 0 \;\text{ and }\; b = 0 \;\Longrightarrow\; z = 0,

where the first implication is formal reality (once for aa, once for bb by symmetry) — contradicting z≠0z \neq 0. The proof of this lemma is the only place in the whole construction that touches MinusOneNotASquare.two_squares_vanish.

Lemma norm2_nonzero : forall z : C F, z =/= 0 -> norm2 z =/= 0.
Proof.
  intros z Hz Hn. apply Hz. split.
  - exact (two_squares_vanish (re z) (im z) Hn).
  - exact (two_squares_vanish_r (re z) (im z) Hn).
Qed.

Read it by contradiction, which is how the =/= (meaning “not equal”) goals unfold. Assume z =/= 0 and, for contradiction, norm2 z == 0 (that is Hn). To derive the contradiction we show z == 0, i.e. both components vanish: MinusOneNotASquare.two_squares_vanish gives re z == 0 from Hn, and its companion two_squares_vanish_r gives im z == 0. Together they contradict Hz. Without formal reality this lemma is simply false, and everything below collapses.

The inverse law, in full

Now the field law that formal reality was for: inv z * z == 1 for z nonzero. Multiplying (aN−1)−(bN−1)i(a N^{-1}) - (b N^{-1})\,i by a+bia + b\,i, where N=a2+b2N = a^2 + b^2, the real component runs

a2N−1+b2N−1=(a2+b2)N−1{distributivity}=NN−1{N=a2+b2 by definition}=1{inverse law — the step that needs N≠0}\begin{aligned} a^2 N^{-1} + b^2 N^{-1} &= (a^2+b^2)\,N^{-1} && \{\text{distributivity}\}\\ &= N\,N^{-1} && \{N = a^2 + b^2 \text{ by definition}\}\\ &= 1 && \{\text{inverse law — the step that needs } N \neq 0\} \end{aligned}

and the imaginary component cancels by commutativity alone:

abN−1−baN−1=0.ab\,N^{-1} - ba\,N^{-1} = 0.

The real part is where N≠0N \neq 0 is spent — it is the step NN−1=1N\,N^{-1} = 1. Everything before that step is polynomial rearrangement: reassociating, cancelling a double negation, factoring out the shared N−1N^{-1}. The Coq proof separates the two exactly along that line:

#[export] Instance C_mul_left_inverse
  : LeftInverseOn (C F) (nonzero (C F)) mult inv 1.
Proof.
  intros z Hz.
  assert (Hn : norm2 z =/= 0) by exact (norm2_nonzero z Hz).
  split; simpl.
  - calc ((re z * inv (norm2 z)) * re z + - ((- im z * inv (norm2 z)) * im z))
      == [expand] (inv (norm2 z) * norm2 z)
      == (1 : F)  { (left_inverse_on (defined_on := nonzero F) (norm2 z) Hn) }.
    [expand]: unfold norm2; ring.
  - ring.
Qed.

LeftInverseOn T P op inv unit is the guarded inverse law: inv a undoes a for every a satisfying the predicate P. Here P is nonzero (C F), so intros z Hz gives a complex number together with the proof that it is not 0, and the first thing the proof does is convert that into Hn : norm2 z =/= 0 — the one appeal to formal reality in the whole construction.

split; simpl produces the real-part goal and the imaginary-part goal, and they are discharged very differently.

The imaginary part is ring, in one word. Coq’s ring solver normalizes both sides of a polynomial equation and compares them, and the section enables it over the abstract field with

  Add Ring F_ring : (ring_theory_of_Ring (R := F) commutative).

which builds the ring_theory record the solver wants out of the field’s own laws. The imaginary component is abN−1−baN−1ab\,N^{-1} - ba\,N^{-1} against 00, a polynomial identity in the three atoms aa, bb and N−1N^{-1}, so the solver closes it and there is nothing to walk.

The real part is not a polynomial identity — it ends with NN−1=1N\,N^{-1} = 1, which is true only because N≠0N \neq 0, and no amount of normalizing will produce it. So the calc chain routes around exactly that one step. It has two links:

  • The first link is named [expand] rather than justified inline. The chain’s == [expand] (inv (norm2 z) * norm2 z) leaves that step as a goal labelled expand, selected afterwards by [expand]: and proved by unfold norm2; ring — the unfold because norm2 z must be visible as aa+bba\,a + b\,b for the solver to see the polynomial, and then ring for the whole rearrangement the blackboard chain spelled out in three steps.
  • The second link carries its justification in braces: left_inverse_on (norm2 z) Hn, the guarded field law inv n * n == 1 applied at n := norm2 z. This is the one step that consumes Hn.

That single use of left_inverse_on, reachable only because norm2_nonzero supplied Hn, is the entire dependence of the complex field on formal reality. Every other law for C F — associativity, distributivity, commutativity, the additive group structure — is a polynomial identity in the components, so each is one ring over Field F alone, with no mention of order or formal reality:

  #[export] Instance C_add_associative : Associative (C F) (C F) add add.
  Proof. intros z w v. split; simpl; ring. Qed.

and eleven more of the same shape. Those instances then assemble the tower without further proof, each structure asking search for the laws it needs:

  #[export] Instance C_Magma : Magma (C F) add := {}.
  #[export] Instance C_Semigroup : Semigroup (C F) add := {}.
  #[export] Instance C_Monoid : Monoid (C F) := {}.
  #[export] Instance C_Group : Group (C F) := {}.
  #[export] Instance C_AbGroup : AbGroup (C F) := {}.
  #[export] Instance C_MulMagma : Magma (C F) mult := {}.
  #[export] Instance C_MulSemigroup : Semigroup (C F) mult := {}.
  #[export] Instance C_MulMonoid : @Monoid (C F) _ C_One C_Mult := {}.
  #[export] Instance C_Ring : Ring (C F) := {}.

The {} is an empty record literal: every field of the structure is left for instance search, which finds the law instances proved just above. A Ring is an abelian group plus a multiplicative monoid plus two distributivity laws, and all four are already in the database, so the ring costs one line.

The complex rationals, for free

Assemble all the laws and you get an instance C_Field : Field (C F) that holds whenever −1-1 is not a square in F. Nothing in it is specific to any particular F. So to obtain the complex rationals as a genuine field, the only new obligation is the one hypothesis, and that single instance lives in Impl/Qof.v, proved from Q’s order (a rational square is nonnegative, a sum of two nonnegative rationals is zero only when both are):

Instance Q_MinusOneNotASquare : MinusOneNotASquare Q := Q_two_squares_vanish.

And then, in the same file, the complex rationals are a field with no further construction — the underscore asks Coq to find the field structure, and its instance resolution assembles it, reaching for Q_MinusOneNotASquare at exactly the point the inverse law needs it:

Example cq_field_check : Field (C Q) := _.

The file compiles as it stands, so the _ really is filled by resolution alone. That makes the point of the post concrete: register one fact about the rationals — a sum of two rational squares vanishes only at zero — and the complex rationals, with working addition, multiplication, and division, appear at once, without a single line of code written specifically for them.
