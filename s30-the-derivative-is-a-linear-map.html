The derivative is a linear map

The derivative of a function of one variable is usually introduced as a number: the slope of the tangent line. That description does not survive the move to several variables, where the answer is a Jacobian matrix, and it does not survive the move to infinite dimensions at all. There is one description that survives every move, and it is the one worth taking as the definition: the derivative of ff at aa is the linear map that best approximates ff near aa. This post writes that definition down precisely, proves it picks out at most one map, and proves the chain rule from it — where the composition of derivatives is literally the composition of two linear maps.

Two ingredients are assumed. A vector space over a field is a carrier whose elements add and scale, with the usual laws; a normed space adds a length ∥u∥\|u\| with ∥u+v∥≤∥u∥+∥v∥\|u+v\| \le \|u\| + \|v\| and ∥u∥=0\|u\| = 0 only for u=0u = 0. A linear map is a function L between two vector spaces with L (u + v) == L u + L v and L (a *: u) == a *: L u, respecting the equality == on each space; the linear maps from U to V themselves form a vector space, so Lf + Lg and linear_map_comp Lg Lf are ordinary expressions.

What “differentiable” says

The derivative answers: which linear map best approximates f near a? In Theory/Derivative.v:

Definition is_deriv (f : U -> V) (a : U) (L : LinearMap F U V) : Prop :=
  linear_map_bounded L /\
  forall eps : F, 0 < eps ->
    exists delta : F, 0 < delta /\
      forall h : U, ‖ h ‖ < delta ->
        ‖ f (a + h) + - (f a + L h) ‖ <= eps * ‖ h ‖.

Three deliberate choices, each with a story:

No division. The textbook says ∥f(a+h)−f(a)−Lh∥/∥h∥→0\|f(a+h) - f(a) - Lh\| / \|h\| \to 0, which forces the annoying side condition h≠0h \neq 0. The equivalent form ∥r(h)∥≤ε∥h∥\|r(h)\| \le \varepsilon \|h\| is division-free and at h=0h = 0 is simply true. Fewer side conditions, shorter rewrites.

LL is a LinearMap, an element of the vector space of linear maps U -> V. So “the derivative of a sum is the sum of the derivatives” can be stated with that space’s own addition, and is:

Theorem deriv_add : forall (f g : U -> V) (a : U)
    (Lf Lg : LinearMap F U V),
  is_deriv f a Lf -> is_deriv g a Lg ->
  is_deriv (fun u : U => f u + g u) a (Lf + Lg).

LL is bounded (∃C,∥Lu∥≤C∥u∥\exists C,\ \|Lu\| \le C\|u\|). In finite dimension every linear map is bounded, so courses never mention it — but the chain rule uses it, silently. Watch it appear below.

Uniqueness

Blackboard. If L1,L2L_1, L_2 both approximate ff at aa, then for small hh, ∥(L1−L2)h∥≤2ε∥h∥\|(L_1 - L_2)h\| \le 2\varepsilon\|h\|. Take h=tuh = t\,u with t>0t > 0 tiny: t∥(L1−L2)u∥≤2εt∥u∥t\|(L_1-L_2)u\| \le 2\varepsilon\, t\|u\|, cancel tt, and ∥(L1−L2)u∥\|(L_1-L_2)u\| is below 2ε∥u∥2\varepsilon\|u\| for every ε — hence zero, hence L1u=L2uL_1 u = L_2 u for every uu. ∎

The Coq statement says the same thing, with “equal” meaning equal as elements of the space of linear maps — that is, agreeing at every point:

Theorem deriv_unique : forall (f : U -> V) (a : U)
    (L1 L2 : LinearMap F U V),
  is_deriv f a L1 -> is_deriv f a L2 -> L1 == L2.

The proof follows the blackboard shape, and the “take tt tiny” step is a lemma of its own, small_scale_exists : forall d c : F, 0 < d -> 0 <= c -> exists t : F, 0 < t /\ t * c < d in Theory/Order.v — no Archimedean axiom needed, just halving. The final squeeze is nonneg_below_all_pos_is_zero (“a non-negative quantity below every positive quantity is zero”), and the cancellation of tt is mul_le_cancel_l.

The chain rule

Blackboard. Let k(h)=f(a+h)−f(a)k(h) = f(a+h) - f(a), the increment. Then

g(f(a+h))−g(f(a))−Lg(Lfh)=[g(f(a)+k)−g(f(a))−Lgk]⏟g’s remainder at k+Lg[k−Lfh]⏟Lg of f’s remainder.g(f(a+h)) - g(f(a)) - L_g(L_f h) = \underbrace{\big[g(f(a)+k) - g(f(a)) - L_g k\big]}_{\text{g's remainder at } k} + \underbrace{L_g\big[k - L_f h\big]}_{L_g \text{ of f's remainder}}.

Bound the two pieces: the second is ≤Cg⋅ε1∥h∥\le C_g \cdot \varepsilon_1\|h\| — there is the boundedness of LgL_g, doing the work your lecturer waved through. The first is ≤ε2∥k∥\le \varepsilon_2 \|k\|, and the increment itself satisfies ∥k∥≤(Cf+ε1)∥h∥\|k\| \le (C_f + \varepsilon_1)\|h\| — ff is locally Lipschitz-ish because it is differentiable, boundedness of LfL_f again. Add up, choose the ε’s to share the budget. ∎

Theorem deriv_comp : forall (f : U -> V) (g : V -> W) (a : U)
    (Lf : LinearMap F U V) (Lg : LinearMap F V W),
  Proper (equ ==> equ) g ->
  is_deriv f a Lf -> is_deriv g (f a) Lg ->
  is_deriv (fun u : U => g (f u)) a (linear_map_comp Lg Lf).

The Coq proof is the blackboard split, factored into named pieces. The algebraic identity — that the composite’s remainder really is those two terms — is comp_remainder_split, whose last step is the abelian-group telescope sub_mid_cancel : (p + - (q + x)) + (x + - y) == p + - (q + y); the increment estimate ∥k∥≤(Cf+ε1)∥h∥\|k\| \le (C_f + \varepsilon_1)\|h\| is deriv_increment_bound. One deviation from the classical statement: g must respect equality, the hypothesis Proper (equ ==> equ) g. It is needed because is_deriv constrains g only at the points written in its own statement, and the split above moves g across b + (y + - b) == y; every function anyone writes has this property, but it does not follow from is_deriv itself.

And the derivative of the composition is linear_map_comp Lg Lf — composition in the space of linear maps. That is what makes the Jacobian version free: a Jacobian is mat_of applied to a derivative, and mat_of_comp already says that reading a composite off in bases gives the product of the two matrices read off separately. The Jacobian of a composition is the product of the Jacobians, with no new analysis.

Using the definition

The base cases of any differentiation are the two facts a course states without much comment: a constant function has derivative zero, and a linear map is its own derivative. Both are theorems here, and the second is the one that shows the definition doing what it promised —

Theorem deriv_lm : forall (g : LinearMap F U V) (a : U),
  linear_map_bounded g -> is_deriv (lm_fun g) a g.

read: at any point a, the best linear approximation to a bounded linear map g is g itself. Its proof supplies delta := 1 and then appeals to lm_remainder_zero, which says ‖ g (a + h) + - (g a + g h) ‖ == 0: by g’s own additivity the remainder is a quantity subtracted from itself, so the estimate 0 <= eps * ‖ h ‖ holds for every eps with nothing to choose. Together with deriv_const, deriv_add, deriv_scale and deriv_comp, that is enough to differentiate any expression built from linear maps by sums, scalings and composition, with the chain rule doing the composing.
