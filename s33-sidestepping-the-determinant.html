Sidestepping the determinant

A textbook gives the determinant twice. First as cofactor expansion: pick a column, multiply each entry by the determinant of the matrix with that entry’s row and column struck out, alternate signs, add. Second as a sum over permutations:

det⁡A=∑σ∈Snsign⁡(σ)∏jAσ(j),j.\det A \;=\; \sum_{\sigma \in S_n} \operatorname{sign}(\sigma) \prod_j A_{\sigma(j),\,j}.

The two agree — that is a theorem, not a definition — and a course usually proves it once and then uses whichever is convenient. Which one is convenient is not a matter of taste. The properties that fall out easily from one are painful from the other, and the split is sharp enough that the right response to a stuck proof is often to change the formula rather than to push harder on it.

This post is about one such switch, and about the theorem that licenses it. The property in question is antisymmetry: exchange two rows of a matrix and its determinant negates.

Why antisymmetry resists the recursion

Take the cofactor definition, expanding along the first column (detM, in Impl/Det.v):

det⁡A=∑i(−1)i−1Ai1det⁡(minor Ai),\det A \;=\; \sum_i (-1)^{i-1} A_{i1} \det(\text{minor } A_i),

where the minor deletes row ii and column one. To show that swapping rows pp and qq negates the whole thing, you follow rows pp and qq through the recursion. The recursion deletes some row rr and shrinks the matrix by one — so before the induction hypothesis applies, you must know where rows pp and qq have landed inside the smaller matrix.

The deletion is implemented by skip r, the increasing injection Fin.t n -> Fin.t (S n) that misses r. Relocating a row through it means computing its inverse, which is partial: the deleted position is the one thing skip r never produces, so it has no preimage to compute in the smaller matrix. That inverse exists (unskip, in Impl/Fin.v), and with it a single tracked row is manageable. Two tracked rows are not. Each of pp and qq may or may not be the deleted row, they may land on each other, and they may land on the position the recursion has singled out — and the cases multiply until the argument is no longer one induction but a combinatorial case analysis in its own right. Nothing about it is subtle; it is simply large, and it grows for reasons that have nothing to do with the mathematics being proved.

The reformulation

The permutation sum has no recursion to track. A row swap acts on it by postcomposing σ\sigma’s values with a transposition, which is a pointwise rewrite of each factor and nothing else.

Making that precise needs a data type of permutations that Coq can enumerate and compute with. Perm n is the standard “choose the first value, recurse on the rest” encoding, reusing the same skip injection — once, to build the enumeration, never to relocate an already-fixed row:

Inductive Perm : nat -> Type :=
| Perm_O : Perm O
| Perm_S : forall {n : nat}, Fin.t (S n) -> Perm n -> Perm (S n).

Fixpoint perm_apply {n : nat} (sigma : Perm n) {struct sigma} : Fin.t n -> Fin.t n :=
  match sigma in Perm n0 return Fin.t n0 -> Fin.t n0 with
  | Perm_O => fun x => Fin.case0 (fun _ => Fin.t 0) x
  | @Perm_S m c p => fun x =>
      Fin.caseS' x (fun _ => Fin.t (S m)) c (fun x' => skip c (perm_apply p x'))
  end.

Perm_S c p says: σ\sigma sends the first position to c, and the remaining positions go where p sends them among the values other than c. That is the Lehmer-code way of writing a bijection down, and it makes the collection of them a finite, computable enumeration — so “sum over all permutations” becomes a structural recursion, psum, mirroring Perm’s own shape:

  Fixpoint psum {n : nat} (h : Perm n -> F) {struct n} : F :=
    match n as n0 return (Perm n0 -> F) -> F with
    | O => fun h0 => h0 Perm_O
    | S m => fun h0 =>
        bigopF (fun i : Fin.t (S m) => psum (fun p : Perm m => h0 (Perm_S i p)))
    end h.

The sign of a permutation is the product, over the levels of that tree, of sign_at at each level’s chosen value — sign_at c being 1,−1,1,…1, -1, 1, \dots by recursion on the position, the same alternating sign the cofactor expansion uses:

  Fixpoint perm_sign {n : nat} (sigma : Perm n) {struct sigma} : F :=
    match sigma with
    | Perm_O => 1
    | Perm_S c p => sign_at c * perm_sign p
    end.

The product term is flat — it never recurses through a minor:

  Definition perm_prod {n : nat} (A : Matrix n n F) (sigma : Perm n) : F :=
    prodF (fun j => A (perm_apply sigma j) j).

and the definition is the textbook formula, transcribed:

  Definition detM_leibniz {n : nat} (A : Matrix n n F) : F :=
    psum (fun sigma : Perm n => perm_sign sigma * perm_prod A sigma).

The two formulas agree

∑σsign⁡(σ)∏jAσ(j),j=∑i(−1)i−1Ai1det⁡(minor Ai).\sum_{\sigma} \operatorname{sign}(\sigma) \prod_j A_{\sigma(j),j} \;=\; \sum_i (-1)^{i-1} A_{i1} \det(\text{minor } A_i).

Blackboard. Group the permutations by their value at the first position. Those with σ(1)=i\sigma(1) = i contribute Ai1A_{i1} times a sum over the permutations of the remaining positions, and that sum is the Leibniz determinant of the minor at ii; the sign sign⁡(σ)\operatorname{sign} (\sigma) factors as (−1)i−1(-1)^{i-1} times the sign of the smaller permutation. Induct.

Coq. The grouping is not a construction to be built — it is what psum already does. Peeling one level of psum produces exactly the bigopF over first values that detM’s own expansion produces, so the two peelings match term by term:

  Theorem detM_leibniz_eq_detM : forall (n : nat) (A : Matrix n n F),
    detM_leibniz A == detM A.

The inductive step is a five-link calc chain inside one bigopF_ext. perm_sign_S and perm_prod_S split the two factors at the peeled level, turning each summand into a product of four things:

(sign⁡i⋅sign⁡p)⋅(Ai1⋅∏p)=(sign⁡i⋅Ai1)⋅(sign⁡p⋅∏p).(\operatorname{sign}_i \cdot \operatorname{sign} p) \cdot (A_{i1} \cdot \textstyle\prod p) \;=\; (\operatorname{sign}_i \cdot A_{i1}) \cdot (\operatorname{sign} p \cdot \textstyle\prod p).

The two belonging to the peeled level have to be brought together, and the two belonging to the smaller instance likewise. That regrouping is an equation between two products of the same four factors, so ring proves it, and the whole link is

      + apply psum_ext. intros p. ring.

psum_ext reduces the two sums to their terms, and ring normalizes both sides of the term equation and finds them identical. Then psum_scale — the psum mirror of the “constant factor comes out of a sum” lemma — pulls the level’s factor out, and the induction hypothesis rewrites the remaining sum to detM (minor A i). Crucially, the peeling always happens at the fixed first position of the product’s own index, never at a position relocated through someone else’s deletion, so unskip never appears.

What a row swap does to the product

Here is the payment for the reformulation.

  Theorem perm_prod_row_swap : forall (n : nat) (A : Matrix n n F)
      (i j : Fin.t n) (sigma : Perm n),
    perm_prod (row_swap A i j) sigma
      == prodF (fun c : Fin.t n => A (swap_fin i j (perm_apply sigma c)) c).
  Proof.
    intros n A i j sigma.
    unfold perm_prod.
    apply prodF_ext. intros c.
    exact (row_swap_eq_swap_fin n A i j (perm_apply sigma c) c).
  Qed.

Three lines. prodF_ext says two products agree if their factors do, and row_swap_eq_swap_fin says reading entry (r,c)(r,c) of the row-swapped matrix is reading entry (τr,c)(\tau r, c) of the original, for τ\tau the transposition swap_fin i j. So swapping rows ii and jj of AA replaces σ\sigma by τ∘σ\tau \circ \sigma inside every factor, for any ii and jj — adjacent or not, distinct or not. There is no relocation, no case analysis, and no induction: the obstruction that stopped the recursion is not present in this representation at all.

What is left is the other half of antisymmetry, and it is a genuinely different question: the sign must also flip, and sign\operatorname{sign} is a property of the permutation, not of the matrix, so nothing above touches it.

A reindexing lemma worth having on its own

Turning “every term is rewritten by τ\tau” into “the sum is unchanged” needs to know that a finite sum does not care about a bijective relabelling of its index. That is worth stating once, for any commutative monoid, rather than for determinants:

  Theorem bigopF_reindex : forall (n : nat) (g : Fin.t n -> M)
      (tau tau' : Fin.t n -> Fin.t n),
    (forall x, tau' (tau x) = x) -> (forall y, tau (tau' y) = y) ->
    bigopF g == bigopF (fun i => g (tau i)).

A bijection is supplied as a pair of mutually inverse functions rather than as an existence claim, so the proof can compute with it. There is no induction over positions at all: the sum over Fin.t n is the sum over an explicit duplicate-free enumeration of it (bigopF_bigopI), the image of that enumeration under τ\tau is the same list reordered (NoDup_Permutation, with injectivity from the inverse pair), and a sum over a commutative monoid does not see the reordering (bigop_list_permutation). That is bigopI_reindex, stated once for any finite index type and transported to Fin.t n.

Running it

The reformulation is a definition that computes, so it can be checked against the original on actual numbers rather than only related to it by a theorem:

Example detM_leibniz_2x2_Q :
  detM_leibniz (mat2 (1#1)%Q (2#1)%Q (3#1)%Q (4#1)%Q) == ((-2)#1)%Q.
Proof.
  rewrite (detM_leibniz_eq_detM 2 (mat2 (1#1)%Q (2#1)%Q (3#1)%Q (4#1)%Q)).
  exact det2_Q.
Qed.

And the reindexing lemma gets its own test at a real transposition on three positions, with both sides of the reordered sum evaluated independently by conversion — 1+(2+(3+0))1 + (2 + (3 + 0)) against 2+(1+(3+0))2 + (1 + (3 + 0)) — before the theorem itself is applied at the same transposition.
