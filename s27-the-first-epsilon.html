The first ε

The ε–N definition of a limit needs two things and no more: a way to measure how far apart two points are, and a way to compare distances against a positive tolerance. Neither of those requires the real numbers. The previous post’s normed space supplies the first — a length ‖ u ‖ assigned to each vector u, taken not in ℝ but in whatever ordered field F the space is built over — and the order on F supplies the second. Nothing in the definition of convergence, and nothing in the first theorems about it, asks whether limits exist; existence is what completeness is for, and it can wait. So this post defines sequence limits over an arbitrary normed space over an arbitrary ordered field, proves the limit of a sequence is unique, and works through the algebra of limits — the first ε, the first N, the first ε/2 argument.

The definition

A sequence x0,x1,x2,…x_0, x_1, x_2, \dots of vectors converges to LL when it eventually stays inside every ε-ball around LL (Theory/Limits.v):

Definition seq_lim (x : nat -> V) (L : V) : Prop :=
  forall eps : F, 0 < eps ->
    exists N : nat, forall n : nat, (N <= n)%nat -> ‖ x n + - L ‖ < eps.

Read it aloud and it is the sentence from your first analysis course. The distance from x n to L is the norm of their difference, and the ε it is compared against is a scalar of the same field the norm takes its values in.

Theorem: limits are unique — the ε/2 argument

Blackboard. Suppose xn→L1x_n \to L_1 and xn→L2x_n \to L_2. For any ε>0\varepsilon > 0, go far enough that both ∥xn−L1∥<ε/2\|x_n - L_1\| < \varepsilon/2 and ∥xn−L2∥<ε/2\|x_n - L_2\| < \varepsilon/2; then by the triangle inequality

∥L1−L2∥≤∥L1−xn∥+∥xn−L2∥<ε2+ε2=ε.\|L_1 - L_2\| \le \|L_1 - x_n\| + \|x_n - L_2\| < \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \varepsilon.

So the nonnegative quantity ∥L1−L2∥\|L_1 - L_2\| is below every positive ε, hence zero; and the norm is definite, so L1=L2L_1 = L_2. ∎

In Coq. Every phrase above is a named lemma, and the proof is their chain. The lemma types to check it against:

blackboard phrase lemma
“go far enough that both…” Nat.max of the two N’s
“ε/2 + ε/2 = ε” half_sum : half a + half a == a
“ε/2 is still positive” half_pos : 0 < a -> 0 < half a
triangle via the midpoint norm_sub_triangle : ‖u + -w‖ <= ‖u + -v‖ + ‖v + -w‖
“below every positive ε ⇒ zero” nonneg_below_all_pos_is_zero
“norm is definite” definite : ‖u‖ == 0 -> u == 0

None of those lemmas is deep, and none of them comes for free either. An ordered field hands you <=, abs and the field laws and nothing else, so every step of arithmetic the ε/2 argument performs above that has to be derived. That derivation is what Theory/Order.v holds — monotonicity of + and * in each strict/non-strict mixture, 0 < 1, 0 < 2, positivity of inverses, and halving, defined as multiplication by the inverse of two, with the two facts about it that the argument actually uses: half_sum and half_pos. Each is a short calculation, and each is then available as a rewrite to every later analytic proof.

The fine print your lecturer skipped

One step above is subtler than it looks. “Below every positive ε, hence zero” — how do you conclude that, constructively? If the order were decidable you’d case-split on x == 0. It isn’t (think computable reals). What the halving argument actually yields is “x cannot fail to be ≤ 0” — a double negation. So OrderedField carries one further field, whose only job is to discharge that double negation:

    le_stable            : forall a b : F, ~ ~ a <= b -> a <= b;

The order can’t be undecided forever. Every intended model pays nothing for it: decidable orders like ℚ trivially, classical ℝ trivially, and constructive Cauchy reals define ≤ negatively (a ≤ b := ¬ b < a), so stability is built in. This is the kind of line an informal proof never writes down — and exactly the kind a machine-checked one must.

The algebra of limits

With uniqueness done, the everyday lemmas follow the same pattern — a rearrangement lemma, then the triangle inequality, then the ε/2 split. Take the sum. If xn→Lx_n \to L and yn→My_n \to M, then for nn beyond both indices

∥(xn+yn)−(L+M)∥≤∥xn−L∥+∥yn−M∥<ε2+ε2=ε,\|(x_n + y_n) - (L + M)\| \;\le\; \|x_n - L\| + \|y_n - M\| \;<\; \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} \;=\; \varepsilon,

so xn+yn→L+Mx_n + y_n \to L + M. The first inequality is norm_sub_pair, which is the abelian-group interchange law sub_pair — (x+y)−(L+M)=(x−L)+(y−M)(x+y)-(L+M) = (x-L)+(y-M) — followed by the triangle inequality. In Coq:

  Theorem lim_add : forall (x y : nat -> V) (L M : V),
    seq_lim x L -> seq_lim y M -> seq_lim (fun n => x n + y n) (L + M).
  Proof.
    intros x y L M Hx Hy eps Heps.
    destruct (Hx (half eps) (half_pos eps Heps)) as [N1 HN1].
    destruct (Hy (half eps) (half_pos eps Heps)) as [N2 HN2].
    exists (Nat.max N1 N2).
    intros n Hn.
    apply (le_lt_trans _ (‖ x n + - L ‖ + ‖ y n + - M ‖) eps).
    - apply norm_sub_pair.
    - apply (lt_le_trans _ (half eps + half eps) eps).
      + apply add_lt_mono.
        * apply HN1. apply (max_le_l N1 N2 n). exact Hn.
        * apply HN2. apply (max_le_r N1 N2 n). exact Hn.
      + apply eq_le. apply half_sum.
  Qed.

The two destructs are “go far enough”: each hypothesis is applied at the tolerance half eps, yielding an index N1, N2 and the bound past it. exists (Nat.max N1 N2) is the choice of a single index that clears both, and max_le_l / max_le_r are what turn n beyond that maximum into n beyond each of N1 and N2. The rest is the displayed chain read left to right: le_lt_trans inserts the componentwise bound, discharged by norm_sub_pair; lt_le_trans inserts half eps + half eps, with add_lt_mono adding the two strict bounds and half_sum closing the final equality.

Scaling has a classic trap. For axn→aLa\,x_n \to a\,L you want δ=ε/|a|\delta = \varepsilon / |a|, but aa might be zero, and “is aa zero?” is again not decidable. lim_scale pads the denominator instead — δ=ε/(1+|a|)\delta = \varepsilon / (1 + |a|), positive unconditionally — and strictness comes out of the padding itself: |a|⋅t<(1+|a|)δ=ε|a| \cdot t < (1+|a|)\,\delta = \varepsilon whenever t<δt < \delta, which is mul_lt_pad. No case split, no classical axiom. lim_neg needs no new ε at all: norm_neg_add, the law ‖ - u + - v ‖ == ‖ u + v ‖, says the distance from −xn-x_n to −L-L is the distance from xnx_n to LL, so the very N that worked for the sequence works unchanged for its negation.
