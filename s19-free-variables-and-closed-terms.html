Free variables are decidable, and a closed term ignores substitution

A lambda term written with de Bruijn indices has three shapes — a variable Var n, counting the binders out to the lambda that binds it; a function body Abs b; an application App f a — and two renumbering operations: lift d k t shifts every free index at or above k up by d, and subst k u t replaces index k by u and closes the gap the consumed binder leaves. Any program transformation over these terms keeps asking the same three questions. Does index k occur free in t? Is t closed — no free variables at all? And if t does not mention k, do lift and subst leave it alone, as they obviously should? The last question is less obvious than it sounds: substitution at an absent index still renumbers everything above it, so “leaves it alone” is an equation that needs stating with care. This post is the metatheory file that answers all three, with answers that compute.

Free occurrence, twice

Impl/Lambda/FreeVars.v defines the occurrence predicate by recursion on the term — under a binder, the index in question grows by one, because the variable that was k outside is S k inside:

Fixpoint free_in (k : nat) (t : tm) {struct t} : Prop :=
  match t with
  | Var n => k = n
  | Abs b => free_in (S k) b
  | App f a => free_in k f \/ free_in k a
  end.

Alongside it, the same recursion with bool answers instead of propositions — Nat.eqb for =, || for \/:

Fixpoint free_inb (k : nat) (t : tm) {struct t} : bool :=
  match t with
  | Var n => Nat.eqb k n
  | Abs b => free_inb (S k) b
  | App f a => free_inb k f || free_inb k a
  end.

The two are the same function seen from two sides, and the equivalence free_inb_spec : free_inb k t = true <-> free_in k t is a structural induction whose application case is a three-step calc chain through orb_true_iff and the two induction hypotheses. Packaged as free_in_reflect, it lets a proof branch on the boolean and receive the proposition in the taken branch — and it makes freeness a fact vm_compute can settle:

Definition open_tm : tm := App (Var 0) (Abs (App (Var 0) (Var 3))).

Example free_inb_open_0 : free_inb 0 open_tm = true.
Proof. vm_compute. reflexivity. Qed.

Example free_inb_open_1 : free_inb 1 open_tm = false.
Proof. vm_compute. reflexivity. Qed.

In open_tm, index 0 is free at the head of the application; inside the abstraction, Var 0 is bound (it points at that abstraction) while Var 3 reaches out to what is index 2 outside — so 0 and 2 are free and 1 is not.

Closedness below a cutoff

“Closed” generalizes to “closed above c”: every free index lies below the cutoff. The file states it positively, and its header says why — the positive form feeds lia directly and composes without double negation, and closed_above_spec proves it equivalent to the negative reading “no index at or above c is free”:

Definition closed_above (c : nat) (t : tm) : Prop :=
  forall k : nat, free_in k t -> k < c.

Definition closed (t : tm) : Prop := closed_above 0 t.

One characterization per constructor turns the quantified definition into structural pieces — a variable is closed above c exactly when its index is below c (closed_above_var), an abstraction when its body is closed above S c (closed_above_abs), an application when both halves are (closed_above_app) — and a boolean mirror closed_aboveb with closed_aboveb_spec makes closedness computable too, so closedb k = true is a vm_compute fact about the two-argument constant function k.

What lift does to free indices, exactly

The renumbering operations now get their inventories. For lift the statement is a single equivalence, covering every index j of the lifted term. Writing j∈FV(t)j \in \mathrm{FV}(t) for free_in j t and ↑cdt\uparrow^{d}_{c} t for lift d c t:

j∈FV(↑cdt)⇔(j<c∧j∈FV(t))∨(c+d≤j∧j−d∈FV(t)).j \in \mathrm{FV}(\uparrow^{d}_{c} t) \;\iff\; \bigl(j < c \,\wedge\, j \in \mathrm{FV}(t)\bigr) \;\vee\; \bigl(c + d \le j \,\wedge\, j - d \in \mathrm{FV}(t)\bigr).

Lemma free_in_lift : forall (t : tm) (d c j : nat),
  free_in j (lift d c t)
  <-> (j < c /\ free_in j t) \/ (c + d <= j /\ free_in (j - d) t).

Low indices pass through untouched; high ones are the old indices moved up by d; and — the part transforms rely on — the band c≤j<c+dc \le j < c + d is empty, freshly opened and mentioning nothing. The proof is a structural induction: the variable case is a case split on the Nat.leb test inside lift, closed by lia; the binder case re-indexes the equivalence at S c and S j, with lia-sized arithmetic to move the S through the subtraction; the application case is tauto over the two induction hypotheses. Three directional corollaries (free_in_lift_lo, free_in_lift_hi, free_in_lift_gap) package the shapes a proof actually reaches for. The matching inventory for substitution, free_in_subst, has three disjuncts instead of two — an index of subst c u t is a low index of t, a high index of t shifted down past the consumed binder, or an index contributed by a copy of u, and this last only when c was free in t to begin with.

Substitution at an absent index

Now the question from the opening. If k is not free in t, then subst k u t never places a copy of u — but it still lowers every index above k by one, because the binder that k pointed at is being consumed. So the correct “does nothing” equation re-lifts the result: the file has no lowering function, and lift 1 k is exactly the inverse of that renumbering,

k∉FV(t)⇒↑k1(t[k:=u])=t.k \notin \mathrm{FV}(t) \;\Longrightarrow\; \uparrow^{1}_{k}\bigl(t[k := u]\bigr) = t.

Lemma subst_not_free : forall (t u : tm) (k : nat),
  ~ free_in k t -> lift 1 k (subst k u t) = t.
Proof.
  induction t as [n | b IH | f IHf a IHa]; intros u k H; simpl in H |- *.
  - destruct (Nat.ltb n k) eqn:E1.
    + apply Nat.ltb_lt in E1. simpl.
      destruct (Nat.leb k n) eqn:E2.
      * apply Nat.leb_le in E2. lia.
      * reflexivity.
    + apply Nat.ltb_ge in E1.
      destruct (Nat.eqb n k) eqn:E2.
      * apply Nat.eqb_eq in E2. exfalso. apply H. lia.
      * apply Nat.eqb_neq in E2. simpl.
        destruct (Nat.leb k (Nat.pred n)) eqn:E3.
        -- f_equal. lia.
        -- apply Nat.leb_gt in E3. lia.
  - f_equal. apply IH. exact H.
  - f_equal.
    + apply IHf. intros Hf. apply H. left. exact Hf.
    + apply IHa. intros Ha. apply H. right. exact Ha.
Qed.

The variable case walks the three arms of subst’s comparison. An index below k is left by subst and left by lift — the inner Nat.leb test comes out false, reflexivity. An index equal to k contradicts the hypothesis H outright. An index above k was lowered to Nat.pred n by subst, the lift raises it back, and f_equal plus lia confirm the round trip is the identity. The binder and application cases just thread the hypothesis through — under a binder, “not free at k” is “not free at S k” by definition, so IH applies as it stands. A companion, subst_not_free_irrelevant, states the other consequence: at an absent index, what is being substituted cannot matter, subst k u t = subst k v t.

For closed terms the equations lose their side conditions and their re-lifts. A term closed above c is fixed by any lift at cutoff c (lift_closed_above) and by any substitution there (subst_closed_above), and with monotonicity (closed_above_mono) the fully closed case quantifies over everything:

Lemma subst_closed : forall (t u : tm) (k : nat),
  closed t -> subst k u t = t.

This is the fact evaluators lean on when they duplicate a closed function body: copying it under fresh binders and substituting around it provably never edits it.

A computable bound on the free indices

Finally, finite support, in computable form: fv_bound t is a strict upper bound on the free indices of t,

Fixpoint fv_bound (t : tm) {struct t} : nat :=
  match t with
  | Var n => S n
  | Abs b => Nat.pred (fv_bound b)
  | App f a => Nat.max (fv_bound f) (fv_bound a)
  end.

with the bound proved in fv_bound_spec (every free index is below it, so closed_above (fv_bound t) t always holds — fv_bound_closed_above), and proved tight in fv_bound_tight: a nonzero bound S m is witnessed, index m really is free. So fv_bound t = 0 is a complete, computable test for closedness, and on the running example the numbers come out exactly as read off above:

Example fv_bound_open : fv_bound open_tm = 3.
Proof. vm_compute. reflexivity. Qed.

Example closed_aboveb_open_3 : closed_aboveb 3 open_tm = true.
Proof. vm_compute. reflexivity. Qed.

Example closed_aboveb_open_2 : closed_aboveb 2 open_tm = false.
Proof. vm_compute. reflexivity. Qed.

The bound is 3 because index 2 is free and nothing higher is — closed_aboveb confirms both facts by computation, and fv_bound_tight is what guarantees the boundary case is never slack.
