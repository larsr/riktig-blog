Go-Back-N delivers a prefix, because a stale expectation never catches up

The alternating-bit protocol tags every message with a single bit, flipped once per message, so that a receiver can tell a fresh message from a stale retransmission. One bit is a two-value alphabet, and a two-value alphabet has a blind spot: after a whole burst is lost, the next burst carries the same bit the receiver is still waiting for, and the receiver accepts it — a genuine message, delivered in order, but with a hole in front of it. The delivered list is a subsequence of what was sent, and that is all the alternating bit can promise.

A sliding-window protocol in the Go-Back-N family replaces the bit with a sequence number — a counter that advances once per message and never repeats. This post proves what that buys, over the same channel relation that may drop and duplicate packets in any interleaving: the delivered list is a prefix of the sent list — an unbroken front, no holes. The mechanism is one asymmetry. A receiver that has fallen behind is expecting a tag the sender will never emit again, so from that moment it accepts nothing at all; it can miss the tail of the conversation, but it can never resume in the middle.

Sender and receiver

From Channel/GoBackN.v. A wire packet is a message together with its tag, now a natural number rather than a bit:

Record Packet := { pkt_seq : nat; pkt_msg : M }.

The sender emits a burst of k identical copies per message and advances the tag once per message, not per copy; the receiver accepts strictly in order and buffers nothing. Neither is written in this file. Both are the functions the alternating-bit post showed, in Channel/ARQ.v, written over an abstract tag with a comparison and a successor — and supplying those is all a protocol has to do:

  Definition gbn_protocol : Protocol nat M Packet :=
    {| tag_eqb := Nat.eqb;
       tag_next := S;
       mk := fun s m => {| pkt_seq := s; pkt_msg := m |};
       tag_of := pkt_seq;
       msg_of := pkt_msg;
       tag_eqb_true := fun s1 s2 => proj2 (Nat.eqb_eq s1 s2);
       tag_eqb_false := fun s1 s2 => proj2 (Nat.eqb_neq s1 s2);
       tag_dec := Nat.eq_dec;
       tag_next_neq := fun s Hs => Nat.neq_succ_diag_l s (eq_sym Hs);
       tag_of_mk := fun _ _ => eq_refl;
       msg_of_mk := fun _ _ => eq_refl |}.

Every law is the standard library’s: Nat.eqb reflects equality both ways, equality on nat is decidable, and no number is its own successor. That last one is where the alternating bit had no_fixpoint_negb. Sender and receiver are that instance:

  Definition sender_burst_gbn (seqn : nat) (m : M) (k : nat) : list Packet :=
    ARQ.burst gbn_protocol seqn m k.

  Definition gbn_stream_from (seqn : nat) (ms : list M) (k : nat) : list Packet :=
    ARQ.stream gbn_protocol seqn ms k.

  Definition gbn_stream (ms : list M) (k : nat) : list Packet :=
    gbn_stream_from 0 ms k.

  Definition gbn_deliver (expect : nat) (ps : list Packet) : list M :=
    ARQ.deliver gbn_protocol expect ps.

  Definition gbn_next (expect : nat) (ps : list Packet) : nat :=
    ARQ.next gbn_protocol expect ps.

Every packet of one burst is literally the same record, and successive bursts carry successive tags — S seqn, never seqn again. gbn_next computes only the final expectation, so a proof can split a run at a burst boundary: gbn_deliver_app states that delivering over w1 ++ w2 is delivering over w1, then over w2 from wherever w1 left the expectation.

The one modeling disclosure, from the file’s own header: these tags are plain, never-wrapping naturals. A real Go-Back-N header field is fixed-width and wraps around; the safety argument needs only a decidable equality and a successor that never returns where it started, so the window-size-versus-header-width refinement is a separate piece of work, deliberately not attempted here.

Safety, inherited from the same engine as the alternating bit

The channel is lossy_dup, the drop-and-duplicate relation, and the burst-level fact is not merely the same argument that carried the alternating-bit safety post — it is the same lemma. Every packet the channel produces from one burst is the same record, so the receiver delivers either nothing from it or exactly its one message, and neither the statement nor its proof mentions what a tag is:

  Lemma burst_delivery_gbn : forall (seqn : nat) (m : M) (k : nat) (w : list Packet) (expect : nat),
    lossy_dup (sender_burst_gbn seqn m k) w ->
    (gbn_deliver expect w = [] /\ gbn_next expect w = expect) \/
    (gbn_deliver expect w = [m] /\ gbn_next expect w = S expect).
  Proof. exact (ARQ.burst_delivery gbn_protocol). Qed.

Inducting over the message list with that fact — cutting the wire at each burst boundary with lossy_dup_app_split, exactly as the seam post set up — gives the safety theorem, and that induction is shared too:

  Lemma gbn_deliver_subseq : forall (k : nat) (ms : list M)
      (seq0 expect : nat) (wire : list Packet),
    lossy_dup (gbn_stream_from seq0 ms k) wire -> subseq (gbn_deliver expect wire) ms.
  Proof. exact (ARQ.deliver_subseq gbn_protocol). Qed.
  Theorem gbn_safety : forall (k : nat) (ms : list M) (wire : list Packet),
    lossy_dup (gbn_stream ms k) wire -> subseq (gbn_deliver 0 wire) ms.

So far the sequence number has bought nothing the bit did not have — which is exactly why the file up to this point is a page of citations. Its value shows up in the next section, which the bit cannot follow, and which is therefore the one part of the protocol written here.

A stale expectation accepts nothing, ever

Suppose the receiver expects tag expect while the sender’s stream has moved on to tags starting at seqn, with expect < seqn. Every remaining burst carries a tag that is seqn or larger — never expect again — so nothing more is delivered. First the single-burst version: a burst whose tag differs from the expectation delivers nothing and moves nothing,

s≠e⇒De(w)=[]∧Ne(w)=e,s \neq e \;\Longrightarrow\; D_e(w) = [\,] \;\wedge\; N_e(w) = e,

writing De(w)D_e(w) for what the receiver delivers from ww when expecting ee, and Ne(w)N_e(w) for its final expectation:

  Lemma gbn_burst_miss : forall (seqn : nat) (m : M) (k : nat) (w : list Packet) (expect : nat),
    lossy_dup (sender_burst_gbn seqn m k) w -> seqn <> expect ->
    gbn_deliver expect w = [] /\ gbn_next expect w = expect.
  Proof. exact (ARQ.burst_miss gbn_protocol). Qed.

(The proof is the homogeneity fact again — all of w is one record whose tag is seqn, and seqn never equals expect — so it too is shared.) Then the whole-stream version, by induction over the messages. On the blackboard, with e<ne < n and one burst split off the stream:

De(w)=De(w1)++DNe(w1)(w2)=[]++De(w2)=[], D_e(w) \;=\; D_e(w_1) \mathbin{+\!\!+} D_{N_e(w_1)}(w_2) \;=\; [\,] \mathbin{+\!\!+} D_e(w_2) \;=\; [\,],

the middle step because the burst’s tag nn misses the expectation ee (delivering nothing, leaving ee in place), and the last step by the induction hypothesis at the rest of the stream, whose tags start at n+1n+1 and still exceed ee. The Coq proof is that chain, written as a calc block whose every step names its justification:

Lemma gbn_deliver_nomatch : forall (k : nat) (ms : list M) (seqn expect : nat) (wire : list Packet),
  expect < seqn -> lossy_dup (gbn_stream_from seqn ms k) wire -> gbn_deliver expect wire = [].
Proof.
  intros k ms.
  induction ms as [| m ms' IH]; intros seqn expect wire Hlt H.
  - simpl in H.
    assert (Hnil : wire = []).
    { apply (lossy_dup_nil_l [] wire H). reflexivity. }
    rewrite Hnil. reflexivity.
  - simpl in H.
    destruct (lossy_dup_app_split _ _ H
                (sender_burst_gbn seqn m k) (gbn_stream_from (S seqn) ms' k)
                eq_refl) as [w1 [w2 [Hwire [H1 H2]]]].
    assert (Hneq : seqn <> expect) by lia.
    destruct (gbn_burst_miss seqn m k w1 expect H1 Hneq) as [Hd1 Hn1].
    assert (Hlt' : expect < S seqn) by lia.
    calc (gbn_deliver expect wire)
      == (gbn_deliver expect (w1 ++ w2))
         { Hwire }
      == (gbn_deliver expect w1 ++ gbn_deliver (gbn_next expect w1) w2)
         { (gbn_deliver_app w1 w2 expect) }
      == ([] ++ gbn_deliver (gbn_next expect w1) w2)
         { Hd1 }
      == ([] ++ gbn_deliver expect w2)
         { Hn1 }
      == ([] : list M)
         { (IH (S seqn) expect w2 Hlt' H2) }.
Qed.

Walking it. The base case: an empty message list means an empty stream, lossy_dup_nil_l forces the wire empty, and delivery from an empty wire is []. The step case cuts the wire at the first burst’s boundary (lossy_dup_app_split), notes seqn <> expect from expect < seqn (lia), and then the calc chain is the blackboard chain: rewrite the wire as w1 ++ w2, split the delivery at the seam (gbn_deliver_app), erase the burst’s contribution (Hd1, the miss), restore the unmoved expectation (Hn1), and finish with the induction hypothesis one tag higher.

The prefix theorem

Now run the receiver in phase — expectation equal to the stream’s starting tag — and induct. Each burst either hits, delivering its message and moving both counters forward together, or misses, after which the previous lemma silences the entire rest of the run. So delivery never resumes after a gap: it is everything up to the first lost burst, and nothing after —

ld(streamn(ms,k),w)⇒Dn(w)is a prefix ofms.\mathrm{ld}\bigl(\mathrm{stream}_n(ms, k),\; w\bigr) \;\Longrightarrow\; D_n(w) \ \text{is a prefix of}\ ms.

A prefix is a subsequence with no holes; the library states it as “the longer list is the shorter one with something appended,” in Theory/Subseq.v:

  Definition prefix (p s : list A) : Prop := exists s2, s = p ++ s2.
Lemma gbn_deliver_prefix_gen : forall (k : nat) (ms : list M) (seqn : nat) (wire : list Packet),
  lossy_dup (gbn_stream_from seqn ms k) wire -> prefix (gbn_deliver seqn wire) ms.
Proof.
  intros k ms.
  induction ms as [| m ms' IH]; intros seqn wire H.
  - simpl in H.
    assert (Hnil : wire = []).
    { apply (lossy_dup_nil_l [] wire H). reflexivity. }
    rewrite Hnil. simpl. apply prefix_refl.
  - simpl in H.
    destruct (lossy_dup_app_split _ _ H
                (sender_burst_gbn seqn m k) (gbn_stream_from (S seqn) ms' k)
                eq_refl) as [w1 [w2 [Hwire [H1 H2]]]].
    rewrite Hwire.
    rewrite (gbn_deliver_app w1 w2 seqn).
    destruct (burst_delivery_gbn seqn m k w1 seqn H1) as [[Hd1 Hn1] | [Hd1 Hn1]].
    + (* miss *)
      rewrite Hd1. rewrite Hn1. simpl.
      unfold prefix.
      assert (Hno : gbn_deliver seqn w2 = []).
      { apply (gbn_deliver_nomatch k ms' (S seqn) seqn w2).
        - lia.
        - exact H2. }
      rewrite Hno.
      exists (m :: ms'). reflexivity.
    + (* hit *)
      rewrite Hd1. rewrite Hn1. simpl.
      unfold prefix.
      destruct (IH (S seqn) w2 H2) as [ms2 Heq].
      exists ms2. rewrite Heq. reflexivity.
Qed.

Walking the two branches of the step case, after the by-now-familiar cut at the burst boundary:

  • Miss (Hd1 : gbn_deliver seqn w1 = [], Hn1 leaves the expectation at seqn): the rest of the stream carries tags from S seqn up, strictly above the stuck expectation, so gbn_deliver_nomatch erases the whole tail. The delivered list is [], a prefix of anything — the witness is the entire remaining m :: ms'.
  • Hit (Hd1 : gbn_deliver seqn w1 = [m], Hn1 advances to S seqn): the delivered list is m :: whatever the tail run delivers, and the induction hypothesis says that tail is a prefix of ms'; prepending the shared m keeps it one.

The theorem at the protocol’s actual starting state, and the check that a prefix is in particular a subsequence, close the file:

Theorem gbn_prefix : forall (k : nat) (ms : list M) (wire : list Packet),
  lossy_dup (gbn_stream ms k) wire -> prefix (gbn_deliver 0 wire) ms.
Proof.
  intros k ms wire H.
  apply (gbn_deliver_prefix_gen k ms 0 wire H).
Qed.

Corollary gbn_safety_from_prefix : forall (k : nat) (ms : list M) (wire : list Packet),
  lossy_dup (gbn_stream ms k) wire -> subseq (gbn_deliver 0 wire) ms.
Proof.
  intros k ms wire H.
  apply prefix_subseq.
  apply (gbn_prefix k ms wire H).
Qed.

prefix_subseq recovers the alternating bit’s guarantee from the stronger one — the sequence number’s subsequence theorem is a corollary of its prefix theorem, while for the bit, subsequence is the ceiling. What the alternating bit needs in order to reach a prefix guarantee — a return channel of acknowledgements, and a sender that halts on silence — is the subject of the acknowledgement post, together with the concrete counterexample showing the bit alone really does deliver holes.
